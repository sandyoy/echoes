# 苏格拉底学伴 · 独立小程序

> 从「往事可追忆」小程序中拆分出来的独立产品（2026-08-01）。

## 这是什么
给孩子的个性化伴读 / 陪伴学习工具 —— 通过苏格拉底式提问引导，帮孩子**建立自己的学习知识库**。

## 现状
- 已具备：拼音闪电卡、拼音查询、数学运算律（苏格拉底式对话）
- **初始化阶段：仅给自己的孩子在本地设备上使用**

## 知识库存储架构（重要）
| 阶段 | 存储方式 | 说明 |
|------|---------|------|
| **当前** | 本地 `wx.getStorageSync` | 孩子自己设备上用，简单可靠 |
| **未来** | 后端服务器共享 | 跨设备同步、家长查看孩子知识库 |

**架构已预留后端扩展口**：`app.js` 中的 `CONFIG.BACKEND_SYNC` 开关 + 统一存储接口 `getKB()`/`setKB()`。未来接后端时，只需实现这两个接口、打开开关，无需改动页面代码。

> ⚠️ 按 sandy 决策：**当前不二次开发**。等有真正的孩子用户来提需求后，再基于真实需求重做代码架构。此独立目录现在只是完整保留苏格拉底代码，方便将来单独提审。
