### 3.2 逐条规则的具体说明

**（1）编号类字段（治疗记录编号、设备编号）——直接删除**

治疗记录编号（id）为单条记录流水号，治疗波形图嵌入该编号；设备编号为硬件唯一标识。二者均可能在系统内被反向检索，故一并删除，不作替换。

**（2）关联类编号（治疗方案编号、疗程编码）——替换为新编随机序号，且不由原编号计算**

处理规则：

1. 在导出脚本内生成独立随机序列，与生产库无任何关联输入；
2. 同一治疗方案下的所有记录，映射为同一个新序号（保持治疗方案内的记录可串联）；
3. 同一疗程下的所有记录，映射为同一个新序号；
4. **不使用原编号作为散列输入、不做顺序平移、不做任何可由原编号推导的变换**；
5. 映射过程仅在导出进程内存中一次完成，**不写入任何文件、不写日志、不入库**，进程结束即消失。

**（3）时间字段——只保留到日**

time_begin、time_end 截断至「年-月-日」，时分秒丢弃，并合并为单一「治疗日期」字段。原精确时间戳不入库、不留存于登记版本。

**（4）渠道编码——替换为地级市**

不再保留机构编码（org_id）、机构名称、机构地址。仅保留该机构所在的**地级市**名称（如广州市、珠海市、佛山市）。同一地级市内不区分机构，无法由地级市字段定位到具体机构。

**（5）治疗波形图——清除标识后重命名**

1. 逐张检查图片内容，确认图像内不含使用者姓名、编号、设备号、机构名称等文字或标识；
2. 图片元数据（含拍摄时间、设备信息、地理位置）全部剥离；
3. 文件名改为本数据版本内的新编序号，不含原编号、治疗日期、机构信息；
4. 不提供可直连生产系统的 URL。

**（6）保留字段**

处方编码、疗程阶段、处方索引、治疗时长、电流强度、治疗状态、是否手动结束，均为纯治疗过程参数，不含身份属性，保留原值。

## 四、小样本记录的合并或删除规则

### 4.1 规则内容

同一地级市、同一处方编码在同一月份，如仅有个别使用者的记录，存在通过极少数样本间接缩小到特定个体的可能，故按以下顺序处理：

1. **合并**：将所在地级市上提为「广东省」，使该组记录并入全省范围，不再体现具体地级市；
2. **删除**：若合并后该组仍为极少数记录（不足 3 条），则整组删除，不进入登记版本。

### 4.2 具体阈值

| 情形 | 处理 |
|---|---|
| 同一地级市 + 同一处方编码 + 同一月份，记录条数 ≥ 3 | 保留原样 |
| 同上，记录条数 1–2 条 | 所在地级市上提为「广东省」，保留记录 |
| 上提后，同一处方编码在同一月份全省范围仍不足 3 条 | 删除该组记录 |

### 4.3 实际执行结果

按上述规则处理后，被合并的记录共 〔　　〕 条，被删除的记录共 〔　　〕 条，删除部分不体现在本数据版本的记录条数、容量与波形图件数中。

## 六、不保留对照关系的措施

**6.1 技术措施**

| # | 措施 |
|---|---|
| 1 | 新编序号由导出进程内的随机序列生成，生产库中不存在该序列 |
| 2 | 生成过程不读取原编号作为输入，不存在「原编号 → 新序号」的可计算路径 |
| 3 | 映射仅在进程内存中存在，进程结束即释放，不落盘、不写日志、不入库 |
| 4 | 导出完成后，登记版本独立存放于与生产库物理隔离的存储位置 |
| 5 | 登记版本的全量导出，仅技术团队按审批流程在受控环境下可执行，操作留痕 |

**6.2 组织措施**

| # | 措施 |
|---|---|
| 1 | 登记版本导出须经数据安全负责人审批，单人不可自行完成 |
| 2 | 导出的登记版本不进入任何生产业务系统，不参与业务查询与调用 |
| 3 | 参与导出的人员签署保密承诺，知晓不得擅自留存映射信息 |
| 4 | 匿名化前后的数据不在同一环境中并存 |

**6.3 关于匿名化前记录的说明（如实告知）**

匿名化前的原始记录，目前仍存储于本公司业务系统内，按个人信息标准管理，用于：

1. 使用者本人在 App 内查询自身治疗记录；
2. 合作医疗机构医师调阅本院使用者记录，用于诊疗评估与随访管理；
3. 售后与服务质量核查。

该部分记录**不对外提供**，**不进入本次登记的数据版本**，**不作为本数据版本的任何还原依据**。本公司确认：本数据版本自生成之时起，即与匿名化前记录之间不存在任何可复原的关联路径。

## 七、匿名化效果的结论

1. 本数据版本不含姓名、身份证号、手机号、住址、平台用户编码（uid）、设备编号、机构名称等任何直接标识信息；
2. 原系统的全部编号（治疗记录编号、治疗方案编号、疗程编码、设备编号）或已删除、或已替换为不可由原值推导的随机序号，且无对照表留存；
3. 时间精确度已降至「日」，地域精确度已降至「地级市」，且在样本过少时进一步上提至省级或删除；
4. 治疗波形图已剥离全部标识与元数据，并以新编序号命名；
5. 本公司不具备、亦未保留将本数据版本重新关联到特定自然人的条件与技术路径。

**据此，本数据版本的处理结果达到匿名化程度——处理后的数据无法识别特定个人，且不能复原。**
