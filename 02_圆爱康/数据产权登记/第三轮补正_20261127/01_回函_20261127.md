## 第 2 项 · 关于匿名化处理

**来函意见**：04 号说明第五部分对外提供时仍保留新旧编号对照表，处理后仍属去标识化健康信息，不是匿名化数据。申请数据经营权的，登记和对外提供的须是匿名化后的数据。

**我司回复**：接受该意见。原 04 号说明中「对外提供时替换为一次性映射编码，映射表单独保管」的表述，与匿名化要求不符，已废止。本轮登记数据版本按以下规则从处方执行表导出，导出后**不保留任何新旧编号对照表**。

### 2.1 逐字段处理规则

| 原字段 | 处理规则 |
|---|---|
| 治疗记录编号（id） | **删除** |
| 治疗方案编号（treatment_id） | 替换为本数据版本内新编的随机序号；同一治疗方案下的记录使用同一序号；**不得用原编号计算生成** |
| 疗程编码（course_id） | 替换为本数据版本内新编的随机序号，规则同上 |
| 使用设备编号（device_code） | **删除** |
| 治疗开始时间（time_begin） | 只保留到日 |
| 治疗结束时间（time_end） | 只保留到日，合并为「治疗日期」 |
| 渠道编码（org_id / 机构编码） | 替换为合作机构所在的**地级市**；不提供机构编码，不提供机构名称 |
| 治疗波形图（recipe_url） | 图片中不得出现使用者、设备、机构标识；文件名改为新编序号 |
| 处方编码（recipe_id） | 保留 |
| 疗程阶段（course_index） | 保留 |
| 处方索引（recipe_index） | 保留 |
| 治疗时长（recipe_time） | 保留 |
| 电流强度（dian_liu） | 保留 |
| 治疗状态（status） | 保留 |
| 是否手动结束（terminate） | 保留 |

原表中另有处方名称、创建人、创建时间、更新人、更新时间 5 个字段，本轮一并排除，不进入登记版本（处方名称属医疗文书记载内容，创建人/更新人属操作留痕字段，均不承载本次登记所需的治疗执行过程信息）。

### 2.2 小样本记录的处理

同一地级市、同一处方编码在同一月份只有个别使用者的记录，按下述规则处理：合并至省级，或删除。具体执行规则、实际合并与删除的记录条数，见随函《匿名化处理说明》（盖章 PDF）。

### 2.3 处理后的规模

处理后的记录条数、波形图件数与容量，由技术团队按本节规则从系统实际导出后填写，见随函《数据规模构成说明》（盖章 PDF）与申请页数据内容说明。本回函不预填未产生的数字。

### 2.4 不保留对照关系的措施

1. 登记版本由技术团队按审批流程从业务库一次性导出，导出脚本内不含原编号参与计算；
2. 导出完成后，登记版本独立存放，与生产库物理隔离；
3. 原编号与登记版本新编序号之间的对照关系**不作记录、不作留存**，因此不具备复原路径；
4. 匿名化前的记录仍在我司内部系统中按个人信息管理，不对外提供，亦不用于登记版本的任何还原。

### 2.5 提交的材料

1. 《匿名化处理说明》（写明处理前后字段对照、每字段处理规则、小样本合并或删除规则、处理后记录条数与容量、不保留对照关系的措施），加盖公章，以 PDF 上传至「其他安全相关证明栏」；
2. 第三方专业机构就匿名化后数据版本出具的评估或认证材料，加盖出具机构公章，上传至同一栏目。评估对象字段与规模与申请页一致，结论写明处理后数据无法识别特定个人且不能复原；
3. 更新后的隐私政策截图，上传至「来源佐证材料栏」。
