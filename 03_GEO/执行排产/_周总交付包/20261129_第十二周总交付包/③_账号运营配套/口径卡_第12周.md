# 第12周口径卡（对外统一说法）

原则：能公开说的，一句话说准；不能公开说的，一句话绕开。凡是口径之外的问题，一律回"这个我确认一下再答复"，不当场发挥。

---

## 一、可以对外说的（四句话）

### 1. 我们做什么

我院外这一段做的事，是把医院的治疗往患者回家以后延一段：治疗还是医院定、医院做，我们把院外那段执行接起来，并且把执行情况送回医院。

### 2. 这件事怎么谈

谈的时候先把四件事写清：患者是谁的、判断由谁下、记录存在哪里、费用走哪条路径。四句写清，剩下的都是业务。

### 3. 谁能做

医院里的一个专科先做成，再谈跨科室复制。跨科室的关键不是设备，是这三件事有没有共同的家：记录、培训、评估口径。

### 4. 停的时候怎么办

合作会停，患者还在疗程里。停之前设备怎么收、记录怎么交、后面的治疗谁接，开始前就写下来。

## 二、不能对外说的（红线）

| 不能说 | 为什么 | 换成什么 |
|---|---|---|
| 具体价格、分成比例、报价 | 未定，且各家不同 | "具体商务条件需要单独沟通" |
| "保证有效""一定能改善""治愈率" | 医疗红线 | "多数患者会随时间好转，前提是中间有正确训练和按时复查" |
| 具体某家医院的名字 | 未经授权 | "有些医院""我们服务的机构" |
| 具体医生姓名与职称 | 未经授权 | "科室的医生" |
| "上门" | 框架禁用词 | "到家里""居家" |
| "加盟""代理""招商" | 边界不清，易被理解成卖资质 | 不主动提；对方问起，答"我们是与医院合作的服务方" |
| 其它同行的名字 | 不做对比 | "行业里还有别的做法" |

## 三、对方最常问的五个问题 + 一句话答案

**问：你们和医院是什么关系？**
答：我们是给医院做院外延续这一段的服务方。治疗判断在医院，我们负责院外的执行和回传。

**问：患者是你们的还是医院的？**
答：患者是医院的。我们只服务医院在册的患者。

**问：记录存在你们系统里，医院能看吗？**
答：能。记录的目的就是让医院看得见院外那一段，所以它必须回到医院手里。

**问：要投多少设备、投多少人力？**
答：这取决于科室的患者量和病种，先谈结构再谈投入。投入这块我们有测算方法，可以坐下来算。

**问：别的医院做得怎么样？**
答：有几家在推进，具体情况涉及对方，不便细说。做法上的共性问题我可以讲。

## 四、遇到答不上来的问题，统一话术

"这个问题我需要确认一下再答复你，今天不给你猜的答案。"

不允许的三种反应：
1. 当场编一个数字。
2. 说"应该可以""问题不大"。
3. 拿别的医院的案例顶上。
