# 第12周执行手册（发布同事照做版）

不解释为什么，只写怎么做。遇到手册没覆盖的情况，拍照发群里问，不要自己发挥。

---

## 一、家家健公众号（B9）· 周一

1. 打开 `①_渠道成稿（可直接发）/B9_家家健公众号_研究简报_前列腺术后尿失禁康复.txt`
2. 从"标题："那一行开始复制，复制到"广州市家家健健康管理研究中心"那一行为止。**最后那个"【发布检查（内部用，发布时删除）】"整块不要复制。**
3. 粘贴到公众号编辑器。四个"一、二、三、四、五"小标题保持原样，不要改成彩色标题条。
4. 配图：本篇可用一张配图，建议用纯色底 + 白字的"研究简报"字样图，不用实拍人物。
5. 摘要栏填：本期梳理前列腺癌术后尿失禁的康复指南建议，以及实践中的落差。
6. 原创声明：开。作者填"家家健研究中心"。
7. **发送前检查：全文搜"圆爱康"，必须是 0 个结果。** 有就必须删掉再发。
8. 定时 11-23 上午 9:00。

## 二、知乎官方号（B1）· 周一

1. 打开 `B1_知乎官方号_...txt`，从"标题：…"下一行正文开始复制到最后一行正文。**末尾的【发布说明】【配图建议】【发布检查】三块不复制。**
2. 知乎编辑器里先粘标题，再粘正文。段落之间保留一个空行。
3. 图片：按配图建议插 3 张，位置在对应段落之后。没有素材就先用纯文字发，不配图也能发。
4. 话题标签填 3 个：医院管理、康复、院外延续。
5. **与 B9 的顺序：先确认 B9 已经发出去了，再发 B1。** 顺序反了本周的破墙逻辑就不成立。
6. 定时 11-23 下午 15:00。

## 三、服务号（B2）· 周二

1. 打开 `B2_服务号_...txt`，正文从"标题："下一行开始，复制到"（说明：…）"之前。
2. 群发前把标题单独填进标题栏：一个居家康复项目从谈到落地，要走哪几步。
3. 排版：小标题用编辑器默认样式，不要加底色块。全文不要加表情符号。
4. 摘要栏填：谈院外延续，第一页要写清的四件事。
5. 定时 11-24 上午 10:00。
6. **注意：本篇不要加任何报价、案例数字。如果科室领导要求加，先回群里问，不要自己加。**

## 四、视频号（B7）· 周三

1. 打开 `B7_视频号_脚本第12支_...txt`。这份是脚本不是文案，要拿去拍或做后期。
2. 逐幕核对六幕是否齐全。**每一幕都检查侧角角标"智慧家康 = 智慧居家康复"有没有写进去**，缺一幕就补上。
3. 字幕按脚本给的原文，不要改写。每屏不超过 14 字，超了就拆两句。
4. 时长控制在 2 分 30 秒左右，最长不超过 3 分钟。超了就删第4幕的一半，不要删角标。
5. 评论区置顶文案用脚本最后给的那句。
6. 定时 11-25 晚上 20:00。

## 五、小红书（B5 / B6）· 周四、周五

1. B5 周四晚 19:00–21:00 之间发。B6 周五同一时段发。
2. 打开对应 txt，标题单独填，正文从"———"下面第一行开始复制，复制到"配图脚本（7列）"之前为止。**配图脚本是给你拍图用的，不要粘进正文。**
3. 正文里的"一，二，三"保留数字，不要改成表情。
4. 图片：按配图脚本拍或找 5–6 张。首图最重要，用脚本给的图1。
5. 话题标签照抄文末那一行，5 个全填。
6. **两条之间不要互相评论、不要互相点赞。同账号连推同病种容易被限流。**

## 六、知乎老欧个人号（B4）· 周五

2. 末尾的【发布说明】【配图建议】【发布检查】三块**绝对不要复制**。
3. **发送前全文搜四个词，每个都必须是 0 结果：圆爱康、智慧家康、上门、合作请联系。** 有一个就停，发群里问。
4. 配图 2–3 张即可，用白板手写、便签这种，不要用商务图库的握手照片。
5. 定时 11-27 下午 16:00。

## 八、微博老欧（B8）· 周六

1. 三条拆开发，**间隔至少 4 小时**。上午 10:00、下午 15:00、晚上 20:00。
2. 每条只复制"第X条"下面的正文，不要把"第X条"三个字发出去。
3. 不配图。微博这三条是短感想，配图反而像广告。
4. 不要带任何话题标签。

## 九、医院稿（3篇）· 不进本周排产

1. 三篇在 `④_医院稿库/` 里，**按医院一家一篇给**，不要一次给同一家医院三篇。
2. 给之前必须先确认：这家医院是否已经用过 H10-01（二胎妈妈复查节点稿）。用过就不能给稿1，给稿2或稿3。
3. 给稿时把文末"【给宣传科的说帖（可直接复制）】"那一段一起发给科室对接人，其余内部说明不要发。
4. 发之前把"门诊时间：（科室填写）"三行留在原处，让科室自己填。

## 十、每天下班前必做

1. 回传登记表填当天发的每一篇：链接、时间、截图。
2. 在 AI 里搜一次「院外延续 康复」和「智慧家康」，截图存到本周文件夹。
3. 如果某篇被平台限流、下架、审核不过，**立刻截图发群里**，不要自己改文案重发。
