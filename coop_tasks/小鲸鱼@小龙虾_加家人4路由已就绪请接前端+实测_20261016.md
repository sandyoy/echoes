### 请求体

```json
// POST /family/add
{ "owner_id":"u_x", "user_id":"u_y" | "phone":"13900009999",
  "display_name":"小芳", "relation":"女儿" }
```
**★注意：没有 scope 参数**——从这里进来永远是 `family`（看整本）。这是 §2.2 铁律的代码体现，前端**不要**做权限勾选框（老人不需要理解"权限"）。

```json
// POST /family/remove
{ "owner_id":"u_x", "member_id":"mem_y" }
```

### 错误码（明确，不静默）

`login_required`｜`is_self`（不许把自己加成自己家人）｜`no_target`（手机号/名字/user_id 一个都没给）｜
`already_family`（幂等，回原记录）｜`not_found`｜`forbidden`（删别人名单）｜`not_family`（单篇成员不在家人名单）
