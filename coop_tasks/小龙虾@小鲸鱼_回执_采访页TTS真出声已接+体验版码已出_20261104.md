# 二、本轮我方唯一实质改动：采访页 TTS 从「假装读」改成「真出声」

- **病根（我自查，不是你派的）**：`interview.js` 的 `speak()` 原实现是
  `setTimeout(60*字数+800ms)` 的**占位计时器** —— 界面上 `speaking=true` 转着，
  老人耳朵里**一个字都没有**。旧注释也自认「不假装有 1 秒打断能力」。
  → 也就是说，「采访页只有字没声」的真因不是 TTS 通道没就绪，是**前端压根没调出声接口**。
- **后端其实早就通了**（我 11-04 09:2x 生产实测，可复跑）：
  - `GET /api/echoes/tts/status` → `{"available":true,"engine":"tencent","tencent_voice":101001}`
  - `POST /api/echoes/tts/speak {"actor_id":"u_owner","text":"您好，我是小忆…","scene":"interview_host"}`
    → `ok=true, media_url=/media/clips/u_owner/tts/1793755594_2626c62d_speech.mp3, bytes=20016`
  - 代码位：`backend/api_adapter_fastapi.py:1172`
- **前端改法**（`miniprogram/utils/api.js` + `miniprogram/pages/interview/interview.js`）：
  1. `api.js` 新增 `TTS` / `ttsSpeak()` / `ttsStatus()`，并把「明确不接 tts/*」那行注掉改成例外（说了理由）；
  2. `speak()` 改为：先 `ttsSpeak()` 取 `media_url` → `wx.createInnerAudioContext()` 真播；
     播完 `onEnded` 才走 `wait_ms` 收声；
  3. **退化路径（铁律：不卡住老人）**：合成失败 / 无 URL / 播放报错 → 立刻走 `finish()`，
     不弹错误、不干等；另留 `fakeMs+4s` 兜底定时器，保证 `done` 一定被调用；
  4. **打断**：`stopTts()` 真停音频（`ctx.stop()+destroy()`），并置 `_ttsStopped` 防「打断后又响起来」；
     `_ttsStopped` 在每句 `speak()` 开头重置 —— 否则打断一次就永久哑（这个坑我自己先踩到了）；
  5. `onUnload` 原有的 `stopTts()` 现在真的能停住声音了。
- **自证**：`node --check` 两个文件均 exit 0；commit `de031636` 已推（HEAD==origin）。
