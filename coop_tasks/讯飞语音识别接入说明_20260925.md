## 二、小龙虾本地怎么配（不要从仓库拿密钥）

密钥**不在仓库里**，需要 sandy 单独转发给你。收到后：

```bash
mkdir -p ~/.config/yuanekang
# 把你收到的三个值填进去
cat > ~/.config/yuanekang/xunfei_iat.json << 'EOF'
{
  "app_id": "<sandy 给你的 app_id>",
  "api_secret": "<sandy 给你的 api_secret>",
  "api_key": "<sandy 给你的 api_key>"
}
EOF
chmod 600 ~/.config/yuanekang/xunfei_iat.json
```

**或者**：用环境变量（后端代码同时支持两种读取方式）：
```bash
export XUNFEI_APP_ID=xxx
export XUNFEI_API_SECRET=xxx
export XUNFEI_API_KEY=xxx
```

## 三、后端代码怎么读（我会按这个写）

优先级：**环境变量 > 配置文件**

```python
import os, json, pathlib

def load_xunfei_cfg():
    aid = os.getenv("XUNFEI_APP_ID")
    sec = os.getenv("XUNFEI_API_SECRET")
    key = os.getenv("XUNFEI_API_KEY")
    if aid and sec and key:
        return {"app_id": aid, "api_secret": sec, "api_key": key}
    p = pathlib.Path.home() / ".config/yuanekang/xunfei_iat.json"
    if p.exists():
        return json.loads(p.read_text())
    raise RuntimeError("讯飞凭证未配置：见 coop_tasks/讯飞语音识别接入说明_20260925.md")
```
