## 三、前端实现（`miniprogram/pages/book/`，一页两态）

**取材态**（`tab='source'`）：
- 进页面调 `POST /book/source`，把两筐摆出来；
- **筐① own=「你的记录」**：不可取消勾选（wxml 里 own 卡片无 `bindtap`，勾选框恒 ✓），显示条数；
- **筐② public=「别人提到的」**：`bindtap="onTogglePublic"` 可勾，显示「已选 N 条」，每张卡片带 `这段来自XX的讲述` 署名；
- 书名输入框（可空，空则由后端兜底「我的一生」）；
- **生成按钮**：调 `POST /book/generate`，带勾选的 `picked_public_ids`；**若已有 `ebookId` 则回传 = 覆盖刷新（活文档）**，按钮文案随之显示「重新做一本」。

**成书态**（`tab='ebook'`）：
- 点【我的书】调 `GET /book/ebook`；
- `empty=true` → 显示「这本书还没做呢」空态（**不当报错**）；
- 章节按后端 `time_sort_key` 顺序渲染（前端不重排）；
- **引用段**：`entry.is_quote==true` → 渲染成 `quote-block`（灰底引用块）+ `quote_label`（如「这段来自李婶的讲述」），**不给编辑按钮**；
- **本人原话**：`entry.editable==true` 才显示「改一改」入口（引用段永不显示）；
- 贡献者区列 `contributors`。

**错误处理**：`no_stories`/`empty_book`（空书明确拒绝）→ toast 如实回话，**不假装成功**；`forbidden`（非书主人）→ 走 catch 显示中文人话。

**双界面**：`ui-standard` / `ui-large`（`uiMode` 来自 `app.getUiMode()`）。
