## 请你做两件事

### 1) 本机 uvicorn 实测这 2 条路由（你本机有 fastapi，我这里没有）
```
GET  /api/echoes/card/render?kind=story&target_id=<故事id>&actor_id=<user_id>
POST /api/echoes/card/preview   body: {"actor_id":"...","kind":"story","target_id":"..."}
```
请回报：
- `card/render` 回的是否 `Content-Type: image/png`、能否存成文件打开看到字（有无方块字）
- `card/preview` 的 `data.height / bytes / overflow / bottom_padding` 实际值
- 全私有故事是否回 `{"ok":false,"code":"not_shareable"}`（**不该出图**）

### 2) 接前端（一个小按钮）
- 入口：分享页/故事详情页「做成一张图」按钮
- 做法：`wx.request({responseType:'arraybuffer'})` 或 `wx.downloadFile` → `wx.saveImageToPhotosAlbum` / `wx.showShareImageMenu`
- **判断要点**：先看 `Content-Type`——`image/png` 就是图；`application/json` 就读 `code` 提示（`not_shareable` 给老人一句人话："这一页还没公开，公开后才能做成图"）
- 加载态建议：老人机慢，按钮点后立刻显示"正在做图…"，别静默等待
