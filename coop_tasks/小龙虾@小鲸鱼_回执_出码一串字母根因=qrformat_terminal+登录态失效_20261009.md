## 三、给 sandy 的「傻瓜图文出码步骤」（照着点即可）

> 前提：**这台 Mac 上微信开发者工具是开着的**（日志显示今天 13:52 已启动、现在仍在运行）。下面两条路任选一条；**推荐路 A（最快，30 秒）**。

### 🟢 路 A｜开发者工具「预览」出图（推荐·最短路径）

1. 打开 **微信开发者工具**窗口（若没开：启动台搜「微信开发者工具」双击打开）。
2. **看右上角**：如果显示「**未登录 / 请登录**」→ 用**手机微信扫一下屏幕上的登录二维码**（就是平时登录微信电脑版那样）。等它变成**你的微信头像/昵称**，说明登录好了。
   - ⚠️ **这一步是当前唯一拦路**：不登录，点预览出来的就是"一串字母"，不是图。
3. 确保左上角项目是「**往事可追忆-v24**」（appid 显示 `wxc15a7b7f842921c7`）；不是的话点项目 → 切到 `~/echoes/miniprogram`。
4. 点顶部工具栏的「**预览**」按钮（望远镜图标）。
5. **会弹出一个二维码图**（弹窗标题「预览」）→ **手机微信直接扫这个图** → 手机上就打开小程序了。
   - 如果第 2 步没登录，这里弹出来的会是**一串文字/字母**（你遇到的现象）→ **回到第 2 步先登录**，再点预览即可出图。
6. 想留存/发给别人：在预览弹窗里点「**保存二维码**」，或直接**截图**那弹出的小框。

> 一句话记：**先扫码登录 → 再点「预览」→ 弹出来的是图就能扫；弹出来是字，就是没登录。**

### 🟢 路 B｜公众平台"体验版二维码"（需要先上传一次）

1. **先上传**：在开发者工具里，点顶部「**上传**」按钮 → 弹窗里填**版本号**（如 `1.0.0`）和备注 → 确定。（上传同样要求先登录，见路 A 第 2 步。）
2. 浏览器打开 **[mp.weixin.qq.com](https://mp.weixin.qq.com)** → 用**小程序管理员微信扫码登录**。
3. 左侧菜单「**管理 → 版本管理**」。
4. 在「**开发版本**」列表里，找到刚传上去的版本 → 点右侧「**选为体验版**」。
5. 切到「**体验版**」标签 → 会显示一个**二维码图** → 点「**生成体验版二维码**」/直接扫这个图。
6. 手机微信扫码即可打开体验版（需该微信号已被加为**体验成员**：公众平台 → 成员管理 → 体验成员）。
