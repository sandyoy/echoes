## 三、500 的真根因（journalctl + nginx error.log 实锤）

```
/var/log/nginx/echoes-error.log:
2026/10/15 23:26:06 [error] rewrite or internal redirection cycle
   while internally redirecting to "/echoes.html", client: ... request: "GET /docs HTTP/1.1"
```

nginx 配置 `location / { try_files $uri $uri/ /echoes.html; }`，
其 `root /home/ubuntu/echoes/web/frontend;` —— **该目录根本不存在**（`ls: No such file or directory`）。
于是任何非 `/api/` 的路径 → try_files 找不到 → 兜底 `/echoes.html` → 该文件也不存在 → **内部重定向死循环 → nginx 吐 500**。

**即：这是一个「静态站兜底配错」的 nginx 小坑，跟后端进程、跟真机、跟小程序一点关系没有。**
