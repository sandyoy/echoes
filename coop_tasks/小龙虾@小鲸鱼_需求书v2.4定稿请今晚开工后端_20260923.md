## 四、今晚请开工的三件事（均不需等前端）

### 1️⃣ 数据模型（最底层，必须先定死）

- **数据主体 = 故事，不是人**（v2.1 重大修正）
  - 故事有：讲述人 / 记录者 / 参与者
- **素材挂在「同一件事」上**：文字 / 语音（保留原声，不只是转文字）/ 照片 / 视频
- **时间 vs 故事两个维度独立**：
  - 时间 = **排序**维度（决定排在哪）
  - 故事 = **归属**维度（决定跟谁一组）
  - **同一时间点允许多个故事**
  - 时间精度分级：**年 / 季 / 月 / 模糊**，**精度不影响排序**
- **"待认领"机制**（新增，重要）：
  - 加人时对方**可能还没账号** → 先按**手机号/名字**登记为「待认领」
  - 对方注册后用**同一手机号**登录 → **自动认领** → 首页出现「有 N 篇故事提到了你」
  - 手机号对不上 → 走**按名字搜索认领**（写故事方确认）
- **权限由入口决定，不设权限勾选框**：
  - 故事里的加号 → 只看**这一篇**
  - 家人加号 → 看**整本书**
  - **被提到的人看"提到自己的那篇"永不需要授权**；**只有看全本才须授权**

### 2️⃣ ASR（卡着"按住说话"整个功能，今晚必须给方案）

- 现状：`backend/asr.py` 依赖百度语音 API，**服务器 .env 未配凭证 → 走 mock**
- 三方案待定：**A 申请百度 Key / B 本地 Whisper / C 先用占位**
- **请今晚给一个结论**，不必完美，但要有可跑的路径

### 3️⃣ 时间轴提取算法（全项目最难，能开头就开）

- 从**语音内容**和**文字内容**提取时间线索，自动归位；**保存即触发**排序调整
- **三类线索**：
  1. **显式年代**："1968年""七几年"
  2. **历史事件**："文革那会儿""分田到户那年"
  3. **人生锚点**："我八岁那年""嫁过来第二年"→ 用已知年份反推
- 一旦采到锚点（出生年/结婚年等），后续同类表述**可自动换算**
- **无法判定时标「时间待定」，不瞎猜、不归错位**
- ⚠️ **模糊表述原样保留**：老人说"七几年"→ 记成**「1970年代（老人说的）」**，**绝不许凑整成"1975年3月"**
- 这是**建议优先立为独立攻坚项目**的一项
