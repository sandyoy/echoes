## Bug 1｜自述页按住说话：无反应、不录音、不转文字

**现象**：首页"自述"模式按住话筒说话，松手后无任何结果（无音频、无文字、无提示）。

**代码证据**：
- `miniprogram/pages/index/index.wxml` L19-21
  ```
  bindtouchstart="startRecording"
  bindtouchend="stopRecording"
  bindtouchcancel="stopRecording"
  ```
  → 用 `bind*` 冒泡绑定，页面滚动/长按手势会抢事件；`touchend` 移出按钮范围不触发。
- `miniprogram/pages/index/index.js` L71-80
  ```js
  startRecording() {
    if (this.data.currentMode !== 'self') return
    if (app.isRecording() || this.data.isRecording) return
    this.setData({ isRecording: true, showRecordingToast: true })
    const ok = app.startRecord()
    if (!ok) {
      this.setData({ isRecording: false, showRecordingToast: false })  // ← 静默复位，不告诉用户
    }
  }
  ```
  → `app.startRecord()` 返回 false（权限未给/被拒）时**只默默复位，无任何 toast**，用户看到的就是"按了没反应"。

**修法**：
1. `bindtouchstart/bindtouchend` → 改 `catchtouchstart/catchtouchend`（阻止冒泡，事件不被抢）
2. `startRecord()` 返回 false 时**必须弹提示**：`wx.showModal` 引导去 `wx.openSetting` 打开麦克风权限
3. 进入页面时 `wx.getSetting` 检查 `scope.record`；未授权**主动 `wx.authorize`**，被拒后给可点击的重新授权入口

## Bug 2｜采访页：发送键永久灰色、打字发不出去、保存不了

**现象**：采访页输入文字后，发送键灰色点不动；即使发送了也保存不了。

**代码证据**：
- `miniprogram/pages/interview/interview.wxml` L90
  ```
  <button class="send-btn" bindtap="sendMessage" disabled="{{!inputText.trim() || isThinking || voicePress}}">
  ```
- L87 `<input ... disabled="{{voicePress}}">`

  → `voicePress` 只有在 `onStop` 回调里才复位（`interview.js` L59、L70）。**一旦录音回调丢失（权限被拒 / 系统打断 / onError 未触发），`voicePress` 永久 true** → 输入框可输入但**发送键永久灰**、保存链路一起死。

**修法**：
1. `voicePress` 加**兜底超时**：按下即 `setTimeout(() => this.setData({voicePress:false}), 3000)`，`onStop/onError` 里 `clearTimeout`
2. 发送键 `disabled` 条件**去掉 `voicePress`**（录音状态不应阻断文字发送）
3. 文字通道与语音通道**彻底解耦**：录音异常不得污染输入框/发送键状态

## Bug 3｜统一保存页：内容为空 → 保存静默失败

**现象**：打出的文字点保存无反应。

**代码证据**：
- `miniprogram/pages/save/save.js` L107-108
  ```js
  const text = this.data.content.trim()
  if (!text || this.data.saving) return   // ← 空内容直接 return，无任何提示
  ```
- 内容经 URL 传递：`index.js L124-131` / `interview.js L186-194`
  ```js
  'content=' + encodeURIComponent(content || '')
  wx.navigateTo({ url: '/pages/save/save?' + q.join('&') })
  ```
  → 微信小程序 `navigateTo` URL 有长度上限（约 1024 字节）。**采访页"整场问答串起来"的长文本必然超限被截断** → `content` 变空 → 保存静默 return。

**修法**：
1. **正文改走 storage 中转**：`wx.setStorageSync('pendingStory', {content, audioPath, sourceType, dur})`，save 页 `onLoad` 读 `pendingStory` 并即清。URL 只传轻标记。
2. 保存页空内容时**必须弹提示**（"还没写内容，说点什么吧"），不许静默 return
3. 兼容老调用方：`onLoad` 先读 query，再读 storage（storage 优先）
