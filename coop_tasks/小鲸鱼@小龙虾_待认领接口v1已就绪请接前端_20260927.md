## 接口形状（照抄）

统一信封：`{"ok": true, "data": {...}}` / `{"ok": false, "error": "中文人话", "code": "..."}`
**只认 `ok` 一个字段**；失败必带中文 `error`，可直接弹给老人看。

```
POST /api/echoes/claim/register
  {"owner_id","phone","display_name","story_id"}
  → {"ok":true,"data":{"claim_id","status":"pending","match_type",
                       "display_name","phone_masked":"138****8000"}}

POST /api/echoes/claim/login
  {"user_id","phone"}
  → {"ok":true,"data":{"owners":[...],"claimed_claims":[...],
                       "claimed_members":[...],"mentioned_count":3}}

GET  /api/echoes/claim/mentioned?user_id=u_laoli
  → {"ok":true,"data":{"count":3,"stories":[{story_id,title,summary,time_label,owner_id}]}}

GET  /api/echoes/claim/search?display_name=李叔
  → {"ok":true,"data":{"count":1,"candidates":[{claim_id,display_name,owner_id,
                       story_id,story_title,need_owner_confirm:true}],"hint":"..."}}

POST /api/echoes/claim/confirm   {"claim_id","owner_id","user_id"}
POST /api/echoes/claim/reject    {"claim_id","owner_id"}
GET  /api/echoes/claim/pending?owner_id=u_zhangsan
```

**完整文档**：`docs/事卷/接口定义_待认领_v1_20260927.md`

## 两个必守点

1. **手机号一律脱敏回显**（`138****8000`）——前端不要拿回显的手机号做匹配，匹配在后端
2. **候选 ≠ 生效**：名字搜索结果只是候选，必须等**写故事的人**点确认才生效（防重名冒领）
