## 三、你要的"最后一份=最终版"，怎么落地

靠改文件名做不到。我加**三层机制**：

### 第 1 层：每个项目/事项夹里放一份 `_当前状态.md`
固定格式，只有五栏：

```
# XX 事项 · 当前状态
状态：进行中 / 已结案 / 已作废
最新版本：<文件名>
最后更新：2026-11-19
一句话结论：<现在到哪一步了>
下一步：<谁做什么>
```

**这是你说的"最后一份文件"。** 打开夹子先看它，不用翻。

### 第 2 层：文件命名统一成 `事项_版本_日期`
- 当前有效版：`居家康复项目报价表_v2.0_20261119.md`
- 被取代的进 `99_归档/`，保留原名加 `_已取代`
- **`.bak` 全部进归档**，第一层不许出现

### 第 3 层：根目录 `00_总索引.md`
一张表列全部事项 + 状态 + 该看哪份。你打开仓库第一眼就是它。

## 四、这次整理"不做什么"（避免把事搞砸）

1. **不删任何文件**——只移动、归位、加 `_当前状态.md`。全部可回滚。
2. **不改代码目录**——`backend/` `miniprogram/` `xiaoqiao/` 一行不动。
3. **不动 `wiki/medical/`** 内部结构——那是资料库，按产品/文献/政策已分好，只把它整体挪到 `06_资料库/`。
4. **路径引用全部同步改**——移完立刻全仓 grep 旧路径，改 cron、脚本、文档内引用。这是最容易静默失败的地方。
