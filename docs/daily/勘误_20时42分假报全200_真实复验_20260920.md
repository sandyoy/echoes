## 四、教训（铁律）

**自测必须看 HTTP 状态码，不能只看 JSON 能不能解析。**
404/500 也会返回合法 JSON，`json.loads()` 成功 ≠ 接口正常。
写进自测规范：**每个接口断言 `status_code == 200` + 关键字段存在**，两条都过才算通。
