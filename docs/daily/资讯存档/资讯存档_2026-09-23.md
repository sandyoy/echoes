## 1. 【国家战略·最重要】9月18日国务院常务会议部署实施"医疗康复护理扩容提升工程"，康复护理资源向社区、家庭延伸
- 来源：**中国政府网官方原文已核实** —— 《国务院常务会议解读｜国务院常务会议部署实施医疗康复护理扩容提升工程》，新华社北京9月18日电（记者 李恒），gov.cn 发文日期 2026-09-18（文号页 content_708…）；国家发展改革委、中国政府网公众号 09-18 同步发布
- 内容（官方摘要原文）：9月18日国务院常务会议**部署实施医疗康复护理扩容提升工程**，"指出要**以基层为重点**建强医疗康复护理服务体系，**推动康复护理资源向社区、家庭延伸**，增强城乡居民康复护理服务可及性"。会议同时听取老龄工作情况汇报，部署积极应对人口老龄化（健全养老保障、培育银发消费新场景），并审议通过中医药传统知识保护条例。
- 延伸要点（多家行业号一致解读）：①"**开发更多智能康复技术和设备**，优化新技术新产品审评审批"；②"**动态调整康复医疗、长期照护服务项目目录**"；③"深化医疗康复护理**服务价格改革**"；④完善人才培养政策。
- 意义：**圆爱康主赛道获得国务院级背书**。"康复护理资源向社区、家庭延伸" = 居家康复被写进国常会部署；"动态调整服务项目目录 + 服务价格改革" = 支付端口正在打开；"开发智能康复技术和设备" = 设备+系统型服务商的政策顺风。

## 2. 【支付端】康复设备/耗材入院要过"全国统一"三道支付关；全国统一医保医疗服务项目目录首批13类含康复
- 来源：微信公众号「思宇MedTech」（2026-09-18）、「医康医讯」（2026-09-19）、「力之智能科技」（2026-09-21）
- 内容：国家医保局发布医疗器械入院支付相关工作方案，**康复设备等高度依赖器械和装备的领域全部进入首轮评审范围**；9月9日国家医保局宣布**第40批医疗服务价格项目立项指南**。截至2026年5月口径累计39批、统一新增约200余项新技术价格项目。康复被列入**首批13类全国统一医疗服务项目目录**，此前的痛点是"各地康复项目编码不统一、支付范围差异大、跨省结算有壁垒"。
- 意义：康复从"各省自定编码"走向"全国统一编码" → 对**跨区域连锁/异地服务**是结构性利好；对圆爱康这类"服务+系统"企业，统一编码意味着可标准化报价、可批量对接医院。

## 3. 【支付端·风险面】康复科按床日付费（PDPM/DRG3.0）改革推进，基层康复遭遇"加一张床亏一张"
- 来源：微信公众号「华医数创」（2026-09-17）、「康复知音」（2026-09-10、09-18）、「在时代的变迁中」（2026-09-13）；原始信息源为国家医保局新闻发布会（2026-09-02）
- 内容：医保支付方式改革（DRG3.0/DIP）把康复科从"按项目收费"推向"按床日/按病种打包付费"。行业反馈：**县域康复扩容被医保支付卡住**——受访者称当地康复科住院统一执行DRG付费，导致"**加一张床亏一张**"，康复扩容积极性受挫；康复科一度被称"赔钱科室"，DRG3.0 后"康复科独立入组/同病同付"被视为转机。
- 附加：多地医保飞检点名康复、理疗、针灸"**编码高套**"（湘医保飞检样本），康复治疗师个人医保支付资格记分制（12分扣完暂停/取消）浮现。
- 意义：**这是圆爱康"医院侧"客户（康复科）真实痛点**——院内康复不赚钱 → 医院更有动力把康复"往外推"到居家/社区。这条与第1条合并读：**院内支付收紧 + 国常会推动资源向家庭延伸 = 居家康复的窗口正在被医保逻辑本身推开**。

## 4. 【地方·大本营】广东多地康复政策密集落地：残疾人基本康复服务纳入医保（9月1日施行）、广州残疾人康复经费管理办法（2026年版）实施、医保个账"白名单"
- 来源：微信公众号「残疾人温馨家园」（2026-09-16，标注来源广东省人民政府，发布日期2026-09-01）、「联和街社工服务站-普爱社工」（2026-09-18）、「金飞鹰药械技术咨询集团」（2026-09-11，标注来源广东医保局）
- 内容：①广东省层面残疾人基本康复服务纳入医保，2026-09-01 起施行；②《广州市残疾人康复经费管理办法（2026年版）》正式实施，明确"残疾人在享受医保、救助等基础保障之后，**还可以按政策叠加享受康复资助**"，降低个人承担部分，且**困难残疾人居家康复上门服务的资助对象有调整**；③广东医保个账"白名单"落地，医疗器械行业支付逻辑重构。
- 意义：**广东=圆爱康大本营**，"医保+康复资助可叠加"是直接可用的商业话术与获客逻辑；上门服务资助对象调整须索取原文核对是否影响接单结构。

## 5. 【行业·设备】"智能康复设备"首进国常会，康复机器人从"医院专用"下沉基层与家庭
- 来源：微信公众号「思宇MedTech」（2026-09-22）、「政企快联」（2026-09-20）、「九系明朴说」（2026-09-21）、「康复知音/欣姐的康养圈」（2026-09-18/19）
- 内容：行业普遍认为国常会"开发更多智能康复技术和设备"是**智能康复设备首次进入国常会级表述**。但多方一致提示：这**是"实施工程"的总体方向，不是政府采购清单**，"优化审评审批"的具体监管规则和产品目录尚未公布；**国常会强调的"开发智能康复技术和设备"不鼓励单点技术孤立突破，而指向系统级整体方案**。
- 意义：对圆爱康——**"系统级整体方案"（服务能力+系统+设备组合）比单卖一台设备更贴政策方向**；同时"不是采购清单"的提醒很关键，别把政策热度误读成短期订单。

## 6. 【行业·数据】县域/基层医院转型康复：卫健委发文引导二级及以下医疗机构转型康复医院，"康复护理扩容"配套细则待出
- 来源：微信公众号「求学通教育」（2026-09-16）、「楚文祺」（2026-09-21）
- 内容：卫健委发文给出明确转型路径"引导部分二级及以下医疗机构转型为康复医院"，被解读为"为无路可走的基层医院开辟新赛道"。行业解读称国常会后"**各部委将密集出台配套细则**"，二级医院考虑转型康复医院/护理院或拓展康复护理床位，基层机构抓特色科室和社区康复。
- 意义：**县域二级医院转型康复医院 = 圆爱康的合作医院池扩大**；转型中的医院最缺的正是"运营+居家延伸+系统"能力（圆爱康的核心产品）。

## 7. 【长护险】国家长护险36项服务目录（全国统一）持续在各地落地执行，不得随意调整
- 来源：微信公众号「上海敦敏教育」（2026-09-18）、「齐啦说长护险」（2026-09-16）
- 内容：新开展长护险的地区**必须严格照国家36项目录执行，不能自行调整服务项目**；上海作为原试点城市另有42项目录。汇总口径：生活照护类 + 医疗护理类合计36项。
- 意义：长护险扩面过程中**目录刚性 = 门槛清晰**，符合36项目录内服务（含康复训练）的机构可直接对标申报；圆爱康长护险相关服务包应按36项逐条对齐（此前技能已梳理：康复训练在医疗护理类、认知训练在内；盆底/心脏术后/胃肠起搏不在目录内 → 作增值搭售）。
