# 医疗康复护理扩容提升工程 与 珠海市妇幼保健院

## 一、政策依据

国务院《关于〈医疗康复护理扩容提升工程实施方案〉的批复》（**国函〔2026〕99号**，2026年9月28日）

国家卫生健康委、国家发展改革委《医疗康复护理扩容提升工程实施方案》（**国卫规划发〔2026〕24号**，2026年9月30日）

## 二、方案中直接涉及妇幼保健机构的条文（原文照录）

**第（二）条**　"其他医疗卫生机构结合自身优势加强**妇女、儿童**、老年人、精神障碍患者、职业病患者等重点人群康复护理服务。"

**第（三）条**　"推动**妇幼保健机构**、儿童医院、精神卫生机构、职业病防治机构等其他医疗卫生机构围绕提供专业特色康复护理服务，**配置康复评估、训练等设备**，**拓展康复护理功能**，**补齐设施设备短板**。"

## 三、方案中涉及居家康复护理的条文（原文照录）

**第（二）条**　"基层医疗卫生机构重点为慢性稳定期患者提供康复护理服务，积极提供**社区、居家康复护理等延伸服务**。"

**第（六）条**　"支持有条件的基层医疗卫生机构开设康复医疗门诊，**规范发展家庭病床**，鼓励在家庭医生签约服务中提供**居家康复护理**等服务。"

**第（九）条**　"促进从**功能评估、计划制定、康复训练到效果随访**的康复护理全过程数智化应用。发展'**人工智能+康复护理**'服务，运用康复机器人、智能可穿戴设备等，实现**多维数据监测**，提供智能康复训练和健康管理服务。"

## 四、珠海市的政策适用性

第（三）条："国家**优先支持城区常住人口100万以上**的地级及以上城市实施医疗康复护理扩容提升工程。"

珠海市统计局数据：年末全市常住人口 **254.31万人**，常住人口城镇化率 **90.96%**。

——珠海市属于方案"优先支持"范围。

## 五、方案中对服务体系方向的表述（原文照录，方向性表述）

**第六部分 组织实施**　"探索**医疗卫生机构、社区、居家有效联动**的康复护理模式。"

**第二部分 总体要求**　"健全以**二级医院为主体**、**基层医疗卫生机构为网底**、**三级医院指导支持**、其他医疗卫生机构共同参与的康复护理服务网络。"
