## 【正面】项目与证据 —— 这是什么东西，凭什么靠谱

### 主标题
**儿童认知训练 · 把注意力与执行功能训练延伸到孩子家里**

### 一句话（页首）
把医院儿童精神科、儿保科的认知评估与训练能力，通过"评估—训练—回看"闭环延伸到孩子家中；医生开方案、看数据、调难度，孩子在游戏化任务中居家训练。

### 一、我们做什么（核心手段：认知训练）

- **主体是认知训练**，按国际通用诊断标准 **DSM-V 六大认知域**建模：
  复合注意 / 学习记忆 / 知觉运动 / 语言言语 / 执行抑制 / 社会认知
- **六个模块 · 36 个标准训练任务**（可依临床需要自定义扩展到 50 个）
- **每个任务 6 级难度**，按评估结果自适应匹配
- 配套 **55 个量表**（含 SNAP-IV、Conners、BRIEF 等 ADHD 相关家长版/老师版评估问卷）
- **针对 ADHD 的靶点**：持续注意（CPT漏报）、冲动抑制（误报）、工作记忆、认知灵活性、计划能力

### 二、凭什么靠谱（可核验的硬依据）

| 依据 | 内容 |
|---|---|

### 三、这套系统的逻辑：评估驱动（不是拍脑袋分档）

```
① 临床面诊 + 认知评估（行为量表 + 系统任务测评）
        ↓
② 系统对比同龄常模 → 出「认知轮廓图」（雷达图）+ 基线报告
        ↓
③ 每个任务给出：正确率 + 该任务测的能力 +「建议起始难度（1–6级）」
        ↓
④ 一键跳转 → 训练系统按建议难度开始训练
        ↓
⑤ 后台看训练记录 → 医生据此调整难度与任务
```

**一句话：无评估，不训练。** 难度不是手填的，是评估算出来、医生再核定的。

**标准训练参数（临床通用）**：单次 20–25 分钟 / 每周 5 天 / 基础疗程 8–12 周（4周中期小复测）。

## 【背面】落地动作 —— 我（医生）要做什么，孩子怎么进来

### 四、医生端看到什么 / 孩子（家长）端看到什么

| | 医生端 | 孩子/家长端 |
|---|---|---|
| 看什么 | 孩子认知轮廓图（雷达图）＋ 各任务正确率＋建议起始难度＋训练记录＋量表结果 | 系统安排的游戏化训练任务（按建议难度）＋ 指引 |
| 做什么 | 核对/调整任务与难度、看训练回执、定期复测 | 家长监督孩子按系统指引完成居家训练 |
| 记录什么 | 训练时长与完成度可追踪 | — |

**⚠️ 对外表述红线：只能说"训练时长与完成度可追踪"，绝不能说"能看到孩子是否专注/做题对不对"。**

### 五、孩子怎么进来（渠道清晰，责任分明）

- 入口 = 医院/科室公众号（开放接口即可）→ 家长跳转至圆爱康小程序/H5 完成操作，**机构无需开发**。
- **每个科室在系统里是独立"渠道"** → 孩子一进来就打上来源标签 → **病源归属、数据归属、服务责任清清楚楚**。
- 数据第一落点 = 圆爱康系统医生端，医生实时可看；医院需要数据，由我们整理提供。

### 六、合规口径（给医务科的定心丸）

> **医疗行为留在贵院**：所有评估/诊断/训练方案由贵院医生核定，医疗主体责任在贵院；
> **执行与运营由圆爱康承担**：设备、系统、客服跟进、运营端管理。
> 责任边界清楚，经得起审计。

### 七、哪些孩子适合（面向儿童精神科/心理科/儿保/发育儿科）

- 确诊或疑似 **ADHD（注意力缺陷多动障碍）** 的辅助康复训练
- **注意力不集中**（含不伴多动的注意力缺陷型）
- **多动冲动**、执行功能弱（做事没条理、易分心、拖延）
- 学习相关执行功能困难的注意力/认知训练需求
- ⚠️ 具体适用与禁忌由贵院医生结合孩子情况判断，本页不替代医嘱、不替代药物治疗决策
