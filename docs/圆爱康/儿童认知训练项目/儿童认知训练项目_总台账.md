> 定位：照搬心脏康复 + 认知康复（成人）整套交付物的**第三个病种出口**
> ⚠️ 与"认知康复项目（成人·神经内科）"关系：**同一鹤灵系统底座、共用同一套任务库**，仅病种出口/科室/受众人群不同。

## ⚠️ 顶层口径（sandy 已定，不得擅自改）

1. **科室落点（待 sandy 最终确认）**：儿童精神科／心理科为主 + 儿保科／发育儿科为辅。
2. **核心人群**：儿童**多动/注意力缺陷（ADHD）**，主诉多为"注意力不集中、多动、冲动"。
3. **核心干预**：**认知训练**（鹤灵"数智化认知评估与训练"儿童版）；**评估驱动**——ADHD 在评估阶段即被识别，依评估结果匹配训练方案。
4. **系统底座**：与成人版**共用一套任务库**（DSM-V 六大认知域 / 六大模块×36任务 / 每任务6个以上难度等级）。
5. **资质口径**：
   - 成人版=二类械注册证（粤械注准20232070187，《认知功能评估与训练软件》）
   - **儿童版=也有二类医疗器械证**（sandy 2026-10-12 确认；**证号待补**）
   - 另可讲"数字疗法/行为疗法软件"属性
6. **定价口径**：与成人认知康复一致——**一律自费项目定价**（待确认是否沿用成人套餐结构）。
7. **居家端入口**：**鹤灵脑星球小程序**（我们系统与其相连，数据回流）。
8. **⭐"医生核定"口径（sandy 2026-10-21 定）**：儿童线**本质是评估，不是医生核定整个治疗流程**。评估出轮廓图+建议起始难度 → 系统自动生成任务 → 医生看训练记录调难度与任务。**"医生核定表"此件永久注销**，成人线同步注销；对外一律禁说"训练方案由医生核定"，只说"评估与诊断由医生把关"。

## 一、临床全流程（sandy 2026-10-12 口述，厂家口径）

```
一、前置：专科面诊，确认适用（必须最先做）
   1. 儿童精神科/发育儿科/临床心理学家面诊，完成 ADHD 临床诊断，排查共病（读写障碍、焦虑、自闭症、智力问题）
   2. 医生评估：判断是否适合数字化认知训练；排除不适合（严重情绪失控、癫痫等）
   3. 建立儿童档案：录入年龄、发育史、学校/家庭行为资料
        ↓
二、系统基线认知评估（电脑/平板，约40–60分钟，治疗师/心理师陪同，安静环境）
   1. 行为量表问卷：SNAP-IV、Conners、BRIEF 执行功能问卷（家长+老师填写）
   2. 系统认知任务测评（核心）：
      · 持续操作测试 CPT（持续性注意、漏报、冲动误报 —— ADHD核心指标）
      · 选择性注意、工作记忆、冲突抑制、认知灵活性、计划能力
   → 系统对比同龄常模，自动生成基线报告，标出短板（如持续注意弱/冲动抑制差/工作记忆不足）
   → 医生+治疗师解读报告，定训练目标、训练模式（院内／居家账号／混合）
        ↓
三、系统自动生成个性化训练方案
   · 模块：持续注意、选择性注意、听觉/视觉工作记忆、反应抑制、认知转换、计划排序
   · 游戏化闯关 + 自适应难度（做好升、失误降，维持"跳一跳够得着"区间）
   · 标准训练参数（临床通用）：单次 20–25分钟 / 每周 5天 / 基础疗程 8–12周（4周做一次中期小复测）
        ↓
四、周期训练 → 阶段性复测 → 维持/调整
```

**⚠️ 训练靶点对应关系（sandy 确认）**：
- CPT 类（漏报/冲动误报）= 系统内 **捕捉蝴蝶** + **不能按的炸弹/云彩**
- 选择性注意、工作记忆、冲突抑制、认知灵活性、计划能力 = 系统六大模块均已含
