# 认知康复 · 视频号制作文档（神经内科成人版）

> 版本：v1.0 · 2026-10-21 · 小鲸鱼
> **这份文档解决一件事**：拿到文字稿和分镜脚本之后，**具体怎么把它做成能在视频号发出去的东西**——账号怎么设、规格怎么定、用什么工具做、一条视频从开工到发布要过哪几步、每步谁做。
> 配套：文字稿《认知康复门诊科普片_神经内科_文字稿_v1.0_20261021》＋ 分镜《认知康复门诊科普片_神经内科_分镜脚本_v1.0_20261021》
> 适用对象：公司做内容的人（非专业影视团队也能照做）

---

## 一、先定三件事（做完这三件，后面才有意义）

### 1. 这条片子发在哪个号？

| 选项 | 适合 | 注意 |
|---|---|---|
| **A. 合作医院科室视频号** | 想借医院公信力、给科室导患者 | 内容由医院审，结尾可放医院咨询口；**我方不署名** |
| **B. 圆爱康企业视频号** | 做行业曝光、给代理商看、给医院看 | 不出现具体医院名；走"我们在做的事"口径，不写"我院开展" |
| **C. 老欧个人号** | 纯个人观察、行业观点 | ⚠️ **不适用本片**——本片是科普片，个人号铁律是"转述+归纳、不冒充亲历、不出现公司" |

> **建议默认走 A（医院科室号）**：本片内容本来就是给患者看的，医院号的信任度远高于企业号；同一支片子企业号可另外再发，改片尾即可。
> **A 和 B 可以用同一套素材，只换片尾 3 秒。**

### 2. 主发形态选哪个？

| 形态 | 时长 | 用处 |
|---|---|---|
| **主版 5 分钟**（横版 16:9） | 4:50–5:00 | 门诊候诊区大屏循环 + 视频号"完整版"发布 |
| **拆条 3 条**（竖版 9:16） | 各 45–60 秒 | 视频号首发主力；抖音/小红书同步 |

> **发布顺序建议**：先发拆条（3 条，每条间隔 2–3 天），第 3 条发完再发主版。理由：视频号推荐机制偏短视频，长视频完播率低；先用拆条把流量拉起来，主版作为"完整版"沉淀。

### 3. 谁来干？

| 环节 | 谁 | 工作量 |
|---|---|---|
| 文案口径 | 小鲸鱼（已出稿） | 已完成 |
| 实拍 | 公司运营 或 外包摄影（半天） | 半天 |
| 动画 + 剪辑 | 剪辑（会剪映即可，本片动画均为模板可实现） | 2 天 |
| 配音 | 真人配音 或 AI 配音 | 半天 |
| 审核 | 医院科教科/宣传科（走 A 时必过） | 3–5 工作日 |
| 发布 | 医院宣传科 或 我方运营 | 半小时 |

## 二、规格参数（照着填就行）

### 主版（横版）

| 项 | 参数 |
|---|---|
| 分辨率 | 1920 × 1080 |
| 帧率 | 25 fps |
| 码率 | ≥ 8 Mbps（视频号上限内越高越好） |
| 格式 | MP4（H.264） |
| 音频 | AAC，48 kHz，立体声，人声 -6 dB，音乐 -24 dB |
| 字幕 | **硬字幕**（烧进画面），思源黑体 Medium，白色 + 20% 黑边 |

### 拆条（竖版）

| 项 | 参数 |
|---|---|
| 分辨率 | 1080 × 1920（9:16） |
| 帧率 | 25 fps |
| 安全区 | 上留 15%（顶部信息区）、下留 20%（文案/互动区）、右留 12%（点赞按钮区） |
| 字幕 | 字号 ≥ 画面高 4%（约 78 px），**距底边不少于 20%** |
| 封面 | 首帧 + 大字标题（占画面宽 70%），标题见分镜脚本拆条表 |

### 视频号发布填写规范

| 字段 | 怎么写 |
|---|---|
| 标题 | 用分镜脚本里的拆条标题，**不加"震惊/速看/必看"等诱导词** |
| 描述 | 2–3 句，讲清"这是什么、谁适合看"，不写疗效；末尾不带联系方式（A 号可带医院咨询口） |
| 话题标签 | `#认知障碍` `#认知训练` `#居家康复` `#记忆力`（每条不超过 5 个） |
| 定位 | 不加（加定位等于暴露医院位置，A 号由医院自己决定） |
| 合集 | 建"认知健康"合集，3 条拆条放同一合集 |
| 评论区 | 开启；**不回复任何"能不能治好/多少钱"类问题**，统一回"需由医生评估，建议到门诊咨询" |

## 三、制作工具（两套方案，按人手选）

### 方案一 · 剪映专业版（推荐，零基础可用）

> 本片所有动画（格子母题、六域图标、雷达图、数据流线）**都能用剪映的模板和关键帧做出来**，不需要 AE。

| 环节 | 剪映里怎么做 |
|---|---|
| 格子母题 | "图文成片"→ 画布加 3×3 网格贴纸 → 关键帧控制不透明度（0→100→0） |
| 六域图标 | 剪映"贴纸"搜"线性图标"，或用"文字+形状"自绘；统一改同色（深蓝 #1B4F72） |
| 文字逐字浮现 | 文字动画 → "打字机"或"逐字出现" |
| 雷达图生长 | 用"六边形"贴纸 + 蒙版（线性蒙版从左往右扫）模拟生长；或直接用"图表"模板 |
| 数据流线 | 形状"直线" + 动画"擦除"（从左到右）+ 端点小圆点移动 |
| 难度条 | 矩形条 + 关键帧宽度变化 |
| 字幕 | 剪映"识别字幕"→ 全片识一遍 → 手动核对改错（**必须人工核对，AI 识别会错专业词**） |
| 配音 | 剪映"文本朗读"可选 AI 音色，**但本片建议真人配音**（AI 音在"注意休息，定期复查"这类共情句上会露） |

### 方案二 · 外包（预算允许时）

- 交付给外包的不是"想法"，是**分镜脚本 + 文字稿 + 本规格表**三份。分镜已写到镜号级，外包只要执行。
- 报价参考：5 分钟动画重片（大量动画）= 中高；本片实拍少、动画均为几何动效，属**中档**。
- 验收标准：逐镜对分镜表核（镜号、时长、字幕、画面元素），**任一项不符即返工**。

## 四、制作流程（8 步，含卡点）

| 步 | 动作 | 产出 | 卡点/注意 |
|---|---|---|---|
| 1 | 定号、定形态（本文第一节三件事） | 一句话结论 | 走 A 号需先拿到医院授权 |
| 2 | 备素材 | 实拍素材 + 素材库素材 | 实拍半天；素材库 M3/M7/M8/M12 需买授权，**保留授权凭证** |
| 3 | 做动画 | 6 个域图标 + 格子母题 + 雷达图 + 数据流线 | 统一色板，别混风格 |
| 4 | 配音 | 主版旁白 + 3 条拆条旁白（同一条人声） | 语速 270–280 字/分，**不要播音腔** |
| 5 | 粗剪 | 主版 5 分钟按分镜铺满 | 严格按镜号时长，先不管细节 |
| 6 | 精剪 + 字幕 | 硬字幕全片 + 音效（低频"咚"、转场） | AI 识字幕**必须人工核**，专业词易错 |
| 7 | 拆条 | 3 条竖版，重新裁切（不是压扁） | 首帧标题字 + 安全区 |
| 8 | 审核 → 发布 | 审核意见回改 → 发布 → 建合集 | **A 号必过医院审核**，预留 3–5 工作日 |

## 五、审核与合规（这一节比制作更重要）

### 1. 发布前必须自检的 8 条（逐条打勾）

| # | 检查项 | 判断标准 |
|---|---|---|
| 1 | 无疗效承诺 | 全片无"改善""治愈""有效""预防痴呆""恢复记忆" |
| 2 | 无诊断性表述 | 不写"AI 诊断""智能诊断"；不出现"您患的是XX" |
| 3 | 无百分比数字 | 不出现患病率、转化率、有效率 |
| 4 | 无品牌/厂商 | 画面、字幕、口播均无厂名、无系统 Logo、无设备品牌 |
| 5 | 无医院可识别信息 | 白大褂无院名、墙面无院徽、无院牌（A 号发布时由医院自行加片尾） |
| 6 | 无价格 | 全片不提任何金额 |
| 7 | 无真人肖像风险 | 无患者正面、无医生正面；实拍人物已签肖像授权（如有） |
| 8 | 字幕与配音一致 | 逐句核对，字幕不得自行改写 |

> **任一条不过，不发。**医疗类账号一次违规，限流是长期的。

### 2. 平台侧风险词（发布时避开）

| 类别 | 避开用词 | 替换说法 |
|---|---|---|
| 疗效类 | 治好、根治、有效、见效、改善、恢复、逆转 | 训练、练一练、保持在被使用的状态 |
| 绝对化 | 最好、第一、唯一、彻底 | 删掉，或改"其中之一" |
| 诱导类 | 必看、速看、震惊、99% 的人都 | 删掉 |
| 诊断类 | 自测、测出你有、一键诊断 | 评估、查一查、由医生判断 |
| 恐惧类 | 不治就晚了、会痴呆、等着瘫痪 | 早查早练、越早越省力 |

### 3. A 号（医院号）特有的两道关

1. **医院宣传科/科教科审核**：通常要求提供资质（二类械证复印件）、内容不涉及疗效承诺、不出现商业推广。→ 提前把《注册证》《适用范围》备好一并提交。
2. **不得出现"第三方公司"字样**：医院号发布的科普片里不写我方公司名，服务内容以"科室开展的居家训练"表述。

## 六、发布后（很多人漏掉的一半）

| 时点 | 动作 |
|---|---|
| 发布后 1 小时 | 检查是否被限流（播放量长期停在个位数=可能被限）；核对封面与标题显示正常 |
| 发布后 24 小时 | 看**完播率**：<15% → 前 3 秒不够抓人，剪新版；>35% → 内容成立，可加投 |
| 第 3 天 | 看**转发数**：转发 > 点赞 的 1/10 → 家属在自发传播，这条值得复制成系列 |
| 第 7 天 | 汇总数据（播放/完播/转发/评论高频问题）→ 高频问题变成下一条选题 |
| 每条发布后 | 归档：成片 + 分镜 + 数据截图，存 `04_科普视频与公众号稿/成片归档/` |

**评论区运营三条**：
1. 问"能不能治好"→ 回"需由医生评估，建议到门诊咨询"（**不承诺、不解释疗效**）。
2. 问"多少钱"→ 回"费用需按医生制定的方案确定，可到门诊咨询"（**不在评论区报价**）。
3. 问"哪里能做"→ A 号回本院科室；B 号回"目前与多家医院合作开展，具体可私信了解"（**不列医院名**）。

## 七、一稿多用的四条延伸（做完这支片，还能出什么）

| 延伸物 | 怎么做 | 成本 |
|---|---|---|
| 公众号图文 | 文字稿 + 分镜截图 → 排版成图文，标题用拆条标题 | 1 小时 |
| 候诊区静音版 | 主版去掉配音、加大字幕、加背景音乐 | 半小时 |
| 展板二维码 | 主版传视频号 → 生成二维码 → 印在展板底部（医院决定是否加） | 10 分钟 |
| 科室会开场片 | 主版剪到 90 秒（第一段+第五段），科室会开场放 | 半小时 |

## 八、这一版要先解决的三个待定项

| # | 待定 | 影响 | 建议 |
|---|---|---|---|
| 1 | 首发号选 A（医院科室号）还是 B（企业号） | 决定片尾、审核流程、发布时间 | **建议 A**，医院信任度高；企业号同素材另发 |
| 2 | 配音用真人还是 AI | 决定成本与档期 | **建议真人**（本片共情句多，AI 音容易露） |
| 3 | 实拍是自己拍还是外包 | 决定周期（自己拍 1 天 vs 外包 3–5 天） | 本片实拍只有 7 个场景、无真人正面，**建议自己拍** |
