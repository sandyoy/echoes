## 读法说明（给拍摄和剪辑的人）

1. **【镜号】** 是拍摄/剪辑的最小单位，一个镜号 = 一次镜头。
2. **【画】** = 镜头里要出现什么；**【动】** = 镜头怎么走（推/拉/摇/移/固定）。
3. **【字幕】** = 屏幕文字，**视频号必须全程上字幕**（大量静音观看）。
4. **【配】** = 配音对应的原文，**一个字不许改**。
5. **【拍法】**：`实拍` / `素材`（附中英搜索词）/ `动画`（附做法）。
6. **⭐** = 关键镜头，决定片子成不成，不要省。

## ⚠️ 拍摄前必须知道的四条红线

| # | 红线 | 落地做法 |
|---|---|---|
| 1 | **零真人** | 不出现患者面部、不出现医生正面（用背影/手部/侧影/虚化） |
| 2 | **零医院可识别信息** | 白大褂不绣院名、墙上无院徽、病历本无院名、门口无院牌 |
| 3 | **零疗效承诺** | 画面无对勾✅、"有效""改善""治愈"字样、无康复前后对比照 |
| 4 | **零品牌厂商** | 平板/设备上不出现厂商标识、不出现系统界面里的公司 Logo |

> **额外一条（本片特有）**：认知训练的画面**不出现"痴呆老人"刻板形象**（呆坐、流口水、走失）——本片面向的是"还好好生活着、但有点变化"的人群，画面要让人愿意代入，不是让人害怕。

## 视觉母题（本片唯一的设计语言）

**一片"亮起来的格子"。**

- 出现位置：片头 1 镜、第二段六域图、第四段"记位置"任务、第五段数据回传。
- 做法：3×3 或 4×4 网格，某一格亮起 → 熄灭 → 再亮另一格。**全片这一个动效贯穿**，观众看到格子就想到"大脑在被使用"。
- 好处：不依赖鹤灵系统截图（无厂商 Logo 风险），纯几何动画，剪映模板即可做。
