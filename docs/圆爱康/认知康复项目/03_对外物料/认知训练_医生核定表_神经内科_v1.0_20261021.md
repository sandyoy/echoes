# 认知训练 · 医生核定表（神经内科 · 成人版）

> 版本：v1.0 · 2026-10-21 · 小鲸鱼
> 用途：**科室落地第一张表**。医生用它做两件事——① 判定患者能不能进居家认知训练 ② 定初始训练任务与难度。表由医生填写签字，不替代医嘱。
> 打印建议：A4 双面，一患者一份，随病历归档；系统内同步一份电子记录。
> 配套：与《认知康复居家彩页 v3》《认知康复口径与话术卡》口径一致。

---

## 使用说明（给科室，3 行看完）

1. 表分三段：**准入判定 → 训练方案设定 → 阶段性复核**。第一段不通过，后两段不用填。
2. 医生只填打勾和数字，**不需要写长文字**。
3. 第三段在首个疗程节点（默认第 30 天）复核一次，决定续、调、停。

## 附 · 填表口径五条（科室内部用）

1. **准入判断权在医生**：第三方不设定临床标准，不替代医嘱；表内所有分层、受损、准入、方案，均由医生填写。
2. **系统只作参考**：注册证明示「不具备自动诊断功能」，系统输出的是评估数据与建议值，不是诊断结论。
3. **任务与难度由医生定**：系统给建议方案，医生可增可减可换，不预设、不强制。
4. **数据落点在医生端**：训练数据第一落点在系统医生端，医生随时调阅；医院需要报表由我方整理提供。
5. **不写疗效**：本表所有复核结论只写「继续 / 调整 / 停止」，不写「有效 / 改善 / 好转」。
