### 【第 2 面 · 内页 · 院内段】

**版面结构**：三栏纵向排版，标题带序号，表格用浅灰底。

**开篇：一、患者入组后的管理路径**

- 标题行：「一、患者入组后的管理路径」＋ 金线分隔
- **闭环动线图**占本面**上半部约 60% 高度**，横向铺开：
  - ①进来 → ②评估 → ③分层 → ④A 认知功能下降 / ④B 原发病诊疗 → ⑤转入居家 → ⑥全程管理
  - 六边形或圆角矩形节点 + 金色箭头；④A / ④B 为并行双支，最后汇入 ⑥
  - 底部一行小字：**「院内段由 CMS 管理，出院后由居家康复系统承接——两段衔接，形成完整闭环」**
- 动线图下：两栏对照表（认知功能下降 / 需先行诊疗原发病），浅灰底、深绿表头
- 收尾一句（加粗）：**「最终，神经内科认知功能下降患者均纳入统一管理，实现患者管理无断点。」**

**第二块：二、院内段：CMS 患者管理系统**

- 标题行：「二、院内段：CMS 患者管理系统」
- 三行端口表（医护 PC 管理端 / 医生管理小程序 / 患者使用小程序），**每行左侧配端口图标**（PC / 手机 / 患者头像）
- 表下两条要点（可独立部署 / 支持模块化拆用），用金点引导
- 底部一句灰底提示：**CMS 覆盖四类管理场景：专科管理 / 居家衔接 / 运营统计 / 筛查与活动入组**

**第三块：三、居家治疗模块**

- 标题行：「三、居家治疗模块」
- 引语一句：由医生按临床需要选用、组合，各模块并列，不预设先后与主次
- **两个模块并列成左右两栏**（视觉等权重，不得一大一小）：
  - **左栏 · 模块一 认知训练（评估驱动）**：系统名称 +「国家二类医疗器械」＋五条要点表（建模标准 / 训练任务 / 难度分级 / 评估量表 / 评估逻辑）
  - **右栏 · 模块二 经颅磁刺激（居家）**：设备名称 +「国家二类医疗器械」＋注册证号 + 型号 + 适用范围原文（加引号）＋ 三条使用说明（按方案执行回传 / 禁忌筛查 / 不适停用）
  - 两栏下方合并一行：**两者均为非药物手段，均可在居家场景开展，按需选用，相互独立。**
- ⚠️ 经颅磁栏**不做能力介绍、不讲原理**，仅证原文＋使用要求——sandy 定。

**第四块：四、六师共管 · 全程协同管理**

- 标题行：「四、六师共管 · 全程协同管理」
- 两行角色表（院方 3 角色 / 圆爱康 3 角色），**左右两列并排**，中间用「＋」或竖线连接
- 底部一行加粗：**六师共管贯穿院内与居家两段，是服务执行的保障机制。**

### 【第 3 面 · 内页 · 居家段】

**版面结构**：左图右文或上图下文，保持与第 2 面同一网格。

**开篇：五、院内外衔接：出院后训练的持续开展**

- 标题行：「五、院内外衔接」
- **顶端一条横向流程带**：院内 CMS →（箭头）→ 出院 →（箭头）→ 居家康复系统，三段色块递进
- **左右两栏卡片**（等宽）：
  - **左卡 · 医生端**：三条要点（查看方案与执行回执 / 时长与完成度可追踪 / 可远程调整任务与难度）
  - **右卡 · 患者端**：三条要点（平板手机小程序居家训练 / 任务清晰难度自适应 / 居家经颅磁按医嘱使用）
- 中段一句加粗：**院内段与出院后两段衔接，构成院内—居家完整闭环，亦即智慧居家康复的完整形态。**
- 下半部：**患者管理全过程横向流程条**（建档入组 → 方案下发 → 居家训练 → 依从性跟踪 → 记录回传 → 远程调整 → 复诊衔接），七段箭头串联，字号略小

**第二块：六、服务类型：三类，按时长选用**

- 标题行：「六、服务类型：三类，按时长选用」
- 引语：由医生评估后确定服务类型与时长档
- **三行服务表**（认知训练 / 居家经颅磁 / 组合套餐），表头深绿、行间浅灰
  - 组合套餐行可加金边强调（**不加价格**）
- 表下三条共同保障（金点引导）
- 底部一行：院内配套项目由科室按自身条件组合
- **页面最下方一行小字**：选用原则——具体服务类型、时长档及是否适合开始，以医生评估意见为准。（价格另附销售价目单）

### 【第 4 面 · 封底】

**版面结构**：上密下疏，文献表压底。

**开篇：七、数据与服务保障**

- 标题行：「七、数据与服务保障」
- **上方四段式链条图**：评估（院内 CMS）→ 训练（居家→医生端）→ 回传（医生端）→ 复诊（院内 CMS），配小图标
- **四行数据表**（环节 / 数据落点 / 用途），浅灰底
- 三行角色化要点（金点引导）：**医生掌握**｜**患者执行**｜**团队跟进**｜**数据可追溯**
- 中段一行加粗：**服务可追溯**——入组登记 → 方案下发 → 居家执行 → 依从性跟进 → 记录回传 → 复诊衔接，每一环有记录、可查证
- **四道安全线**：做成 2×2 小卡片（评估线 / 医嘱线 / 设备线 / 停用线），每卡一行说明，卡左缘金线
- 收尾一句（深绿底色条）：**与院内一致的医疗规则，延伸到患者家中。**

**第二块：八、适用人群（面向神经内科 / 康复科）**

- 标题行：「八、适用人群」
- 四条要点，前置金色小圆点（MCI 辅助康复训练 / SCD 认知储备训练 / AD 等所致认知障碍居家辅助训练 / 脑卒中后·帕金森伴认知下降康复期人群）
- 末行灰色小字：具体适用与禁忌由医生结合患者情况判断，本页不替代医嘱

**第三块：九、依据的权威文献与标准**

- 标题行：「九、依据的权威文献与标准」
- **四行文献表**（文献 / 标准 ｜ 用途），字号 10.5–11 pt，行高紧凑
- 底部一行灰字：学术共识指出——认知训练是非药物干预的重要组成部分；具体适用与禁忌，由医生结合患者情况判断。
