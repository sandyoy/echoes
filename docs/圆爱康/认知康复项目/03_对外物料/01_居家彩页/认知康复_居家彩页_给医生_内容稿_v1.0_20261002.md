# 圆爱康 · 认知康复 居家彩页（给医生看）

版本：v1.0 · 2026-10-02 · 小鲸鱼起草
**用途：只给医生看。** 医生第一次接触这个项目，正面看"这是什么东西、靠不靠谱"，背面看"我作为医生要做什么、患者怎么进来"。
患者不看这张纸。面向主任/神经内科·康复科门诊医生，面谈时递过去。

> 形态：一张纸，双面。正面 = 项目与证据；背面 = 落地动作与合规口径。
> 红线：不印价格；不出现疗效百分比/替代手术类承诺；不写"能看到患者动作是否标准"。

## 【正面】项目与证据 —— 这是什么东西，凭什么靠谱

### 主标题
**认知康复 · 把认知训练延伸到患者家里**

### 一句话（页首）
把医院神经内科、康复科的认知评估与训练能力，通过"评估—训练—回看"闭环延伸到患者家中；医生开方案、看数据、调难度，患者在系统指导下居家训练。

### 一、我们做什么（核心手段：认知训练）

- **主体是认知训练**，不是泛泛的"行为干预"——按国际通用诊断标准 **DSM-V 六大认知域**建模：
  复合注意 / 学习记忆 / 知觉运动 / 语言言语 / 执行抑制 / 社会认知
- **六个模块 · 36 个标准训练任务**（可依临床需要自定义扩展到 50 个）
- **每个任务 6 级难度**，按评估结果自适应匹配
- 配套 **55 个量表**（覆盖认知、语言、睡眠、日常生活能力）。

### 二、凭什么靠谱（可核验的硬依据）

| 依据 | 内容 |
|---|---|
| **器械资质** | 核心系统为**国家二类医疗器械**（鹤灵"数智化认知评估与训练系统"） |
| **学术底座** | 基于 DSM-V 六大认知域模型；专家方案参照《阿尔茨海默病康复管理中国专家共识（2019）》《中华老年医学杂志》及 DSM-5 相关标准 |
| **收费正规性** | 对应项目在医疗体系内有正式收费编码（认知功能检查/认知功能训练/认知知觉功能障碍训练/量表评估），证明该服务被正规医疗体系认可（**本页不印价格**） |
| **临床团队** | 首席科学家 = 宋鲁平教授（牵头《阿尔茨海默病多元康复干预中国专家共识 2025》） |

> ⚠️ 内部注：器械为合作方鹤灵产品，注册人为其主体；对外注明即可，不冒充自有注册证。

### 三、这套系统的逻辑：评估驱动（不是拍脑袋分档）

```
① 多维评估（六大认知域）
        ↓
② 系统算出「认知轮廓图」（雷达图）——直观呈现脑认知障碍的范围与程度
        ↓
③ 每个任务给出：正确率 + 该任务测的能力 +「建议起始难度（1–6级）」
        ↓
④ 一键跳转 → 训练系统按建议难度开始训练
        ↓
⑤ 后台看训练记录 → 医生据此调整难度与任务
```

**一句话：无评估，不康复。** 难度不是医生手填的，是评估算出来、医生再核定的。

## 【背面】落地动作 —— 我（医生）要做什么，患者怎么进来

### 四、医生端看到什么 / 患者端看到什么

| | 医生端 | 患者端 |
|---|---|---|
| 看什么 | 患者认知轮廓图（雷达图）＋ 各任务正确率＋建议起始难度＋训练记录 | 系统安排的训练任务（按建议难度）＋ 指引 |
| 做什么 | 核对/调整任务与难度、看训练回执 | 按系统指引完成居家训练 |
| 记录什么 | 训练时长与完成度可追踪 | — |

**⚠️ 对外表述红线：只能说"训练时长与完成度可追踪"，绝不能说"能看到患者动作是否标准"。**

### 五、患者怎么进来（渠道清晰，责任分明）

- 入口 = 医院/科室公众号（开放接口即可）→ 患者跳转至圆爱康小程序/H5 完成操作，**机构无需开发**。
- **每个科室在系统里是独立"渠道"** → 患者一进来就打上来源标签 → **病源归属、数据归属、服务责任清清楚楚**。
- 数据第一落点 = 圆爱康系统医生端，医生实时可看；医院需要数据，由我们整理提供。

### 六、合规口径（给医务科的定心丸）

> **医疗行为留在贵院**：所有评估/训练方案由贵院医生核定，医疗主体责任在贵院；
> **执行与运营由圆爱康承担**：设备、系统、客服跟进、运营端管理。
> 责任边界清楚，经得起审计。

### 七、哪些患者适合（面向神经内科 / 康复科）

- 轻度认知障碍（MCI）的辅助康复训练
- 主观认知下降（SCD）人群的认知储备训练
- 阿尔茨海默病等原因造成认知障碍的居家辅助训练
- 脑卒中后/帕金森病等伴认知功能下降的康复期人群
- ⚠️ 具体适用与禁忌由贵院医生结合患者情况判断，本页不替代医嘱
