# 【第 2 面 · 内页·院内段】

## 一、患者进来之后，是怎么被管起来的

### 闭环动线（示意图）

```
   ①进来                ②评估                 ③分层
患者进入          六大认知域评估            一次评估，
神经内科门诊·住院   （系统出认知轮廓图）       分出两条路
                          │
          ┌───────────────┴───────────────┐
          ▼                                ▼
   ④A 认知功能下降                    ④B 原发病诊疗
   进入居家认知康复                   由科室按临床路径
   评估驱动、分层训练                   诊疗原发病
          │                                │
          │                                ▼
          │                         ⑤病情稳定后转入居家认知康复
          │                         训练维持、延缓下降
          └───────────────┬───────────────┘
                          ▼
                ⑥管起来 —— 一条闭环
        院内段由 CMS 患者管理系统管
        出院后由居家康复系统接着管
        ── 两段接上，就是一条闭环 ──
```

**建档入组** → 患者进入神经内科门诊 / 住院，**由科室医生完成认知评估**（六大认知域 + 相关量表）

**一次评估，分出两条路：**

| | 认知功能下降 | 需先诊疗原发病 |
|---|---|---|
| **去向** | 进入居家认知康复，按评估结果分层训练 | 由科室按临床路径诊疗原发病（卒中 / 帕金森 / AD 等） |
| **之后** | 持续训练管理，延缓认知下降 | 病情稳定后转入居家认知康复，维持训练 |

**最终——神经内科认知下降患者都被纳入管理**，不再有「看完门诊就断了」的患者。

## 二、院内段：CMS 患者管理系统

**CMS 患者管理系统 —— 我们把科室里的患者管起来：**

| 端口 | 使用者 | 管理内容 |
|---|---|---|
| **医护 PC 管理端** | 科室医护 | 患者档案、训练方案录入下发、训练数据查看、依从性监测、复诊提醒、科室治疗量统计 |
| **医生管理小程序** | 科室医生 | 随时查看患者数据、调整训练方案、接收消息提醒（碎片时间也能管） |
| **患者使用小程序（预约）** | 患者 | 预约登记、训练记录查看、就诊提醒、健康信息填报 |

- **可单独部署**，也可与居家系统组合成完整体系
- **可按模块拆用**，科室按需选用

> CMS 覆盖四类管理场景：**专科管理 / 居家衔接 / 运营统计 / 筛查与活动入组**。

## 三、六师共管 · 全程有人管

患者从院内到居家，全程不是一个医生在扛，而是一个团队：

| 组别 | 角色 | 负责什么 |
|---|---|---|
| **院方** | 医生、康复师、护士 | 认知评估判断与训练方案 |
| **圆爱康** | 线上客服、线下督导、设备工程师 | 执行、跟进、设备保障 |

> 患者无论住在院内还是回家，**都有人跟着、有人管着**。

## 四、核心能力：评估驱动的认知训练系统

**鹤灵「数智化认知评估与训练系统」**（国家二类医疗器械）

| 项 | 内容 |
|---|---|
| **建模标准** | 按国际通用诊断标准 **DSM-V 六大认知域**建模：复合注意 / 学习记忆 / 知觉运动 / 语言言语 / 执行抑制 / 社会认知 |
| **训练任务** | **六个模块 · 36 个标准训练任务**（可依临床需要自定义扩展至 50 个） |
| **难度分级** | **每个任务 6 级难度**，按评估结果自适应匹配 |
| **评估量表** | 配套 **55 个量表**（覆盖认知、语言、睡眠、日常生活能力） |
| **评估逻辑** | 多维评估 → 系统算出**认知轮廓图**（直观呈现障碍范围与程度）→ 每个任务给出正确率 + 建议起始难度 → 医生一键开训 → 训练记录回传、医生调难度 |

> **一句话：无评估，不康复。** 难度不是医生手填的，是评估算出来、医生再核定的。

## 五、新增手段：居家经颅磁刺激治疗（与认知训练并列）

**经颅磁刺激治疗仪**（国家二类医疗器械）
- 注册证号 **苏械注准 20192090432**｜型号 **EK-9100A 家庭款**（可居家使用）
- **适用范围（注册证原文）**：**「适用于缺血性脑血管病、神经衰弱、脑损伤性疾病的辅助治疗」**
- 注册人：江苏亿康电子科技有限公司（设备由厂家提供，圆爱康负责居家服务与系统承接）

**与认知训练的关系**：两者是**并列的非药物手段**，**均可居家进行，可按医生判断灵活组合**（都居家 / 一院内一居家）。

> ⚠️ 经颅磁按注册证适用范围使用；具体是否适用、如何安排，**由医生结合患者情况判断**。

# 【第 3 面 · 内页·居家段】

## 六、出院回家之后，训练接着走

患者出院回家后，康复由**智慧居家康复系统**承接 —— **医生掌握、患者执行、有人跟进**：

**医生端**
- 查看患者训练方案与执行回执
- 训练时长与完成度可追踪
- 可远程调整任务与难度

**患者端**
- 平板 / 手机 / 微信小程序（鹤灵脑星球），在家即可训练
- 每次训练任务清晰可执行，难度随进度自适应
- 居家经颅磁按医嘱使用

**两段怎么接上**
- **院内段** → CMS 管理：患者、训练路径、依从性、复诊，全在 CMS 里
- **出院** → 转入居家康复系统：训练方案在院外延续
- **合起来 = 院内—居家完整闭环**：这也是**智慧居家康复**的完整形态

**患者是怎么被管着的（一条管理过程）**：
建档入组 → 医生核定训练方案并下发 → 患者居家训练（系统按日推送任务）→ 执行情况被跟踪，未坚持的有人提醒 → 训练记录回传供医生查阅 → 医生按数据远程调整难度 → 复诊衔接

## 七、服务类型：三类，按时长选用

患者转入居家康复，**由医生评估后确定服务类型与时长档**：

| 服务类型 | 内容 | 规格档 |
|---|---|---|
| **① 认知训练** | 鹤灵认知评估与训练系统（居家端） | 30 天 / 60 天 / 12 个月（时长内不限次数） |
| **② 居家经颅磁** | 经颅磁刺激治疗仪（EK-9100A 家庭款） | 10 送 2 / 20 送 5 / 30 送 5 |
| **③ 组合套餐** | 认知训练 ＋ 居家经颅磁 | 30 天＋10 送 2 / 60 天＋20 送 5 / 12 个月＋30 送 5 |

**三类的共同保障：**
- **训练内容与评估内容由医生在系统内自行安排**，不预设、不强制
- **六师共管**（全程有人管，见第 2 面）
- 训练记录回传医生端，医生随时可见

**院内配套项目**（认知量表评估、影像检查、血液检查、专科诊疗等）**由科室按自身条件组合**。

> **怎么选**：具体选哪一类、选哪一档、是否适合开始，**以医生评估意见为准**。

**阶梯难度（按评估结果匹配）**：

| 难度层 | 目标 |

| **6 级以上** | 常模增强 —— 对标常模水平持续强化 |

## 十、哪些患者适合（面向神经内科 / 康复科）

- 轻度认知障碍（MCI）的辅助康复训练
- 主观认知下降（SCD）人群的认知储备训练
- 阿尔茨海默病等原因造成认知障碍的居家辅助训练
- 脑卒中后 / 帕金森病等伴认知功能下降的康复期人群
- ⚠️ 具体适用与禁忌由医生结合患者情况判断，本页不替代医嘱
