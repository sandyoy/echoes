## 二、只可口头说、不印进物料的

| 内容 | 为什么不能印 |
|---|---|
| 医保发〔2019〕47 号 具体内容 | 涉及医保支付，印进物料易被理解为"能走医保" |
| 认知功能检查/训练/知觉障碍训练/量表评估有收费编码 | 可口头说"证明被正规医疗体系认可"，**印进物料易被理解为"可医保报销"**；且编码各地不一 |
| MCI 转痴呆的年转化率（各文献 5%–15% 不等） | **不同研究差异大、随访人群定义不同**，引用任意一个都站不住；对外一律不报数字，只说"进展性、有相当比例会进展" |
| 中国认知障碍患病率 | 各研究口径差异极大（年龄分层/诊断标准不同），**不报具体百分数** |
| "认知训练可降低痴呆风险 X%" | 现有证据强度不足以支撑因果性承诺，属疗效宣称，**禁用** |
| 经颅磁对认知的作用 | 注册证适用范围不含认知障碍，**任何场合不得表述"经颅磁改善认知"** |

## 四、被追问时的标准应对（口头话术）

| 追问 | 怎么答 |
|---|---|
| "有没有临床研究证明有效？" | "认知训练作为非药物干预方式，国内外指南里有相应推荐。我们这个系统是二类医疗器械，注册适用范围是轻度认知障碍的辅助康复训练——**我们只说注册范围内的话，不承诺疗效**。具体到某位患者适不适合、有没有效果，由医生评估判断。" |
| "训练多久能见效？" | "这个不能一概而论，取决于患者基线、训练依从性和原发病情况。我们能保证的是：训练时长和完成度可追踪，医生随时能看到数据、随时调整方案。**效果由医生评估，我们不做承诺**。" |
| "跟别的认知训练 App 有什么区别？" | "区别在三点：①**先评估后训练**，不是上来就做题目；②**数据第一落点在医生端**，医生远程调难度，不是患者自己练自己的；③**院内院外一条线**，出院不断档。" |
| "经颅磁是不是也能改善认知？" | "经颅磁的注册适用范围是缺血性脑血管病、神经衰弱、脑损伤性疾病的辅助治疗，**不含认知障碍**。我们把它作为神经内科场景下的非药物辅助治疗手段提供，认知这一块讲的是认知训练。两法都可在居家开展、可按医嘱组合，但**不讲组合疗效**。" |
| "能不能进医保？" | "**一律自费**。收费编码只是说明这类服务在医疗体系内有正式项目、被正规体系认可，不作为我们定价或支付的依据。" |

## 五、出稿自检（本表核过）

- ✅ 无任何疗效百分比、无转化率
