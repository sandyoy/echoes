# 神经线「干预训练」到底是什么 — 卒中老人能用吗（查证）

日期：2026-10-27 · 小鲸鱼
用途：回答 sandy 三问 —— ①我们神经线的干预训练里有行为干预训练吗 ②对卒中老人的训练强度有多大 ③卒中有语言/行为障碍，我们的训练还有效吗
证据来源：自家产品原件（注册证／36任务清单／服务包）+ PubMed 原文摘要（每篇都标 PMID，可回溯）

---

## 直接结论（先看这三行）

1. **有，而且“行为干预”就是我们那套认知训练的名字**。它不是另一种疗法，就是鹤灵认知训练系统在套餐表里的叫法（套餐表原文：入口二「行为干预套餐」＝只有认知训练）。
2. **对卒中老人，能覆盖的是“认知”这一层，强度是“泛认知训练”，不是“针对卒中的专项康复”**。系统按 DSM-5 六大认知域建模、按 GDA/GDS 分六个难度档，卒中患者多数落在“评估后自动匹配难度”这条路上。**它不是偏瘫肢体训练，也不是言语治疗。**
3. **“卒中必然有语言障碍/行为障碍”这句话是错的，不能这么讲**。卒中后认知障碍很常见、抑郁约 1/4、失语只占一部分。**正确姿势不是“人人都有障碍所以我们有效”，而是“先评估筛出有认知问题的人，再给他配训练”——评估驱动，这是我们的真优势。**

## 一、我们的“干预训练”到底是什么（产品原件坐实）

### 1.1 主体＝一套软件，不是一台机器

| 项 | 内容 |
|---|---|
| 产品名称 | 认知功能评估与训练软件（鹤灵） |
| 注册证 | 粤械注准20232070187（二类，有效期至 2028-06-13） |
| **证面适用范围（原文，一字不改）** | **适用于轻度认知障碍的辅助康复训练，不具备自动诊断功能** |
| 结构 | 评估模块 + 训练模块 + 用户管理 + 系统管理 |
| 任务库 | 6 大认知域 × 共 36 个任务，每任务设 6-12 个难度 |
| 难度依据 | 总体衰退量表（GDS）7 期映射；重度/极重度不纳入适用人群 |

### 1.2 “行为干预”这个名字的由来（重要，别被名字骗）

- **套餐表原文**：入口二 = 「**行为干预套餐**」= 只有认知训练（鹤灵系统）。入口一 = 「综合套餐」= 认知训练 + 经颅磁。
- 所以：**行为干预 = 认知训练**，两者在我们体系里是同一个东西的两个叫法。行为干预是大范畴（认知训练本身属非药物干预），**不作 BPSD（精神行为症状）窄口使用**——这条是 2026-10-01 定过的口径。
- 对外物料一律写“认知训练”，**不写“行为干预训练”**（避免被理解成心理治疗/行为矫正）。

### 1.3 36 个任务，覆盖认知的六个面（这是“训练什么”的答案）

| 模块 | 覆盖 | 对卒中老人的意义 |
|---|---|---|
| 复合注意 | 持续/选择/分配注意、加工速度 | 卒中后最常见的问题之一：走神、反应慢、容易分心 |
| 学习记忆 | 瞬时/短时/语义/再认 | 记不住刚说的话、忘了东西放哪 |
| 执行抑制 | 计划、决策、抑制、灵活 | “想好了又做不出来”、做事没条理 |
| **语言言语** | 命名、找词、流畅性、语法、理解 | **有语言障碍的人，练的是这一块** |
| 知觉运动 | 视知觉、空间、手眼协调 | 偏侧忽视、找东西找不到 |
| 社会认知 | 情绪再认、表情识别 | 认不出家人的情绪、变得“不像原来那个人” |

> 这张表的用法：**不是“卒中老人什么都练”，而是“评估出来哪块弱，就练哪块”**。评估 → 认知轮廓图 → 建议起始难度 → 医生一键开 → 训练 → 数据回传调难度。

## 二、对卒中老人，这个训练有多强的依据（PubMed 实证，标 PMID）

### 2.1 卒中后认知障碍到底有多普遍（这决定我们要不要做这个人群）

| 结论 | 出处 | 怎么用 |
|---|---|---|
| 卒中后认知障碍极常见，且**基线已有认知损害是最强的预测因子**（PSCI 风险比 2.00，卒中后痴呆 3.10） | *Lancet Healthy Longev* 2024（PMID **38101426**，89 项研究、160,783 人） | 可写：卒中后认知问题常见、且早期就有 → 出院时评估有必要 |
| 卒中后抑郁总体患病率约 **27%**（1 年累积 38%，71% 在 3 个月内起病） | *PLoS Med* 2023（PMID **36976794**，77 项研究） | ⚠️ 只可讲“情绪问题常见”，**不可讲我们能治抑郁** |

> ⚠️ 这两条都**只是流行病学**，不证明我们产品有效。用法＝说明“这个人群的需求真实存在”，不越界。

### 2.2 认知训练对卒中人群有没有效（这才是我们要的“有效性”依据）

| 证据 | 出处 | 关键数字 | 能支撑我们说什么 |
|---|---|---|---|
| **计算机辅助认知训练（CACT）在卒中后认知障碍中排名第一**，27 项 RCT 网络荟萃 | *J Med Internet Res* 2025（PMID **40705404**） | 相比常规康复，MoCA 提高 **MD 3.03**（95%CI 1.69–4.38），SUCRA **91.53%**（第一） | ✅ 这是最硬的一条：**我们这类“软件化认知训练”正是被证明最有效的那一类**（不是 VR、不是机器人） |
| **有实证支持的认知康复（EB-CR）系统综述**，循证认知康复的权威文献 | *Arch Phys Med Rehabil* 2019（PMID **30926291**） | 对注意、记忆、语言、执行等分域给出推荐等级 | ✅ 支撑“认知训练是分域做的、有标准做法” |
| 虚拟现实康复训练对卒中后认知与日常生活能力有效 | *Arch Phys Med Rehabil* 2022（PMID **35417757**，21 项 RCT、1149 人） | MMSE/MoCA/日常生活能力均改善 | 🟡 佐证“数字化训练有效”，但我们不是 VR，不可说等同 |
| 有氧运动 + 计算机化认知训练（多中心 RCT） | *Top Stroke Rehabil* 2022（PMID **34340637**） | 联合组优于单做 | 🟡 支撑“训练要成体系、不是随便做题” |
| 计算机化认知训练对认知、活动与参与的影响（RCT） | *NeuroRehabilitation* 2022（PMID **35311716**） | 认知与参与均改善 | 🟡 备引 |

### 2.3 经颅磁这边（我们套餐里的另一半）

| 证据 | 出处 | 关键数字 | 怎么用 |
|---|---|---|---|
| rTMS + 认知训练对卒中后认知障碍 | *Ageing Res Rev* 2023（PMID **37004840**，8 项 RCT、336 人） | 整体认知 **g=0.78**、执行 **0.77**、工作记忆 **0.61**、日常生活能力 0.42；**记忆与注意无效** | ⚠️ **只能作为“学术上有人这么做”的背景，不能当我们的产品宣传**——因为我们注册证适用范围是“缺血性脑血管病、神经衰弱、脑损伤性疾病的辅助治疗”，**不含认知障碍**；且我方无自有数据，禁讲“组合疗效” |

## 三、三句话的边界：“卒中→语言障碍/行为障碍→所以我们有效”（这个推理链不能用）

### 3.1 错在哪

- **“卒中必然有语言障碍”是错的**：失语是卒中的常见后遗症之一，但**远不是全部**；很多卒中患者语言完好，问题在运动、在注意、在记忆。
- **“行为障碍”这个说法本身就偏**：卒中后更常见的是**抑郁（约 27%）、淡漠、情绪不稳、执行功能下降**，这些在临床上和家属口中常被说成“脾气变了/不像原来那个人”，但它不等于精神行为症状（BPSD，那是痴呆的术语）。我们不做这一块。
- **逻辑上更危险**：如果按“人人都有障碍 → 所以我们有效”去讲，等于**承诺对所有卒中患者有效**——这正是医疗器械广告最容易被判违规的表述（超出注册证适用范围 + 疗效承诺）。

### 3.2 我们能站得住的推理链（换这一条）

> **卒中后认知问题常见（有文献数）→ 所以出院时要评估 → 评估出哪一域弱 → 就练哪一域 → 训练有量、有记录、医生能调 → 才谈得上有没有用。**

关键差别在主语：**不是“卒中老人都有障碍”，而是“先评估，评估出有认知问题的那部分人，才是我们的人”。** 这条链里每一环都有出处，而且不需要承诺疗效。

### 3.3 落到嘴上的两句标准答

**对医生（科室会/随访）**
> “卒中后认知障碍很常见，指南里也把认知训练列为非药物干预的常规手段。我们这套是二类医疗器械，注册适用范围是轻度认知障碍的辅助康复训练——所以我们的用法是先评估，评估出认知域的问题再针对性练，不是所有人都上来做题。训练时长和完成度会回到你这边，方案你随时能调。”

**对家属（内容/评论）**
> “中风以后记性差、反应慢、做事没条理，这些不一定是‘老了’，也不一定自己会好。要不要练、练哪一项，得先做评估。练什么、练多少，由医生定——家里能做的是陪着练、把记录留好。”

## 四、⚠️ 对第 8 周主线的影响（必须改，否则会写错）

第 8 周主轴原定“讲训练三要素（方案／量／记录）”，落点 A2 是**卒中**。查完证据后要修三处：

| # | 原写法 | 必须改成 |
|---|---|---|
| 1 | 讲“卒中老人回家最缺训练”，暗示肢体康复 | **明确讲“认知训练”这一层**，不碰偏瘫肢体训练、不碰言语治疗（那是言语治疗师的活） |
| 2 | 可能写成“中风后多少都会有说话/行为问题” | **禁写**。改“中风后有不少人会出现记性、注意力、反应速度的问题，也有的会出现说话找词困难，程度因人而异” |
| 3 | 可能用“我们有效”作结 | 改“**有效没效，要看有没有评估、有没有量、有没有人看数据**”——把判据交给流程，不交给产品 |

> **一句话**：第 8 周能讲、且站得住的正面机制是「**评估驱动 + 训练有量 + 数据回医生端**」，不是「我们的训练有效」。
