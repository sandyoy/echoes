# 「不评估，不给练」硬立场 v1.0

日期：2026-10-27 · 小鲸鱼
**定性：sandy 2026-10-27 拍定 —— 这是一条对外的硬立场，不只是内部流程说明。** 原话：「不评估，不给练，这一点是可以的。把它写进去吧。」
用途：认知康复线（成人神经内科 / 儿童 ADHD）对外全部物料、话术、GEO 内容、科室会、销售应答的**统一入口立场**。凡讲"我们这套训练怎么用"，开口第一句就是这条。

---

## 一、立场原句（对外统一这几句，不再自创变体）

| 场合 | 标准句 |
|---|---|
| **主句（八字）** | **不评估，不给练。** |
| 展开句（一句说清为什么） | 没做评估，就没有认知轮廓图，也就不知道要练哪一域、从几级起步——练了也不算康复，只是做题。 |
| 讲完整流程时 | 先评估 → 出认知轮廓图（哪一域弱、弱到什么程度）→ 系统给各任务建议起始难度 → 医生一键开训 → 患者在家练 → 训练记录回传医生端 → 医生据此调难度与任务。**中间任何一环断掉，这条链就不成立。** |
| 遇到"能不能先练着看" | 不建议。先评估，评估结果说话——这也正是我们和别人不一样的地方。 |

**与原口径的关系**：原来的「无评估，不康复」是**学术理念**（讲系统怎么设计）；「**不评估，不给练**」是**对外的硬立场**（讲我们的规矩）。两者并存：理念句用于学术/共识引述，立场句用于所有对外开口。

---

## 二、为什么这条能当硬立场（三条支撑，讲给医生听）

1. **合规上站得住**：器械注册证面适用范围是「**适用于轻度认知障碍的辅助康复训练，不具备自动诊断功能**」（粤械注准20232070187）。**"不具备诊断功能"恰恰意味着必须先有医生的评估与诊断，训练才有落点**——不评估就开练，等于绕开了这个前提。
2. **临床上站得住**：认知训练是分域做的（DSM-V 六大认知域），卒中后、MCI、AD 各人弱的域不同；不评估就统一发题，等于给所有人穿同一双鞋。业内共识反复强调"先评定、后训练、再复评"。
3. **差异化上站得住**：市面上卖"刷题 App / 益智小游戏"的不评估、不记录、不回传；我们是**评估—开训—回传—调整**的闭环。**这条立场本身就是我们的护城河**——敢说"不给练"，说明我们卖的不是软件账号，是一套有医生的流程。

---

## 三、落地到各环节（这条立场出现在哪、怎么写）

| 环节 | 怎么落 |
|---|---|
| **服务包 / 套餐表** | 套餐是「时长容器」，**评估前置是硬条件，不是可选项**。医生动作 = 先完成评估、看轮廓图，再选套餐编号。⚠️ 评估环节是否单列必购项（原截图顶部露出"必购/共2次/600"）仍是待定项，但"必须先评估"这个前提已定死 |
| **居家彩页（给医生）** | 保留金句条「无评估，不康复」；**新增/替换为「不评估，不给练」作为模块一的立场标**，与"评估驱动"并列出现 |
| **科室会 PPT** | 「评估前置」页的标题就是这句；讲解顺序＝立场 → 三条支撑 → 闭环图 |
| **口径与话术卡** | 进"核心三句话"；进自检表（凡出稿必查这一句有没有出现） |
| **GEO 内容 / 公众号 / 知乎** | 认知康复相关稿的**固定收口句之一**；卒中、AD、MCI 人群稿必须出现 |
| **销售应答** | 客户问"能不能只买系统不评估" → 「不评估，不给练」+ 三条支撑，不退让 |
| **儿童 ADHD 线** | 同一条立场（儿童版同样是评估驱动：ADHD 在评估阶段即被识别，依评估结果匹配训练方案） |

---

## 四、⚠️ 三条不能说过头的（守边界）

1. **不等于"我们的评估能诊断"**——证面写明"不具备自动诊断功能"。评估是**医生做的、系统辅助的**，诊断权在医院和执业医师。
2. **不等于"练了一定有效"**——立场句管的是"该不该练、怎么开始"，不承诺结果。疗效表述仍受原红线约束（不写有效 rates、不承诺改善）。
3. **不等于"拒绝收人"**——评估出来不适合（如重度/极重度认知障碍，系统本身不纳入适用人群）就不开训，这是对患者负责，也是合规。话术落点＝「评估完如果不适合练，我们会明说」。

---

## 五、与原口径的冲突检查（已核）

- ✅ 与 2026-10-21 定的「**永久停用『医生核定』**」不冲突：本立场讲的是**评估前置**（评估与诊断由医生把关），不是"训练方案由医生核定"。对外禁说"训练方案由医生核定"，只说"评估与诊断由医生把关"。
- ✅ 与"训练内容由医生在系统内排、我方不预设"一致。
- ✅ 与"一律自费、不走医保"无关联，不触碰支付口径。
- ✅ 与"经颅磁"无冲突：本立场只针对**认知训练模块**；经颅磁按注册证适用范围与医嘱执行。
- ⚠️ **不再使用"难度非医生手动设定，由评估生成、经医生核定"这句完整表述**（"医生核定"四字已停用）→ 改写为「**难度由评估生成，医生在系统内可调**」。
