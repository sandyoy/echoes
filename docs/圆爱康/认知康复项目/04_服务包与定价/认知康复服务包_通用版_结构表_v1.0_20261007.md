# 圆爱康 · 认知康复服务包（通用版）结构表

版本：v1.0 · 2026-10-07 · 小鲸鱼起草
定位：**通用版**——所有医院一致，不出定制版。
用途：①销售/方案页骨架 ②系统开发依据 ③认知训练任务库的挂载母表 ④套餐与价格表的母表

---

## 〇、一句话说清这个项目和心脏康复的区别

| | 心脏康复 | 认知康复 |
|---|---|---|
| 患者怎么分档 | **状态式**：卧床期→起步期→基础期→强化期→维持期 | **评估驱动**：评估结果说了算，不按状态分档 |
| 卖什么 | 超声治疗次数 + 运动计划 | **纯时长**：30天 / 60天 / 1年 |
| 内容谁定 | 我方按状态预设套组 | **医生定**——训练内容和评估内容由医生在系统里排 |
| 干预手段 | 心脏超声波治疗仪 + 运动疗法 | 认知训练（鹤灵数智化认知评估与训练系统） |
| 科室 | 心内科 / 心脏康复科 | **神经内科（主）＋ 康复科（辅）** |

> ⚠️ **严禁套用心脏康复的"状态式分档"骨架。** 认知康复是**评估驱动**，套餐只是"时长的容器"。

## 一、服务包三层结构

| 层级 | 性质 | 内容 | 谁提供 |
|---|---|---|---|
| 第一层 · 居家核心 | 固定，不可拆 | 认知训练系统使用（含评估+训练）＋ 医生远程开方案/调方案 ＋ 训练数据落医生端 ＋ 六师共管 | 圆爱康（系统+服务）／医院（医生） |
| 第二层 · 院内可选模块 | 医院按条件勾选 | 院内认知评估量表、影像/化验等检查 | 医院（已有则勾，无则不勾） |
| 第三层 · 患者可执行内容 | 配套，随第一层交付 | 认知训练任务（DMS-V 六大认知域任务，患者在家做） | 圆爱康（系统+内容）／医院（医生排任务） |

## 二、第一层 · 居家核心（固定项）

| 项目 | 内容 | 说明 |
|---|---|---|
| 认知训练系统 | 鹤灵"数智化认知评估与训练系统"（二类医疗器械） | 电脑一体机 / iPad / 手机多载体；微信小程序"鹤灵脑星球"可居家练 |
| 认知评估 | 系统自带评估（含 AD8 初筛 / MoCA 二筛 / 各认知域任务评估） | 评估在**圆爱康医生端**开 |
| 医生远程服务 | 线上评估解读、方案（训练任务）制定与调整 | 由合作医院执业医师执行；**训练内容医生定** |
| 数据服务 | 训练记录（日期/内容/时长/正确率变化趋势）落入圆爱康系统医生端 | 医生随时可见；医院需要时由圆爱康打包提供 |
| 六师共管 | 医生/康复师/护士（院方）＋ 线上客服/线下督导/设备工程师（我方） | 6个角色不等于6个人 |

**核心：套餐时长内不限次数使用。**

## 三、第二层 · 院内可选模块（医院勾选表）

> 用法：医院在「有／无」栏打勾，有则纳入服务包，无则留空跳过。**不强制、不替代医院既有项目。**

| 模块 | 内容 | 医院有／无 | 纳入服务包 |
|---|---|---|---|
| 认知功能量表评估 | MoCA / MMSE / 各认知域量表（院内） | ☐有 ☐无 | ☐ |
| 头颅 CT／MRI | 结构影像（排除其他病因） | ☐有 ☐无 | ☐ |
| 血液生化检查 | 甲状腺功能、维生素B12、叶酸等（可逆病因排查） | ☐有 ☐无 | ☐ |
| 神经心理测评 | 成套神经心理测验 | ☐有 ☐无 | ☐ |
| 日常生活能力 ADL 评估 | 自理能力评估 | ☐有 ☐无 | ☐ |
| 精神行为症状评估 | NPI 等（BPSD 排查，需时做） | ☐有 ☐无 | ☐ |
| 抑郁／焦虑量表 | 情绪共病筛查 | ☐有 ☐无 | ☐ |
| 康复科物理治疗 | 院内已有康复治疗（有则并做） | ☐有 ☐无 | ☐ |
| 认知训练（院内） | 院内智慧台车/一体机训练（有设备则勾） | ☐有 ☐无 | ☐ |

**核心原则：院内模块可有可无，居家核心始终成立。** 医院条件不足不影响项目落地。

## 四、第三层 · 患者可执行内容（认知训练）

### 4.1 训练内容组织方式

| 项目 | 设计 |
|---|---|
| 理论底座 | DSM-V **六大神经认知域**：①复合注意 ②学习记忆 ③知觉运动 ④语言言语 ⑤执行功能 ⑥社会认知 |
| 任务库 | **6 个模块、36 个标准训练任务**（对外口径；可自定义扩展至 50）；任务数按需由医生排 |
| 难度分级 | 每个任务 **6 个难度等级**；速度可调（慢/中/快） |
| 组织方式 | **评估驱动**：患者评估 → 系统出「认知轮廓图」（雷达图）+ 每任务正确率与建议起始难度 → 医生一键开训练 → 患者在家练 |
| 交付形态 | 载体：智慧台车 / 智慧平板 / 智慧一体机 / **鹤灵脑星球微信小程序**（居家） |
| 数据回传 | 训练记录（日期/内容/时长/正确率趋势）回传至**圆爱康系统医生端** |
| 跟踪方式 | 医生端可见 + 客服按节点跟进 |

### 4.2 评估驱动闭环（核心图）

```
① 评估（AD8 初筛 → MoCA 二筛 → 认知域任务评估）
        ↓
② 系统出「认知轮廓图」（雷达图）+ 每任务正确率 + 建议起始难度(1-6级)
        ↓
③ 医生一键开训练方案（选任务 + 定难度）
        ↓
④ 患者居家/院内训练（H5 训练页 / 小程序）
        ↓
⑤ 训练记录回传医生端（日期/内容/时长/正确率趋势）
        ↓
⑥ 医生看记录调整方案 → 回到 ③
```

**学术理念：「无评估不康复」。**

**⚠️ 已确认的对接机制**：评估在圆爱康医生端开 → 医生端一键跳转 → 患者直达 H5 训练页 → 数据回传我们的小程序/患者 APP。**对接已完成，无需再谈鹤灵开通条件。**

**⚠️ 对外表述红线**：只能说「**训练时长与完成度可追踪**」，**绝不能说「能看到患者训练是否标准/对错」**——不承诺审核能力，出事不担责。
