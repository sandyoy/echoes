## 〇、一句话说清这个项目

**评估驱动，不是状态分档。** 患者在医院由医生用系统做认知评估 → 系统出「认知轮廓图」（雷达图）+ 每个任务的正确率与建议起始难度 → 医生一键开训练方案 → 患者在家通过 **H5 训练页** 直接练 → 训练记录回传我们的小程序/APP/医生端 → 医生看记录调方案。

> ⚠️ **严禁套用心脏康复的「卧床期→维持期」5 档壳**。认知康复的分期是**评估结果驱动**，不是患者状态分档。

## 二、系统真身（读鹤灵原件核实）

### 理论底座
- **DSM-V 六大认知域**：①复合注意 ②学习记忆 ③知觉运动 ④语言言语 ⑤执行抑制 ⑥社会认知
- **学术理念**：「无评估不康复」

### 系统构成
| 项 | 数值 |
|---|---|
| 训练模块 | 6 个 |
| 标准训练任务 | **36 个**（对外口径）；可自定义扩展至 50 |
| 每任务难度 | 6 级 |
| 量表 | **55 个** |

### 评估产出
认知轮廓图（雷达图）+ 每任务正确率 + 评估能力 + **建议起始难度（1-6 级）**
> 示例：色词训练 66.67%→难度4；数符转换 16.67%→难度1；群雁飞翔 83.33%→难度5

### 载体
智慧台车 / 智慧平板 / 智慧一体机 / **鹤灵脑星球微信小程序**（居家）

### 与圆爱康系统的对接（sandy 2026-10-01 确认）
| 环节 | 落在哪 |
|---|---|
| 评估 | 圆爱康**医生端**开 |
| 开/调治疗方案 | 圆爱康**医生端** |
| 患者训练 | 点训练 → 直达 **H5 训练页** |
| 训练数据回传 | 回**我们的小程序 / 患者 APP** |

> ✅ 对接已完成，无需再去谈鹤灵开通条件。
