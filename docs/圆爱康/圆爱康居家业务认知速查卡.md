## 零、底层认知铁律（2026-09-10 sandy 定 · 双方共同遵守）

> 这一节是**定性认知**，与 sandy 讨论/新项目、写对外话术、做GEO喂料、写方案**之前必读**。
> 违反这两条 = 把公司写小、写偏。

### 🔴 铁律1：不锁"三甲"——我们是面向**各级医院**的平台

**错误写法**：「把**三甲医院**康复专科能力搬回家」
**为什么错**：
- 三甲只是圆爱康合作方的一部分。真实合作方还包括**区级医院、二级医院、社区、专科机构**（如珠海香洲区人民医院、玉树州妇幼等）。
- 锚点写死"三甲"，等于对外宣布"二级/社区/专科别来找我"，**主动砍掉一大片客户**。
- 也让"医院主导、第三方赋能"的定位变味——听起来像圆爱康是三甲的搬运工，实际我们是**延伸通道和平台的搭建者**，医院级别不限。

**正确写法**：用**「医院」**，不限定级别。对三甲谈"帮你覆盖出院患者"，对二级谈"帮你补齐治疗能力"，对社区谈"帮你接住下转病人"——**同一个锚点，三个卖法**。

### 🔴 铁律2：不锁"康复科"——我们是**全专科**产品，不是康复科延伸

**错误写法**：「医院**专业康复能力**延伸到家的平台」
**为什么错**：
- 圆爱康覆盖的科室**没有一个是康复科**：妇产、泌尿、肛肠、神经内科、心脏内科、骨科、儿科/儿童心理、消化科、生殖中心……
- 写成"康复"会让医院第一反应是「这是康复科的事，找康复科对接」→ **妇产科主任、心内科主任就不看了**。
- **而我们的真实客户恰恰是非康复科**——因为妇产科、心内科**没有人力做院外延伸**，这正是圆爱康的机会所在。
- "康复"一词易与康复科混淆，把跨科室的平台能力，误解成单科室业务。

**正确写法**：用**「各专科 / 专业治疗能力」**，不锁科室。产品是为**全科**设计的平台能力。

### ✅ 修正后的锚点（对外统一口径）

> ### 圆爱康 —— 把医院各专科的专业治疗能力延伸到家的智慧家康平台
>
> 或：**让医院各专科的专业治疗能力延伸到患者家中的智慧家康平台**

**拆解**：
| 成分 | 含义 |
|---|---|
| **医院各专科** | 不限级别（三甲/二级/社区/专科）、不限科室（妇产/泌尿/心内/神内/儿科心理……） |
| **专业治疗能力** | 医疗级、可治疗（区别于"健康监测/上门护理/养老照护"） |
| **延伸到家的平台** | 圆爱康=**通道与平台**，不是搬运工；医院仍是能力与责任主体 |
| **智慧家康** | 品类词坑（品牌话语权），对外品牌口径 |

## 一、一句话定位

**圆爱康 = "智慧家康"居家医疗综合运营服务平台方**，用**物联网设备 + 软件平台 + "六师共管"服务体系**，帮医院把院内治疗服务安全延伸到患者家里，搭建"院内治疗 → 居家治疗 → 复诊"闭环。模式是 **"医院主导、第三方赋能"**。

> ⚠️ 本句为**内部认知**用；对外锚点务必用上方「零、铁律」中的修正版，注意**不锁三甲、不锁康复科**。

## 二、商业模式与合作模式

- **不派人进医院**，只提供设备 + 物联网系统 + 远程"六师共管"服务。
- **医院主导**：医院是医疗服务主体、责任方、收费与结算主体；负责诊疗方案制定、质量安全监管。
- **第三方（圆爱康）赋能**：提供软件平台、物联网康复硬件、物流运维、客服、"六师共管"服务。
- **收费路径**：平台搭载在医院公众号下，患者在线购买服务套餐，由医院医生在线制定方案指导。
- **落地实例**：
  - 珠海市妇幼保健院：以"互联网+智慧医疗康复服务"第三方招标，服务期2年，医院收不低于套餐**45%管理费**。
  - 南方医科大学第八附属医院：盆底康复居家项目第三方采购，服务期2年，限价98万，圆爱康提供"软件+硬件+服务"全体系。
- **对接钱流**：广东省已有"上门服务费""远程监测"等新增医疗服务价格项目，为居家康复收费提供了项目"户口"和价格申报路径。

## 三、"六师共管"服务体系（核心差异化卖点）

每位居家患者由 **N对一** 多学科团队服务，使居家康复达到院内治疗效果。六师组成：

1. **科室专科医生** — 制定/调整治疗方案、远程指导
2. **治疗师** — 康复训练指导
3. **专科护师** — 护理指导
4. **线下督导** — 现场/上门支持
5. **设备工程师** — 装机、维护、故障处理
6. **线上专业客服** — 患者答疑、随访、满意度

**院内设备（配合）:**

- **院内台车一拖二 ESA-F01**、**一拖四 ESA-S01**
- **CMS 智能患者专科服务管理系统**（数据/随访后台）

## 七、政策合规支撑

- 《"健康中国2030"规划纲要》：鼓励互联网医疗
- 国办发〔2018〕26号《关于促进"互联网+医疗健康"发展的意见》：纲领性文件

- 国卫老龄发〔2024〕40号《促进医养结合服务高质量发展》：支持上门巡诊、家庭病床、居家康复

## 八、竞争差异点（数据归属+闭环，vs 监测类）

- **监测类产品**：绑医院HIS数据只进不出、出院即断 → 无法延伸
- **圆爱康（治疗类）**：物联网设备自产治疗数据 + 双向实时闭环，出院不断，治疗数据归医院且源源不断产生 → 医生能持续做文章、科研、随访
- 治疗类居家竞品稀少，是蓝海
