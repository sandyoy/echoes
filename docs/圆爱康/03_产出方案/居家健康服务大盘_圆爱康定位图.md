## 一、先想明白这张图要回答的问题

sandy 的核心问题：**"如果居家康复是一个大盘子，这里头有检测、用药管理、营养、治疗、上门服务……那这个整体架构什么样？我们（圆爱康）在哪一部分？"**

答案一句话：**圆爱康不是做"基础居家服务"的公司，它是做"专业医疗级居家治疗"的公司——处在整个大盘里最有医疗门槛、最稀缺、也最值钱的格子。**

## 二、居家健康服务 · 大盘全景（按"服务深度/医疗含量"分层）

把整个"居家 + 健康/医疗"的大盘子想象成从"生活便利"到"医疗治疗"递进的金字塔，越往上越靠近真正的医疗，越稀缺：

### 底层 · 生活照料层（非医疗，门槛低，玩家最多）
- 助餐 / 助浴 / 助洁 / 助行
- 家政、日间照料、精神慰藉
- **代表玩家**：福寿康、安康通、天与养老、普亲养老、众多家政养老公司
- **特点**：量大、标准化、谁都能做、利润薄、靠规模

### 第二层 · 健康监测/管理层（半医疗，靠数据）
- 家用血压 / 血糖 / 心电 / 血氧 / 体重
- 慢病管理、CGM连续血糖、智能穿戴
- **代表玩家**：鱼跃、三诺、微泰、华为健康、智云健康
- **特点**：强监测，"看着你"，但**不做治疗**，出院即断，数据进HIS只出不进

### 第三层 · 上门护理/服务层（半医疗，靠人力上门）
- 护士上门（打针/换药/压疮护理）、上门采血/检验
- 陪同就医、家庭医生巡诊
- **代表玩家**：金牌护士、医护到家、微医、东软熙康
- **特点**：靠人上门，标准难统一，成本高，难规模化

### 第四层 · 居家营养/用药层（专业给养，靠产品+处方）
- 医学营养（特医食品）、居家肠内营养
- 送药、用药依从性管理、处方流转
- **代表玩家**：费森尤斯卡比、诺特健康、叮当快药、京东健康、圆心科技
- **特点**：强产品/供应链驱动，但单点，不成治疗闭环

### 🎯 顶层 · 居家治疗/康复层（真正医疗，门槛最高，最稀缺）
- **用设备输出"治疗能量"，让患者在家完成真正的治疗**
- 物理治疗（电刺激/磁疗/冲击波）、盆底康复、心肺康复、神经康复、运动康复
- **代表玩家**：麦澜德（盆底）、伟思医疗（盆底/精神）、术康（心脏数字疗法）、翔宇医疗、大艾/傅利叶（机器人外骨骼）
- **特点**：⚠️ **这一层才是"医疗"，不是"服务"**——有治疗价值、有疗效、患者愿意付费、医保/长护险逐步覆盖

## 三、圆爱康到底站在哪一格

**圆爱康的位置：顶层的"居家治疗/康复层"，而且是这一层里靠"专业医疗闭环"打法的那一档。**

| 维度 | 圆爱康的坐标 |
|------|------------|
| **赛道** | 居家治疗/康复（盆底 + 心脏）✅ 顶层 |
| **打法** | 设备（家用康复治疗仪）+ 物联网（数据双向闭环）+ **六师共管**（专业医疗赋能居家） |
| **和监测类的本质区别** | 监测类"看着你但治不了"；圆爱康"治你"——治疗数据自己产生、双向闭环，出院也不断 |
| **六师是哪六师** | ①科室专科医生 ②治疗师 ③专科护师 ④线下督导 ⑤设备工程师 ⑥线上专业客服 |
| **和上门护理的区别** | 不靠人上门堆人力，靠"设备+物联网+远程专业化"规模化 |
| **商业模式** | 设备租赁 + 服务费 + 医院科室共赢（医院零投入、科室拿绩效） |

## 五、关键洞察：圆爱康的护城河（为什么这个位置值钱）

1. **绝大多数"居家玩家"都在金字塔中下层**（生活照料/监测/上门），做的是"服务/数据"，不是"治疗"。圆爱康在顶层做**真治疗**——这是稀缺位。

2. **居家的"监测"和"治疗"是分水岭**：
   - 监测类（鱼跃、华为）：绑医院HIS、数据只进不出、出院即断 → 治不了
   - 治疗类（圆爱康）：设备自产治疗数据、双向实时闭环、出院不断 → 真治病
   - ⚠️ 治疗类竞品极少（麦澜德/伟思做盆底、术康做心脏、机器人做神经），**是蓝海**

3. **六师共管是圆爱康独有的一张牌**：别人给设备/给监测，圆爱康给的是"专业医疗团队远程管你"——把居家康复从"自己瞎弄"提升到"医疗治疗目标"。这让圆爱康同时卡住了"治疗层"和"远程医疗专业层"两个位。

4. **可横向扩展**：圆爱康现在做盆底+心脏，但这个"设备+物联网+六师"的打法是**可复制的**——未来可加骨科、神经、脑康、永磁旋振、认知训练等（这些产品资料里其实已经有了），从一个病种扩展成"居家治疗矩阵"。这正是代理商"一家医院做透所有项目"的根基。

> **"市面上居家健康公司，大多在'看数据、送服务'；圆爱康是少数'在家把病治了'的——用医疗级设备 + 物联网闭环 + 六师远程共管，让患者不出家门完成专业治疗。这是整个居家大盘里，最有医疗门槛、也最稀缺的那一格。"**
