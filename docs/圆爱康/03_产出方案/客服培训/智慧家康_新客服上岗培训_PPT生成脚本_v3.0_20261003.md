【第 8 页】　你在群里的一天（五个动作）

上屏文字｜
五个动作，覆盖你 95% 的工作
① 接群 —— 系统拉了新群，3 分钟内主动说第一句：报身份 + 说清群是干嘛的 + 告诉他下一步
② 回消息 —— 工作时间内 5 分钟内回复；先分类（业务/操作/流程/医疗/情绪）再处理
③ 催办 —— 每天固定时间，谁 N 天没治疗就去催（说天数 + 挂钩医嘱 + 留台阶）
④ 回访 —— 每天抽时段，盯"效果不明显、异常未闭环、长期没回应"的患者
⑤ 盯数据 —— 每天用后台查一次各院异常（掉队/退费/设备闲置/医院掉线），把问题找出来

催办是客服最有价值的动作 —— 也是唯一能直接减少退费的杠杆。
可照念的话术：
"提醒您已 5 天未进行康复治疗，请遵医嘱坚持治疗，祝您康复愉快。"

版式建议｜上方五个动作卡片横排 + 下方话术条
配图位置｜无需配图；可加"时钟"图标呼应"一天"
讲师备注｜重点讲催办与盯数据。催办=说天数、挂钩医嘱、留台阶，不是催患者给面子，是帮他做完疗程、帮公司少一笔退费。盯数据是本版新增——从"等医院开口"变成"主动发现问题"。

【第 9 页】　第 5 个动作：主动盯数据（异常预警）

上屏文字｜
别等医院开口 —— 系统/后台每天告诉你"哪里出问题了"
现在人工客服是被动的：医院说什么、要改什么，你去帮着做完。这不叫服务，这叫接单。
每天要看这四类异常：
① 患者掉队 —— 超期未治疗、剩余次数还有好多次（直接关系退费）
② 退费异常 —— 本月退费率比上月明显升高
③ 医院掉线 —— 某院连续多天没有任何预约或服务记录
④ 设备闲置 —— 设备长期使用率偏低（资产浪费，医院也关心）
发现异常 → 提醒医院对接人（口吻："发现一个情况跟您同步"）→ 重要事项上报主管 → 记进当天登记表。

版式建议｜上方一句话定调 + 中部四类异常卡片 + 底部动作链
配图位置｜可放"客服工作台 push 异常清单"的示意界面
讲师备注｜这是 v3.0 新增页，也是本版最大的升级点。核心转变：把"人找问题"变成"问题找人"。异常预警规则会在系统里逐步自动化，但现阶段先靠人工核查登记跑起来。

【第 10 页】　通道纪律：哪些动作才"算数"

上屏文字｜
留痕通道内做的服务才算数
白名单（算数）：企业微信 / 小鲸客服APP / 服务群 / 医生端系统内对话

【第 11 页】　能答 / 代做 / 转人

上屏文字｜
遇到拿不准的事，先在这张表里找位置
✅ 能答：设备怎么用、小程序怎么操作、套餐剩几次、预约怎么弄、押金流程 → 自己答（不会就查问答库）
✅ 能代做：数据录入、账号开通、参数配置、报表导出、表单整理 → 进后台替他做完，做完告诉他一声
⚠️ 转人：涉病情判断、涉钱（退款/押金）、涉纠纷（投诉/媒体）、身体异常 → 不自己扛，当天上报
❌ 绝不能：下诊断、说疗效、替医生定方案、承诺退费金额和时间、替医生签字 → 碰都不要碰
代做的边界：一句话判据——"这个动作会留下医疗责任吗？"会 → 不做；不会 → 可以做。

版式建议｜上方四分类表 + 下方左右边界表 + 底部判据条
配图位置｜无需配图
讲师备注｜代做是我们的核心优势，但边界要清楚。记住判据：会不会留下医疗责任。

【第 12 页】　服务怎么算"一条"

上屏文字｜
按"有效服务动作"算 —— 一个标签 = 一条服务
处理完一件事，在客服APP里手动选一个标签：
操作指导 / 使用提醒 / 订单物流 / 服务期咨询 / 异常响应 / 回访 / 投诉
共 7 个标签，对应合同 10 条服务内容，点一下即可。
一次对话里既教了操作又催了回访 → 打两个标签 → 算两条。
为什么要这么算：将来医院问"你们做了哪些服务"，只有这种算法答得上——这就是我们的可追溯能力。

【第 13 页】　投诉分责：看记录，不看嘴

上屏文字｜
投诉怎么算，不看"谁说的"，看"记录里有没有动作"
客服按口径答了、按流程做了（有记录）→ 患者问题 → 不计你投诉
客服答错 / 答慢 / 没按口径 / 没闭环 → 客服问题 → 计投诉
无对话记录（私聊、口头）→ 不计投诉，但扣"留痕缺失分"
一句话：留痕是你的护身符 —— 有记录，你就不背锅。

【第 17 页】　对外口径：三不说 + 一不得

上屏文字｜
三不说（说错=违规或纠纷）：
不说疗效 —— 不说"能治好""不会复发""可以不做手术"
不说数据直传医院 —— 正确说法："您的治疗数据医生随时能看；医院需要的话我们打包给医院"
不说资质 —— 不提"我们平台有诊疗资质"；诊疗由合作医院执业医师依规完成
一不得：
不得把"等保"说成"认证" —— 正确说法："系统部署在通过等保三级测评的阿里云平台上，享有三级等保保护"

版式建议｜左右"错误说法 / 正确说法"对照表 + 底部红线条
配图位置｜无需配图
讲师备注｜本页专治"新人一热情就说错"。三句话记牢：疗效不说、数据不直传、资质不提；还有"保护"不等于"认证"。这些错话一旦说出去，是公司和医院一起担。
