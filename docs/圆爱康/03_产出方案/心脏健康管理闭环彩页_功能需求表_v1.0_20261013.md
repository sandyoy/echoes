# 功能需求表 · 心脏健康管理闭环彩页（给医院·销售用）

版本：v1.0 · 2026-10-13 · 小鲸鱼起草
状态：**待 sandy 确认后开工**（按功能需求表制度，无表不开工）

---

## 一、这是什么

**销售拿去递给医院客户（心内科主任/医生 + 院领导）的彩页**，讲清圆爱康的
「心脏健康管理闭环服务」——从患者进心内科、评估、分岔（手术指征有无）、到术后/非术后的
居家心脏康复，把**心内科所有患者**都纳入管理。

**跟已有物料的区别（关键，别混）：**
| 已有物料 | 受众 | 能不能出现公司名 |
|---|---|---|
| 门诊住院部展示内容·三载体 | **患者** | ❌ 不能（走医院科室名义） |
| 运动疗法对照表·只给医生 | 医生 | — （技术件，只核动作） |
| **本件·闭环彩页** | **医生+院领导** | ✅ **能，且必须出现**（商务材料） |

## 三、核心内容骨架（正面：闭环逻辑）

```
                    患者进入心内科
                          ↓
                  ① 医院做「心脏评估」
              （心功能 / 冠脉情况 / 危险因素）
                          ↓
                 ② 分岔判断：有无手术指征？
         ┌────────────────┴────────────────┐
    无手术指征                          有手术指征
         ↓                                   ↓
  ③A 直接进居家康复                   ③B 医院安排【手术】
   （减症状·控风险）                         ↓
         │                            ④ 术后 → 居家心脏康复
         └────────────────┬────────────────┘
                          ↓
              ⑤ 居家心脏康复（核心·圆爱康承接）
              ┌──────────────────────┐
              │ 院内段（医院有则用）    │
              │  院内治疗 / 运动康复    │
              ├──────────────────────┤
              │ 居家段（圆爱康·核心）   │
              │  心脏超声波治疗仪租赁    │
              │  + 居家运动疗法（视频）  │
              │  + 医生远程开方调方案    │
              │  + 治疗数据落医生端      │
              └──────────────────────┘
                          ↓
       ⑥ 心内科患者全量管理闭环
      （有指征 / 无指征，全被管起来）
```

**一句话卖点**：帮医院把心内科**所有患者**纳入管理闭环——不是只服务术后那一小撮。

## 四、背面要放的（证据 + 落地 + 价值）

| 块 | 内容 | 素材来源（已有，可直取） |
|---|---|---|
| **凭什么靠谱** | SUT-C 超声治疗仪（天行健，京械注准20162091164，Ⅱ类"冠心病辅助治疗"）+ 6份权威文献（2018指南/心衰共识/PCI共识/分级诊疗共识/八段锦团标/冠心病运动共识） | 心脏康复_6项待核项文献依据对照表 |
| **居家 vs 到院** | 学术结论：规律心脏康复是长期管理重要一环 | 文献（引学术结论，非"产品有效"） |
| **系统怎么转** | 医生端看什么 / 患者端看什么 / 数据落哪 | 服务包结构表·第一层;认知康复彩页模板§四 |
| **患者怎么进来** | 医院/科室公众号入口 → 圆爱康系统 → 科室独立渠道 → **病源/数据/责任清晰** | 认知康复彩页模板§五 |
| **对医院的价值** | ①全量患者管理（不只术后）②数据留在我们医生端、主动权在医院侧 ③医疗行为留院内、执行运营圆爱康担 ④不占医院人手/不重资产 | 差异化分水岭（数据归属+闭环） |
| **合规口径** | 医疗行为留贵院（医生核定）；执行运营圆爱康担；责任边界清楚 | 认知康复彩页模板§六 |

## 五、红线（做这张彩页必守·心脏线总台账第六条）

- ❌ 不印价格
- ❌ 不写疗效承诺（"89%缓解""避免支架搭桥"禁写）——这是话术非注册范围
- ❌ 不写非自有注册证（超声仪注册证由天行健提供，**注明即可**，不冒充自有）
- ❌ 不写"能看到患者动作是否标准" → ✅ 只能说"训练时长与完成度可追踪"
- ✅ 可写"圆爱康""居家康复""智慧康复"品牌名
- ✅ 可引公开指南的**学术结论**（不引"我们产品有效"）
