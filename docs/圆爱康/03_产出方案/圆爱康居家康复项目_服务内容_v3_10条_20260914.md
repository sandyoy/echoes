# 圆爱康居家康复项目 · 服务内容

（合同附件）

**一、项目咨询服务**
为患者提供项目讲解、服务方式说明与服务包选型推荐，协助完成订单确认与治疗排期对接。

**二、设备发放与回收服务**
按医院确认的治疗方案准备并发放设备（现场领取或物流寄送），服务到期后按约定方式回收并完成清洁消毒处理。

**三、使用教学服务**
提供视频与图文操作指引及一对一远程指导，帮助患者正确安装、使用设备并能独立完成居家治疗。

**四、在线客服服务**
提供全时段线上客服，受理操作答疑、使用提醒、订单查询与服务进度等咨询。

**五、使用指导与随访服务**
按治疗方案提醒患者使用频次与疗程节点，按周期定期线上回访，了解患者使用情况与感受并做好记录。

**六、异常响应服务**
发现患者未按方案使用或使用中断时，主动联系患者了解并协助解决；需医院处理的情形及时告知医院对接人。

**七、治疗报告服务**
按疗程生成治疗过程报告并推送给患者，协助安排报告解读，帮助患者看懂自己的治疗情况。

**八、档案管理服务**
患者治疗记录与报告在系统内留档，支持随时查询与下载打印。

**九、设备运维服务**
设备使用异常或软件使用问题时，提供远程排查与线上协助处理。

**十、服务周期与售后保障服务**
到期前提前提醒患者，受理续期、延期及服务调整咨询；收集患者意见与建议并跟进反馈；安排专职对接人与医院指定科室保持日常沟通。
