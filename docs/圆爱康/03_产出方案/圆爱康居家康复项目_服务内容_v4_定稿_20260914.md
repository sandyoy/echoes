# 圆爱康居家康复项目 · 服务内容

（合同附件）

**一、项目咨询服务**
为患者提供项目讲解、服务方式说明与服务包选型推荐。

**二、设备发放与回收服务**
按医院治疗方案准备并发放设备，服务到期后按约定回收并完成清洁消毒。

**三、治疗运营支持服务**
安排专职服务团队，跟踪患者居家治疗执行情况，负责日常服务协调与进度跟进。

**四、居家随访服务**
按治疗周期定期线上回访，了解患者使用情况与感受并做好记录。

**五、使用提醒服务**
提醒患者使用频次与疗程节点，对未按时治疗的患者主动联系、协助坚持完成。

**六、在线客服服务**
提供全时段线上客服，受理操作答疑、订单查询与服务进度等咨询。

**七、使用教学服务**
提供视频与图文指引及一对一远程指导，帮助患者正确安装使用设备。

**八、异常响应服务**
发现治疗中断或使用异常时主动联系患者协助解决，需医院处理的情形及时告知医院对接人。

**九、治疗报告服务**
按疗程生成治疗过程报告并推送给患者，协助安排报告解读。

**十、服务周期与售后保障服务**
到期前提前提醒患者，受理续期与调整咨询；收集患者意见并跟进反馈；设备、服务与运营由我司统一负责。
