## 第一部分 · 使用前提（先读这一页，后面每个动作都建立在此之上）

### 1.1 分级双轴（一套动作，两张皮）

| 轴 | 用于 | 分级 | 说明 |
|---|---|---|---|
| **医学轴** | 医生端开方 | NYHA 心功能分级 Ⅰ／Ⅱ／Ⅲ／Ⅳ | 医生认这个，写进医嘱不心虚 |
| **患者轴** | 患者端呈现 | 阶段一（术后1-2周）／阶段二（术后1-3月）／阶段三（3月后及长期） | 患者看得懂，不用问自己几级 |

**换算对照表**

| NYHA | 患者端阶段 | 可进入的动作 |
|---|---|---|
| Ⅳ 级 | 不做运动，仅呼吸训练 | A01、A02（仅准备段动作） |
| Ⅲ 级 | 患者轴·阶段一 | A01-A03、B01、B02、D01、D02 |
| Ⅱ 级 | 患者轴·阶段一末→阶段二 | A01-A03、B01-B03、C01-C02、D01-D02 |
| Ⅰ 级 | 患者轴·阶段二→阶段三 | 全部动作 |

### 1.2 三段结构（每个动作内部）

1. **准备段**：呼吸／关节热身（每套必做，不可跳）
2. **训练段**：主运动
3. **收尾段**：放松／自测（记录心率、症状）

### 1.3 红线区（全局共用，不随分级变化）

**必停信号（出现任何一条立即停止）**：胸闷、胸痛、喘憋、心慌、头晕、大汗、下肢无力、恶心、濒死感
**禁做动作类型**：举重、拔河、俯卧撑、短跑、剧烈打球、任何憋气用力的动作（竞技性运动、重体力劳动、剧烈对抗运动）
**强度判断（唯一标准，优先于心率公式）**：能正常交谈，但不能唱歌（说话试验）
**靶心率参考**：（220 − 年龄）× 50%-70%。装有起搏器者需结合起搏器设定。首次运动前建议做心肺运动试验评估安全阈值。
**呼吸铁律**：全程禁止憋气（Valsalva 动作会引起血压骤变与心律失常风险）。用力时呼气，放松时吸气。AI 生成没有真人在旁喊口令，「呼吸时相」必须写死在画面文字与配音里。
**禁忌部位**：超声治疗仪需避开皮肤破损处、起搏器植入部位
**运动与超声治疗的时序**：先完成超声治疗再运动，或运动后休息片刻再做超声治疗，避免同时进行增加心脏负担
**环境要求**：饭后1小时再运动，不空腹运动（避免低血糖）；运动前热身5-10分钟
**强度上限（患者自测）**：以微微出汗、呼吸稍快、能正常说话为宜

### 1.4 AI 生成脚本的硬约束（写提示词时必须遵守）

| 约束 | 原因 |
|---|---|
| **按「单次动作」为最小生成单元** | AI 视频对连续周期性重复动作会出现动作漂移（第3次起手部位置偏移）。一个动作一个短镜头，重复次数用剪辑循环或画面文字标注表现。 |
| **必须双机位（正面+侧面）** | 关节角度与脊柱中立位只有侧面才能审。单正面机位无法判断动作是否标准。 |
| **画面文字必须含呼吸指令** | AI 生成无人喊口令，呼吸引导只能靠画面文字+配音。 |
| **禁止出现真人面部** | 用卡通化／简笔人物或背影/局部，规避肖像权问题，也降低 AI 生成难度。 |
| **老人体型设定** | 提示词须指定「65岁以上亚洲老年人体型」，避免 AI 默认生成年轻健硕体型，患者看了不代入。 |
| **居家环境** | 客厅／卧室，有椅子可扶，不做花园／健身房（与居家场景匹配）。 |
| **动作幅度保守** | 提示词须注明「动作幅度保守，不追求最大范围」，医学上是安全的，AI 也不会生成夸张姿态。 |

### A 类 · 呼吸训练（全分级可用，含Ⅳ级）

#### A01 腹式呼吸

| 字段 | 内容 |
|---|---|
| 动作编号 | A01 |
| 动作名 | 腹式呼吸（膈肌呼吸） |
| 适用分级 | NYHA Ⅰ／Ⅱ／Ⅲ／Ⅳ（Ⅳ级唯一可做的动作之一） |
| 适用阶段 | 全阶段（含卧床期） |
| 目的 | 改善心肺功能、缓解紧张、为运动做准备；降低交感兴奋 |

**动作过程（含呼吸时相）**
1. 起始姿态：仰卧屈膝或端坐靠椅，一手放胸口、一手放腹部，肩颈放松，目视前方
2. 吸气（4秒）：用鼻缓慢吸气，**只有腹部鼓起**，胸口保持不动
3. 呼气（6秒）：用嘴缓慢呼气，腹部自然回落，呼气长于吸气
4. 全程不憋气、不耸肩、不刻意用力

**节拍与重复**：每次 10 个呼吸周期（约 100 秒），每天 2-3 次

**安全限制与停止指征**：出现头晕、胸闷、心慌立即停止；不得用力屏气（禁止 Valsalva）

**AI 生成提示词（EN）**
```
Elderly Asian person (65+), seated upright on a simple chair in a bright
living room, one hand on chest one hand on lower abdomen, practicing
diaphragmatic breathing. Abdomen rises slowly on inhale, falls on exhale.
Side view, full torso framing, vertical 9:16, soft natural window light,
calm neutral background, flat illustration style, no facial detail,
conservative movement range, medical instructional tone.
```
**AI 生成提示词（中文对照）**：65岁以上亚洲老年人，端坐椅上，一手置胸一手置腹，做腹式呼吸；吸气时腹部缓慢鼓起，呼气时回落。侧面机位、半身画幅、竖屏9:16、柔和自然光、简洁居家背景、扁平插画风格、不露面部、动作幅度保守、医学教学调性。

**画面文字**：吸气4秒（腹部鼓起）／呼气6秒（腹部回落）／全程不要憋气

**配音词**：吸气——用鼻子慢慢吸，感觉肚子像气球一样鼓起来……好，呼气——用嘴慢慢呼出去，肚子慢慢瘪下去。再来一次。

**医生审核点**：①确认Ⅳ级患者是否允许坐位（vs 必须卧位） ②呼吸周期 4:6 是否需按患者肺功能调整

#### A02 缩唇呼吸

| 字段 | 内容 |
|---|---|
| 动作编号 | A02 |
| 动作名 | 缩唇呼吸 |
| 适用分级 | NYHA Ⅰ／Ⅱ／Ⅲ／Ⅳ |
| 适用阶段 | 全阶段（含卧床期） |
| 目的 | 延缓呼气、防止小气道塌陷、减轻憋气感与呼吸困难 |

**动作过程（含呼吸时相）**
1. 起始姿态：端坐，肩放松，口唇微闭
2. 吸气（2秒）：用鼻缓慢吸气
3. 呼气（4-6秒）：嘴唇缩成吹口哨状，缓慢呼气，**呼气时间是吸气的2-3倍**
4. 全程不憋气

**节拍与重复**：每次 10 个呼吸周期，每天 2-3 次

**安全限制与停止指征**：出现头晕、口唇发麻（过度通气）立即停止并恢复自然呼吸

**AI 生成提示词（EN）**
```
Elderly Asian person (65+), sitting upright on a chair in a home living room,
practicing pursed-lip breathing, lips shaped as if gently blowing through a
straw. Chest close-up plus side view, vertical 9:16, soft daylight,
flat illustration style, no facial detail, medical instructional tone.
```
**画面文字**：鼻吸2秒／缩唇慢呼4至6秒／呼气要比吸气长

**配音词**：用鼻子吸气，一、二……现在嘴唇像吹口哨一样，慢慢呼出去，一、二、三、四。呼气一定要比吸气长。

**医生审核点**：①确认是否需配合血氧监测 ②过度通气的识别与处理口径

#### A03 坐位肩颈放松

| 字段 | 内容 |
|---|---|
| 动作编号 | A03 |
| 动作名 | 坐位肩颈放松 |
| 适用分级 | NYHA Ⅰ／Ⅱ／Ⅲ |
| 适用阶段 | 阶段一至三（作为每次运动前的准备活动） |
| 目的 | 放松上身、打开胸廓、降低运动起始的循环负荷 |

**动作过程（含呼吸时相）**
1. 起始姿态：端坐，双脚平放地面与肩同宽，双手自然置于大腿上，脊柱中立
2. 第一节·耸肩绕肩：双肩缓慢上提至耳侧（吸气），向后划圈后落下（呼气）。前后各 8 次
3. 第二节·颈部侧屈：头缓慢向左侧屈至有牵拉感（呼气），回正（吸气）；右侧同。各 5 次
4. 第三节·扩胸：双手交叉置于脑后，双肘缓慢向后打开（吸气），回到前方（呼气）。8 次
5. 全程颈部不做环绕（避免颈椎过度活动）、不憋气

**节拍与重复**：约 3 分钟

**安全限制与停止指征**：出现头晕、颈部疼痛、心慌立即停止；颈椎病患者颈部侧屈幅度减半

**AI 生成提示词（EN）**
```
Elderly Asian person (65+) seated on a chair, performing gentle shoulder
rolls and neck side-bends, hands resting on thighs. Front and side view,
upper body framing, vertical 9:16, warm home living room, soft daylight,
flat illustration style, no facial detail, very conservative range of motion,
medical instructional tone. No head circling.
```
**画面文字**：肩绕圈 前8次后8次／颈部侧屈 左右各5次／不做颈部环绕

**配音词**：肩膀慢慢向上提，吸气……向后画一个圈，呼气。再来。注意，脖子只做左右侧屈，不要转圈。

**医生审核点**：①颈椎病患者的幅度限制 ②是否需排除颈椎不稳患者

### B 类 · 有氧训练

#### B01 原地踏步

| 字段 | 内容 |
|---|---|
| 动作编号 | B01 |
| 动作名 | 原地踏步 |
| 适用分级 | NYHA Ⅰ／Ⅱ／Ⅲ |
| 适用阶段 | 阶段一（术后1-2周起步期） |
| 目的 | 起步期有氧训练，最低负荷、零位移、最安全 |

**动作过程（含呼吸时相）**
1. 起始姿态：站立，一手可扶椅背或墙面（**推荐扶稳，防跌倒**），双脚与肩同宽，脊柱中立
2. 抬腿：右腿屈髋抬至膝关节约 45 度（不追求高抬），自然呼吸不憋气
3. 落腿：缓慢放下，脚掌完整着地
4. 交替进行，节奏均匀，**以能正常交谈为准**（说话试验）
5. 全程不跳、不快速、不憋气

**节拍与重复**：每次 5-10 分钟起步，逐周递加；感觉良好者可在 2-4 周内增至上肢同步摆动（中期方案可选）

**安全限制与停止指征**：胸闷、胸痛、喘憋、头晕、心慌、大汗、下肢无力立即停止并坐下休息；平衡差者必须扶稳

**AI 生成提示词（EN）**
```
Elderly Asian person (65+) standing beside a chair with one hand resting on
the chair back for balance, performing slow marching in place, knees lifting
to about 45 degrees. Side view, full body framing, vertical 9:16,
bright simple living room, flat illustration style, no facial detail,
conservative movement, medical instructional tone, no jumping.
```
**画面文字**：扶稳椅背／抬腿约45度，不追求高抬／能说话、不能唱歌

**配音词**：一只手扶着椅子，站稳。右腿慢慢抬起来——像原地走路一样，慢慢放下。注意，抬到大腿和小腿成直角就够了，不用抬得很高。感觉能正常说话，就对了。

**医生审核点**：①确认站立位是否适合该患者（心功能Ⅲ级者建议先坐位） ②是否需要心率监测

#### B02 室内慢走（间歇式）

| 字段 | 内容 |
|---|---|
| 动作编号 | B02 |
| 动作名 | 室内慢走（间歇式） |
| 适用分级 | NYHA Ⅰ／Ⅱ／Ⅲ |
| 适用阶段 | 阶段一至阶段二（核心有氧项目） |
| 目的 | 核心有氧训练，恢复日常活动耐量 |

**动作过程（含呼吸时相）**
1. 起始姿态：室内平坦地面，穿防滑鞋，可沿墙或扶扶手行走
2. 走 2 分钟：自然步速，不追求速度与距离，自然呼吸
3. 休息 1 分钟：原地站立或坐位休息，恢复正常呼吸
4. 重复上述循环，总活动时间 20-30 分钟
5. 全程不憋气、不追求步数

**节拍与重复**：走2分钟＋休息1分钟＝1个循环，重复 6-8 个循环；每周 ≥5 天

**安全限制与停止指征**：走时明显胸痛、头晕、极度乏力立即停下休息并记录，复诊时告知医生；环境中无绊脚物、地面不湿滑

**AI 生成提示词（EN）**
```
Elderly Asian person (65+) walking slowly along a corridor inside a home,
one hand lightly touching the wall for support, calm pace, then stopping to
rest. Side tracking view, full body framing, vertical 9:16, home interior
with clear walkway, flat illustration style, no facial detail,
conservative pace, medical instructional tone.
```
**画面文字**：走2分钟／休息1分钟／重复6至8轮

**配音词**：沿着走廊慢慢走两分钟——不用快，正常速度就行。好，现在停下来休息一分钟。休息好了，再走两分钟。这样走两分钟、歇一分钟，走六到八轮就够了。

**医生审核点**：①明确"明显胸痛、头晕"的处理流程 ②是否需记录每次步行距离

#### B03 快走

| 字段 | 内容 |
|---|---|
| 动作编号 | B03 |
| 动作名 | 快走 |
| 适用分级 | NYHA Ⅰ／Ⅱ |
| 适用阶段 | 阶段二至阶段三（进阶） |
| 目的 | 提升心肺耐力，进入维持期核心运动 |

**动作过程（含呼吸时相）**
