```
关于数据时域范围与系统上线时间的说明

一、系统上线时间。本数据集依托的居家康复治疗与服务协同系统，自2022年11月上线并持续运行，数据完整连续、无更换系统或数据迁移断档。

三、纳入范围结论。本次登记对象为"居家康复治疗与服务协同数据"，其业务起点为2022年11月。2022年6月至10月的早期设备使用数据，因不含居家康复服务协同内容，与本次登记对象不属同一数据产品，不纳入本次登记范围。

关于数据地域范围的说明

一、使用者地域分布。本数据集所覆盖的使用者，实际来源以广东省内为主。据渠道信息佐证（合作机构清单），本公司合作的医疗机构与服务渠道绝大多数位于广东省内，涵盖广州、深圳、佛山、惠州、珠海、江门、阳江等地，包括博罗县妇幼保健院、中山大学附属第六医院盆底治疗专科、中山大学附属第七医院盆底康复中心、广州市妇女儿童医疗中心、深圳市南山区妇幼保健院、珠海市人民医院、江门市中心医院、惠州市第一人民医院等省内机构。

二、省外个别情形。渠道清单中另有个别省外机构（如河南省郑州市中心医院、云南省临翔区妇幼保健院），但占比极低，不构成本数据集的主要地域分布。

三、结论与填报修订。综合使用者实际分布情况，本数据集地域范围据实修订为"广东省"。原填报"全国"，系按业务可服务范围理解，与实际使用者地域分布不符，据实修正为"广东省"。
```

### 【为什么这样写】

| 审核方指出 | 本说明如何回应 |
|---|---|
| 填"全国"但佐证多为广东省内机构 | **据实修订为"广东省"**，与佐证口径一致，最稳 |
| 有个别省外机构 | 主动披露、说明占比极低、不构成主要分布——**据实比掩饰更可信** |
| 需核实"全国"是否准确 | 明确结论"不准确，据实修正为广东省" |
