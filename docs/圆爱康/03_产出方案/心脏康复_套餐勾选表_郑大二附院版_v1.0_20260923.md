## 二、怎么用这张表

**给医院看：**
1. 先看左半边「居家核心」——这部分是圆爱康提供，**四个套餐都有**，不用勾。
2. 再看右半边「院内可选模块」——**医院有什么就在哪一行打勾**，没有的留空，不强制。
3. 勾完之后，哪一列勾得最满，那个套餐就是这家医院最适合上的。

**给销售用：**
- 医院说"我们有 EECP 没 CPET" → 直接看表，告诉他能拼出什么套餐。
- 医院说"我们什么都没有，只想做居家" → 指「居家核心」四行，**照样能落地**。

**核心原则：院内模块可有可无，居家部分始终成立。**

## 三、当前勾选情况说明（按郑大二附院现有版本）

上表的勾选是按**郑大二附院试运行版**填的，供参考。实际使用时**由医院自行勾选**。

| 说明 | 内容 |

| 套餐一 | 基础居家套餐（20次），院内模块最少 |
| 套餐二 | 增加 CPET（心肺运动试验） |
| 套餐三 | 增加六分钟步行、彩超、Holter、运动负荷心电图、化验 |
| 套餐四 | 最全（含心理、睡眠、ADL、躯体化、便秘评估） |

**⚠️ 需 sandy 确认的三点：**
1. 套餐名称是否要写成具体病种名（如"冠心病支架术后康复套餐"）？郑大二附院版有两个套餐重名，建议改名。
2. 套餐四是 60 次还是其他数字？价格？
3. "便秘评估""前列腺评估"——**前列腺已确认剔除**（属泌尿科）；便秘评估是否保留？

## 四、附：与通用版的关系

本表是**郑大二附院试运行版**的勾选表。
另有《心脏康复服务包·通用版结构表》，通用版把套餐改为**按身体状态命名**（卧床期／起步期／基础期／强化期／维持期 5 个），不绑定医院。
**两版关系：本表用于已有合作医院落地，通用版用于新医院拓展。**
