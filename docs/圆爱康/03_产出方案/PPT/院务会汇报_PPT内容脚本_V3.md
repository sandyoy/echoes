## P2 · 先看大势：居家康复为什么必须现在做

**左侧/上半——政策在推：**
- 国家卫健委「互联网+护理服务」试点扩面，居家康复是明确方向
- 医保支付改革（DRG/DIP）倒逼医院缩短平均住院日——但出院后的康复谁来管？

**右侧/下半——患者在变：**
- 盆底、心脏、认知等居家康复需求年增速超 30%
- 大量患者"想治疗、但嫌来医院麻烦/没时间"，治疗被一拖再拖

**底部结论（大号字）：**
居家康复不是选做题，是必答题。

**设计建议：**
- 左右/上下分栏；左侧📋政策浅蓝，右侧📈需求浅绿
- 底部粗体大字突出结论

## P4 · 为什么居家康复落地难

**左侧——医院的痛：**
- 患者出院＝失联，科室没有工具和人力管出院后患者
- 想做居家康复但缺三样：技术平台、运营团队、服务闭环

**右侧——患者的痛：**
- 出院后没人管，不知道何时复诊、怎么做
- 跑医院太折腾，想治却没时间 / 嫌麻烦，治疗一拖再拖

**底部：** 这就是我们要解决的事。

## P5 · 我们是谁 —— 智慧家康的底座能力（四端）

> 页面提示：这是"我们必须有、别人也有的底盘"，一笔带过建立信任，**不是差异化卖点**。呈现为底座，不展开。

**四个底座能力（四宫格）：**
- 🏥 **三端互联平台**：医院端（医生看数据，跟查房一样）/ 患者端（训练、看进度）/ 运营端（客服随访）
- 👩‍⚕️ **六师共管体系**：医生/康复师/护士（归属医院）+ 客服/工程师/督导（圆爱康）—— 帮医护减负，让医护能管更多患者
- 📈 **患者运营体系**：存量患者激活（产后42天召回、PCI随访）→ 提升依从性和复购
- 🏷️ **开放设备平台**：绑定设备但不卖，按标准精选适合居家的设备

**设计建议：**
- 四宫格，每格图标+一句
- 定位为"底座"，视觉上低于后面差异化页
- **绝不出现数据归属、患者归属表述**

## P6 · 患者在我们平台走一遍 —— 全流程证据链（新增·重点）

> 页面提示：这是本版核心新增。不横向比竞品，而是把"患者在平台每一个触点，我们做了什么、患者得到什么"做成一条证据链，用效果说话。这才是"别人抄不走"的。

**六步证据链（从左到右/从上到下）：**

| 环节 | 我们做了什么 | 患者/科室得到了什么 |
|------|-------------|---------------------|
| ① 入院/医生开方 | 平台即时对接医生方案，设备信息同步 | 不跑腿，方案即达 |
| ② 设备到家 | 圆爱康寄设备+首次远程教学 | 免去医院往返 |
| ③ 居家治疗 | 24小时客服：人工 + Agent 智能体 + 自我学习，实时响应 | 随时有人应，依从性高 |
| ④ 客服跟催 | 客服按疗程主动提醒、督促、指导 | 治疗完成率 98.7% |
| ⑤ 评估/复诊 | 客服提醒患者回院复诊，疗效数据同步医生 | 医生掌握疗效，患者回流复诊 |
| ⑥ 复购/续单 | 医院据评估结果转化复购；平台支撑续单 | 科室增收、患者复购率 30%+ |

**底部一句话：**
我们做的不是平台，是把"每个触点上患者都被管住、科室都增收"，用体系跑成现实。

**设计建议：**
- 用一条横向流程轴，六节点逐步推进
- 每节点分两行："我们做" / "患者得到"
- 突出④⑤的客服和复诊回流（院务会爱听患者回流、科室增收）
- **不出现"收编/圈患者/抢患者"等词**

## P7 · 盆底治疗闭环 —— 一条完整的居家治疗线（新增·临床主任视角）

> 页面提示：给临床主任/医生看流程是否真正通。注意区分两类设备的闭环。

**明确两种闭环（用图标区分，不混）：**

**盆底（设备自带评估）—— 全程闭环：**
```
医院开方 → 设备到家 → 在家治疗 → 线上评估 → 疗效结论 → 复诊转化续单
```
- 设备自带评估，患者线上得出进展结论，无需为评估专门跑院
- 疗效达标结束；未达标 → 医院复诊转化续单

**心脏/骨科等（多数治疗设备不带评估）—— 回院复评闭环：**
```
医院开方 → 设备到家 → 在家治疗 → 客服提醒回院重新评估 → 医院据疗效复诊转化闭环
```
- 治疗完成后，我们的客服**主动提醒患者回院评估**，由医院读取疗效、转化复购

**核心表达：**
- 无论哪种闭环，**"患者回流复诊、由医院评估和转化"是共同主线**——这是院务会最关心的：患者回流、科室有后续收入
- 我们做的是"把治疗过程管到顺"，复诊转化归医院

## P9 · 医院怎么跟我们合作

**医院出什么：**
- ✅ 场地（现有科室）
- ✅ 医护人员（医生+康复师+护士）

**我们出什么：**
- ✅ 三端互联平台 + 六师共管运营团队
- ✅ 精选居家康复设备（绑定但不卖）
- ✅ 患者运营 + 全流程客服管家

**结果是什么：**
- ✅ 医院获得纯增量收入
- ✅ 患者出院不离院、持续回流复诊
- ✅ 科室口碑提升、患者黏性增强

**设计建议：**
- 三栏：医院出 ← 合作 → 我们出 → 结果
- 每栏底色区分（浅蓝/浅绿/浅橙）

## P10 · 我们跟其他医院的合作方式

**四步走（横向时间轴）：**
① 招标（1-2月）→ ② 签约（2月）→ ③ 启动（2-3月，选一专科部署培训）→ ④ 扩面（3月起，口碑扩散）

**底部核心原则：**
先从1个科室开始，做出口碑和效果后，其他科室自然想加入。患者在哪，服务就跟到哪。

## P11 · 为什么选我们

> 页面提示：讲"我们不一样"，但**不踩竞品、不讲"别人没有/不行"**。让差异在事实里长出来。

**四条对比式表述（温和、不攻击）：**
- 🟦 **不是纯软件公司** → 我们做的是"运营+服务"，不只是系统
- 🟩 **不是纯设备商** → 设备是载体，六师共管和运营才是闭环
- 🟧 **全流程管家** → 24小时人工+智能体客服，每个触点患者都被管住（对应P6证据链）
- 🟪 **已验证的模式** → 20+ 医院验证，数据可查，不是概念

**设计建议：**
- 四条色块并列，"从XX"到"我们是XX"温和对比
- 最后一条放大强调"已验证"
- **不出现"别人没X能力""行业无人做"等踩竞品表述**
