## P2 · 先看大势：居家康复为什么现在必须做

**左侧/上半——政策在推（多层次）：**
- 国务院「互联网+医疗健康」、互联网+护理、互联网+康复等顶层设计密集落地
- 康复医疗首次被提升为国家战略：国办发文推进康复医疗工作发展
- 医养结合、老年健康、居家医疗服务等连续多个国家级文件明确方向

**右侧/下半——巨大的未满足需求（数据痛点在）：**
- **美国约80美元/人/年康复费用，中国仅约7.25美元/人**（不足1/10）
- **美国康复治疗师约5人/10万人口，中国约0.4人**（不足1/10）
- **美国康复辅具使用率约82%，中国仅约7.3%**
- 缺口 = 中国康复医疗的巨大增长空间，居家/社区康复是补缺口的最快路径

**底部结论（大号字）：**
居家康复不是选做题，是必答题。

**设计建议：**
- 左右/上下分栏；左侧📋政策浅蓝，右侧📈缺口对比浅绿
- 右侧用"中美对比"卡片，突出"不足1/10"差距
- 底部粗体大字结论

> 📌 数据来源：政策文件名称见P2-辅助页；康复费用/治疗师/辅具等中美对比数据来自中国网财经2024报道（周燕芳代表提案），可标注"数据：公开报道"

## P4 · 为什么居家康复落地难 / 为什么医院必须做

**左侧——医院的痛（三个缺口）：**
- 出院后康复断档：患者出院＝失联，科室没工具/人力管
- 政策已要求做康复延伸，但缺三样：技术平台、运营团队、服务闭环
- **康复资源缺口巨大**（人均费用、治疗师仅为美国1/10），院内床位/人力覆盖不过来

**右侧——患者的痛：**
- 出院后没人管，不知何时复诊、怎么做
- 跑医院太折腾，想治没时间 / 嫌麻烦，治疗一拖再拖、甚至流失

**底部：** 这就是我们要解决的事——把院内康复延伸到家里，补齐这个缺口。

**设计建议：**
- 左右对比：左侧🏥医院三个缺口、右侧👤患者两个痛点
- 左侧可加"中美康复资源10倍差距"小卡强化紧迫性
- 底部转折到"我们的解决方案"

## P4b（关键补充）· 医保/支付趋势：居家康复的付费意愿在上升

> 页面提示：给财务/分管副院长看，缓解"居家康复患者愿不愿付费"的疑虑。

- 医保改革（DRG/DIP）倒逼医院缩短平均住院日 → **患者出院后康复由谁承接？居家康复承接**
- 国家已为"互联网+远程医疗服务"开放自主定价口子 → 居家康复服务包可自主定价
- 患者为"方便+能持续被管"付费意愿高，居家康复客单价足以支撑独立运营
- 参考：多个省级"互联网+医疗健康/护理"试点已落地相关项目定价与支付路径

**设计建议：** 可选页，视时间与对象决定是否呈现；对财务敏感可保守只留DRG/DIP痛点。

## P6 · 患者在我们平台走一遍 —— 全流程证据链（新增·重点）

> 页面提示：这是本版核心新增。不横向比竞品，而是把"患者在平台每一个触点，我们做了什么、患者得到什么"做成一条证据链，用效果说话。这才是"别人抄不走"的。

**六步证据链（从左到右/从上到下）：**

| 环节 | 我们做了什么 | 患者/科室得到了什么 |
|------|-------------|---------------------|
| ① 入院/医生开方 | 平台即时对接医生方案，设备信息同步 | 不跑腿，方案即达 |
| ② 设备到家 | 圆爱康寄设备+首次远程教学 | 免去医院往返 |
| ③ 居家治疗 | 24小时客服：人工 + Agent 智能体 + 自我学习，实时响应 | 随时有人应，依从性高 |
| ④ 客服跟催 | 客服按疗程主动提醒、督促、指导 | 治疗完成率 98.7% |
| ⑤ 评估/复诊 | 客服提醒患者回院复诊，疗效数据同步医生 | 医生掌握疗效，患者回流复诊 |
| ⑥ 复购/续单 | 医院据评估结果转化复购；平台支撑续单 | 科室增收、患者复购率 30%+ |

**底部一句话：**
我们做的不是平台，是把"每个触点上患者都被管住、科室都增收"，用体系跑成现实。

**设计建议：**
- 用一条横向流程轴，六节点逐步推进
- 每节点分两行："我们做" / "患者得到"
- 突出④⑤的客服和复诊回流（院务会爱听患者回流、科室增收）
- **不出现"收编/圈患者/抢患者"等词**

## P7 · 盆底治疗闭环 —— 一条完整的居家治疗线（新增·临床主任视角）

> 页面提示：给临床主任/医生看流程是否真正通。注意区分两类设备的闭环。

**明确两种闭环（用图标区分，不混）：**

**盆底（设备自带评估）—— 全程闭环：**
```
医院开方 → 设备到家 → 在家治疗 → 线上评估 → 疗效结论 → 复诊转化续单
```
- 设备自带评估，患者线上得出进展结论，无需为评估专门跑院
- 疗效达标结束；未达标 → 医院复诊转化续单

**心脏/骨科等（多数治疗设备不带评估）—— 回院复评闭环：**
```
医院开方 → 设备到家 → 在家治疗 → 客服提醒回院重新评估 → 医院据疗效复诊转化闭环
```
- 治疗完成后，我们的客服**主动提醒患者回院评估**，由医院读取疗效、转化复购

**核心表达：**
- 无论哪种闭环，**"患者回流复诊、由医院评估和转化"是共同主线**——这是院务会最关心的：患者回流、科室有后续收入
- 我们做的是"把治疗过程管到顺"，复诊转化归医院

## P10 · 我们跟其他医院的合作方式

**四步走（横向时间轴）：**
① 招标（1-2月）→ ② 签约（2月）→ ③ 启动（2-3月，选一专科部署培训）→ ④ 扩面（3月起，口碑扩散）

**底部核心原则：**
