## 二、必须返工的 4 张

### 🔴 B01 原地踏步 —— 画成了「登阶」，是另一个动作

| 项 | 内容 |
|---|---|
| **清单要求** | **原地踏步**：站立，一手扶椅背防跌倒，原地交替抬腿，膝抬至约45度，**零位移** |
| **图上实际** | 站立，右手扶**阶梯凳**，左脚**踩上踏板**——是「登阶/上下台阶」，有器械、有位移 |
| **为什么必须改** | 两者不是一个动作。登阶多了器械依赖、有跨步位移与跌倒风险，负荷也高于原地踏步。心脏康复起步期（阶段一）只能给最低负荷、零位移的动作 |
| **具体怎么改** | 取消阶梯凳。人物站立，**一手轻扶椅背或墙面**，在**原地**做交替抬腿踏步，屈髋抬至大腿与小腿约成直角（约45度），脚掌完整落地，节奏均匀 |

### 🔴 E01 坐位踝泵 —— 画成了「直腿抬高」，踝泵是防血栓的关键动作

| 项 | 内容 |
|---|---|
| **清单要求** | **坐位踝泵**：脚踝做「勾脚—绷脚」的上下往复运动（踝关节背屈/跖屈），**小腿以下动作**，腿本身不动 |
| **图上实际** | 坐沙发，**双腿前伸**，两个红色箭头指向水平方向——呈现为「直腿抬高」 |
| **为什么必须改** | 踝泵是本套动作里**唯一针对下肢静脉血栓预防**的动作，也是 NYHA Ⅳ 级卧床患者唯一能做的下肢动作，价值就在「小腿肌肉泵」这个机制上。画成直腿抬高，机制完全不同，等于这个动作的意义丢了 |
| **具体怎么改** | 机位收到**小腿与脚部**：人物坐位（或半卧），腿自然放松不动，**只有脚踝做勾脚（脚尖朝自己）→ 绷脚（脚尖朝前）的往复**。建议加箭头表示脚踝上下摆动方向，让「踝在动、腿没动」一眼可见 |

### 🔴 A03 坐位肩颈放松 —— 图上只有静坐闭眼，看不到肩颈动作

| 项 | 内容 |
|---|---|
| **清单要求** | **坐位肩颈放松**，三节：①耸肩绕肩（双肩上提至耳侧，向后划圈落下，前后各8次）②颈部侧屈（头向左/右侧屈，各5次）③扩胸（双手交叉置脑后，双肘向后打开，8次）。**不做颈部环绕** |
| **图上实际** | 端坐闭眼、双手掌心向下搭在大腿上，为**静息调息**姿态，画面中无肩颈动作特征 |
| **为什么必须改** | 这个动作是每次运动**前的准备活动**，作用在「放松上身、打开胸廓」。图上画成了静息坐姿，患者跟做时不知道该动哪里，准备活动的功能没有传达出来 |
| **具体怎么改** | 画出**肩颈动作特征**：建议取「耸肩绕肩」这一节——双肩明显**上提至耳侧**，配合箭头表示**向后划圈**的方向。可另加一帧表现「颈部侧屈」。**保持不露面部、颈部不做环绕**（清单红线） |

### 🔴 C02 靠墙静蹲 —— 膝盖角度画深了，涉及医学安全

| 项 | 内容 |
|---|---|
| **清单要求** | **靠墙静蹲（浅角度）**：背靠墙下滑，**膝关节屈曲不超过30-45度**（浅蹲），膝盖不超过脚尖、不内扣 |
| **图上实际** | 背靠墙，**双膝弯曲接近90度**（大腿接近水平），属标准深蹲幅度 |
| **为什么必须改** | 这是**医学安全**问题，不是美观问题。心脏康复患者的抗阻训练强调**低强度、浅角度**起步；深蹲会显著增加心脏负荷与膝关节压力，**医生审核时一定会打回**。清单明确写「不做到90度」，图上正好做成90度 |
| **具体怎么改** | 把膝屈角度**改浅到约30度**：背靠墙面下滑一点点即停，膝盖只微微弯曲，**大腿接近直立、仅小幅屈曲**，双手自然放在大腿上，双脚离墙约半步、与肩同宽 |

## 三、请确认的 1 张

### 🟡 D02 太极拳·起势与云手 —— 动作归属需确认

| 项 | 内容 |
|---|---|
| **清单要求** | 太极拳·**起势与云手**（简化）：起势（双臂前举至肩高、屈膝下按）+ 云手（重心左右移、手在胸前划弧，上手不过眉、下手不过脐） |
| **图上实际** | 马步站姿，**双手在胸前呈抱球状**，掌心相对 |
| **判断** | 「抱球」是太极拳的经典姿态，**属太极拳范畴，不算画错**，但不是「云手」的划弧特征 |
| **请你定** | ①按现状接受（抱球也是太极拳，可用）；②或让同事补一帧「云手划弧」以贴合清单动作名。**这条不影响其他图，可单独决定** |
