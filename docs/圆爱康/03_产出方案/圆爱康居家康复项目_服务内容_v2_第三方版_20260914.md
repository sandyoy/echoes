# 圆爱康居家康复项目 · 服务内容

（合同附件）

**一、项目咨询服务**
为患者提供项目讲解、服务方式与适配性说明、服务包选型推荐。

**二、订单与排期服务**
协助患者完成服务订单确认，并按医院治疗安排对接服务起止时间。

**三、设备发放服务**
按医院确认的治疗方案准备并发放设备，患者可现场领取核验或选择物流寄送。

**四、设备回收服务**
服务到期后按约定方式回收设备，含清洁消毒处理。

**五、使用教学服务**
提供视频与图文操作指引，并一对一远程指导患者完成设备安装与正确使用。

**六、使用答疑服务**
患者在使用过程中遇到操作问题，随时提供线上答疑。

**七、在线客服服务**
全时段线上客服，受理使用提醒、订单查询、服务进度等咨询。

**八、使用提醒服务**
按医院治疗方案提醒患者使用频次与疗程节点，帮助患者坚持完成。

**九、随访回访服务**
按疗程周期定期线上回访，了解患者使用情况与感受，做好记录。

**十、异常响应服务**
发现患者未按方案使用或使用中断时，主动联系患者了解并协助解决；需医院处理的情形及时告知医院对接人。

**十一、报告推送服务**
按疗程生成治疗过程报告，以电子方式推送给患者。

**十二、报告解读服务**
协助安排报告解读，帮助患者看懂自己的治疗情况。

**十三、档案管理服务**
患者治疗记录与报告在系统内留档，支持随时查询与下载打印。

**十四、设备运维服务**
设备使用异常时提供远程排查与指导处理。

**十五、软件支持服务**
客户端软件及小程序使用中的登录、功能等问题提供线上协助。

**十六、服务周期管理**
服务到期前提前提醒患者，受理续期、延期及服务调整咨询。

**十七、意见反馈服务**
收集患者在使用过程中的意见与建议，跟进处理并反馈结果。

**十八、项目对接服务**
安排专职对接人与医院指定科室保持日常沟通，保障服务运行顺畅。
