# 圆爱康居家康复项目 · 服务内容（合同附件版）

1. **前置咨询服务**：为患者提供项目咨询、服务方式与费用说明、服务包选型推荐，协助完成订单确认与治疗排期对接。

2. **评估协同服务**：配合医院完成患者参与居家治疗所需资料收集与信息录入，衔接治疗前评估流程。

3. **设备发放核验**：按医院确认名单与技术方案完成设备准备、发放与现场核验，支持现场领取与物流寄送两种方式。

4. **设备周期管理**：按约定周期管理服务起止时间，到期前提前提醒，并按约定方式配合完成设备回收。

5. **设备清洁消毒**：回收设备按感染控制要求完成清洁消毒并做好记录。

6. **线上操作教学**：提供视频与图文操作指引，涵盖设备使用、配件安装、参数确认与日常维护。

7. **远程使用指导**：为首次使用设备的患者提供一对一远程指导，完成安装调试与操作要点教学。

8. **居家规范宣教**：向患者讲解使用环境要求、注意事项与不适情形下的联系渠道。

9. **全时段客服**：提供全时段线上客服，受理设备操作、使用提醒、订单物流、服务期限等咨询。

10. **问题响应闭环**：对患者消息及时响应并记录跟进，确保每条问题有回复、有结果反馈。

11. **数据采集回传**：保障居家治疗数据完整采集并实时回传至医院端口。

12. **数据查看支持**：保障医院端可随时查看患者居家治疗执行情况。

13. **数据存档留痕**：治疗数据按周期留档，形成可追溯记录供医院调阅。

14. **异常即时响应**：发现数据异常或治疗中断时即时响应，第一时间联系患者了解并协助解决。

15. **医院同步协同**：需医院介入的情形即时通知医院对接人，协助联系患者并跟进处理结果。

16. **定期线上随访**：按治疗周期执行定期回访，了解居家治疗执行情况并做好记录。

17. **治疗执行提醒**：按医院设定的治疗方案提醒患者使用频次与疗程节点。

18. **报告解读协同**：配合医院完成报告推送与反馈收集，协助安排报告解读环节。

19. **报告生成推送**：按疗程节点生成治疗报告并以电子方式推送至患者与医院。

20. **档案云端归档**：患者治疗数据与报告云端归档，支持历史记录查询与下载打印。

21. **远程故障排查**：设备使用异常时提供远程排查，指导患者完成基础自检与复位。

22. **软件问题协助**：客户端软件及小程序端登录、上传、功能使用问题提供线上协助处理。

23. **设备保障服务**：按约定提供设备保障方案，硬件故障时按约定方式处理。

24. **服务周期管理**：按约定周期管理服务起止，到期前提前提醒患者与医院。

25. **续期延期咨询**：受理服务续期、延期及套餐调整咨询并协助办理。

26. **反馈收集闭环**：收集医院与患者意见，建立问题台账并逐条跟进至闭环。

27. **项目对接协同**：安排专职对接人，与医院指定科室及管理部门保持日常沟通。
