## 【正面】心脏健康管理闭环 · 让心内科每一位患者都被管起来

> **副标题**：从评估、手术到术后居家康复——让心内科患者「进得来、管得住、跟得上」的完整管理链路

### 患者管理动线（六步闭环）

**第一步｜患者进入心内科**
门诊 / 住院 / 科室通道，患者来到贵院心内科。

**第二步｜心脏评估**
心功能分级（NYHA）、冠脉情况、危险因素评估，为下一步治疗决策提供依据。

**第三步｜一次分岔，两条路径**

| | 无手术指征 | 有手术指征 |
|---|---|---|
| **去向** | 进入居家心脏康复，减轻症状、控制风险 | 安排手术/介入治疗 |
| **之后** | 持续康复管理，防止病情进展 | 术后转入居家心脏康复，巩固疗效、预防再发 |

**第四步｜院内 + 居家，全程有系统管着**
- **院内段（CMS 患者管理系统）**：心内科患者档案、治疗方案、依从性、复诊——**全在 CMS 里管起来**（院内超声治疗 / 院内运动康复记录在案）
- **居家段（圆爱康智慧康复系统）**：
  - 心脏超声波治疗仪 **居家按医嘱使用**
  - **居家运动疗法**——医生开方，视频动作指导，患者在家按方训练
  - **康复方案可远程调整**
  - 训练数据**回落到医生端**（训练时长与完成度可追踪）

**第五步｜形成闭环**
无手术指征的、有手术指征的、术后的——**心内科每一位患者都被纳入管理**，不再有"看完门诊就断了"的患者。

> **一句话**：圆爱康帮贵院心内科，把**全部患者**（而不只是术后患者）纳入心脏健康管理闭环。

## 【背面·一】凭什么信得过

**核心设备**
心脏超声波治疗仪（SUT-C）
- 国家二类医疗器械｜注册证号 京械注准 20162091164
- 适用范围：冠心病辅助治疗

**依据的权威文献（6 份）**
| 文献 | 用途 |
|---|---|
| 中国心脏康复指南（2018） | 康复分期、适应证与禁忌证 |
| 慢性心力衰竭心脏康复中国专家共识（2020） | 分阶段运动参数、禁忌证 |
| PCI 术后运动康复专家共识（2016） | 术后启动时机、运动强度 |
| 心脏康复分级诊疗中国专家共识（2022） | 居家康复准入条件 |
| 冠心病患者运动治疗中国专家共识 | 运动治疗原则 |
| 八段锦团体标准 T/CACM 1676—2026 | 传统功法呼吸配合标准 |

> 学术共识指出：**规律的心脏康复是心血管疾病长期管理的重要一环**。

## 【背面·二】系统怎么管（院内 CMS + 居家系统，一套闭环）

**院内段｜CMS 患者管理系统（圆爱康自研·供科室使用）**

一套独立的**院内患者管理系统**，帮心内科把科室内的患者管起来：

| 端口 | 使用者 | 管理内容 |
|---|---|---|
| **医护 PC 管理端** | 科室医护 | 患者档案管理、治疗方案录入下发、治疗数据查看、依从性监测、复诊提醒、科室治疗量统计 |
| **医生管理小程序** | 科室医生 | 随时查看患者数据、调整治疗方案、接收消息提醒（碎片时间也能管） |
| **患者使用小程序（预约）** | 患者 | 预约登记、治疗记录查看、就诊提醒、健康信息填报 |

- **可单独部署**，也可与居家系统组合成完整体系
- **可按模块拆用**，科室按需选用

> CMS 覆盖四类管理场景：**专科管理 / 居家衔接 / 运营统计 / 筛查与活动入组**。

**居家段｜圆爱康智慧康复系统**

**医生端**
- 查看患者康复方案与执行回执
- 训练时长与完成度可追踪
- 可远程调整方案

**患者端（患者在家用）**
- 视频动作指导，大字幕、自动跳转
- 心脏超声治疗仪按医嘱居家使用
- 每日训练任务清晰可执行

**两段怎么接上**
- **院内段 → CMS 管理**：心内科患者、治疗路径、依从性、复诊，全在 CMS 里
- **出院 → 转入居家康复系统**：治疗方案在院外延续，治疗数据双向连通
- **合起来 = 院内—居家完整闭环**：这也是圆爱康「智慧康复」的完整形态

## 【背面·三】患者被怎么管（全流程管理动作）

| # | 管理环节 | 管理动作 |
|---|---|---|
| 1 | 建档入组 | 患者进入科室体系，建立康复档案 |
| 2 | 方案下达 | 医生核定治疗方案，录入系统、下发给患者 |
| 3 | 居家执行 | 患者按方案在家治疗/训练，系统按日推送任务 |
| 4 | 依从性监测 | 跟踪治疗执行，未按时治疗者提醒、协助坚持 |
| 5 | 随访记录 | 按治疗周期定期回访，记录使用情况与感受 |
| 6 | 异常响应 | 治疗中断或使用异常时主动联系，需医院处理的及时告知对接人 |
| 7 | 数据回落 | 训练数据回落到医生端，时长与完成度可追踪 |
| 8 | 报告生成 | 按疗程生成治疗过程报告，供医生查阅与解读 |
| 9 | 方案调整 | 医生按数据远程调整方案并下发 |
| 10 | 复诊衔接 | 复诊提醒、疗程衔接，让患者持续在管理体系内 |

> **一句话**：从建档、开方、执行、监测到复诊——**患者整个康复过程都在管理体系里**。

## 【背面·四】给贵院带来什么

| 维度 | 价值 |
|---|---|
| **患者管理** | 从"只管术后"到"全量管理"——心内科每一位患者都不流失 |
| **管理不断链** | 院内 CMS 管，出院居家系统接着管，患者始终在科室体系内 |
| **不增负担** | 不占医院人手，系统化管理由圆爱康承接 |
| **管理延伸** | 康复护理资源向社区和家庭延伸——响应国家分级诊疗与康复扩容政策方向 |
