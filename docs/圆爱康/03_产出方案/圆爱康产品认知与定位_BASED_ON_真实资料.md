## 〇、顶层定性（最外层认知）

> **圆爱康提出并实践的，是「智慧家康模式」——一套居家康复服务管理模式。**
>
> 「智慧家康模式」把医院各专科的专业治疗能力延伸到患者家中：患者在合作医疗机构**执业医师开具的方案**指导下，于家中使用医疗级设备完成治疗性训练，治疗数据实时回传医院，由**六师共管团队**分工协作随访管理、医师评估调整方案，形成**不断档的延续治疗闭环**。

**这一定性的三层含义：**
- **"智慧家康"** —— 模式名（不是产品名，不是公司名）
- **"圆爱康提出"** —— 归属确权
- **"居家康复服务管理模式"** —— 性质（医疗范畴、服务形态、可复制）

**五要素**（名称与顺序不得改动）：①医疗级家用设备 ②治疗数据物联网 ③院内-居家治疗闭环 ④六师共管 ⑤医院主导·第三方赋能

## 一、圆爱康自己是什么（设备 + 平台 + 六师）

圆爱康不是纯粹的"设备厂"，是 **"医疗级居家治疗设备 + 物联网平台 + 六师远程共管"** 三位一体的居家康复服务商，也就是**「智慧家康模式」**的提出者与实践者。

| 心脏超声波治疗仪 | 天行健 | 心脏康复（心膜炎/冠心病/心律不齐/心功能不全等） | 居家 |

**"六师共管"是哪六师（从资料确认）：** ①科室专科医生 ②治疗师 ③专科护师 ④线下督导 ⑤设备工程师 ⑥线上专业客服。把专业医疗能力赋能居家，让居家能达到医疗治疗目标。

**从这份表得出的铁证（圆爱康的护城河）：**
1. **医护端服务管理小程序** —— 竞品全是"患者端APP+卖设备"，圆爱康多一个医护端工具，医生/护士能管患者。这是竞品没有的。
2. **六师共管** —— 竞品卖完设备就完了，圆爱康有六师远程管患者。这是服务层差异。
3. **治疗方案与院内处方一致** —— 竞品的居家设备跟医院开的处方脱节，圆爱康居家治疗和院内处方一致，这是"医疗级"的关键证据。
4. **租赁模式（¥1600-2300）** —— 竞品多是"卖设备"（¥3500-11000），圆爱康走租赁，患者门槛低。

> 这跟之前聊的一致：圆爱康的差异正在于**"监测类看着你、治疗类圆爱康也看着你，但圆爱康同时用医护端+六师+处方一致把'治'做到医疗级"**。

## 三、圆爱康在居家大盘的位置（修正后）

之前版本用了外面AI编的竞品举例（如"伟思有家用盆底"——已核实是错的，伟思是院内设备）。**修正后的定位：**

```
居家健康服务大盘（从高到低）
┌─────────────────────────────────────────────┐
│ 顶层·居家治疗/康复（真医疗·稀缺）            │
│  盆底康复：圆爱康(圆小汫) vs 麦澜德/乐普/杉山│
│  心脏康复：圆爱康(天行健心脏超声波)          │
│  认知康复：圆爱康(鹤灵认知)【待确认】        │
│  神经康复：圆爱康院内线(天行健脑康)          │
├─────────────────────────────────────────────┤
│ 中层·医护上门/远程诊疗（半医疗）              │
├─────────────────────────────────────────────┤
│ 下层·居家监测/营养/用药/生活照料（服务/数据） │
│  鱼跃/华为/福寿康等                          │
└─────────────────────────────────────────────┘
```

**圆爱康的独特位置（与竞品对照，硬事实）：**
- 同赛道竞品（麦澜德/乐普/杉山/麻麻康）都在顶层"卖居家盆底设备"
- **圆爱康的差异不是"设备"，是"医护端+六师+院内处方一致"** —— 把"卖设备"升级成"医疗级居家治疗服务"
- 这正是观察竞品（监测类、单纯卖设备类）都够不着的一格
