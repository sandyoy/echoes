# 郑州经济技术开发区"三甲—社区—居家"智慧家康联动建设工程方案（汇总版）

> 为积极落实国家分级诊疗、居家养老和医养结合相关部署，推动优质医疗资源下沉基层，特提出本方案，供审议指导。

---

## 一、建设背景

党中央、国务院系列部署明确：推动优质医疗资源扩容下沉，推进分级诊疗，发展居家和社区医养结合服务，实施健康中国行动。将康复服务由院内延伸至家庭，已成为医疗卫生改革的方向性共识。

郑州经济技术开发区此前已在基层医疗领域投入建设了社区病房、救护车等基础设施，具备承接分级诊疗的硬件基础。但从实际运行看，患者在三甲医院治疗后、回归社区与家庭阶段的"院外管理"仍属短板——院外管理不到位，直接导致慢病复发、再住院率上升，医疗成本沉淀于医保和家庭。

本方案补齐这一环节，盘活区内现有资源，将三甲医院技术能力延伸至社区与家庭，形成"三甲—社区—居家"服务闭环。

---
## 二、政策依据（详见配套解读文件）

本方案严格落实**《国家卫生健康委办公厅关于进一步健全城市社区卫生服务体系 提升服务能力的通知》（国卫办基层发〔2026〕7号）**的各项要求，特别是三甲医院分区包片帮扶社区、"康复医师下沉"、"居家康复护理"、"数智化赋能"与"引入社会力量"等方向。本项目"三甲—社区—居家"联动正是该文件鼓励的实现路径，方案各环节与政策条款的详细对应关系见配套《政策理解与依据》文件。

## 三、项目定位与整体架构

### 3.1 项目定位

本项目由**郑州经济技术开发区政府牵头**，协同三甲医疗下沉，引领社区卫生服务中心及社区基层工作人员，区域统筹居家护理、智慧养老、慢病全程管理一体化建设。积极拓展"互联网智能体＋居家上门护理服务"，推进家庭病床和家庭养老床位落地；搭建智慧健康监测平台，深化家庭医生签约服务；落实慢病分级分类、全程闭环管理，推动医疗资源下沉社区及家庭，构建"居家可及"的医养康复服务格局，打通居家健康服务"最后一米"，切实增强群众获得感、幸福感。

### 3.2 一句话定位

**以区域内三级甲等医院（郑州市第七人民医院）为技术枢纽，区属社区为服务网点，以成熟第三方专业服务机构为技术支持方，打造"三甲—社区—居家"三位一体、多病种的智慧家康联动体系，建设郑州经济技术开发区首个慢病全周期居家康复管理示范区。**

### 3.3 核心逻辑：四个"零"与一个"闭环"

- **零设备采购**：评估与康复设备由第三方机构自带，区、医院、社区无需采购资金
- **零养人负担**：康复执行与指导由第三方专业团队完成，基层医护无新增用人压力
- **零软件开发**：依托成熟数字化平台，复用全国已运营样板，本区无需从零搭建
- **零风险启动**：依托成熟模式落地，效果可见、稳步推进、分步实施
- **一个闭环**：筛查/宣教 → 评估 → 三甲诊疗 → 居家/社区康复 → 数据反馈，全程闭环、留痕、可量化

### 3.4 平台载体

依托**已在多家医院成熟运营、可直接本区复用的数字化健康管理平台**，提供医生端、患者App、社区端、决策数据大屏等端口，各端均为成熟产品，本区直接启用，无需定制开发。

## 四、多病种服务内容（试点聚焦）

### 核心病种一：心脏康复

- 依托郑州市第七人民医院心血管专科实力，承接术后、PCI术后、心衰稳定期患者的**院外延续康复**。三甲开处方，第三方承接居家执行。
- 服务：入院/出院评估、康复处方、居家远程康复（超声电治疗设备＋远程指导）、数据实时监测与急症预警、双向转诊。

### 核心病种二：盆底／产后康复

- 依托社区筛查，前置"早发现、早干预"，服务产后女性及中老年盆底功能障碍患者。
- 服务：社区筛查（表面肌电评估仪）、快速评估与报告解读、居家治疗方案、六师共管远程指导、周期结束效果复评。

### 扩展病种：神经康复与慢病综合管理

- 面向认知障碍早期（MCI）、脑卒中后康复、儿童发育迟缓等，提供居家数字疗法与延续康复；后续可扩展。

> 各病种依托**同一套平台、一支专业团队、统一数据底座**协同，一次体系落地、长期多病种复用，边际扩展成本低。

## 六、联动机制（系统支撑下的双入口闭环）

**本项目落地依赖成熟的圆爱康"互联网+居家康复"系统支撑**（CMS患者管理系统＋小程序＋H5活动页＋公众号接口），医院、街道、社区只需向圆爱康开放公众号接口，所有患者最终汇聚到圆爱康小程序内完成预约、购买与执行，流程自动化跑通，无需医院、街道投入系统开发。

**入口一 · 医院科室（经七院公众号）**
```
七院评估 → 医生让患者选"在家做/医院做" → 选"在家做"
→ 点七院公众号"互联网+居家康复"入口 → 跳转圆爱康小程序
→ 在线购买居家康复 → 后续执行全由圆爱康承担
```

**入口二 · 社区/街道（经街道/社区公众号）**
```
街道用CMS发布活动 → 街道公众号 → 居民点链接跳圆爱康H5/小程序预约报名
→ 活动当日社区医生初筛/或到社区用院内设备评估 → 分级：
   轻症 → 点社区医院公众号 → 跳圆爱康小程序 → 直接买单居家康复
   重症 → 重症转诊 → CMS生成转诊单 → 圆爱康对接七院科室号源
        → 患者小程序预约科室号 → 到院就诊（院内费用由医院收取）
```

**闭环原则**：所有患者汇聚圆爱康系统执行；组织协调以社区、街道为主；医疗行为与院内费用归医院；圆爱康只做服务执行与技术支撑，不触碰医疗收费。

**协同机制**：月度专班调度会（区领导牵头）＋每周技术例会（医院＋第三方）＋季度评估会（卫健＋民政＋第三方＋医院），对标量化指标督办。

## 七、实施路径（先试点、见数据、再扩面）

- **第一阶段·试点（第1-2个月）**：以七院一个对口科室为起点，优先开一次科室会；同步设1-2个社区卫生服务点，社区牵头第一场筛查。**直接启用圆爱康成熟系统（CMS＋小程序＋公众号接口对接），免开发上线**，打通"科室/社区双入口→评估→居家执行→数据回传"全过程闭环，积累首批数据。
- **第二阶段·扩面（第3个月起）**：按试点成效扩至更多社区、开放多病种、健康讲座与专家义诊常态化、按月输出运营报告。
- **推广期**：形成全区慢病全周期康复管理网络。

> 全案以"先试点、见数据、再扩面"为原则，各方以最小成本验证模式，效果显著后再行复制推广。

## 八、项目价值

- **民生名片**：建设郑州经济技术开发区首个"三甲—社区—居家"慢病康复管理示范区，可承接各级考察观摩
- **财政效益**：零设备采购、零养人负担、零软件投入；居家康复降低慢病复发与再住院率，从源头压缩医保支出
- **治理考核**：补齐筛查覆盖率、慢病管理率、康复随访率、双向转诊量等公卫考核指标，全数据化、可追踪
- **区域协同**：以市七院为技术枢纽，深化区域医联体；依托全国样板形成"全国经验—本地落地"路径

### 示范期可量化目标

| 指标 | 预期成效 |
|:---|:---:|
| 心脏康复参与率 | 由不足10%提升至30%以上 |
| 盆底疾病筛查覆盖率 | 试点社区提升至60%以上 |
| 出院患者延续康复转诊率 | 建立并持续提升 |
| 慢病居家管理达标率 | 提升20-30个百分点 |
| 居家康复依从率 | 80%以上 |

## 九、成熟经验与落地基础

本项目服务模式已在全国**50家医院**实际运营验证，代表性机构包括：中山医科大学附属第六医院（一年）、南方医科大学附属第八医院（半年多）、花都妇幼保健院（一年）、珠海妇幼保健院（两年）、珠海人民医院（三年）、广东省第二人民医院（一年半）、武汉亚心总医院（一年）等，已具备成熟可复制的落地基础。
