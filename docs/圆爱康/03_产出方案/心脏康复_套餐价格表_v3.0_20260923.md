## 四、最终价格怎么算

**这家医院的价格 = 圆爱康标准价（按次数） + 医院勾选的院内项目加价**

- 医院只做居家 → 按我们的标准价
- 医院要加项目 → 在标准价上另计，具体金额由医院与圆爱康商定

**每家有院内项目参与的医院，价格表略有不同——这是正常的，底价始终是圆爱康的标准价。**
