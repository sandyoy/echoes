# 心脏康复门诊科普片 ·【第二支 · 病种版】分镜脚本 v1.0

> **形态**：✅ 可直接开拍/直接剪辑的落地分镜脚本（纯旁白版 · 零真人出镜）
> **片长**：主版约 6~7 分钟（与配音稿一致）／每段可独立拆成 40~60 秒视频号短内容
> **画面策略**：**关键场景实拍 + 医学过程动画 + 素材库过场**，与第一支共用素材
> **口径基准**：与《心脏康复门诊科普片_病种版_第二支_文字稿_20260918》逐字一致，画面不得引入稿外信息
> **不做的事**：无真人出镜 / 无品牌名 / 无价格 / 无医院名 / 无疗效承诺数字
> **复用**：素材清单见第一支分镜脚本「素材采购清单」，M1~M14 全部通用

---

## 读法说明（给拍摄和剪辑的人）

1. **【镜号】** = 拍摄/剪辑最小单位。
2. **【画】** = 镜头里出现什么；**【动】** = 镜头怎么走。
3. **【配音】** = 严格对应配音稿原文，一个字不许改（改了会和第一支口径打架）。
4. **【拍法】** 三种标签：`实拍` / `素材` / `动画`。
5. **⭐ = 关键镜头**，不要省。

## ⚠️ 本支特别红线（除通用四条外，追加两条）

| # | 红线 | 落地做法 |
|---|---|---|

# 【拍摄与制作要求】

## 画面风格
- **调性**：专业、清楚、不吓人。**本支比第一支更"讲道理"，画面以解释性动画为主。**
- **色调**：暖白 + 浅绿（同第一支），病名类字幕卡用**深绿底金字**；危险提示（斑块破裂/血管堵死）用**低饱和暗红**，不做血红。
- **原则**：所有病理解释**用简笔/扁平风格**，不做写实解剖（避免血腥感）。

## 动画规范（三处质量锚点）
1. **水管→血管 双线并行**：第一段的"垢"与第六段的"杂质挂壁"必须用**同一套视觉语言**，观众才会串起来。
2. **局部 vs 全局**（镜 3-3）：这是全支最敏感的一镜，务必"先给足支架正面，再拉远视野"，不要让观众误读成"支架没用"。
3. **六卡翻面**（镜 7-2）：六张病名卡同时翻成"次数/时长/频率"——这是全支的收口逻辑，动画要慢、要清楚。

## 音乐
- 每一段独立：前 4 秒微沉 → 中段平稳 → 段尾收束 0.5 秒（**因为要拆条，每段必须有完整起收**）
- **不要跨段连续 BGM**，否则拆条后音乐断头断尾
- 全片不要激昂、不要励志 BGM

## 配音
- **纯旁白，中低音，语速偏慢（270~280 字/分钟）**
- 必须停顿的词：`它不疼` `救的是命` `不是整条路` `心脏在超负荷` `要的是次数` `最怕的就是断`
- **"这一段你要记住的一句话"读的时候要有明显停顿**，像在跟人叮嘱

## 字幕
- **全程字幕**（视频号大量静音观看）
- 病名类关键词（冠脉硬化/心肌缺血/心力衰竭/心律失常）**一律整屏大字卡片，停留 ≥ 2 秒**
- 关键数字（10次/36次/150分钟）**金色**
- 段尾"你要记住的一句话"**单独一屏，居中，不叠在画面上**

## 片尾（医院可自定）
- 不出现任何品牌/厂商
- 可放：（　　）科 门诊时间 / 咨询电话 / 医院LOGO（需医院提供并同意）
- 若用于视频号：**必须加免责字幕**——"本内容为健康科普，不构成诊疗建议，具体诊疗请遵医嘱。"
