## 二、这张表怎么看（给销售/给医院）

**第一步：定行。** 患者现在什么状态？
- 刚做完手术还躺着 → 套餐一 卧床期
- 出院一周、走几步就喘 → 套餐二 起步期
- 术后一个月、日常活动没问题 → 套餐三 基础期
- 术后三个月、想恢复运动能力 → 套餐四 强化期
- 长期维持、防止复发 → 套餐五 维持期

**第二步：看中列①。** 居家套餐里的东西**五个套餐完全一样**（超声治疗仪＋医生远程＋数据落医生端＋六师共管），**不分期**。变的是**运动疗法做哪几个动作**——越往后动作越多，逐级长出来。

**第三步：看中列②。** 医院有什么就勾什么，**没有的不勾，不强制**。这一栏决定**医院的实际配合深度**。

**第四步：价格。** 由医院勾选的院内项目决定。

## 三、三个关键规则（对外讲的时候要用到）

**规则一：超声治疗不分期。**
心脏超声波治疗仪是每日1次×30分钟×每疗程10次的固定方案，**五个套餐完全一致**。分期的只有运动疗法。

**规则二：动作逐级长出来，每级只加1-2个新动作。**
患者不会一次面对14个动作，学习成本最低：
- 卧床期 4 个 → 起步期 5 个 → 基础期 5 个 → 强化期 9 个 → 维持期 14 个

**规则三：院内模块可有可无，居家部分始终成立。**
医院条件不足不影响项目落地——这正是居家模式的价值。
