# 载体二 · 墙上科普海报

> 贴在科室墙面，患者可站定慢慢读。中等篇幅，讲透一层道理。

**主标题**

## 心脏康复：出院以后，还有很长的路要走

**正文**

**冠心病的管理，分两段**

一段是**医院里做的**——手术、用药、检查，解决眼前的问题；
另一段是**出院之后的**——血压、血脂、血糖、体重怎么管，日常怎么动。

后一段更长，往往要持续几十年。国内外心脏康复指南都指出：**规律的心脏康复，是冠心病长期管理的重要一环。**

**一个常见的误解**

"我的血管还没堵到要放支架，先不用管。"

血管狭窄需要时间才表现出来，但风险因素（高血压、高血脂、高血糖、超重、缺少运动、吸烟）在更早就已经在起作用。
**没到手术指征，不代表可以放着不管。** 该控制的控制，该运动的运动，该康复的康复。

**心脏康复包含什么**

- **运动康复**：由医生制定运动处方，从呼吸训练、慢走，逐步到有氧、轻度抗阻，按恢复情况循序渐进
- **危险因素管理**：血压、血脂、血糖、体重的综合管理方案
- **综合评估**：心理、睡眠、日常活动能力等方面的评估与跟进
- **随访支持**：治疗方案由医生制定与调整，治疗情况由医护人员跟进

**一句话**

> 心脏康复不是"多此一举"，而是冠心病管理本来就该有的一半。

**屏脚**

> 想了解自己是否适合心脏康复，请咨询本科室医生。
> 〔本内容参考公开心脏康复指南等学术资料整理，为健康科普，不作为诊疗依据〕

# 载体三 · 宣传折页（三折页）

> 患者拿在手里看，可带走。信息最完整。

**封面**

## 心脏康复
### 出院以后，还有很长的路

封面小字：冠心病长期管理科普 · 〔医院科室名〕

**内页一 · 为什么**

**手术和吃药，只是第一段**

血管通了、药吃上了，急性风险先稳住。但出院之后的日子更长——
血压、血脂、血糖、体重、日常运动，这些决定了往后的风险走向。

指南指出：**规律的心脏康复，是冠心病长期管理的重要一环。**

**一个常见误解**

"血管还没堵到要放支架，先不用管？"
—— 风险因素往往在更早就已经起作用。
**没到手术指征，也要运动、要康复、要治疗。**

**内页二 · 做什么**

**心脏康复包含四项**

1. **运动康复**
   由医生制定运动处方，从呼吸训练、慢走，逐步到有氧运动与轻度抗阻训练，按恢复情况循序渐进。

2. **危险因素管理**
   血压、血脂、血糖、体重的综合管理方案。

3. **综合评估**
   心理状态、睡眠、日常活动能力等方面的评估与跟进。

4. **随访支持**
   治疗方案由医生制定与调整，治疗情况由医护人员持续跟进。

**内页三 · 怎么做**

**怎么开始**

1. 到本院科室就诊，由医生评估
2. 医生确认适合后，为您制定方案
3. 按方案进行，医生定期随访、跟进调整

**哪些情况请先咨询医生**

存在以下情况时，请先请医生评估是否适合：
- 安静状态下即有胸痛，或明显气短
- 血压未控制（收缩压 ≥180mmHg 或舒张压 ≥110mmHg）
- 安静时心率 ＞100 次／分，或 ＜50 次／分
- 新发心律失常，或原有心律失常加重
- 急性心力衰竭、严重主动脉瓣狭窄
- 合并急性感染、发热
- 医生明确告知暂不宜活动

**出现以下情况请立即停止并告知医生**：
胸闷 · 胸痛 · 明显气短 · 心慌 · 头晕 · 大汗 · 下肢无力

> 具体诊疗方案请遵医嘱。

# 制作与投放说明（给同事·不印在物料上）

1. **三载体一套内容**：核心信息一致（"没到手术指征也要康复"），只是字数与节奏按载体调整。可同时投放，也可按医院需要只做其中几个。
2. **字号**：面向老年患者，正文字号宁大勿小。易拉宝标题要"路过就能看清"。
3. **不出现**：公司名（圆爱康）、价格、医生姓名、疗效承诺（"治好""避免支架""缓解率"）。
4. **配图**：居家／诊室场景，老年患者形象，柔和暖光，**不出现真人面部特写**。
5. **落款**：以医院科室名义落款；如医院要求，可在角落以极小字号标注"技术支持：圆爱康"（由医院决定是否保留）。
