## 二、建议改动（共 6 处，全部只改"依据/安全"文字，不改动作本身）

### 改动 1 · 抗阻训练参数（C01 坐位抬腿 / C02 靠墙静蹲）

| | 内容 |
|---|---|
| **原稿** | 起始负荷、每组次数、术后启动时机 —— 标"待核" |
| **改成** | 补一段《抗阻训练参数（依据）》： |
| | · 起始：**无负重/自身重量起**；器械类低风险 **40% 1RM** 起、中高风险 **20%~30% 1RM** 起 |
| | · 剂量：**10~15 个/组，1~3 组/（肌群·次）**；虚弱者 **3~5 次**起渐进到 10~15 次 |
| | · 频率：**1 次/周起始**（慢性心衰每日 1 次） |
| | · 术后启动：PCI 桡动脉 **24h 后**评估、股动脉 **7d 后**；心衰稳定 **7d 后**；**以医生评估结论启动** |
| **出处** | PCI 术后共识 表4 + 运动时间栏；慢性心衰共识；中国心脏康复指南 |
| **影响** | 只加一段依据，动作描述不变 |

### 改动 2 · 新增"不做 1RM 测定"声明 ⭐

| | 内容 |
|---|---|
| **原稿** | 无此声明 |
| **改成** | 在抗阻训练安全说明里**加一句**：「**本方案不做 1RM 测定**。依据：1-RM 测量可能对心衰患者增加心血管风险，目前并不常用（慢性心衰共识 2020）」 |
| **为什么重要** | 医生很可能问"你用多少 %1RM 得有 1RM 数据吧" → 这句话**反向解释我们为什么不做**，是把短板变成专业度的关键 |
| **出处** | 慢性心衰共识 |

### 改动 3 · 强度参数升级为"分层 + 分阶段"双维度

| | 内容 |
|---|---|
| **原稿** | 各动作强度栏写"心率区间、时长"，单薄、标"待核" |
| **改成** | ① 强度改**双轨表达**：RPE 自感劳累（居家首选）+ 靶心率=静息心率+20~30 次 |
| | ② 按分层给值：低风险 RPE **12~13**；中高风险 RPE **10~11**；慢性心衰 RPE **<12** |
| | ③ 时长：起始（低风险 5~10min / 中高风险 15~30min）→ 目标 **30~60min** |
| | ④ 频率：**≥3 次/周** |
| | ⑤ 心衰分阶段：初始 2 周 peakVO₂ **40%~50%**、15→30min、2~3 次/周；提高期 **50%→60%→70%→80%** |
| | ⑥ **加免责限定**：CPET 相关参数**仅供医生参考，不由第三方执行**（居家无 CPET） |
| **出处** | PCI 术后共识 表4；慢性心衰共识 |
| **影响** | 各动作"强度"栏文字替换，动作本身不变 |

### 改动 4 · 八段锦呼吸配合（D01 / D03）⚠️ **必须改**

| | 内容 |
|---|---|
| **原稿** | 「上举吸气、下落呼气〔以国家体育总局标准版为准，待核实〕」 |
| **问题** | ❌ **与标准原文不符**。标准是 6 段式：一、二自然呼吸；三、四吸气；五停闭；六呼气 |
| **改成** | 「按 **T/CACM 1676—2026 第 5.2.2 条**：动作一、二**自然呼吸**；动作三、四**吸气**；动作五**停闭呼吸**；动作六**呼气**」 |
| **同步加** | ① 「**停闭呼吸不宜超过 2 秒**」（标准 3.1.18）② 「**NYHA III~IV 级者建议全程自然呼吸，不做停闭**」 |
| **口径修正** | ⚠️ 措辞改为「依据 **T/CACM 1676—2026**（该标准以国家体育总局推广版为蓝本）」，**不直呼"国家体育总局标准"**——避免口径不实 |
| **出处** | 八段锦团体标准 T/CACM 1676—2026 |

### 改动 5 · 安全限制栏升级为三级清单

| | 内容 |
|---|---|
| **原稿** | 各动作末尾零散写"安全限制与停止指征" |
| **改成** | 统一升级为**四级**（放文末总表，各动作引用）： |
| | **✅ 准入条件**：8h 内无新发胸痛/心律失常；肌钙蛋白无升高；静息心率 50~120；静息 SBP 90~150 / DBP 60~100；血氧 >90% |
| | **❌ 绝对禁忌**：不稳定心绞痛 / 未控高血压（>180 或 >110）/ 严重瓣膜狭窄伴症状 / 未控心率（>130）/ 未控心衰 / 三度房室传导阻滞未植入起搏器 / 活动性心包炎心肌炎 / 静息 ST 压低抬高 >2mm / 血栓性静脉炎 / 近期血栓栓塞 / 急性栓塞 / 新发房颤房扑 |
| | **⚠️ 相对禁忌（须医生评估）**：1~3d 体重增加 >1.8kg / 用多巴酚丁胺 / 运动时收缩压降低 / **NYHA IV 级** / 劳力时复杂性室性心律失常 / <2 METs 即心肌缺血 / 血糖未控 / 急性甲状腺炎 / 低钾高钾血容量不足 |
| | **🛑 立即停止信号**：头晕、心悸、呼吸急促、明显肌肉疼痛、胸痛 → 停止并坐下 |
| **出处** | 心脏康复分级诊疗共识；中国心脏康复指南；慢性心衰共识（三份互证） |
| **影响** | 大幅增强安全性表述，是**给医生看的"专业度证明"** |

### 改动 6 · 太极拳（D02）待核 → 落定 + 6MWT 降级

| | 内容 |
|---|---|
| **D02 改成** | 「**适用**。依据：推荐采用**太极拳和八段锦**等传统运动形式替代有氧运动（慢性心衰共识 2020）」+ 限定：「**取简化式、以坐位或扶椅站立为主**；不取低架、不取单腿站立平衡动作，防跌倒」 |
| **6MWT 改成** | 原"待核：六分钟步行距离分级" → 改为「**6MWT 在本方案中仅作为前后对比的疗效指标，不做绝对值分级**；如需分级须医生提供依据」 |
| **出处** | 慢性心衰共识（D02）；慢性心衰共识+PCI共识+分级诊疗共识（6MWT 定位） |
| **诚实标注** | 文献**只有类级别推荐**，未细化到具体招式 → **招式仍须医生确认** |
