## 一、已摸到的真实硬情报（非想象，已核实）

### 【香港】长者社区照顾服务券（社区券 / CCSV）—— 圆爱康头号利好

来自香港社会福利署官方 + 2024-25年度财政预算案（财政司司长陈茂波）：

1. **"钱跟人走"资助模式**：港府把补贴直接打进合资格长者的信息系统，老人自己在社区选"日间照料"或"家居照顾/上门服务"，用券付费。
2. **金额**：2013年试行时中度缺损长者**每月最高5800港元**；此后政府补贴随年上调（有共同付款分级）。
3. **2023年9月1日已转恒常措施**，非试点。
4. **2024-25年度扩展**：社区券**适用范围扩展到"租用辅助科技产品"**，社区券增至**11000张，全年开支约9亿港元**。
5. 香港特首2022施政报告：服务券适用**扩展至租借辅助科技产品**。

**→ 对圆爱康的意义（关键咬合）：**
- 圆爱康的核心模式就是**居家康复设备租赁**（盆底仪等，¥1600-2300/月）
- 香港社区券**明确可支付"租用辅助科技产品"** = 圆爱康的房租直接被政府社区券买单
- 这就是圆爱康切香港的**合法、可回款、不依赖人工照护价格战**的切口

**【已摸清】香港器械合规坎 —— 金钥匙（2026-08-11 实锤）**
- 香港医疗器械受 **MDACS 表列制度**监管，参考 IMDRF 分级（I-IV按风险）
- **关键利好**：香港医疗仪器科（MDD）官方决议——**继续试行接受由 NMPA 发出的上市许可，作为第二/三/四类医疗器械符合《基本原则》的证明**。即圆爱康内地已有的 NMPA 注册证，在香港**被认可**，可支撑表列审核，不必强制走 CE
- IVD 类（体外诊断）设备，香港**无专门法律监管进口分销**，限制更松
- 走表列需 CE/510K 及 ISO13485（NMPA认可路径下以NMPA证为主）
- 医疗仪器科 2025-01-21 已更名**医疗器械科**

**【待进一步】香港经营坎：**
- 社区券服务机构需社署认可——圆爱康需通过持牌服务机构承接，还是可单独申请认可
- 香港收款账户 / 资金进出境的合规路径

### 【中国电信】智慧养老/康养生态 —— "搭骨架缺血肉"

来自电信各地分公司公开信息：
1. **武汉电信**："爱心翼站"智慧康养服务体系（响应国家健康老龄化战略）
2. **安徽电信**：智慧家庭"一屏多用"、AI康养服务打通家庭日常硬件设备+居家服务
3. **电信黑科技应用**：云监控、天翼管家等（智慧养老）
4. **电信全球未来康养体验中心**：引入康复陪护机器人

**→ 关键洞察：电信做的是"云端监控 + AI硬件 + 家庭连接 + 呼叫"（骨架层）**
- 全是"监测 / 连接 / 呼叫"层，**没有一个环节真正输出"治疗/康复"**
- 这正是圆爱康能补的**血和肉**：设备开放平台 + 六师共管 + 居家康复病种（盆底/肠胃/心脏）
- 印证：电信搭平台骨架，圆爱康供"康复治疗落地服务"这一环
