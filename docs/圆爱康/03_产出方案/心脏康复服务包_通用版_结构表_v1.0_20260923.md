# 圆爱康 · 心脏康复服务包（通用版）结构表

版本：v1.0 · 2026-09-23 · 小鲸鱼起草
定位：**通用版**——不绑定某一家医院，医院按自身条件勾选院内模块即可落地。
用途：①销售/方案页骨架 ②系统开发依据 ③动作套组与视频脚本的挂载母表

---

## 一、服务包三层结构

| 层级 | 性质 | 内容 | 谁提供 |
|---|---|---|---|
| 第一层 · 居家核心 | 固定，不可拆 | 心脏超声波治疗仪居家租赁 + 医生远程开方调方案 + 治疗数据落医生端 + 六师共管 | 圆爱康（设备+系统+服务）／医院（医生） |
| 第二层 · 院内可选模块 | 医院按条件勾选 | EECP、CPET、六分钟步行试验、各评估量表 | 医院（已有则勾，无则不勾） |
| 第三层 · 患者可执行内容 | 配套，随第一层交付 | 运动疗法（按病种+心功能分级固定套组 + 动作视频 + 播完回传）、营养疗法 | 圆爱康（内容+系统）／医院（医生审定） |

---

## 二、第一层 · 居家核心（固定项）

| 项目 | 内容 | 疗程 | 说明 |
|---|---|---|---|
| 心脏超声波治疗仪 | 居家租赁，患者在家自行治疗 | 每日1次×30分钟，每疗程10次，建议1-3疗程 | 设备型号 SUT-C，注册证由注册人（天行健）提供 |
| 医生远程服务 | 线上评估解读、方案制定与调整 | 随疗程 | 由合作医院执业医师执行 |
| 数据服务 | 治疗数据落入圆爱康系统医生端，医生随时可见 | 全程 | 医院需要时由圆爱康打包提供 |
| 六师共管 | 医生/康复师/护士（院方）+ 线上客服/线下督导/设备工程师（我方） | 全程 | 6个角色不等于6个人 |

**说明：20次／40次／60次＝全部在家完成的疗程数**（即2个、4个、6个疗程），不含院内。

## 三、第二层 · 院内可选模块（医院勾选表）

> 用法：医院在「有／无」栏打勾，有则纳入服务包，无则留空跳过。**不强制、不替代医院既有项目。**

|---|---|---|---|

| 心肺运动试验 CPET | 院内心肺功能评估，确定安全运动阈值 | ☐有 ☐无 | ☐ |
| 六分钟步行试验 | 院内活动耐力评估 | ☐有 ☐无 | ☐ |
| 心脏彩超／射血分数 | 结构功能评估 | ☐有 ☐无 | ☐ |
| 动态心电图 Holter | 心律评估 | ☐有 ☐无 | ☐ |
| 运动负荷心电图 | 心肌缺血筛查、安全运动阈值 | ☐有 ☐无 | ☐ |
| 血脂血糖等化验 | 危险因素评估 | ☐有 ☐无 | ☐ |
| 心理状态量表 | 焦虑抑郁筛查 | ☐有 ☐无 | ☐ |
| 睡眠呼吸评估 | 睡眠呼吸暂停排查 | ☐有 ☐无 | ☐ |
| ADL 日常生活能力评估 | 自理能力评估 | ☐有 ☐无 | ☐ |
| 躯体化症状评估 | 躯体化量表筛查 | ☐有 ☐无 | ☐ |
| 便秘评估 | 便秘相关评估 | ☐有 ☐无 | ☐ |
| 营养体重管理处方 | 营养与体重管理方案 | ☐有 ☐无 | ☐ |

## 四、第三层 · 患者可执行内容

### 4.1 运动疗法（本次新增·核心增量）

| 项目 | 设计 |
|---|---|
| 组织方式 | **按病种 + 心功能分级给固定套组**，医生像选套餐一样选（例：心功能不全 II 级 → A 套组） |
| 交付形态 | 每套组配**整套动作视频**，患者打开跟着做 |
| 打卡方式 | 视频播放完成（或播至80%）才记入完成 |
| 数据回传 | 训练时长与完成度回传至**圆爱康系统医生端** |
| 跟踪方式 | 医生端可见 + 客服按节点跟进 |

**⚠️ 对外表述红线**：只能说"**训练时长与完成度可追踪**"，**绝不能说"能看到患者动作是否标准"**——一旦这么说即承诺影像审核能力，出事要担责。

## 五、医院设备勾选对照表（一页速览版）

| 医院条件 | 可勾选的院内模块 | 服务包完整度 |
|---|---|---|
| 三级医院·心脏康复中心齐全 | EECP + CPET + 六分钟步行 + 全套评估 | 全套 |
| 三级医院·有心功能评估无 EECP | CPET 或 六分钟步行 + 彩超 + 化验 | 完整 |
| 二级医院·评估能力有限 | 六分钟步行 + 彩超 + 化验 | 基础版 |
| 社区／基层 | 无院内模块，仅慢病随访 | 仅居家核心 |

**核心原则：院内模块可有可无，居家核心始终成立。** 医院条件不足不影响项目落地——这正是居家模式的价值所在。

## 五点五、与现有版本（郑大二附院·试运行版）的差异说明

现有试运行版为「4 套餐 × 3 档（20/40/60次）= 12 行」，价格 1980／2980／3580 元。本通用版在其基础上做了以下修正：

| 项 | 现有试运行版 | 本通用版 | 原因 |
|---|---|---|---|
| 套餐命名 | 「冠心病支架术后康复套餐」出现两次，区别仅在 EECP 与 CPET | 按**病种+心功能分级**命名，套餐名唯一 | 避免同医院同套餐名重复，医生开单、患者下单不会选错 |
| 前列腺评估 | 出现在心内科服务包「服务内容」中 | **已剔除** | 属泌尿科项目，误植入；心内包带此项目会被心内科医生质疑专业度 |
| EECP／CPET | 直接写进每个套餐 | 列为**院内可选模块**，医院有才勾 | 非所有医院都有，硬写会导致承诺不能兑现 |
| 价格 | 20/40/60次 = 1980/2980/3580 | 〔待定〕，沿用结构 | 价格属商务口径，由 sandy 定 |
| 疗程含义 | 未标注院内/居家 | 明确 **20/40/60次＝全部在家做的次数** | 避免销售与客户理解偏差 |
