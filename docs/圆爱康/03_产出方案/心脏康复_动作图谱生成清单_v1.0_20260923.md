# 圆爱康 · 心脏康复 动作图谱生成清单

版本：v1.0 · 2026-09-23 · 小鲸鱼起草
用途：**交给同事用 AI 工具生成 14 张动作图谱**。每张图谱 = 一个动作的标准姿态示意，用于①医生审阅标注 ②医生端动作图谱展示。
交付对象：会用 AI 工具的同事

---

## 一、生成前必读（3条铁律，先看再看下面的清单）

### 铁律1 · 图片文件名 = 动作编号（最重要）
生成后**必须**按动作编号命名，例如 `A01.jpg` `B01.jpg` `D02.jpg`。
原因：收到后要用程序按编号自动匹配进《医生标注表》，文件名错了就会错位。

### 铁律2 · 统一视觉规范（所有图必须一致，否则整套不能用）
| 项目 | 要求 |
|---|---|
| 画幅 | **竖屏 9:16**（患者端手机用） |
| 风格 | **扁平插画**（flat illustration），不要 3D、不要写实照片 |
| 人物 | **65岁以上亚洲老年人**，体型偏普通（不要健身身材） |
| 面部 | **不露五官**（侧脸或简化处理），避免肖像问题 |
| 环境 | **简朴居家**（客厅/卧室），不要健身房、不要医院病房 |
| 配色 | 主色 **品牌绿 #0b6b5c**，辅色 **金 #c9a227**，白底为主 |
| 文字 | **图上不要生成文字**（文字我们后期叠，AI 出字容易乱码） |
| 动作幅度 | **保守**，以"老人能安全做到"为准 |
| 画面构图 | **全身可见**（能看到手和脚），不要只拍半身 |

### 铁律3 · 出图后自查5项（每张都要过一遍）
1. 关节角度是否符合清单描述（尤其膝关节、肩关节）
2. 有无"憋气征兆"——面部涨红、颈部紧绷（有则重出）
3. 手脚是否都在画面内（被裁掉就重出）
4. 环境是否居家（出现健身房/医院则重出）
5. 人物是否偏年轻/偏健壮（不符合则重出）

## 二、通用提示词（每次生成都要带上这段）

### 正面基础词（放在动作描述后面）
```
65岁以上亚洲老年人，普通体型，简朴居家客厅环境，扁平插画风格，
不露五官，竖屏9:16，全身可见，柔和自然光，动作幅度保守，
医学教学调性，安静克制
```

### 负面提示词（每次都要粘贴，防止 AI 跑偏）
```
不要年轻人，不要健身身材，不要健身房，不要医院病房，
不要面部特写，不要快速动作，不要夸张幅度，不要3D渲染，
不要写实照片，不要文字，不要医疗器械贴在身上，不要跳跃
```

### 机位说明
- **侧面机位**（side view）：适合看姿态角度（如靠墙静蹲、坐位抬腿）
- **正面机位**（front view）：适合看对称性（如八段锦、太极拳）
- **标注"双机位"的**：说明该动作需出一张正面 + 一张侧面（共2张）
