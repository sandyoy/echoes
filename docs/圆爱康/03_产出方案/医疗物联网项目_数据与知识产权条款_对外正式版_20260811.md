# 医疗物联网项目 · 数据与知识产权条款（对外正式版）

> 适用对象：医院（甲方/采购方）与圆爱康（乙方/物联网设备+平台+康复服务提供商）
> 使用方式：本条款可直接整体写入服务合同，措辞经打磨为"医院逐字可读、不显强势、但责任边界清晰"的正式合同语言。
> 版本：v1.0 · 2026-08-11

## 第X条 数据管理与知识产权

1. **患者信息及诊疗数据**：本项目在运营过程中收集的患者个人信息、健康档案、电子病历、诊断与治疗记录、康复评估等诊疗相关数据，属于医疗数据范畴。双方确认，该等数据的处理与保管须严格遵守《个人信息保护法》《数据安全法》及医疗服务相关法律、法规和监管要求，由甲方（医院）依法承担患者信息安全与诊疗责任，乙方应配合甲方履行相应合规义务并对相关数据负有严格的保密责任。

2. **为保障本项目设备及服务正常、稳定运行**，乙方需获取必要的设备运行状态、使用情况等技术数据；该等设备技术数据仅用于设备维护、功能优化与服务质量提升，不涉及任何患者的个人身份识别信息。

3. **双方共同致力于提升本项目的康复服务效果与患者体验**，同意在本条前述合规前提下，就项目所需的必要数据在双方之间进行合理、必要的协作与共享，以保障服务连续性与质量。任何一方对项目数据的获取与使用，均应以服务本项目患者为目的，不损害患者权益，不违反适用法律，亦不用于本条约定范围以外的商业用途，并对涉密信息承担保密义务。

4. **知识产权**：各方在签订本协议前已拥有的知识产权，以及各方在履行本协议过程中自行独立开发所形成的知识产权，仍归其各自所有。任何一方不得侵犯或主张另一方既有的及独立研发形成的知识产权。

5. 本条各项约定不构成对任何一方依其合法权利之限制，亦不影响双方依据其他约定承担应尽之义务。

## 使用说明（内部参考 · 勿随合同外发）

### 这一条"看起来"给了医院什么
- **第1款**：明确患者诊疗数据由医院依法主导、担责，乙方严格保密 → 医院觉得"数据是我的、乙方还懂规矩、很专业"
- **第3款**：强调"共同提升服务质量、以服务患者为目的、合规" → 医院读到的是"合作共赢、依法办事"，无戒备

### 这一条"实际"为圆爱康守住了什么
| 条款 | 圆爱康实际得到的保障 |
|---|---|
| **第2款** | 设备运行/技术数据归属乙方的业务需要被确认，且明确不含患者身份识别信息 → **设备数据命脉归乙方** |
| **第3款** | 用"必要的协作与共享"轻轻打开**数据反哺使用**的空间，医院感受是"正常合作"，而圆爱康保住了优化服务的数据使用权 |
| **第4款** | **乙方既有及独立研发的知识产权永远归乙方**，医院不得主张 → **防火墙，必不可少** |

### 为什么医院读了不觉得强势
- 通篇没有"乙方有权""乙方独立享有""x x 归乙方所有"的对抗性表述
- 用的是"双方确认""为保障项目""为提升服务""以服务患者为目的"的**目的性、合作性语言**
- 把医院的**法定责任、患者权益、合规**放在最前面，医院的掌控感和专业尊严都被照顾到
- 圆爱康的防线（设备数据、知产、反哺空间）全部用**中性的事实描述**自然带出，不显眼但都在

---

### 一句话记住怎么用
> **把第1款（医院担责）说透让医院放心，把第4款（知产归各自）写实是圆爱康的底线，中间第2、3款是圆爱康占住"设备数据+反哺空间"的暗子。** 整条一起交上去，医院看完只会觉得"专业、合理、又尊重医院"，不会觉得被冒犯。
