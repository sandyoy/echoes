# 一、同品种医疗器械判定

申报产品ESA-F01、ESA-V01、ESA-S01型生物反馈电刺激治疗仪的医疗器械管理类别为Ⅱ类，未列入《免于进行临床试验的医疗器械目录》。依据《医疗器械临床评价技术指导原则》（总局通告2015年第14号）、《肌电生物反馈治疗仪注册技术审查指导原则》（国家药监局通告2019年第79号），可以通过同品种医疗器械临床试验或临床使用获得的数据，对申报产品进行临床评价。

同品种医疗器械是指与申报产品在基本原理、结构组成、制造材料（有源类产品为与人体接触部分的制造材料）、生产工艺、性能要求、安全性评价、符合的国家/行业标准、预期用途等方面基本等同的已获准境内注册的产品。申报产品与同品种医疗器械的差异不对产品的安全有效性产生不利影响，可视为基本等同。

见表1，将申报产品与选定的一个同品种医疗器械——南京伟思医疗科技股份有限公司的生物刺激反馈仪（型号规格：S4 10、S4 20、S4 30、S4 40、S4 50、S4 60；注册证号：苏械注准20242092160）进行对比，结果表明，二者的结构组成、性能要求有差异，在其他项目上相同或基本等同。该同品种医疗器械于2024年经江苏省药品监督管理局批准上市，其注册证《适用范围》采用按功能方向列举的表述方式，已明确覆盖盆底功能障碍、产后康复等与本申报产品拟扩展方向相对应的功能领域，可为本次适用范围延续变更提供同类已获准产品的先例支撑。
