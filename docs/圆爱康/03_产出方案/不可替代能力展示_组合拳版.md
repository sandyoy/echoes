## 〇、先讲清：为什么不能只说"我们有XX"

我们的三端、六师共管、闭环、数据报告——**这些功能，任何一家对手都能摆出来**。
只要我们把话停在"我们有这些能力"，就永远处在被"别家也有"顶回来的位置。

所以真正的打法不是"我们有什么"，而是：

> **这些能力别人或许各有其一张，但只有圆爱康把它们捏成一整套"别人打不出"的组合。**

这套组合 = 三张牌 × 一条逻辑。

## 第一张牌　治疗闭环 —— 别人是"看着"，我们是"收着"

### 一句话
> 监测类产品帮医院"看着"患者（复诊提醒器）；
> 圆爱康帮医院"收下"患者（把患者变成你的长期患者）。

### 为什么这张牌别人抄不走

| | 监测类产品 | 圆爱康·盆底治疗闭环 |
|---|---|---|
| 起点 | 患者已经在医院，在院外可能流失 | 患者因"方便"才肯来，**本来就拖着没来看** |
| 结构 | 监测→出问题→提醒回院 | 开方→设备到家→在家治→**线上评估**→复诊转化→续单 |
| 数据源头 | 读数来自"人"，是**观察** | 治疗行为由设备产生，是**治疗记录**，有处方为证 |
| 终点 | 患者可以选择不回来 | 患者被设备+客服+医生一起"收进"治疗流程 |
| 归属感 | 医院=被提醒的一方 | 医院=主治方，患者归医院 |

**关键事实（设备上有评估功能）：**
盆底项目设备自带评估 → 治疗完**线上直接评估** → 没达到目标 → **复诊转化** → 做第二次流程。整条闭环（开方→设备→治疗→评估→复诊→续单）**无需患者回来排队**。

**对手为何做不到：** 监测类只有"提醒"，没有"治疗+评估+续单"的居家闭环装置，**结构上就没有"收编患者"的能力**。

## 第二张牌　把患者收编成本院长期患者 —— 增量而非存量

### 一句话
> 监测类玩的是"存量"（让已在院的患者回来复诊）；
> 圆爱康玩的是"增量"（把本不想来医院、拖着不治的患者，变成你院的长期患者）。

### 逻辑
- 很多人**想治疗，但嫌来医院麻烦**，往往拖着、甚至流失到别家
- 圆爱康用"发个设备到家就能治 + 本院医生远程管 + 客服全程跟"→ **把这个本来不是医院患者的人，拉进医院的名册**
- 一个人，**只有在家用着你院设备、被你院医生管着，才真正属于你院**。监测设备锁不住人，治疗闭环才锁得住
- 患者信任医院 → 除了他自己治，**还带家里人来治** → 复购 + 全家转化

### 对医院的价值
- 患者量增长 +180.3%（珠海妇幼验证）
- 科室年增收 +194万
- 治疗完成率 98.7%，复购率 30%+
- 不是"复诊提醒"，是**把人变成你院的长期患者**

## 第三张牌　信任链资金设计 —— 双模式适配，规避三方雷区

### 一句话
> 大多数第三方只会一种收款模式，谈不下来就没得谈；
> 圆爱康能根据医院能接受的形态，切换两套方案。

### 两个独立的钱袋子（必须分清）

| 钱袋子 | 性质 | 必须走谁的账 | 原因 |
|--------|------|--------------|------|
| **① 设备押金** | 退患者的抵押金，从哪来退哪去 | **必须走圆爱康账** | 设备是圆爱康买的，押金收自己账才有现金流去买设备、开更多院；若押金全放医院账，院开越多圆爱康垫的设备款越多→现金流压死 |
| **② 服务包费用** | 服务费 | **可走医院主账号 + 实时分账** | 规避"医院拖欠→代理商压款→圆爱康两头吃亏"死结 |

### 模式A（主流）：圆爱康收钱，向医院采购医疗服务
- 患者付费进圆爱康账 → 圆爱康向医院购买"医生远程处方/方案"等医疗服务
- 优势：掌握现金流、谈判地位平等（"我买你的服务" vs "你分钱给我"）
- 适用：接受第三方采购、不担心平台跑路的医院

### 模式B（分账）：主账号挂医院 + 微信实时分账
```
患者 → 圆爱康小程序买单（主账号挂医院端）
   │  已向微信申请分账模式
   ▼
微信支付「分账」接口 —— 每笔自动按签约比例分账
   ├─ 医院应得 → 实时进医院商户号（医院只看到自己拿到的）
   └─ 圆爱康应得 → 实时到圆爱康账 → 再结算代理商
```
- **优势①（对医院）**：钱进医院体系，医院不担心圆爱康跑路、资金链断裂
- **优势②（对圆爱康）**：实时分账绕开"医院拖欠"，圆爱康现金流有保障
- **优势③（对代理商）**：不用再向圆爱康压服务包款，缓解层层压款
- **为什么医院没意见**：分账是微信强制自动的，医院看到的只有自己到账的那部分，**对"没看到的钱"不敏感**

### 为什么这是能力
现实中：医院怕第三方平台收钱跑路 → 越来越谨慎；医院欠代理商的钱非常多 → 层层压款。**圆爱康的双模式 + 实时分账，同时解决"医院怕跑路""代理商怕压款"两个真实痛点** —— 这是其他第三方拿不出的运营能力。
