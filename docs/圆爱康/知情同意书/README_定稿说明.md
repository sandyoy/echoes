## 条款定稿文字（两份一致，只差编号）

1. 您使用家用治疗仪进行康复治疗时，设备会自动记录本次治疗的治疗信息，包括治疗时间、治疗时长、所用治疗方案、电流强度以及肌肉收缩的测量数据。
2. 上述治疗信息由我们保存，用于您的治疗过程管理、医生对您康复情况的评估以及治疗方案的调整。
3. 我们同时保存您的手机号，用于治疗期间的随访与联系。
4. 您可以随时向医护人员了解本人的治疗记录。

## 写作口径（sandy 2026-11-25 逐条纠正后定死）

1. **只写设备实际采集到的字段**。已核对数据字典：采集范围为手机号 + 用户编码 + 设备号 + 治疗时间/时长 + 治疗方案 + 电流强度 + 肌肉收缩测值 + 会话内容。**没有姓名、出生日期、身份证号**，一个字都不能写。写不存在的字段＝替公司承认采了没采的东西。
2. **不写统计、不写第三方、不写匿名化**。写着"可做统计"就等于把授权范围放大，患者当场就有顾虑。
3. **不写撤回同意**。正文是治疗同意书，签了就是接受治疗；既已全款签名，再说"可以撤回"逻辑自相矛盾，患者会以为签了还能反悔。替代写法＝第6条不写，改在文末保留"不做这个项目不影响其他诊疗"的意思（本版未写，如需可加）。
4. **不用法务体**。禁"加密传输/访问权限控制/操作留痕/境内存储/可识别个人信息"这类词——患者看不懂，只觉得在推卸责任。用"医院的医生和康复师要看到""我们也要看到"这种直白表述。
5. **主体写"我们"，不点圆爱康**。这两份是医院拿去给患者签的，出现第三方公司名医院会有顾虑，以后就不愿用这个模板。
