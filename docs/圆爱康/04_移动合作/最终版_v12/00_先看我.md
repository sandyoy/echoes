渠道转化测算 v12.0 · 先看这

【这份是什么】
给中国移动广东政企医疗线看的"一家医院一年能做多大"的算术，也可用于代理商/政府渠道评估盘子。

【一句话结论】
综合医院单家：4科室 → 1,275单 → 434万流水 → 渠道分成 43.4万/年
妇幼专科单家：4科室 → 2,875单 → 747万流水 → 渠道分成 74.7万/年
广东30家盘子：5.4万单 → 1.62亿流水 → 渠道分成 1,615万/年（平均单家 53.8万）

【怎么读】
①先看主文档(docx)里的核算路径——每一行都能自己验算
②三张图是给PPT用的可视化，第6页已拼成一页pptx
③签约率是单独一列（重点科室2%/一般科室1%），改一格全表重算

【对外必须加的三句话（少一句会被问倒）】
1. 30家是铺设目标，不是现有合作数（现有18家）
2. 科室门诊量是医院公开数据，4科室占比40%是估算，院方给实际数据可整表重算
3. 2%签约率是用珠海妇幼实测反推的"已跑通水平"，不是天花板
