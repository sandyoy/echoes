## 【P2 内页】患者的治疗与管理动线

**从患者走进心内科，到术后康复管理，全程不断链。**

**① 患者进入心内科**
门诊 / 住院 / 科室通道。

**② 心脏评估**
心功能分级（NYHA）、冠脉情况、危险因素评估。

**③ 一次分岔，两条路径**

| | 无手术指征 | 有手术指征 |
|---|---|---|
| **去向** | 进入居家心脏康复，减轻症状、控制风险 | 安排手术/介入治疗 |
| **之后** | 持续康复管理，防止病情进展 | 术后转入居家心脏康复，巩固疗效、预防再发 |

**④ 院内 + 居家，全程管理**
- **院内**：患者档案、治疗方案、依从性、复诊，全程记录在案
- **居家**：医生开方，患者在家按方训练，训练数据回落到医生端

**⑤ 患者不流失**
无手术指征的、有手术指征的、术后的——**每一位患者都被持续管理**，不再有"看完门诊就断了"的患者。

## 【P3 内页】在您手上，患者怎么被管起来

### 医生端（您在用）
- 查看患者康复方案与执行回执
- **训练时长与完成度可追踪**——不用追问，患者练没练、练了多少，一目了然
- **远程调整方案**——患者在家，方案随时按数据调
- 按疗程生成治疗报告，供您查阅与解读

### 患者端（患者在家用）
- 视频动作指导，大字幕、自动跳转——不懂也能跟着练
- 心脏超声波治疗仪按医嘱居家使用
- 每日训练任务清晰，患者知道今天该做什么

### 从开方到复诊，全流程管理动作

| # | 环节 | 在您这儿发生的事 |
|---|---|---|
| 1 | 建档 | 患者进入您的管理，建立康复档案 |
| 2 | 开方 | 您核定治疗方案，录入、下发 |
| 3 | 执行 | 患者按方案在家治疗/训练 |
| 4 | 依从性 | 未按时治疗者被提醒、协助坚持 |
| 5 | 随访 | 按周期回访，记录使用情况与感受 |
| 6 | 异常响应 | 治疗中断/异常时主动联系、及时告知您 |
| 7 | 数据回落 | 训练数据回落到医生端，时长/完成度可追踪 |
| 8 | 报告 | 按疗程生成报告，供您查阅 |
| 9 | 调方案 | 您按数据远程调整方案并下发 |
| 10 | 复诊 | 复诊提醒、疗程衔接，患者持续在管理内 |

> **一句话**：从建档、开方、执行、随访到复诊——**您手上的每一位患者，整个康复过程都看得见、管得住**。
