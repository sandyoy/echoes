## 【正面】心脏健康管理闭环 · 让心内科每一位患者都被管起来

> **副标题**：从评估、手术到术后居家康复——一条让心内科患者「进得来、管得住、跟得上」的完整链路

### 患者动线（六步闭环）

**第一步｜患者进入心内科**
门诊 / 住院 / 科室公众号入口，患者来到贵院心内科。

**第二步｜医院做心脏评估**
心功能分级（NYHA）、冠脉情况、危险因素评估——**由贵院医生完成，医疗判断始终在院内**。

**第三步｜一次分岔，两条路径**

| | 无手术指征 | 有手术指征 |
|---|---|---|
| **去向** | 直接进入居家心脏康复，减轻症状、控制风险 | 由贵院安排手术/介入治疗 |
| **之后** | 持续居家康复，防止病情进展 | 术后转入居家心脏康复，巩固疗效、预防再发 |

**第四步｜院内 + 居家，全程有系统管着**
- **院内段（CMS 患者管理系统）**：贵院心内科的患者档案、治疗方案、依从性、复诊——**全在 CMS 里管起来**（院内超声治疗 / 院内运动康复记录在案）
- **居家段（圆爱康智慧康复）**：
  - 心脏超声波治疗仪 **居家租赁使用**
  - **居家运动疗法**——医生开方，视频动作指导，患者在家按方训练
  - **医生远程开方、随时调整方案**——患者的康复方案由贵院医生掌握
  - 训练数据**落到贵院医生端**（训练时长与完成度可追踪）

**第五步｜形成闭环**
无手术指征的、有手术指征的、术后的——**心内科每一位患者都被纳入管理**，不再有"看完门诊就断了"的患者。

**第六步｜数据与主动权回到医院**
圆爱康做的是**执行与运营层**，医疗服务与判断始终在贵院；患者数据第一落点在**贵院医生端**，医院要数据随时可取。

> **一句话**：圆爱康帮贵院心内科，把**全部患者**（而不只是术后患者）纳入心脏健康管理闭环。

## 【背面·一】凭什么信得过

**核心设备**
心脏超声波治疗仪（SUT-C）
- 国家二类医疗器械｜注册证号 京械注准 20162091164
- 适用范围：冠心病辅助治疗
- 注册人：天行健（设备由厂家提供，圆爱康负责居家服务与系统承接）

**依据的权威文献（6 份）**
| 文献 | 用途 |
|---|---|
| 中国心脏康复指南（2018） | 康复分期、适应证与禁忌证 |
| 慢性心力衰竭心脏康复中国专家共识（2020） | 分阶段运动参数、禁忌证 |
| PCI 术后运动康复专家共识（2016） | 术后启动时机、运动强度 |
| 心脏康复分级诊疗中国专家共识（2022） | 居家康复准入条件 |
| 冠心病患者运动治疗中国专家共识 | 运动治疗原则 |
| 八段锦团体标准 T/CACM 1676—2026 | 传统功法呼吸配合标准 |

> 学术共识指出：**规律的心脏康复是心血管疾病长期管理的重要一环**。

## 【背面·二】系统怎么运转（院内 CMS + 居家系统，一套闭环）

**院内段｜CMS 患者管理系统（圆爱康自研·供科室使用）**

一套独立的**院内患者管理系统**，帮心内科把科室内的患者管起来：

| 端口 | 使用者 | 主要功能 |
|---|---|---|
| **医护 PC 管理端** | 科室医护 | 患者档案管理、治疗方案录入下发、治疗数据查看、依从性监测、复诊提醒、科室治疗量统计 |
| **医生管理小程序** | 科室医生 | 随时查看患者数据、调整治疗方案、接收消息提醒（碎片时间也能管） |
| **患者使用小程序（预约）** | 患者 | 预约登记、治疗记录查看、就诊提醒、健康信息填报 |

- **可单独部署**，也可与居家系统组合成完整体系
- **可按模块拆用**，科室按需选配
- **可选与 HIS 对接**（接不接、数据回不回传，按贵院信息科要求）

> CMS 覆盖四类场景：**专科管理 / 居家衔接 / 运营统计 / 筛查与活动入组**。

**居家段｜圆爱康智慧康复系统**

**医生端（贵院医生掌握）**
- 查看患者康复方案与执行回执
- 训练时长与完成度可追踪
- 可远程调整方案

**患者端（患者在家用）**
- 视频动作指导，大字幕、自动跳转
- 心脏超声治疗仪按医嘱居家使用
- 每日训练任务清晰可执行

**两段怎么接上**
- **院内段 → CMS 管理**：贵院心内科患者、治疗路径、依从性、复诊，全在 CMS 里
- **出院 → 转入居家康复系统**：治疗方案在院外延续，治疗数据双向连通
- **合起来 = 院内—居家完整闭环**：这也是圆爱康「智慧康复」的完整形态

> **注**：患者数据第一落点在**贵院医生端**，不是进了第三方就断链
> 医疗判断在贵院，执行运营圆爱康担
> 医院需要数据，我们打包给到医院

## 【背面·三】圆爱康提供哪些服务（居家康复服务内容）

| # | 服务项目 | 服务说明 |
|---|---|---|
| 1 | 项目咨询 | 项目讲解、服务方式说明、服务包选型推荐 |
| 2 | 设备发放与回收 | 按医院治疗方案发放设备，到期按约定回收并清洁消毒 |
| 3 | 治疗运营支持 | 专职服务团队跟踪患者居家治疗执行，负责日常协调与进度跟进 |
| 4 | 居家随访 | 按治疗周期定期线上回访，记录患者使用情况与感受 |
| 5 | 使用提醒 | 提醒使用频次与疗程节点，对未按时治疗者主动联系、协助坚持 |
| 6 | 在线客服 | 全时段线上客服，受理操作答疑、订单查询与服务进度咨询 |
| 7 | 使用教学 | 视频与图文指引 + 一对一远程指导，帮助正确安装使用设备 |
| 8 | 异常响应 | 治疗中断或使用异常时主动联系协助解决，需医院处理的及时告知对接人 |
| 9 | 治疗报告 | 按疗程生成治疗过程报告并推送患者，协助安排解读 |
| 10 | 服务周期与售后保障 | 到期提前提醒、受理续期调整；设备、服务与运营由圆爱康统一负责 |

> **一句话**：从设备到家、到患者每天按时治疗、到报告回到医院——**全链条由圆爱康兜住**，医院只管医疗判断。

## 【背面·四】给贵院带来什么

| 维度 | 价值 |
|---|---|
| **患者管理** | 从"只管术后"到"全量管理"——心内科每一位患者都不流失 |
| **数据主动权** | 患者数据落在贵院医生端，主动权在医院侧 |
| **合规清晰** | 医疗行为留院内（医生核定），执行运营由圆爱康承担，责任边界清楚 |
| **轻资产** | 不占医院人手、不重资产投入，系统与服务由圆爱康提供 |
| **服务延伸** | 康复护理资源向社区和家庭延伸——响应国家分级诊疗与康复扩容政策方向 |
