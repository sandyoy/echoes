# 【第 2 面 · 内页·院内段】

## 一、患者入组后的管理路径

### 闭环动线

```
   ①进来                ②评估                 ③分层
患者进入          六大认知域评估            一次评估，
神经内科门诊·住院   （系统出认知轮廓图）       分出两条路
                          │
          ┌───────────────┴───────────────┐
          ▼                                ▼
   ④A 认知功能下降                    ④B 原发病诊疗
   进入居家认知康复                   由科室按临床路径
   评估驱动、分层训练                   诊疗原发病
          │                                │
          │                                ▼
          │                         ⑤病情稳定后转入居家认知康复
          │                         训练维持、延缓下降
          └───────────────┬───────────────┘
                          ▼
                ⑥全程管理 —— 一条闭环
        院内段由 CMS 患者管理系统管理
        出院后由居家康复系统持续承接
        ── 两段衔接，形成完整闭环 ──
```

**建档入组**：患者经神经内科门诊或住院收治，**由科室医生完成认知评估**（六大认知域及相关量表）。

**一次评估，分出两条路径：**

| | 认知功能下降 | 需先行诊疗原发病 |
|---|---|---|
| **去向** | 纳入居家认知康复，按评估结果分层训练 | 由科室按临床路径诊疗原发病（卒中 / 帕金森 / AD 等） |
| **后续** | 持续训练管理，延缓认知下降 | 病情稳定后转入居家认知康复，维持训练 |

**最终，神经内科认知功能下降患者均纳入统一管理，实现患者管理无断点。**

## 二、院内段：CMS 患者管理系统

**CMS 患者管理系统 —— 实现科室患者的全流程管理：**

| 端口 | 使用者 | 管理内容 |
|---|---|---|
| **医护 PC 管理端** | 科室医护 | 患者档案、训练方案录入与下发、训练数据查看、依从性监测、复诊提醒、科室治疗量统计 |
| **医生管理小程序** | 科室医生 | 患者数据随时查看、训练方案调整、消息提醒（支持随时随地方案管理） |
| **患者使用小程序（预约）** | 患者 | 预约登记、训练记录查看、就诊提醒、健康信息填报 |

- **可独立部署**，亦可与居家系统组合构成完整体系
- **支持模块化拆用**，科室按需配置

> CMS 覆盖四类管理场景：**专科管理 / 居家衔接 / 运营统计 / 筛查与活动入组**。

## 三、居家治疗模块

患者转入居家后，可在以下模块中**由医生按临床需要选用、组合**——各模块之间为**并列关系**，不预设先后、不预设主次：

| 模块 | 内容 | 手段性质 |
|---|---|---|
| **① 认知训练** | 数智化认知评估与训练系统（居家端） | 非药物训练 |
| **② 经颅磁刺激** | 经颅磁刺激治疗仪（家庭款） | 非药物辅助治疗 |

### 模块一 · 认知训练（评估驱动）

**数智化认知评估与训练系统**（国家二类医疗器械）

| 项 | 内容 |
|---|---|
| **建模标准** | 依据国际通用诊断标准 **DSM-V 六大认知域**建模：复合注意 / 学习记忆 / 知觉运动 / 语言言语 / 执行抑制 / 社会认知 |
| **训练任务** | **六大模块 · 36 个标准训练任务**（可依临床需要自定义扩展至 40 个） |
| **难度分级** | **每个任务设 6-12 个难度**，按评估结果自适应匹配 |
| **评估量表** | 配套 **42 个量表**（覆盖认知、精神、行为、老年人评估、运动、儿童六个面向） |
| **评估逻辑** | 多维评估 → 系统生成**认知轮廓图**（直观呈现障碍范围与程度）→ 各任务给出正确率及建议起始难度 → 医生一键开训 → 训练记录回传，医生据此调整难度 |

> **无评估，不康复。** 难度非医生手动设定，而是由评估生成、经医生核定。

### 模块二 · 经颅磁刺激（居家）

**经颅磁刺激治疗仪**（国家二类医疗器械）
- 注册证号 **苏械注准 20192090432**｜型号 **EK-9100A 家庭款**（适用于居家使用）
- **适用范围（注册证原文）**：「适用于缺血性脑血管病、神经衰弱、脑损伤性疾病的辅助治疗」

- 使用时长与频次**按方案执行**，使用情况回传医生端
- 有明确禁忌人群，使用前经筛查
- 少数使用者可能出现头皮不适、头晕；出现不适即停用

### 两个模块的关系

两者均为**非药物手段**，**均可在居家场景开展**，**按需选用**，相互独立。

> 经颅磁的使用以注册证适用范围为准。

## 四、六师共管 · 全程协同管理

患者自院内至居家，全程由多角色团队协同管理：

| 组别 | 角色 | 职责 |
|---|---|---|
| **院方** | 医生、康复师、护士 | 认知评估判断与训练方案制定 |
| **圆爱康** | 线上客服、线下督导、设备工程师 | 服务执行、随访跟进、设备保障 |

> 患者无论处于院内或居家阶段，均由专职团队持续跟进管理。
> **六师共管**贯穿院内与居家两段，是服务执行的保障机制。

# 【第 3 面 · 内页·居家段】

## 五、院内外衔接：出院后训练的持续开展

患者出院后，康复由**智慧居家康复系统**承接 —— **医生掌握、患者执行、团队跟进**：

**医生端**
- 查看患者训练方案与执行回执
- 训练时长与完成度可追踪
- 可远程调整任务与难度

**患者端**
- 平板 / 手机 / 微信小程序，居家即可训练
- 训练任务清晰可执行，难度随进度自适应
- 居家经颅磁按医嘱使用

**院内外衔接方式**
- **院内段**：由 CMS 管理患者、训练路径、依从性、复诊等全流程信息
- **出院后**：转入居家康复系统，训练方案在院外延续
- **两者衔接，构成院内—居家完整闭环**，亦即**智慧居家康复**的完整形态

**患者管理全过程**：
建档入组 → 医生核定训练方案并下发 → 患者居家训练（系统按日推送任务）→ 训练依从性跟踪，未坚持者予以提醒 → 训练记录回传供医生查阅 → 医生依据数据远程调整难度 → 复诊衔接

## 七、服务类型：三类，按时长选用

患者转入居家康复，**由医生评估后确定服务类型与时长档**：

| 服务类型 | 内容 | 规格档 |
|---|---|---|
| **① 认知训练** | 数智化认知评估与训练系统（居家端） | 30 天 / 60 天 / 12 个月（时长内不限次数） |
| **② 居家经颅磁** | 经颅磁刺激治疗仪（EK-9100A 家庭款） | 10 送 2 / 20 送 5 / 30 送 5 |
| **③ 组合套餐** | 认知训练 ＋ 居家经颅磁 | 30 天＋10 送 2 / 60 天＋20 送 5 / 12 个月＋30 送 5 |

**三类的共同保障：**
- **训练内容与评估内容由医生在系统内自行安排**，不预设、不强制
- **六师共管**（全程协同管理，见第 2 面）
- 训练记录回传医生端，医生随时可见

**院内配套项目**（认知量表评估、影像检查、血液检查、专科诊疗等）**由科室按自身条件组合**。

> **选用原则**：具体服务类型、时长档及是否适合开始，**以医生评估意见为准**。

# 【第 4 面 · 封底】

## 八、居家治疗模块一览

### 模块一 · 数智化认知评估与训练系统

- 国家**二类**医疗器械｜设备由具备资质的医疗器械企业生产，圆爱康负责居家服务与系统承接
- **能力**：六大认知域建模 · 36 个标准训练任务（可扩展至 40）· 每任务设 6-12 个难度 · 42 个量表
- **载体**：智慧台车 / 平板 / 一体机 / 微信小程序（居家）

**阶梯难度（按评估结果匹配）**：

| 难度层 | 目标 |
|---|---|
| **1–3 级** | 基础修复 —— 由基础认知任务起步 |
| **4–5 级** | 提速增效 —— 在稳定正确率基础上提升处理速度 |
| **6 级以上** | 常模增强 —— 对标常模水平持续强化 |

### 模块二 · 经颅磁刺激治疗仪（EK-9100A 家庭款）

- 国家**二类**医疗器械｜注册证号 **苏械注准 20192090432**
- **适用范围（注册证原文）**：「适用于缺血性脑血管病、神经衰弱、脑损伤性疾病的辅助治疗」
- **形态**：家庭款，适用于居家使用；使用情况回传医生端

> **两者并列**：均为居家可开展的非药物手段，按需选用、相互独立。

## 九、依据的权威文献与标准

| 文献 / 标准 | 用途 |
|---|---|
| 《阿尔茨海默病康复管理中国专家共识（2019）》 | 认知康复管理框架 |
| 《阿尔茨海默病多元康复干预中国专家共识（2025）》 | 多元康复干预路径 |
| DSM-5（《精神障碍诊断与统计手册》第五版） | 六大认知域建模依据 |
| 认知功能相关收费编码（认知功能检查 / 认知功能训练 / 认知知觉功能障碍训练 / 量表评估） | 该服务在医疗体系内具备正式收费依据（**本页不印价格**） |

> 学术共识指出：**认知训练是非药物干预的重要组成部分**；具体适用与禁忌，由医生结合患者情况判断。

## 十、适用人群（面向神经内科 / 康复科）

- 轻度认知障碍（MCI）的辅助康复训练
- 主观认知下降（SCD）人群的认知储备训练
- 阿尔茨海默病等原因所致认知障碍的居家辅助训练
- 脑卒中后 / 帕金森病等伴认知功能下降的康复期人群
- 具体适用与禁忌由医生结合患者情况判断，本页不替代医嘱
