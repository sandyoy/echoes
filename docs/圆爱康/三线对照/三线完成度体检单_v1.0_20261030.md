6. 儿童 ③（科室会 PPT 脚本）
7. 儿童 ④（家长端材料）

**B 方案（先铺儿童，心脏硬伤顺手改）**
1. 心脏 ③④（顺手，2 小时）
2. 儿童 ①→②→③→④ 全套铺开
3. 儿童 ⑥ 刷新并进

**C 方案（只做我判断最要紧的三件）**
