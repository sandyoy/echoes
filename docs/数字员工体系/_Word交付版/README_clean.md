## 七、这个岗位的Agent，什么必须问人

**以下情况不许自己决定，必须标"请核实"并上报：**
- 涉及证照到期、换证、注销
- 涉及对外出具任何证明、承诺
- 涉及劳动/人事关系的判断（合同、社保、绩效争议）
- 涉及金额、付款
- 涉及患者/合作方信息对外提供
- 任何"这条我不确定"的情况
