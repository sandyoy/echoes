## 〇、一句话讲清楚这东西是什么

**一个把老人一生的话、字、照片、视频、原声收集起来，自动按时间轴排好，一键变成一本书（电子书 / 实体书 / 翻页相册）的产品。**

老人只管说。说的东西自己会找到自己的位置。

---

## 一、为什么另起炉灶

| 旧版 | 新版 |
|---|---|
| 只能记录文字 | 文字 + 照片 + 视频 + 原声 |
| 一条故事 = 一段文字 | 一条故事 = 一个素材筐（挂同一件事） |
| 时间 = 用户手动填 | 时间 = 系统自动归位 + 可手调 |
| 无成书 | 一键成书（电子/实体/相册） |
| 无收付款 | 可收费 / 免费 / 年费 |
| 静态页面 | 活文档，可续添 |

旧代码在数据模型根上就不同，修补等于重写，故整体作废。

---

## 二、核心流程（用户视角）

```
老人按住说话 / 打字 / 传照片 / 传视频
        ↓
自动归入某件"事"（素材挂在同一件事上）
        ↓
系统按时间轴自动排序（1980年的事归1980年，1937年归1937年）
        ↓
老人可手动调整顺序 / 用语音说"这事是1937年1月的"
        ↓
点【我要成书】→ 电子书 / 实体书
        ↓
电子书：可分享、可续看、可再添内容
实体书：对接印刷厂 → 邮寄到家
```

---

## 三、时间轴（灵魂功能）

### 3.1 自动归位
- 用户**不按时间顺序说话**是常态：今天说1980年、下次说1937年
- 系统需从**语音内容**和**文字内容**中提取时间线索，自动归位
- **保存即触发**排序调整

### 3.2 手动调整
- 老人看书/素材时发现顺序错，可手动拖动调整
- 支持**语音修正**："这事发生在1937年1月，那个是1937年8月"
- 系统根据语音修正再次调整

### 3.3 时间精度
- 支持模糊时间（"大概是解放前"）与精确时间（"1937年1月"）
- 无法确定时，先归入模糊档位，等更多线索

## 四、素材篮子（一条事，多种素材）

**铁律：所有素材挂在"同一件事"上展示。**

| 素材类型 | 来源 | 说明 |
|---|---|---|
| 文字 | 老人自己写 / 语音转文字 | 原声可保留 |
| 语音 | 按住说话 | 保留原生声音，不只是转文字 |
| 照片 | 老人手机图库 / 子女手机图库 | "+"号 → 跳图库 |
| 视频 | 当场录 / 相册传 | 老人对着手机说话的视频也算 |

### 上传交互（照微信做）
- 一个"**+**"号
- 点了直接跳手机图库
- 选项样式参照微信发消息：上传照片？视频？拍一个？

---

## 五、采访引导

- **AI 当记者**，主动引导老人讲："老人家，您说一下那时候的情况？"
- 不是干等老人自己说，是**被引导着说**
- 引导逻辑归属采访模块

---

## 六、成书机制

### 6.1 触发
- 一个按钮：【**我要成书**】
- 电子书 / 实体书 二选

### 6.2 电子书
- 生成后可**分享**
- 可**继续看**
- 可**往里面再添内容**（照片、视频、文字）
- 成书不是终点，是**活文档**

### 6.3 实体书
- 对接印刷厂（sandy 联系，多家比价）
- 印刷厂决定页数、开本、装帧
- 印完邮寄到家
- **现在不用决定**印刷事宜

### 6.4 书的形态（三种都要）
| 形态 | 说明 |
|---|---|
| 书的形式 | 常规电子书翻页 |
| 手上看的电子书 | 手机端阅读 |
| 翻相册式 | 用翻相册的手势去翻 |

**设计追求**：线上看到什么样，印出来就什么样 → 省排版。
（究竟能否完全免排版，由技术侧评估决定）

## 七、收付款

### 7.1 原则
- 系统只提供"**能收**"的能力
- **收不收钱、收多少、收给谁 = sandy 定**

### 7.2 收费模式
| 模式 | 状态 |
|---|---|
| 电子书收费 | 可选 |
| 电子书免费 | 可选 |
| **年费制** | 待研究：年费挂在哪里（会员？订阅？） |

### 7.3 收款主体
- 疑问：**小程序能否直接收款？** 还是需另外的认证？
- **任务：技术侧先调研清楚，再拍板**

### 7.4 支付渠道
- 第一版：**微信支付**
- 预留：支付宝 / 其他
- 若将来海外售卖，需加海外支付模块

## 八、操作简不简单的验收标准

**合格线：摁一下，哒哒就说。**

- 参照微信"按住说话"——老人已经会的动作
- 一切按**老人的行为习惯**走，不发明新交互
- 老人学不会 = 不合格

## 九、分期节奏（按 1/2/3/4 期）

| 期 | 内容 | 目标 |
|---|---|---|
| 第1期 | 采集（文字/语音/照片/视频）+ 素材挂同一件事 | 能录进来 |
| 第2期 | 自动时间轴归位 + 手动调整 + 采访引导 | 能排对 |
| 第3期 | 一键成书（电子书优先）+ 分享 + 续添 | 能成书 |
| 第4期 | 收付款 + 实体书对接印刷厂 | 能收钱、能印 |

**sandy 拍板：按此四期节奏走。**

## 十、项目制推进（sandy 9-23 新要求）

> 每项东西做成一个项目，每次找到这个项目看推进逻辑。

- 每个模块（采集/时间轴/成书/支付）各为一个项目

## 十二、验收铁律

> **"内测看代码完全看不出问题，只有实际测试才有问题。"** —— sandy
