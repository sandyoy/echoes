## 一、后端这轮改了什么（你不用改前端代码）

### 1. 上传地址接口：返回的协议变了（⚠️ 重要）

`POST /api/echoes/storage/upload_url` 返回的 `data` 现在是：

```json
{
  "upload_url": "/api/echoes/storage/upload_form?key=clips/<actor_id>/image/xxx.jpg",
  "method": "POST",
  "headers": {},
  "form_field": "file",
  "key": "clips/<actor_id>/image/xxx.jpg",
  "expire": 3600
}
```

**为什么改**：微信小程序 `wx.uploadFile` **只支持 POST + multipart/form-data，不支持自定义 PUT**（官方硬限制）。
之前返回的是 PUT 地址（`/storage/put`）→ 真机上 `wx.uploadFile` 物理打不到，表现为"传了半天失败/卡住"。
**域名填得再对也救不了这个。**

**前端正确接法**：

```js
// 1) 取地址
const r = await wx.request({
  url: BASE + '/api/echoes/storage/upload_url',
  method: 'POST',
  data: { actor_id, kind: 'image', file_name: 'a.jpg', file_size: size },
})

// 2) 上传（wx.uploadFile 天生就是 POST 表单，直接用）
const up = await wx.uploadFile({
  url: BASE + r.data.data.upload_url,      // 已含 ?key=...
  filePath: localPath,
  name: 'file',                            // ← 字段名必须是 file
})

// 3) 登记（必须做，否则素材不算数）
await wx.request({
  url: BASE + '/api/echoes/storage/confirm',
  method: 'POST',
  data: {
    actor_id, key: r.data.data.key, kind: 'image',
    story_id,                               // ← 必填，缺了会返回 missing_story_id
    file_name: 'a.jpg', file_size: size, visibility: 'private',
  },
})
```

`kind` 合法值：`image` / `audio` / `video` / `original` / `tts`（**不是** `photo`）。

### 2. `storage/confirm` 修好了一个 10 天的 500

之前这个接口**一律 500**（`TypeError: api_confirm_upload() takes 0 positional arguments`）。
现在正常了，会返回明确中文错误码（如 `missing_story_id`）。**如果你之前测真机发现"传上去但没登记"，就是这个原因，不是你代码写错了。**
