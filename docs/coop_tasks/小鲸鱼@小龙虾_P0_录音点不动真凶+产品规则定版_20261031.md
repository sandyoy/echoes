## 二、真凶已定位（不是后端问题）

**后端是好的**：`echoes-api.service` active，60+ 条 `/api/echoes/*` 路由在册（含 `clip/audio`、`clip/transcribe`、`story/list`、`timeline`）。

**弹「正在准备，稍等一下再试」的位置：`miniprogram/pages/capture/capture.js` 第 88 行**

```js
requireLogin() {
  if (this.data.actorId) return true;
  const uid = (app.globalData && app.globalData.userId) || '';
  if (uid) { this.setData({ actorId: uid }); return true; }
  if (app.globalData.loginError) { this.showLoginFailed(app.globalData.loginError); return false; }
  wx.showToast({ title: '正在准备，稍等一下再试', icon: 'none' });   // ← 第 88 行
  app.ensureLogin().then(...);
  return false;
}
```

**逻辑 bug（三个叠在一起，所以"点几次都一样"）：**

1. `requireLogin()` **同步返回 false**，录音动作被直接扔掉 → 用户点按说话，**一个字都没录进去**。
2. `ensureLogin()` 是异步的，登录成功后只 `setData({actorId})`，**不会回头重放刚才被丢掉的那一次录音**。用户必须再点一次——但他看到的是"没反应"，自然会一直点、一直弹同一句。
3. `app.js` 的 `_loginWithRetry` 里 `loginPending` 已置位，但 `requireLogin()` **没读它**——所以在"正在登录中"和"登录已失败但还没写 error"这两个窗口期，永远只弹同一句含糊提示。
4. 若真机拿不到 openid（`isDevEnv()` 误判走桩或登录三次失败），`loginError` 只在**三次重试都跑完之后**才写入 —— 也就是说 sandy 前两次点击看到的永远是"正在准备"，得不到任何可行动的原因。

## 三、请你改的四处（前端）

### 改点 1：录音乐观放行，身份后补（P0）
`capture.js` 的录音按钮：**不要先过 `requireLogin()` 再开录音**。
建议顺序改为：
```
点按住说话
  → 立刻 wx.getRecorderManager() 开始录（不等登录）
  → 松手 stop，拿到 tempFilePath，先存本地（wx.setStorageSync 兜住）
  → 有 userId 就立刻上传；没有则挂进 pendingUpload 队列
  → loginReady 后统一补传（app.globalData 上挂一个 drainPending() 回调）
```
**核心原则：录音是"老人摁一下就有的东西"，不能被任何登录状态挡在门外。**

### 改点 2：语音改走服务端转写（P0）
松手后调 `POST /api/echoes/clip/audio`（上传音频，multipart，字段 `file`，其余参数走 query）
然后用返回的 `clip_id` 调 `POST /api/echoes/clip/transcribe` 拿文字。
**这样即使真机 openid 不稳，"说一句 → 回来看到文字 → 出现在时间轴"这条链路照样能走通，sandy 能自己验。**

### 改点 3：把提示换成可行动的（P1）
- 正在登录中 → `正在登录，1 秒后自动开始`
- 登录失败 → 复用已有 `showLoginFailed()`，**必须带真实 reason + 重试按钮**（现在已有，别被上面的 toast 挡在前面）
- 不要再用「稍等一下再试」这种没有信息量的话

### 改点 4：复核 `isDevEnv()`（P1）
`app.js:164` 已是 `getDeviceInfo().platform === 'devtools'` 的写法（10-25 修过一次）。
请在真机上打一行 console：`console.log(wx.getDeviceInfo(), wx.getAccountInfoSync().miniProgram)`，
确认 `platform` 不是 `devtools`、`envVersion` 是 `trial`（体验版）或 `release`。
**若 `platform` 仍是 undefined → 说明基础库 < 2.20.1，需要退回 envVersion 判断，并在开发者工具里把调试基础库调到 2.20.1 以上。**
