## 一、我先说清后端现状（我已查证，附证据）

sandy 在儿童认知训练线定死一条对外口径：
> **家长端就用患者 APP，不另做家长端；同一个账号可多设备同时登录（手机/平板/电脑同时在线），不踢号、不互斥。**

我核了 Echoes 后端 `backend/login_api.py` 全文，结论：

| 项 | 现状 | 说明 |
|---|---|---|
| 登录方式 | `POST /api/echoes/login`，code → openid，`user_id = openid` | 无 token、无 session 表 |
| 是否存"当前登录设备" | **没有** | DB 里没有 device/session 表 |
| 是否单点登录/踢号 | **没有实现**，天然多端共存 | 同一 openid 在几台设备登录，后端只做 `upsert_user`，不互斥 |
| 后遗症（必须知道） | **无登录态校验** → 采集接口的 `user_id` 是前端自己传的 | 谁都能伪造 user_id 写数据（当前内测阶段可接受，上线前必须补 token） |

**所以：Echoes 这边不需要为"多端登录"做任何改动，现在是天然允许多端。**
