## 2. 状态机

```
pending(待报价) → quoted(已报价) → confirmed(已确认) → printing(印刷中) → shipped(已寄出) → done(已完成)
   └──────────────┴──────────────────┴→ cancelled(已取消，仅非终态可进)
```

- `printing` **不许取消**（纸已下机）。
- `done` / `cancelled` 为终态，**不可回写**（防账目被改回"未发货"）。
- 同状态重复提交 → `ok + unchanged=true`（幂等，不报错不改时间）。
- 野状态值（如 `"发货了"`）→ `bad_status` 拒，**不静默写库**。

## 3. 接口清单（5 条）

| 方法 | 路径 | handler | 用途 |
|---|---|---|---|
| GET | `/api/echoes/print/catalog` | `api_print_catalog` | 能不能印/几页/什么开本/上次印单 |
| POST | `/api/echoes/print/quote` | `api_print_quote` | 落印单（报价来了就录） |
| GET | `/api/echoes/print/order` | `api_print_order` | 查一张印单（仅本人） |
| GET | `/api/echoes/print/my_orders` | `api_print_my_orders` | 我的印单列表 |
| POST | `/api/echoes/print/status` | `api_print_set_status` | 印刷厂回执→状态流转 |

### 3.1 `GET /print/catalog?owner_id=&book_spec=A5`

未成书：
```json
{"ok":true,"data":{"can_print":false,"reason":"no_ebook",
 "notice":"先把电子书做出来，看着满意了再来印实体书。","specs":null},"error":"","code":""}
```

已成书：
```json
{"ok":true,"data":{
  "can_print":true,"reason":"","ebook_id":"ebook_xxx","ebook_title":"我的一生",
  "specs":{"book_spec":"A5","width_mm":148,"height_mm":210,"fallback":false,
           "page_count":12,"entry_count":34,"chapter_count":6,
           "contributors":["妹妹李桂英"]},
  "last_print_order":{"print_order_id":"print_xxx","status":"quoted",
                      "status_label":"已报价","copies":3,"book_spec":"A5"},
  "stale_against_last_order":false,"notice":""},"error":"","code":""}
```

> **故意不返价格**：价格只能来自印刷厂报价（`vendor` 填报）。
> 页数直接取 `book_view_api.paginate()` 结果，**不另算一套**（§8.6 线上看到什么=印出来什么）。

### 3.2 `POST /print/quote`
```json
{"owner_id":"u1","book_spec":"A5","copies":3,"vendor":"某某印务","unit_price":28.5}
```
- 不带 `unit_price` → `status=pending`，`price=0`，附话术"还没报价…本系统不填默认价"。
- 带 → `status=quoted`，`price = unit_price × copies`（行内算术，不做加价/建议零售价）。
- 拒：`copies<=0` / `>200` → `bad_copies` / `too_many_copies`；`unit_price<0` 或非数字 → `bad_price`；无书 → `no_ebook`。

### 3.3 `POST /print/status`
```json
{"print_order_id":"print_xxx","actor_id":"u1","status":"printing","vendor":""}
```
非法跨级 → `bad_transition`；野值 → `bad_status`；他人 → `forbidden`。

## 4. 前端接入位（给小程序/网页开发看）

- 「我的书」详情页底部：`满意了 → 印一本` 按钮 → 先打 `print/catalog`，
  `can_print=false` 就置灰并显示 `notice`（**不要灰都不置就让人点**）。
- `can_print=true` → 展示 `page_count` / `width_mm×height_mm` / `chapter_count`，
  这是给印刷厂报价用的口径。
- `stale_against_last_order=true` → 顶部黄条"内容更新了，需重新报价"。
- 印单页：`my_orders` 列表 + `status_label` 中文直出。
