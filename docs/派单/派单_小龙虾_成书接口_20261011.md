## 二、接口清单（形状已冻结，照这个接）

### 1) 取材（算两筐）
```
POST /api/echoes/book/source
body: { "owner_id": "u_xxx", "actor_id": "u_xxx" }
→ { ok:true, data:{ books:[...], own:[{clip_id,text,cover_url,time_label,provider_id,is_own}],
                     public:[{clip_id,text,ref_author_name,time_label,...}] } }
```
- `own` = 筐①（**含自己的私有**，自己的一定能装）
- `public` = 筐②（**只有别人公开的**，带 `ref_author_name` 署名）

### 2) 生成 / 刷新电子书
```
POST /api/echoes/book/generate
body: { "owner_id":"u_xxx", "actor_id":"u_xxx",
        "title":"我的一生",
        "picked_public_ids":["c_1","c_2"],   // ②筐里点选的
        "ebook_id":"" }                       // 传了=覆盖刷新（活文档）
→ { ok:true, data:{ ebook_id, title, clip_count,
                    chapters:[ { time_label, entries:[ {clip_id,text,is_quote,
                               ref_author_name,quote_label,editable} ] } ],
                    contributors:["李婶", ...] } }
```
- **页面渲染引用段**：`is_quote==true` 的 entry → 显示成**引用块**（如灰底/带书名号），旁边标 `quote_label`（例："这段来自李婶的讲述"）。
- ⚠️ **引用段前端不给编辑按钮**（`editable=false`）。

### 3) 取我的电子书
```
GET /api/echoes/book/ebook?owner_id=u_xxx
→ { ok:true, data:{ book:{...}, empty:true/false } }   // 没书时 empty=true，别当报错
```

**错误码**（都带 `code`，前端好分支）：
- `forbidden` — 不是书主人（别人不能替你成书）
- `no_stories` / `empty_book` — 一条素材都没有，明确拒绝（**别做成静默成功**）
- `not_found` — ebook_id 找不到

## 三、你这边的活（book 页）

1. **取材页（成书页）**：进页面调 `POST /book/source`，把 `own[]`/`public[]` 两组卡片列出来。
   - `own` = "你的记录（自动收录）"，不可取消勾选（需求书：自己的自动装）。
   - `public` = "别人提到的（点选加入）"，可勾。
2. **点"生成"** → 调 `POST /book/generate`，带上勾选的 `picked_public_ids`。
3. **进"我的书"页** → 调 `GET /book/ebook` 渲染章节；引用段按 `is_quote` 渲染成引用块 + `quote_label`。
4. **刷新（活文档）** → 再点生成时把上次的 `ebook_id` 回传 = 覆盖刷新。
