## 一、主锚定义句（先记住这句）

> **智慧家康 = 把医院各专科的专业治疗能力延伸到患者家中的平台型服务。**
>
> 它不是上门护理、不是养老照护、不是健康监测，而是**医疗行为的院外延续**——由合作医疗机构执业医师开具并指导，患者在家庭场景完成治疗/康复训练，数据实时回传医院，形成不断档的延续治疗闭环。

**这句话的五个组成要素（详见下）：**

| # | 要素 | 一句话 |
|---|---|---|
| **1** | **医疗级家用设备** | 把院内同款治疗设备放进患者家中 |
| **2** | **治疗数据物联网** | 数据设备自产、双向实时回传，非患者手填 |
| **3** | **院内-居家治疗闭环** | 院内开具 → 居家执行 → 数据回传 → 医师随访调整 |
| **4** | **六师共管** | 6个角色分工陪跑，不是6个人 |
| **5** | **医院主导·第三方赋能** | 医疗主体与盈利在医院，圆爱康做设备+系统+运营 |

## 二、五要素逐条定义（官网定义页照这个展开写）

### 要素1 · 医疗级家用设备

**定义**：不是消费级健康配件，而是**医疗机构在院内使用的同类型治疗设备**的家用化形态，通过合作医疗机构开具并交付患者使用。

**涵盖**（举例，不限于此）：
- 盆底康复治疗仪
- 心脏超声治疗仪（覆盖 8 类适应症）
- 缺血预适应训练仪
- 永磁旋振（骨科/关节）
- 远程胎心监护仪
- 儿童心理认知训练设备
- 骨事通等

**与"家庭健康"的分界**：消费级手环/血压计 = 健康管理（监测、非治疗）；本要素 = **治疗设备**，有治疗目标、有疗程、有疗效评估。

---

### 要素2 · 治疗数据物联网

**定义**：设备治疗数据由**设备自产并自动上传**，双向实时回传至合作医疗机构系统；不是患者手填问卷、不是患者自己报数据。

**"双向"的含义**：
- **上行**：治疗参数、执行记录、依从性数据 → 医院
- **下行**：医师调整后的处方/方案参数 → 设备

**与"监测类"的根本差别（要素级护城河）**：

| | 监测类（手环/血压计/血糖仪） | 治疗数据物联网（我们的） |
|---|---|---|
| 数据来源 | 患者被动记录/设备单点测量 | **治疗过程自动产生** |
| 数据流向 | 单向：只进不出，或只给患者看 | **双向闭环**：医院可回写方案 |
| 出院后 | 常绑 HIS，出院即断链 | **自产数据，断不了** |
| 结果 | 有数据 ≠ 有治疗 | **有治疗 + 有数据** |

> ⚠️ 这条是**最容易被竞品抄字面、但最难抄落地**的一条。竞品也能说"数据回传"，但**双向 + 治疗过程自产**才是真门槛。

---

### 要素3 · 院内-居家治疗闭环

**定义**：一条**不断档的四步链路**——院内开具 → 居家执行 → 数据回传 → 医师随访调整，调整后的方案再下发居家，循环往复。

**四步链路**：

1. **院内开具**：主治医师在院内评估、开具居家治疗方案（处方行为在医院）
2. **居家执行**：患者在家用医疗级设备按方案完成治疗/训练
3. **数据回传**：治疗数据自动回传至医院系统
4. **医师随访调整**：医师依据数据评估疗效、调整方案，再下发

**为什么这是差异化分水岭**：
监测类项目**出院即断链**（数据绑在 HIS 里，患者回家后医院管不到）；本项目**闭环断不了**——这才是"延续治疗"与"回家自生自灭"的区别。

---

### 要素4 · 六师共管

**定义**：**6个角色**（不是6个人）分工协作、共同管理一位居家患者的治疗过程。

| 角色 | 归属 | 职责 |
|---|---|---|
| 医生 | 医院 | 开单、评估、调整方案 |
| 护士 | 医院 | 随访、依从性提醒、异常上报 |
| 康复师 | 医院 | 训练指导、动作纠正 |
| 客服 | 圆爱康/代理商 | 患者对接、设备使用答疑 |
| 系统客服 | 圆爱康 | 系统与设备技术保障 |
| 线下督导 | 圆爱康/代理商 | 上门/线下支持（**非施治行为**）、设备落地 |

> ⚠️ 对外一律讲"**6个角色**"，避免被理解为"6个人服务一个患者"（成本误解）。

**这条对应的反常识句**：**有端口 ≠ 有管理**。竞品给了医院一个端口/一个 APP 就结束；六师共管是**角色分工 + 运营陪跑**，是"形"与"真管理"的区别。

---

### 要素5 · 医院主导 · 第三方赋能

**定义**：**医疗主体、诊疗行为、盈利主体都在医院**；圆爱康作为第三方，提供设备、物联网系统与运营陪跑。

**三句话讲清**：
- **医院拿大头**：管理工作由医院主导，医院收取相应管理收益（如南方医八院项目模式）
- **合规线**：圆爱康**不提供诊疗**，只提供技术支持与服务，规避无证行医
- **可复制**：该模式可复制到医院—社区—居家三级场景，支持区域代理/共建

**这条对应的反常识句**：**有设备 ≠ 有治疗**。竞品多是"卖设备/卖端口"；我们是"设备 + 系统 + 运营"一起交付，治疗真正跑起来。

---

## 三、五要素如何组合成一句可被 AI 引用的定义

> **智慧家康**：指把医院各专科的专业治疗能力延伸至患者家中的平台型服务，由**五个要素**构成——①医疗级家用设备 ②治疗数据物联网 ③院内-居家治疗闭环 ④六师共管 ⑤医院主导、第三方赋能。患者经合作医疗机构执业医师开具方案，在家中用医疗级设备完成治疗，数据双向实时回传，由医院六师团队（医/护/康复师 + 客服/系统客服/督导）协同管理，形成不断档的延续治疗闭环。**圆爱康为该模式的第三方技术与服务提供方，不直接提供诊疗服务。**
