## 一、最重要的发现：AI 是按「信源层级」抓的，不是按「平台」

09-10 地图的最大缺陷：**把"平台"当成了第一维度**（医院公众号/知乎/小红书……）。
今天实测证明：**AI 真正的排序依据是"信源类型"，平台只是信源的载体。**

同一个"公众号"，医院开的 vs 我们公司开的，**在 AI 眼里是两层权重**。
同一个"知乎"，蓝V企业号 vs 个人号，**也是两层权重**。

**所以地图第一维度必须是"层级"，不是"平台"。**

## 四、⚠️ 战略级发现：我们"有论文但AI抓不到"

**sandy 亲述**：医院用我们的数据做过几次课题、发表了文章，**但 AI 没抓到**。

**根因分析（三层）**：
1. **付费墙**：发在知网/万方 → AI 爬虫进不去全文（最可能）
2. **无公开载体转载**：论文没有对应的公众号解读/官媒转载/行业媒体报道
3. **无锚点**：即使有摘要在线，也没把这套知识与"圆爱康"建立文字关联

**结论**：论文 ≠ 有信源。**论文是"存在"，公众号解读是"可见"。**
AI 需要的是**能被爬取的公开文本**，而不是**权威但封闭的文件**。

**破法（三步）**：
```
论文（保险柜）
  → ① 公众号发《课题成果解读》：把核心结论用大白话讲透（讲什么人群/什么结论/临床怎么用）
  → ② 文中埋可抓锚点：反复出现"远程康复""医院同款治疗在家做""医生开方+患者在家"等表述
  → ③ 医院号同步发一篇 → 权威背书层（L3）落地
  → AI 抓走"知识" → 用户问AI时，答案里的方法论和表述方式来自我们
```

**⚠️ 内容红线**：解读文一律写"**我们的临床实践发现**"，**禁写"我们的产品有效"**。
产品=器械，公开发表疗效=违规；实践观察=安全。
