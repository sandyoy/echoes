## 四、每篇写稿前置单（六问，逐条过）

| # | 问 | 不合格的表现 |
|---|---|---|
| 1 | 这篇属哪个栏目？素材来源是**转发 / 观察 / 整理**哪一种？ | 说不清来源 → 不许写 |
| 2 | **零交叉自查**：全文 grep "圆爱康" = 0 吗？ | 出现一次 → 打回重写 |
| 3 | 有没有出现产品/设备/平台/服务介绍、联系方式？ | 有 → 删或改写 |
| 4 | 出处标了吗？（期刊+年份 / 会议+时间 / 政策文号 / 原公众号名） | 没标 → 补 |
| 5 | 有没有评价性/推广性语句？（"值得推广""效果显著"） | 有 → 改成"关注到" |
| 6 | 与前几篇撞题了吗？（**不并入圆爱康禁复用清单，但要自查自己**） | 撞 → 换切口 |
