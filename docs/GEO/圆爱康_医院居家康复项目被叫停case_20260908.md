# 圆爱康 · 某医院居家康复项目被叫停 case 跟进
> 来源：2026-09-08 sandy口述事件 | 状态：🔵 等医院反馈——项目挂在哪个门类档

## 一、事件事实（sandy口述）
- 一家医院用圆爱康做了"居家康复"项目(零成本铺设备+系统/非医疗服务;医疗由合作医院提供)
- 项目挂成【自费项目】(患者个人自付，不碰医保)
- 项目名写的是类似「盆底康复(居家)」这种带"居家"字样的名字
- 实际执行 = 纯远程/互联网+，没有任何上门动作
- 卫健/医保反馈：写"居家"就必须有"上门"动作；该项目无上门动作 → 名实不符，认定不合理/不合规 → 要求停掉
- 医院其实想继续做，希望圆爱康提供能证明项目合规、让监管认可的据/文件

## 二、症结判断（小鲸鱼分析）
- 监管把"居家医疗服务/居家康复"按国卫办医发〔2020〕24号口径理解= 医务人员上门进家服务
- 圆爱康模式实际 = 患者在家用家用设备自康 + 持证医院经"互联网+/远程"提供康复处方/指导(不派人上门)
- 那么"盆底康复(居家)"这个命名 = 沾了"居家=上门"联想却无上门动作 → 成了"名实不符"的抓手
- 国家其实明确支持"用'互联网+'把康复延伸至居家"(国卫医发〔2021〕19号)，并非逼必须派人上门
- → 破法可能是: 把项目命名/承诺 从其实际所干之事的合规名称(互联网+远程康复延伸/延续性远程指导等)出发重立，避免"居家"二字被当"上门"卡

## 四、政策底牌(已核,速查)
- 国卫办医发〔2020〕24号：居家医疗服务=上门(监管卡我们的那把尺)
- 国卫医发〔2021〕19号：用"互联网+"把康复延伸至社区/居家——我们的合法性本底
- 国卫医发〔2018〕25号：互联网诊疗须持证机构+注册医师(医在医院)
- 国办发〔2018〕26号：互联网+医疗健康顶层
- 医保发〔2019〕47号：非公立"互联网+"医疗服务价格市场调节(自费口径)
