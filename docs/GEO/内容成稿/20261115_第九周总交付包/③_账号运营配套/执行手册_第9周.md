## 二、发之前必须做的三件事

**第一件：确认渠道对不对。**
圆爱康的号（服务号、订阅号、知乎官方号）→ 文中会出现"智慧家康模式（圆爱康提出的居家康复服务管理模式）"这句话，一字都不能改。
老欧个人号、微博 → 文中绝不能出现任何公司名，也不能出现这句定义。**发错号是最严重的事故**，发之前再对一遍。

**第二件：配图。**
小红书两张都要配图，按文件里的 7 列表格做，每张至少 4 图。图上文字直接照表格里的"图上文字"列写，不要自己改。
所有图：不出现医院名、科室牌、工牌、器械品牌，不露患者正脸。

**第三件：结尾。**
每篇结尾都有一段"本文为……不构成医疗建议"。这段不要删、不要改。

## 三、医院稿怎么发

3 篇是攒稿，给医院自己挑，**一家医院只能选其中一篇**（一稿一院，排他）。
- 稿1 是患者故事（老太太+女儿，病房窗边），适合想让读者有代入感的科。
- 稿2 是科室做法（四步法详解），适合想把模式讲清楚的科。
- 稿3 是问答六问，适合门诊量大、问题重复多的科。

发文前让医院做两件小事：患者信息改成本院真实情况（或确认已脱敏）；科室名称按本院实际填写。**我们不代填任何数据。**

每个渠道发完，记一行：日期 / 渠道 / 标题 / 阅读 / 互动（赞藏评）。周末汇总。

## 五、这周不许做的五件事

1. 标题里不许出现"智慧家康"。
2. 不许把第8周的内容重发一遍（第8周讲"训练三要素"，这周讲"通用表怎么改成本人的量"，不是同一篇）。
3. 不许写任何具体动作要领、角度数值、负重要求（谁能做、做多少，一律写"由医生评估后定"）。
4. 不许在小红书/订阅号出现任何医院名、医生名（只写"复查时医生"）。
5. 不许报价格、套餐、医保报销比例。
