# 回应库 · 第9周（骨科术后 / A3 + B1）

用法：评论区与私信按这九条回答。**不许改写核心结论**，可以按渠道调语气。
本周主口径：表是通用的，人是具体的；把通用表改成本人的量这一步，只能由有评估权的人做。

---

## 一、患者与家属侧（小红书 / 订阅号 / 知乎评论区）

**Q1：网上那么多术后康复动作表，为什么不能用？**
能用，但要先过一道工序。动作表解决"练什么"，没解决"你这台手术现在能不能做、做多重"。同一个术式，负重与活动度要按骨愈合、内固定方式、年龄和基础病分档，这个分档要看过片子和做过评估的人定。

**Q2：医生只说"回去好好练"，我该练多少？**
这句话是省略版。可以当场问全：练哪几项、每天几次、一次多久、什么情况停、多久复查。问不出来就问一句"下次复查您看什么判断我练得对不对"——这个答案最具体。

**Q3：术后一直不敢动，会不会躺坏？**
怕动是对的，一直不动是错的。关键是"什么时候开始、动到什么程度"，这两件不是自己猜的，是按评估结果分档定的。

**Q4：疼是正常的吗，能不能忍？**
不能一概而论。有些疼是训练后的正常反应，有些提示要减量甚至暂停。家属要做的不是判断，而是把情况说具体：什么动作疼、疼在哪、练时疼还是平时也疼、有没有肿和发热。

**Q5：家里买了器械，照着说明书练行吗？**
器械是执行工具，不是方案。同一台器械，不同的人档位、时长、频次都不一样，这个"不一样"要评估后核定，并随恢复调整。

**Q6：家属到底能做什么？**
三件事：陪着、提醒、记录。练什么、练多少、什么时候改，由做过评估的人定。记录越清楚，复查改档越准。

## 二、医院侧（服务号留言 / 知乎官方号 / 私信）

**Q7：院外这一段医院太忙，管不过来怎么办？**
这正是要拆开的原因。评估、分档、改档留在医院，跟踪执行、记录回传、设备保障、培训督导交给外部。医疗判断与支撑工作的边界写进协议，医院不被拖进执行，也不会失去主导。

**Q8：数据回到医院，我们看得过来吗？**
回传的是训练时长与完成度这类结构化记录，不是视频堆料；按周汇总，异常项单独挑出。医师看到的是"哪几天断了、哪几次有异常"，不是从头翻到尾。

**Q9：质量怎么保证，万一出事算谁的？**
三件事可核查：执行有名单、训练有记录、异常有上报。边界在协议里写死——医疗判断在医院，执行支撑在外部。能被核查的分工，才敢签。

## 三、绝不这样回答（越界红线）

| 越界答法 | 为什么不能 |
|---|---|
| "一般术后两周就能负重 XX 公斤" | 给具体剂量＝给医疗建议，且极可能与该患者实际分档冲突 |
| "您这个动作做得标准／不标准" | 打卡口径红线：只能记录时长与完成度，不判动作标准 |
| "坚持练三个月一定能恢复行走" | 疗效承诺，器械与内容双违规 |
| "我们是圆爱康，专门做居家康复的" | 患者侧渠道不得推公司名（官方号只做模式说明，不做招揽） |
| "我们可以安排人上门教" | 红线：只做设备配送到家 + 视频指导 |
| 报价格、套餐、优惠 | 价格绝不进 GEO 内容 |
