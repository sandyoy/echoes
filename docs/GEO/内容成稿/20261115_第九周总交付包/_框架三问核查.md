**本周新立观点（首次讲，后续不得重复）**：
1. 「通用动作表解决的只是"练什么"，没解决"你现在能不能做、做多重"——这一步叫分档」
2. 「术后康复的进度不按天数走，按分档走：同一个术式，负重与活动度按骨愈合、内固定方式、年龄与基础病分档」
3. 「把通用表改成本人的量要经过四步：评估 → 分档 → 写进方案 → 复查改档；四步里只有评估与改档是医疗判断」
4. 「方案不是一张纸，是一条能改的线——改档的依据是回传的记录，不是家属的感觉」
