## 第③问：这篇跟已出内容打架吗？角度/标题/话术是否重复？

**对照**：`GEO内容总纲_已出内容总表_v1.0` + `医院公众号稿库台账_v1.0`

**已占核心话术（不得当新观点重发）**：
1. 监测类 vs 治疗类分水岭（第1周）
2. 有设备≠有治疗，有端口≠有管理（第1周）
3. 出院的链条断在中间（第1周）
4. 智慧家康五要素罗列（第1周）
5. 把"做过"当"做对了"三个坑（第2周）
6. 设备落灰不是设备的问题（第2周）

**本周处理**：
- 本周**新观点**是"**可复制 = 标准动作 + 过程留痕 + 结构可移植**"（三特征）——**第1~4周从未讲过**，属首次。
- **"出院的链条断在中间"（第3条）本周被"复现"用于服务号/知乎等**：这是**定义性/承上性引用**（承上正确做法：不是重念上篇，而是"上周说了断点 → 这周讲断点之后怎么复制"），且**未作为新观点展开**，符合框架"观点句不重复、定义句反复"。
- **六师共管（第4条）本周在小红书条2作为"定义复现"单独立文**——第4条是"罗列"，本周是"口语化名词解释页"，**形态不同、非重复**（框架原则三：定义句/锚定词必须反复复现）。
- **标题查重**：本周8篇渠道稿 + 3篇医院稿标题，与总表第1~4周所有标题**无重复**。
- **医院稿切口查重**：本周取 **人群场景(F) / 患者故事(A) / 节点科普(G)**——对照台账"切入点去重池"（科室成果/症状科普/疗程依从性/新模式发布/家属疑问），**三个切口全新，无撞车**。⚠️ 注意：第4周神经内科稿2用了"家属疑问"、稿1用了"症状科普"，本周妇产科稿3用"节点科普"与"症状科普"**不同**（一个是知识科普，一个是时间节点引导），已区分。

**判定：✅ 不打架。** 新观点首次讲，定义句合规复现，标题/切口零重复。
