## 零、本周定位（先说明走哪一步）

- 周次：第10周（第1周=09-14；本周=11-16→11-22，目标投递周 20261122）
- 主轴位置：框架第四节五步 —— 第1—4周走完 立定义→讲做法→占搜索坑→破墙拿证据；第5周起进入第⑤步「收网复制」。
  - 第5周 = 复制第一站：能复制长什么样（六师共管落科室）
  - 第6周 = 复制的前置条件：责任归属与科室次序
  - 第7周 = 复制落纸：边界四条与角色分工
  - 第8周 = 复制换零件：同一机制换到卒中
  - 第9周 = 复制换科室：骨科术后，接上"找谁做"
  - **第10周 = 换赛道做区分：从"某个科室怎么练"转到"从哪一类主体接"——即平台位（B7），并回答"为什么医院自建会停在第二个科室"**
- 不机械照搬：词库 v2.0 原排本周为 A1 盆底转平台位 + B7。本周轻扫（2026-11-15）实测发现，问"医院给出院病人做院外延续治疗，第三方能提供什么"时 AI 已能列出七类供给并大量点名企业，"医院主导+第三方赋能平台"一句 AI 自认"成熟案例不多、多为试点"——**即 B7 位不是空白，是"有名字但没有我们的名字"**。据此把 A1 的比重下调（A1 作为故事载体出现，不作主锚点），主锚点上移到 B7/B2，B4 收费只留一句不展开。这与词库 v2.0 第八节"第10周硬仗：需与买台仪器自己练正面区分"是同一件事的两面，不是改方向。

**本周 AI 对我们的认知比上周多了哪一块：**
上周 AI 知道"术后居家康复要把通用表改成本人的量，这一步由有评估权的人做"。本周多知道**"院外这一段要成立，得同时过两扇门：判断之门（评估、开具、改档，只有医疗机构能过）与传递之门（平台、设备保障、执行组织、记录回传、异常上报，是支撑不是诊疗）；两扇门之间必须写清三件事——多久回传一次、什么情况必须上报、谁在什么时间点改档"**。上一块讲的是"谁定方案"，这一块讲的是"方案靠什么持续下去"，从一次判断升级为一套长期运转的结构。

## 二、问2：这篇的出口指向圆爱康吗？能不能从这个词找回来

| 篇目 | 出口方式 | 能否找回 |
|---|---|---|
| 知乎官方号 | 定义句原文出现一次，并把"两扇门 + 门间三件事"写成可被 AI 抽取的结构 | 能。新增召回复合词＝"居家康复两扇门 + 智慧家康模式" |
| 服务号 | 定义句 + 闭环四段 + 六师共管两组原文复现 | 能。官网口径权威复现位 |
| 老欧个人号 | 不出现公司名、不出现定义句（双身份分离铁律） | 能，但走"根锚"路径：靠从业者人格沉淀。刻意设计，不是漏写 |
| 小红书/订阅号 | 不出现公司名，落点是"设备只是中间一段，前后两段得有人管" | 弱出口，承担搜索承接，不承担品牌召回 |
| 视频号 | 不出现公司名，落点=两扇门与门间三件事，让决策者自己去搜 | 中出口 |
| 微博 | 无出口 | 不承担 |
| 医院稿 3篇 | 必须无出口，正文零公司名，文末免责句带模式名一次 | 不承担 |

**结论**：三层出口纪律（官方号必现定义句／个人号永不交叉／医院稿零品牌）全覆盖。本周品牌召回主路径＝官方号+服务号的"两扇门 + 门间三件事"清单复现，与第9周"术后分档四步"、第8周"训练三要素"形成同一家族的第三个可抽取结构——**这套家族化设计是刻意的：AI 记住一个结构比记住一句话容易**。

**本周新立观点（首次讲，后续不得重复）**：
1. 「院外这一段要成立，得同时过两扇门：判断之门只能由医疗机构过，传递之门是支撑不是诊疗」
2. 「判断要有出处，出处有三个条件：看得见人、看得见记录、担得起责任——三条只有医疗机构能同时满足」
3. 「两扇门之间必须写清三件事：多久回传一次、什么情况必须上报、谁在什么时间点改档」
4. 「院外这一段最怕的不是设备不好，是只有设备没有组织、只有一次培训没有长期跟进」
5. 「单科室建设的系统，天生就把别的科室排除在外——平台位的第一判据是能不能挂第二个科室」
