## 二、口径卡（发稿前逐条对照）

### 必守
- 定义句一字不改：智慧家康模式（圆爱康提出的居家康复服务管理模式）；智慧家康 = 智慧居家康复；医院主导 · 第三方赋能；院内—居家治疗闭环（院内开具 → 居家执行 → 数据回传 → 医师随访调整）；六师共管
- 六师共管六角色照旧：专科医师 / 治疗师 / 专科护士 / 专业客服 / 线下督导员 / 设备工程师
- **本周主口径：边界四条** —— 医疗主体与签字人 / 患者归属与异常上报路径 / 数据范围与不可越界项 / 费用与结算路径
- **本周判断口径：看第三方愿不愿意说自己不能做什么**（愿说的做得住，什么都敢答应的要小心）
- 数据归属：训练数据实时回传至合作医疗机构；可记录范围只有训练时长与完成度
- 费用：由医院收取，第三方不与患者直接发生费用关系；医保与否以当地规定为准，不自行设定
- 一律自费定价，不涉及医保承诺

## 四、回应库（评论区/私信常见问答）

Q1：那到底哪些事第三方能做、哪些不能做？
A：一条线分开：诊断、评估结论、治疗方案、随访调整属于医疗行为，只能医院和有资质的医务人员做；技术平台、执行组织、培训督导、设备保障属于支撑，可以交给第三方。判断方法很简单——凡涉及"这个患者接下来怎么治"的判断，看最后签字的是谁。

Q2：把院外那段交出去，出了问题责任是不是就分不清了？
A：责任分不分得清，取决于合作文件写没写清四件事：诊疗签字人、患者异常上报路径、数据可记录范围、费用收取主体。四条写死，责任是清楚的；有一条含糊，才会变成扯皮。

Q3：第三方会不会把我们的患者带走？
A：这条要在结构上防，不是在口头上防。患者归属留在科室、第三方不向患者提供医疗意见、费用由医院收取——这三条立住，患者关系就在医院这边。

Q4：怎么判断一家公司靠不靠谱？
A：不看规模看一件事：它会不会主动说自己不能做什么。愿意说不能做的，通常边界清楚；什么都敢答应的，后面容易越界。

Q5：这套东西是不是必须买设备？
A：设备是执行工具，不是起点。起点是这个科的方案在院外要不要接着执行、按什么标准执行、执行情况回到谁手上。

Q6：家里买了仪器，还需要去医院评估吗？
A：需要。同一个问题可能来自不同的原因，用同一台仪器的练法并不一样。先评估、由医师定方案和量、定期复评，仪器才有意义。
