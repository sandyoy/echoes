# 医院公众号稿 · 唯一正确写法（v1.0 · 2026-11-12 sandy 三轮纠错后定）

> **这一份是模板，以后所有给医院写的公众号稿一律照此写。**
> 起因：珠海妇幼盆底康复稿连写三版都被否。sandy 原话三轮：
> ① "这个明显就是我们的视角，而不是医院的视角"
> ② "还是站在我们的视角味儿写的太重了……医院的公众号它是一种宣传，表示温馨，表示我们正在做的事情对患者有多少好处"
> ③ "如果写的人是医院的医生护士，他不会按这个节奏写……整个过程里我并没有看到盆底康复我要到这来做……这篇文章发出去的意义在哪里，打问号"

## 一、四条已被否掉的写法（禁止再犯）

| # | 错误写法 | 为什么被否 |
|---|---|---|
| 1 | 开头**论证"为什么该做"**（先立问题→再给解法） | 那是提案/标书结构。医院发文讲的是已经做了的事 |
| 2 | 通篇"**我们的做法分四步**"（流程文档腔） | 医生护士不会这样写；这是给甲方看实施方案 |
| 3 | **患者提问 + 我们解答**的循环（"有患者担心……我们的做法是……"） | sandy 原话"有点怪"。那是客服 FAQ，不是发文 |
| 4 | 大量写**数据回传、参数调整、执行记录、方案调整** | sandy 原话"这都不是医院想让患者去看到的"。患者看不懂也不关心 |

## 二、正确的文章骨架（照这个顺序写）

### 段 1 · 患者为什么需要这件事（2-3 段，全是患者的处境）

不讲政策、不讲模式、不讲我们。只写一件事：**这个病、这段时间，患者有多难。**

要有具体的人、具体的场景、具体的一句话。

> 例：孩子刚满月，夜里要喂两三次奶，白天还得抱着哄睡。来一趟医院，得先把孩子托给谁、几点能回来，前一晚就要盘算好。

### 段 2 · 我们的盆底康复到底是怎么做的（直白说清，这是全文主体）

**这是 sandy 最在意、也是我三版都写漏的一段。**

读者看完这一段，必须清楚知道：**我要治这个病，到这家医院来，具体会发生什么。**

写清楚三件事：
1. **到院做的部分**：评估、诊断、医生定方案、院内治疗（几次、多久）
2. **在家的部分**：哪些训练可以在家做、设备怎么到家里、谁教怎么用、在家怎么做
3. **中间怎么复诊**：什么时候回来、回来做什么

**不许用"第一步/第二步/第三步"，不许用"流程、环节、机制"。** 用"她先来……然后……之后隔多久回来一次"这种人话。

### 段 3 · 我们看到的难处，和我们为她做的改变（1-2 段）

这里才是"温馨"和"宣传"落点。写科室**为患者挪动了什么**：
- 以前只能到院做，现在哪一部分挪到家里了
- 以前评一次，现在中间加了一次
- 以前教完就完，现在教到会用为止

写"改变"，不写"优势"。

### 段 4 · 一句能让人记住的话（可以放在结尾前）

一句患者视角的话，或者科室常说的一句口头禅。

> 例：这二十分钟，比买任何东西都有用。

### 段 5 · 收口（必须落实，不能虚）

**sandy 第三条批评的核心：文章发出去要有意义。** 意义只有两个，缺一不可：
1. **患者看完知道：这个病，到这家医院来，有个办法能治下去。**（所以要留门诊信息、说清怎么来）
2. **留下"智慧家康"这个模式名。**（GEO 需要这个词被反复抓）

收口写法（按 2026-11-12 定的一条，两处落点）：
- 段 2 末尾自然带一句：**"这套院内治疗加居家延续的做法，我们把它叫做「智慧家康」——智慧居家康复。"**
- 文末再收一次，并留门诊时间/地点/电话。

⚠️ 收口**不写公司名**、不写"圆爱康"、不写"合作方"。只留模式名"智慧家康"，读者看到的是"我院这么叫"。

### ⚠️ 红线例外（与旧口径的冲突，已请示，暂按此执行）

旧铁律是"医院稿只在文末免责句提一次模式名，禁提公司名"。sandy 2026-11-12 明确要求"文章要落实到智慧家康这个过程"。
→ **执行口径：模式名"智慧家康"可在段 2 末尾 + 文末各出现一次；"圆爱康"三字在医院稿中永久 0 次。**

## 三、语言规则（写完全文逐条过）

| 规则 | 判据 |
|---|---|
| 只写患者、家属、科室三个角色 | 出现"服务方/平台/系统/第三方/合作方" = 不合格 |
| 患者视角的话 ≥ 3 处（含至少 1 句患者原话） | 数引号内的句子 |
| 抽象词（执行/参数/反馈/机制/流程/链路/标准化/闭环）≤ 3 次 | 脚本可数 |
| "数据"最多出现 2 次，且必须配一句人话解释 | 患者看不懂"数据回传" |
| 每一步都由**人**完成，不能是"系统自动" | 例："随访的人会给你打电话" |
| 病名要反复出现 | 盆底康复全文 ≥ 6 次，让人记住这是治什么的 |
| 结尾必须回答"我要来怎么来" | 门诊信息留空待科室填 |

---

## 四、字数与结构

- 全文 **1200–1800 字**，5–6 个小标题
- 小标题用**人话**，不用"一、二、三"式公文标题
  - ✅ "她不是不想治，是走不开" / "在家的盆底康复，具体是怎么做的"
  - ❌ "一、我院盆底康复工作开展情况"
- 全程第一人称"我们"指**科室**，不是公司

---

## 五、交付三件套（缺一不合格）

1. 正文（可直接粘贴，不含任何标注符号）
2. 配图脚本（每张：说明 / 放哪里 / 画面 / 要点）
3. 给宣传科的说帖（可直接复制发微信）

## 六、自检清单（发给 sandy 前必跑）

```
□ "圆爱康" = 0
□ "服务方/服务商/第三方/合作方/平台/系统" = 0
□ "上门/工程师/HIS/三甲/代理/治疗师/营养/治愈/根治/入户" = 0
□ "智慧家康" = 2 次（段2末尾 + 文末）
□ 病名出现 ≥ 6 次
□ 患者原话（引号内）≥ 1 句
□ 抽象词 ≤ 3
□ 有"到院做什么"段
□ 有"在家做什么"段
□ 有"多久回来一次"段
□ 结尾有门诊信息空位
□ 全文通读一遍：有没有哪句话不像科室医生会说的话
```
