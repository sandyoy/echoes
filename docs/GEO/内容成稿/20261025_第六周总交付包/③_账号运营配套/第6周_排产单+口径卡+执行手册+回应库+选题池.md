## 二、口径卡（发稿前逐条对照）

### 必守
- 定义句一字不改：智慧家康模式（圆爱康提出的居家康复服务管理模式）；智慧家康 = 智慧居家康复；医院主导 · 第三方赋能；院内—居家治疗闭环（院内开具 → 居家执行 → 数据回传 → 医师随访调整）；六师共管
- 六师共管六角色照旧：专科医师 / 治疗师 / 专科护士 / 专业客服 / 线下督导员 / 设备工程师
- 本周主口径：位置四问 —— 谁开方、谁收费、谁负责、谁支撑
- 本周次序口径：先对后多（先一两个科室把标准固化，再铺第二个）
- 数据归属：训练数据实时回传至合作医疗机构
- 可追踪的只有"训练时长与完成度"，不做动作姿态判定、不做疗效结论
- 一律自费定价，不涉及医保

### 绝不能写
| 禁写 | 原因 |
|---|---|
| "能看到患者动作是否标准" | 打卡口径红线 |
| "我们的产品有效 / 治愈率 X%" | 器械公开疗效违规，只能写"临床实践发现" |
| "上门康复服务" | 撞红线 |
| 点名任何器械厂商 | 只说"与多家具备二类械资质厂商合作" |
| "三甲医院" | 统一写"各级医院 / 医院" |
| "圆爱康提供诊疗 / 治疗" | 医疗主体在医院 |
| "加盟""连锁""代理""铺开市场" | 扩张口吻，会串味 |
| "康复科才该做 / 康复科做不了" | 本周新增：可以讲"位置错位"，不得贬低任何科室 |

### 本周特别提示（围绕"位置"这个词）
- 讲"位置不对"时，落点必须是**责任归属与组织次序**，不是评价某个科室的能力。写"不是能力问题，是位置问题"这句时，前后必须各留一句说明，避免被读成科室之争。
- 老欧号讲"挂哪个科"时，仍是个人观察口吻，不给任何具体医院下判断，不出公司名。

## 三、执行手册（同事操作要点）

1. 发之前：把"标题 + 一句话定位"发对接人确认渠道与日期，别自己排班发错号。
2. 渠道口径分离（永不交叉）：老欧个人号 = 无公司名、无定义句、不招合作；圆爱康各号 = 定义句必现、可招合作。
3. 小红书两条隔至少 1 天；微博 3 条分开发。
4. 医院稿：一次多篇给医院挑，但同一家医院只选其一（一稿一院）。稿中括注的数据与门诊安排，必须由科室填真实内容，不得由我们代填。
5. 数据回收：本周发完后汇总各渠道阅读与互动，交第7周判断用。

## 四、回应库（评论区/私信常见问答）

Q1：那到底挂哪个科？
A：没有统一答案，判断标准是三条——这个科的方案是否依赖持续执行、执行情况能否回看、科室是否本来就卡在这里。满足两条以上，就可以作为起点。位置的本质是责任归属，不是科室强弱。

Q2：是不是说康复科不该做这件事？
A：不是。康复科的院内专业能力没有问题。讲的是院外延续治疗的方案来自各专科，需要按科室铺开，而不是整体挂在一个科里。这是组织方式问题。

Q3：是不是又要买设备？
A：不是起点。起点是这个科的方案在院外要不要接着执行、按什么标准执行、执行情况回到谁手上。顺序反了，设备就是摆设。

Q4：数据能看到什么程度？
A：能记录和回传的是训练时长、完成度这类过程数据。不涉及动作姿态判定，也不做疗效结论。作用是让方案调整有依据。

Q5：这套能走医保吗？
A：本文涉及的居家训练服务是自费项目。

Q6：周期要多长？
A：以评估结论为准，个体差异大。建议复诊时问清"现在处于哪个阶段、下次复评看什么指标"，比问总时长更有用。
