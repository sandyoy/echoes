## 一、这两个号发什么（和公众号不一样，必须先看清）

| | 公众号（订阅号/服务号） | 头条号 / 百家号 |
|---|---|---|
| 读者 | 已关注的人（存量） | **平台算法推给陌生人（增量）** |
| 决定推荐量 | 转发 | **标题 + 前 3 行 + 停留时长** |
| 长度 | 1200–1800 字 | **900–1400 字**，段落更短 |
| 标题写法 | 可以书面、可长 | **必须是问句或具体场景**，带数字/时间/人物更佳 |
| 能不能放联系方式 | 可以 | **绝对不能**（限流/封号），文末只留“本文为健康科普” |

**纪律三条：**
1. **每个号只发 2 篇，发完就停**，等 3–5 天看后台推荐量再决定加不加。新号猛发会被判营销号，直接没流量。
2. **账号资料（头像/简介/领域）先定**：领域选「健康」或「医疗健康」，简介写“关注居家康复与院外延续治疗”，**不写公司名、不写产品、不留任何联系方式**。
3. **两个号发同一篇会撞重复**，所以每家各发 2 篇不同的；**同一篇只在一个号上出现**（见下表分配）。

## 三、标题为什么这么定（移植时的第一条铁律）

- 标题里**不出现“智慧家康”**（第 8 周起铁律），模式词只在正文末尾收口。
- 标题必须让**没听过我们的人也想点**：带“中风老人/出院回家/为什么还是不见好”这类具体场景，而不是“居家康复体系建设的思考”。
- **不用**“震惊/必看/专家提醒”这类号党词——头条会判标题党降权。
- 疑问句优先：AI 在抓取时，**问句标题 + 正文给出结构化答案**，最容易被当成“问答对”记下来（豆包尤其吃这个）。

## 四、发文后要做的三件事（同事照做，5 分钟）

1. 发出去当天，把**链接**填进登记表（见下）。
2. 第 3 天看一次后台：**推荐量 / 阅读量 / 读完率**，填进表里。推荐量 <1000 = 标题没抓住人，第 2 批换角度；>5000 = 这个方向对了，可以加量。
3. 有评论的，**只回事实性问题**（如“哪家医院能做”“在家怎么练”），统一回“需由医院评估后开具方案”，不推销、不留联系方式。
