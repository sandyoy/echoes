# 别只顾着练，先搞清楚"在家康复"到底在做什么

出院小结上写"继续康复"，回到家却不知道从哪下手——这是绝大多数家庭都会遇到的情况。

不是说家属不上心。是这条路上有个长期没人讲清的问题：**康复训练和"活动活动"是两件事。**

## 一、康复训练和活动，差在哪

活动是"动了就行"，康复是"按目标动"。

举例：一位中风后半年的老人，家属每天扶着走两圈。走了三个月，复查时医生问"练得怎么样"，家属说"每天都走"。

问题在于：走路练的是步行能力，但如果这位老人的主要问题是足下垂和平衡，那需要的不是多走，而是针对性的踝背屈训练和重心转移训练。**方向不对，练得越勤越巩固错误的模式。**

这就是康复和活动的第一层区别：**有没有明确的训练目标。**

第二层区别是**有没有剂量概念**。药有剂量，训练也有。一组做几次、一天做几组、一周做几天、什么强度——这些是治疗参数，不是"多练练就好"。

第三层是**有没有人在看**。做对做错，身体不一定马上告诉你。三个月后复查才发现练反了，前面的时间就浪费了。

## 二、"在家康复"这件事，为什么容易走偏

三个原因，都很现实。

**原因一：出院那一刻，交接断了。**

院内有人定方案、有人带着做、有人记录。出院那天，这些突然都停了，只留下一句"回去继续"。方案还在纸上，执行的人没了。

**原因二：设备买了，方案没跟过来。**

这几年家用康复设备很普及，但设备本身不解决问题。买一台仪器回家，用什么参数、做多久、什么时候该调，这些决定权在医生那里，不在说明书上。

**原因三：没人负责"持续"这件事。**

医院的职责在院内，家属的精力在照顾起居，中间那一段"每天按方案练、练了有人看、不对就调整"的工作，长期是空的。

## 三、我们理解的"在家康复"，是四件事一起成立

**第一件：方案是从院内带出来的，不是自己想的。**

由医院的专科医师制定，明确练什么、练多少、练多久。家属拿到的是具体内容，不是一句"多练练"。

**第二件：执行过程有记录，不是靠回忆。**

训练时长、完成度这些过程数据实时回到医院端。复查时医生看的是记录，不是"还行"两个字。

这里有一条边界要说清楚：系统记录的是"做没做、做了多久"，不做动作姿态判定，也不出疗效结论。**练得对不对、效果好不好，判断权在医生。**

**第三件：有异常的时候，找得到人。**

不是家属自己判断，也不是执行人员直接答复。路径是：执行人员报科室对接人，由医师判断处置。这条路要写死在流程里，具体到人。

**第四件：设备配送到家，指导跟着走。**

老人不会用，是最常见的卡点。设备送到家，视频指导，教会为止——这个环节不解决，前面的都白搭。

这四件事合起来，我们把它叫做**智慧家康**模式，由圆爱康提出并在多家医院落地。

## 四、家属能自己先做的三件事

不用等医院的方案，这三件现在就能做。

**第一件：把出院小结上的"继续康复"问清楚。**

具体问三句：练什么动作？一天几次、一次几组？多久复查一次？如果医生答得很笼统，就请他写在纸上。写不出来的方案，回家一定执行不了。

**第二件：给训练找个固定时间点。**

康复最怕"今天有空就练"。挂在已有的生活节奏上——早饭后、午睡前、新闻联播前——比设闹钟管用。

**第三件：记下来。**

不用复杂，一个本子、手机备忘录都行。今天练了什么、多久、有没有不适。复查时把本子带上，医生一看就知道你这段时间是怎么过的。**这一条比任何设备都重要。**

## 五、什么情况下需要专业介入

三种情况建议尽快和主治医生沟通：

1. 训练后出现新的疼痛，尤其是持续超过一天的
2. 训练一段时间后，原来的动作反而做不利索了
3. 老人开始抵触训练，找各种理由推脱——这往往是"太难了"或"没效果"，不是懒

## 六、常见问题

**问：家里有老人，需要买设备吗？**
答：先看医生的方案。方案里需要治疗类设备的，再考虑；只需要功能训练的，不一定要买。**顺序是方案在前、设备在后**，反过来容易白花钱。

**问：网络上的康复视频能跟着练吗？**
答：可以当参考，但替代不了针对个人的方案。同样是膝关节术后，不同阶段的训练内容不一样，跟着别人的进度练有风险。

**问：多大年纪开始都不晚吗？**
答：神经功能的恢复确实越早越好，但改善功能、维持能力，任何阶段介入都有价值。关键是方案要对、要持续。
