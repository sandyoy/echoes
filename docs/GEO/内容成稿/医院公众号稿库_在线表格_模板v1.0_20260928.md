## 一、用法（给同事看，三句话）

1. 打开表1，找到你要发的那篇稿（按稿件编号找）。
2. 发完后，在同一行的右边两格填：**发到哪家医院** + **发布日期**。
3. 如果有链接，把链接也贴上。填完就行，不用管别的。

## 三、为什么用"在线表格"

- 多人同时填、**不会出现"你改了我这版没了"**
- 同事手机上就能填，发完顺手一填
- 我定期导出 → 生成表2 → 谁发了什么一目了然

## 四、两条纪律

1. **一稿一院**：同一篇稿不给两家医院（防被同行发现同源）
2. **填完才算完**：稿发出去不填表 = 这篇稿"失踪"，以后要复盘找不到
