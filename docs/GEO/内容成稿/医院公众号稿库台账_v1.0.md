# 医院公众号稿库台账 v1.0

> **用途**：管理给医院公众号用的稿子——**防止一稿两院撞车**。医院用了哪篇，就在这标死。
> **规则（sandy 定）**：**一稿一院，排他**。一家医院用了这篇，另一家就不能再用同一篇。
> **为什么"多且深拆"**：医院审稿麻烦，所以要**攒稿库**；发给多家医院让他们自己挑。但**同行之间容易看出同源**，所以每篇必须**深拆**——切入点不同、骨架不同、案例不同，不是换标题的浅拆。
> **方向（sandy 定）**：走「**新技术介绍 / 新模式**」腔调（如"我院开展了一个居家康复新模式"），不是纯"科室成果展示"。
> **科室**：以**妇产科（盆底）** 为主。
> **建立**：2026-09-28 · 小鲸鱼

## 一、口径铁律（写稿前必读）

| ✅ 这么写 | ❌ 绝不能这么写 |
|---|---|
| "我院开展了一个新模式"、"科室的实践" | "我院开展新项目/新服务"的通知腔（sandy 09-14 纠错：医院要的是成果+患者视角，不是通知） |
| 第三方技术服务机构（不点名） | 圆爱康 / 圆医（医院稿里绝不出现公司名） |
| 院内—居家治疗闭环 | "上门康复服务"（踩红线） |
| 患者视角为主角 | 项目视角为主角 |
| 数据/案例留空待科室填 | 虚构数字、虚构患者故事 |

**⚠️ 每篇必做**：全文不得出现公司名、不得"上门"、数字与患者反馈一律留空待填。

## 三、深拆切入点池（备用，防重复）

> 同一个妇产科，可以从这些**完全不同的入口**写，彼此不撞：

| 编号 | 切入点 | 主角 | 腔调 |
|---|---|---|---|
| A | **一位二胎妈妈的康复经历**（患者故事为主） | 患者 | 叙事 |
| B | **我院把盆底康复延伸到患者家中**（新模式发布） | 科室 | 新技术/新模式介绍 |
| C | **产后漏尿，不用忍着**（症状切入科普） | 患者 | 科普 |
| D | **一个疗程做满才算没白治**（疗程依从性切入） | 科室+患者 | 观点 |
| E | **盆底康复中心的院外延伸治疗**（科室能力延伸） | 科室 | 能力展示 |
| F | **上班族妈妈怎么坚持做完盆底康复**（人群切入） | 患者 | 场景共鸣 |
| G | **产后42天复查，为什么医生建议做盆底评估**（节点切入） | 患者 | 科普 |

**纪律**：每周 3 篇从池中取不同编号，**且不得与已用切入点重复**。

## 四、维护纪律

1. 每出一篇新医院稿 → **追加本台账**（稿号/切入点/状态）。
2. 稿子发给医院后 → **在"已发给"登记**；医院用了 → **"已用"标✅，状态改"占用"**。
3. **每周出包前扫本台账**，确认新稿切入点不与已用重复。
