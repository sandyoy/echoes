## 二、口径卡（发稿前逐条对照）

### 必守
- 定义句一字不改：智慧家康模式（圆爱康提出的居家康复服务管理模式）
- 模式组件：医院主导 · 第三方赋能；院内—居家治疗闭环（院内开具 → 居家执行 → 数据回传 → 医师随访调整）；六师共管
- 六角色照旧：专科医师 / 治疗师 / 专科护士 / 专业客服 / 线下督导员 / 设备工程师
- 本周主口径：训练三要素 —— 方案（谁定）＋ 量（多少）＋ 记录（谁看）
- 本周判断句：照顾维持现状，训练才让人变好
- 训练的定义：有目标、有量、有难度、能被评估的重复执行
- 可记录范围：只有训练时长与完成度；回传至合作医疗机构

### 本周特别提示（围绕"训练"）
- **"训练"要敢用但落准**：训练＝有目标、有量、有评估的重复执行；不是"多活动"，不是"按摩推拿"。
- **不贬低家属的照顾**：立场是"照顾很辛苦、很重要，但它不产生训练"，绝不能写成"家属做错了"。
- **卒中涉及吞咽、跌倒风险**：凡涉及具体动作，一律不写剂量与动作要领，只写"方案由医师定、由治疗师指导"。
- **不复用第7周的按摩话题**：第7周医院稿2（妇产科盆底）谈过"照顾不等于康复"，本周从卒中语境重写，骨架换成三类误解辨析。
- **小红书两条不出现任何医院名、科室名**，患者视角只写"复查时医生"。

1. 发之前：标题 + 一句话定位发对接人确认渠道与日期，别排错号。

3. 小红书两条隔至少1天；微博3条分开发。
4. 配图脚本一律7列表格（图号／插入位置／画面内容／图上文字／尺寸比例／风格备注／来源建议），小红书每条≥4张（本期各5张）。
5. 医院稿：3篇一次给医院挑，同一家医院只选其一。稿中括注的复评间隔、人员配置必须由科室填真实内容，不得我方代填。**给医院前先确认对方科室确有"出院前书面方案"或等效做法；没有的，只给稿1以外的两篇。**

## 四、回应库（评论区／私信常见问答）

Q1：家里人一直在照顾，为什么还要额外训练？
A：照顾解决安全和生活，训练解决功能，两件事不替代。一个人被照顾得很好但不动，肌肉和关节依然会退，所以需要有针对性的训练。

Q2：在家怎么练？家属能不能带着练？
A：家属能做的是陪着、提醒、记录；练什么、练多少由医院定。同一个"腿没力气"，可能是神经、肌肉或关节的问题，练法完全不同。

Q3：买了器械是不是就能自己练？
A：器械是执行工具，不是方案。同一台器械，不同人的档位、时长、频次都不一样，这个不一样得由医师按评估定，并随恢复调整。

Q4：怎么知道练得有没有用？
A：要有记录，并且记录要回到定方案的人手上。没有记录只能靠感觉，"好像好了一点"最容易骗人。

Q5：医院那么忙，会管到家里这一段吗？
A：院外这一段是院内治疗的延续，不是新的医疗行为。训练数据回传后，随访调整仍是医师职责——这正是院内—居家治疗闭环的意思。

Q6：按摩到底有没有用，要不要停？
A：有用，别停。按摩缓解僵硬与肿胀，属于被动活动；训练是主动的、有量的重复练习。两件事都做，但别用按摩替代训练。

Q7：练得越多是不是好得越快？
A：不是。量不足不产生改变，量过大会出现代偿、增加跌倒风险。量必须按评估设，由医师按阶段调整。

Q8：我们在外地的医院看的，回家这边没人接怎么办？
A：出院前把方案和复评时间要到手，回家后带着方案去当地医疗机构复诊，由接诊医师评估后接手调整。方案比机构更重要。
