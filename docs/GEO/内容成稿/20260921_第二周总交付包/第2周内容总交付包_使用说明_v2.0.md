## 一、三个文件夹分别是什么

| 文件夹 | 给谁用 | 怎么用 |

| **①_渠道成稿（可直接发）** | 发帖同事 | .txt 文件。正文 + 文末配图脚本（纯文本版）。文案可直接复制发布，配图脚本当参考 |

## 三、配图脚本怎么看（7列）

| 列名 | 意思是 |
|---|---|
| 图号 | 图1、图2…标"（封面图）"的就是首图 |
| 插入位置 | 这张图插在正文哪一段后面 |
| 画面内容 | 画什么（场景/图形/分栏）——**不要用真人摆拍照片，用图形+文字** |
| 图上文字 | 图上要写的字（照抄，别自己改口径） |
| 尺寸比例 | 做图时的宽高比 |
| 风格备注 | 配色、字号、注意事项 |
| 来源建议 | 自己做还是找素材 |

## 四、配色规范（做图统一用）

- 品牌绿 `#0b6b5c` — 主色（标题字、图形主体）
- 辅助金 `#c9a227` — 点缀（强调线、数字、箭头）
- 白底为主；分区底用浅灰 `#f5f7fa`
- 小红书封面底：浅绿 `#e8f3f0` + 深绿字
- **不用网上下载的医生/护士摆拍图**——用图形 + 文字表达

## 六、这一版跟上一版的区别

上一版（9-21）8 篇 Word 里**没有配图脚本表**，只有 `【图N：xxx】` 一行占位符，同事没法照做图。
本版（9-22）**逐篇从各自正文重新生成了配图脚本**，补成 7 列表格，并做了三项自检：

1. 配图脚本表存在且 ≥3 行 × 7 列
2. 图上文字与本篇正文对得上
3. **与第1周、以及本周其他篇不重复**（画面和图上文字都不重复）

正文文字**一字未动**，只补了配图部分。
