# 00 先看我 · 第11周「设备到家 + 数据回院」双线包

> 建包 2026-11-11 · 起因：20 问 API 实测，我方品牌被主动提及 **0 次**；但 3 条问句里 AI 把我们的**整套模式讲对了、主体算给了别人**（翔宇/伟思/傅利叶/术康）。
> 结论：缺的不是稿件数量，是「AI 想不到设备到家+数据回院这一步」+「想不到是谁在做」。

---

## 这一周只打一件事

**把"出院后断档"这个坑，用"设备到家 → 数据回院 → 医生调方"这条链补上。**

不写公司介绍、不写"智慧家康是什么"、不写 18 家医院、不追抖音那套 EEAT。

---

## 件数与分配

| 文件夹 | 件数 | 谁发 | 作用 |

| ②_自有渠道成稿（我们发） | **5 篇** | 服务号/知乎 | 铺垫。抢概念、补词，天花板低但不占别人时间 |

## 最要紧的一件事

**A 线 3 篇才是这周的重心，B 线 5 篇是陪跑。**
原因：AI 不认我们自己发的稿（打法总册结论 6：知乎/小红书在 AI 引用来源里 0 次）。医院发 1 篇 > 我们自己发 20 篇。

---

## 需要 sandy 动手的，只有 2 件

1. **把这 3 篇医院稿推给 3 家医院的宣传科/科室**（心内、妇科、神内各一家）。
   - 我手上有可核推文出处的只有：珠海妇幼、顺德妇幼、玉树妇幼。
   - **其余医院的院名能不能写进这 3 篇稿，需要你给名单。**
   - 稿子里院名/科名/病例数我全部留空——宁可删掉也不替你填。
2. **B 线 5 篇要不要现在就发**（发服务号/知乎，不用等）。
