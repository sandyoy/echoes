## 判断标准（为什么是这 9 个）

从 22 个空位里挑出**同时满足 ≥2 条**的：

1. **问句＝我方定位的复述**（AI 答的形态与我方模式最接近，最易被替换）
2. **商业转化意图强**（代理商/医院/患者带决策来搜）
3. **竞品空缺明确**（AI 只答模式/设备/医院，答不出"哪家平台"）
4. **AI 自认"查不到/无权威/信息分散"**（我方一篇稿即可成为唯一答案）
5. **有官方权威锚可挂靠**（政策/指南/共识，借权威提升可信度）

## 执行建议（供 sandy 拍板）

1. **优先顺序**：第一梯队 5 个 → 第二梯队 2 个 → 第三梯队 2 个。
2. **每篇稿的目标**：不是"写给我方官网"，而是**"写一篇能被秘塔 RAG 抓到的第三方形态内容"**（行业稿/问答稿/案例稿，让我方成为"答案里被点名的那个平台"）。
3. **挂靠策略**：可挂权威的（Q12/Q20/Q13）**必须挂**——借政策/指南/共识的权威度，比纯自吹有效得多。
4. **节奏**：GEO 收录有 2–8 周延迟 → **本批稿投出后，约 11 月中下旬全量复测**才能看到水位变化。
5. **禁区**：不碰"定义权被占位"的 Q01/Q04（需先做**校正**而非投放，涉我方口径，须 sandy 定调）；不硬碰已有多家占位的 Q05/Q06（先做低成本的品类稿探路即可）。
