# 圆爱康 · 「居家康复 vs 上门」政策边界调研 2026-09-08
> 背景任务（sandy提出）：居家康复在政策上是否必须绑定"上门"？若药监/审批默认居家=需上门，
> 我们用什么政策/改什么名可合法合规地落在"不需上门"那侧。
> ⚠️ 调研源：秘塔AI搜索(联网查官方源)。部分推论尚未独立复核，见文末。

## 一、核心发现：政策里并无"居家康复"孤立的专门定义，真正被定义的是一条分水岭

国家层面没有专门给"居家康复"一词出定义文件。它分成两堆，边界在"是否上门"：

### 🅰 需上门的（监管重）＝"上门医疗服务"
- 定义：医疗机构医务人员**走出机构、到患者家庭**提供康复治疗/护理/诊疗等
  → 依据：国卫办医发〔2020〕24号《关于加强老年人居家医疗服务工作的通知》
- 触发条件：须取得《医疗机构执业许可证》+ 将"家庭病床/巡诊"等**登记为执业服务方式**
  + 康复治疗专业技术人员≥3年经验+技师及以上职称
- 若你干的是"派人上门施治"，就掉进这堆 → 重资质、高风险（第三方自己派人=非法行医风险）

### 🅱 不需上门的（监管轻）＝患者在家自我康复 / 家用设备自助使用
- 无专门资质要求。患者自行购设备/按指导自主训练，**一般不构成"上门医疗服务"执业行为**
- ⚠️ 但秘塔明确承认：**国家没有专门文件就"家用设备自我康复"给出一句正式定性**，此点是"政策逻辑推导的合理理解"

### 🅲 中间态＝互联网诊疗/在线康复指导
- 远程指导若由持证机构+注册医师组织，走"互联网诊疗/互联网+护理"(国卫医发〔2018〕25号)；门槛=持证机构+注册医师，仍不轻
- 但纯"健康管理/运动指导/非医疗"可能不属医疗执业监管 → 边界模糊需属地定

## 二、对本项目的含义（圆爱康居家模式卡在哪）
- 圆爱康核心是"**患者在家用家用设备自我康复 + 系统/医护远程和指导**"，不是"派人天天上门施治"
  → 理论上应落在 **🅱不需要上门资质** 那侧，或 🅲靠持证医院的注册医生合规
- 但正因为国家没明文点破"家用自我康复不需上门"，审批/监管窗口**有权自由裁量**，
  若他们默认按 🅰上门医疗服务审你 → 你会被累加一堆本不该有的资质/越界压力
- 这就是你说的"药监/审批要求居家就得上门"的套——本质是**边界不明导致的自由裁量风险**

## 三、所以"规避/改名/靠哪份政策"的真实问题
sandy方向对：**与其硬扛"居家康复=需上门"的默认,不如主动把业务"表述"到 🅱/🅲 法理能自洽、又确实符合你模式那侧**。要的不是捏造,是"表述回归事实"——因为你的实质本来就不是"上门医疗",是"家用设备自我康复+远程共管"。
