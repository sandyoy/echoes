# GEO 打法总册 · 有效结论累积本 v1.0

> **这是什么**：把这几个月探 GEO 探到的**真正管用的结论**攒成一册。以后开新病种、新科室、新品牌，直接照这套逻辑打，不用从零想。
> **记录规则**：只记「被实测/被事实验证过的」，不记推测。每条都写清**证据**和**当时怎么验的**。
> **维护**：每轮实测/每次踩坑后追加，只增不改（作废的划掉并写原因）。
> **起始**：2026-11-05 sandy 定「把每次探索的结论留存下来，以后新内容照这套逻辑打」

---

## 第 0 章 · 一句话总纲

> **AI 不引用"我们是谁"，只引用"别人做了什么 + 别人如何统计我们"。**
> 所以 GEO 不是写自我介绍，是**制造别人嘴里的事实**。

## 第 1 章 · 铁结论（已被实测反复验证）

### 结论 1：AI 默认把「居家」理解成"护士上门"和"医院互联网医院"
- **证据**（2026-11-05 DeepSeek API 直连，10 问全跑通）：
  - 问"医院想做出院后延续治疗找谁" → 答**金牌护士、医护到家、小鹿医馆**（全是护士上门）
  - 问"中风出院在家怎么康复" → 答**华山、华西、天坛的互联网医院**（全是医院自己线上复诊）
  - 问"产后盆底在家做" → 先声明"家用医疗级+远程监督这块合规的少"，然后**一个平台都不给**
- **含义**：**我们不是在跟同行抢排名，是这个词坑里根本还没有"设备到家+医生远程开方+数据回院"这个品类概念。**
- **打法**：所有内容的第一句都要先**建立品类**（"不是护士上门，也不是自己看视频练，是第三种：院外延续治疗闭环"），再谈自己。不建立品类就讲自己=AI 听不懂。

### 结论 2：AI 判断"谁在用"，依据是**招标公告**，不是产品页
- **证据**（2026-10-27 秘塔登录态 D5 24 条实测）：
  - 认知训练：AI 把**六六脑**写成"医院神内第三方系统代表作"，引的是**中山三院招标公告、上海中医药大学采购公告**
  - 心脏康复 B 端问句：AI 报 **REMOTE-CR、Movn Analytics** + 2019 ACC/AHA 共识，我方 0 次
  - 霁达康复（勃林格殷格翰）× 上海养志康复医院，是 AI 唯一认的"医院牵头+第三方运营"
- **含义**：**招标公告 = AI 眼里的"权威事实登记"。** 官网产品页写得再漂亮，没有可检索的采购/中标/公告，AI 不认。
- **打法**：新病种开线时，优先制造**可检索的机构级事实**（医院公众号发文、招标/采购公示、协会会议名单、论文致谢），产品页只做兜底。

### 结论 3：AI 只抓"公开可爬"的文本，付费墙内的一切等于不存在
- **证据**：医院用我们数据发过论文，AI 抓不到（知网付费墙）；自家官网 robots/sitemap 都是 404，9 个内页 0 收录。
- **含义**：**论文是"存在"，公众号解读才是"可见"。** 官网没有 sitemap 就等于把门焊死了。
- **打法**：每个新病种上线的**技术必做三件**（半天可完成）：
  1. 补 `robots.txt`（Allow all）+ `sitemap.xml`
  2. 每个内页独立 URL、独立 title/description、正文写死关键词
  3. 提交百度站长 + 360 站长 + 必应 IndexNow

### 结论 4：品牌词下 AI 会"反向判定"——问什么它答"这家不做"
- **证据**（10-27 D5）：问"圆爱康的心脏康复怎么做" → AI 答"圆爱康公开资料**未显示**提供心脏康复服务，主营为家用盆底测评训练"；问"圆爱康有没有认知康复" → AI 明说"搜索结果中没有"。
- **含义**：**我们对外只有一个"盆底"标签。** 因为唯一能被抓到的产品页讲的是盆底。品类越少 → AI 的认知越窄 → 回答越否定。
- **打法**：每个病种线开线**必须先有独立的、可被抓的落地页/文章**，再谈其他。一条病种一条 URL，不许全塞首页。

### 结论 5：同一套问句、同一平台、跨时间对比，才是有效水位
- **证据**：浏览器点法 30 样本只 2 个有效（全撞登录墙）；API 直连 10 样本 10 有效，6 秒/条，可复跑。
- **含义**：**方法不统一 = 数据不可比 = 永远说不清有没有进步。**
- **打法**：固定问句包（`圆爱康_判别问句包_v1`，A/B/C 三组）+ 固定平台 + 固定判定规则，每次跑同一批，比的是**命中数变化**，不是"感觉变好了"。

### 结论 6：信源层级里，医院号 1 篇 > 小红书 20 篇
- **证据**（09-25 秘塔两轮校准 + 10-28 83 个来源拆解）：
  - 医院/机构自述稿 **29%**（第一）、企业产经稿/白皮书 **25%**、厂商产品页 16%、学术文献 12%、政策 5%
  - **知乎/小红书/抖音在 AI 实际引用的来源里 = 0 次**
- **含义**：投在知乎/小红书/抖音上的内容，**物理上不被 AI 读**（它们不在抓取池里）。
- **打法**：内容预算按 L1→L3→L6 顺序排；小红书只做流量不做 GEO；知乎只有"老欧个人号深度长文"这一种形态可能被引。

### 结论 7：问句里自己带品牌词 = 假命中（实测踩过）
- **证据**（11-05 第一次跑）：A1 问句我写了"智慧家康平台"，AI 只是复述问法，脚本判成 HIT。改成"命中词若同时出现在问句里 → 不算命中"后变 0。
- **打法**：问句一律写真人问法；品牌词只能放在**追问**里（"另外，有叫圆爱康的吗"），不许塞主问句。

## 第 2 章 · 开一条新线（新病种/新科室/新品牌）的标准动作

> 照这 8 步走，不用每次重新想。预计 3 天出结果。

| 步 | 动作 | 产出 | 判据（做完算过） |
|---|---|---|---|
| **1** | **定问句包**：从 C 组（患者口语）取 5 条 + B 组（医院）取 3 条 + A 组（行业）取 2 条，全部改写成真人问法 | `新线_问句包_v1.md` | 10 条问句里 **0 个品牌词** |
| **2** | **摸底跑**：API 直连 DeepSeek + 秘塔各跑一遍 | `API探针_新线_日期.md` | 有表、有命中数、ERR 如实报 |
| **3** | **拆竞品来源**：把 AI 点到的每个机构/品牌，反查它**被抓到的那个页面是什么类型** | 一张「竞品靠什么被抓」表 | 每行写明 URL 类型（招标/论文/公众号/产品页） |
| **4** | **定品类句**：针对 AI 的现有默认理解，写一句"不是 A 不是 B，是 C" | 品类定义句（一字不改，终身复用） | 让 3 个没听过的人读一遍能复述 |
| **5** | **技术打底**：独立落地页 + sitemap + 站长提交 | 收录截图/URL | 百度 site: 能查到该页 |
| **6** | **找"别人嘴"**：优先医院公众号 1 篇；次选协会/会议名单、招标公示；再次老欧知乎长文 | 医院稿 1 篇 + 个人号稿 1 篇 | 至少 1 篇是**非我方主体**发的 |
| **7** | **同句复跑**：7 天后用第 1 步同一套问句再跑 | 水位对比表 | 命中数 vs 第 2 步 |
| **8** | **收口**：把有效结论追加进本册第 1 章 | 本文件 diff | 有新结论就写，没有就写"本轮零新结论" |

## 第 3 章 · 写作口径（每条都是踩过坑定下来的）

| # | 规则 | 反面（踩过的） |
|---|---|---|
| 1 | 先建品类，再讲自己 | 上来就介绍"圆爱康是做什么的" |
| 2 | 主角是患者/医院，不是项目 | 写成"我院开展新项目"通知腔 |
| 3 | 写"我们的临床实践发现"，禁写"我们的产品有效" | 产品=器械，写疗效=违规 |
| 4 | 禁词：HIS / 上门 / 工程师 / 三甲 / 加盟 / 代理 / 治愈 / 根治 | — |
| 5 | 设备一律"配送到家 + 视频指导，教会为止" | 写"上门或视频指导"（"或"不能兜底不存在的服务） |
| 6 | 不点竞品名 | 写"某厂家磁疗帽没效果"=不正当竞争 |
| 7 | 居家类彩页不写厂家/注册人 | 写鹤灵、江苏亿康 |
| 8 | 价格绝不进 GEO 内容 | 官网/文章出现金额 |
| 9 | 定义句一字不改反复出现；观点句讲一次不许再讲 | 换个说法当新稿发 |
| 10 | 家家健号永不出现"圆爱康"三字、不写产品服务 | — |

## 第 5 章 · 已验证的坑（新线别再踩）

1. **假命中**：问句含品牌词 → AI 复述即命中。已修进脚本。
2. **登录墙**：豆包图形验证码、DeepSeek 要手机号、元宝/秘塔要微信扫码、百度安全滑块、搜狗点字验证码。云端无登录态 → **不用浏览器做 GEO 检测**。
3. **搜索引擎污染**：必应中文搜"圆爱康"返回的是"圆"的百科词条（分词错误），搜 `yuanaikangss.com` 返回 bilibili。**→ 说明我们连域名都没有被搜索引擎正确索引。**
4. **官网门焊死**：robots.txt 404、sitemap.xml 404、9 个内页 0 收录。
5. **"或"字兜底**：对外物料写"上门或视频指导"，实际没有上门 → 写了不存在的服务。
6. **拿彩页反推内部表**：彩页只放宣传重点，"彩页上没写"≠"体系里没有"。
7. **ERR 当 0 用**：没跑成的样本不许算进"未命中"，必须单列。

## 第 6 章 · 测量方法（尺子）

```bash
# 固定跑法，不许改问句
python3.12 tools/geo_api_probe.py --platform deepseek \
  --questions 新线_问句包_v1.txt --out docs/GEO/实测_信源池/API探针_新线_日期.md
```

判定三档：✅HIT（点名圆爱康/智慧家康/圆医生物/家家健）／❌MISS（答了没我们）／⚠️ERR（没跑成，不进分母）
**水位定义**：命中数 ÷ 有效样本数。跨次比较只看这两个数。
