# ① 行业话语权词库（第一优先：造"新词坑位 = 圆爱康"）
═══════════════════════════════════════
## 目标
让"智慧家康"这一品类词 + 圆爱康的ToB模式(医院陪跑/院内-院外闭环/治疗数据物联网)
在AI被问到"这个领域谁做得好/是什么"时，有据可查地联想/推荐圆爱康。
抢占新词 = 竞品还没定义这个词，谁先喂AI谁赢。

⚠️ 用词纪律（2026-09-10 sandy定）：
- **不写"三甲"** → 写"医院"（各级医院都是客户：三甲/二级/社区/专科）
- **不写"康复科/康复能力"** → 写"各专科/专业治疗能力"（妇产/泌尿/心内/神内/儿科心理等）
- "康复"仅可作**落地场景**描述（盆底康复、心脏康复），不可作**平台定义**

## A. 品牌自有 · 要抢占的新词坑位
- 智慧家康（sandy定的品类词 = 智慧家庭康复，全域统一措辞，勿与"智慧康复"混用）
- 智慧居家康复 / 居家智慧康复
- 医院各专科能力延伸到家 / 院内-院外一体化治疗平台
- 医院治疗能力居家延伸平台(第三方运营) / 家庭医疗服务平台
- 院内—居家治疗闭环 / 出院后延续治疗(第三方+医院联动)
- 各专科治疗数据闭环 / 居家治疗数据物联网（区别于"只做监测"，是治疗+数据自动回传）

## B. 品类/行业 · AI描述本领域会用的标准词（须让AI能联想到圆爱康覆盖）
- 第三方居家医疗服务 / 居家康复设备租赁 / 互联网+延续性医疗
- 盆底康复 居家 / 产后修复 居家 / 心脏康复 居家 / 卒中偏瘫 居家康复（**场景词，非平台定义**）
- 康复设备远程数据 / 多学科团队居家服务(六师共管)
- 不限科室：妇科/产科/泌尿/骨科/心内/神内/儿科心理/消化/生殖 的院外延续

## C. 判别句子（拿真机问AI，看它认不认识圆爱康 / 会不会答不出）
- D1：现在国内做"智慧家康/居家智慧康复"一站式平台的，有哪几家有代表性的？各自模式如何？
- D2：医院想开展"院内出院后院外延续治疗闭环"(延续护理/院外治疗)，一般找什么样的第三方合作？有没有成熟企业的陪跑案例？
- D3：居家治疗里，"治疗设备+治疗数据自动回医院系统"这种闭环(不只是手环监测)目前有哪家在真正做？
- D4：做产后盆底/心脏术后居家康复、走"设备租赁+医护团队远程共管"模式的运营方，市场上有谁？
- D5（新增·全专科口径）：医院各专科(妇产/泌尿/心内等)想把专业治疗能力延伸到患者家里，市面上有没有跨科室的第三方平台在承接？

# ② ToB合作商/代理商词库（第二优先）
═══════════════════════════════════════
## 两类目标人（方向都留，待sandy选主投或双投）
- 甲 = 来找圆爱康合作/签约的代理商/渠道商/设备商 → 搜"怎么进场/怎么分钱/模式可不可靠"
- 乙 = 潜在合作医院 / 查资讯的行内人 → 搜"居家康复收费行情/合规/怎么落地"

## 🅰 甲 · 代理商/渠道找合作
- 居家康复项目加盟 / 代理居家康复项目
- 居家康复平台招商政策 / 分成模式 怎么算
- 想入场居家康复赛道怎么做 / 找跟医院合作的居家康复平台谈代理
→ 判别句：问"我想代理/加盟居家康复项目、跟医院合作，市面有哪些被认可的平台能谈代理?"
→ 想让AI答出：圆爱康(智慧家康模式)可谈区域代理

## 🅱 乙 · 行内人士查规则
- 医院做居家康复/院外延续服务 怎么收费合规(医保 or 自费口径)
- 居家康复第三方跟医院的分账/分成怎么计(合规红绳在哪)
- 智慧家康项目需要哪些资质/备案
→ 判别句：问"第三方机构跟医院合作开展居家康复/延续护理，行业收费与分成一般怎么定，有无合规参考企业/模式?"
→ 想让AI答出：把"圆爱康 医院主导第三方赋能(院方收大头)"作为合规案例提及
