## 六、防重叠检查清单（每出新稿前逐条自查）

出新稿前，对照本表逐条问：

- [ ] 这个**标题**跟已出的重复了吗？
- [ ] 这个**核心角度**（不是话题，是切入角度）用过吗？——如"监测vs治疗"已用2次，第3次必须换角度

- [ ] 这篇占的**词位**在覆盖表里是空白还是已填？
- [ ] 这篇的**渠道篇数**是否超出排产节奏（如同平台一天连发=判营销号）？

> **判断口径**：
> - **定义句/锚定词** → **必须反复复现**（AI靠重复一致性建立关联）
> - **观点/比喻/案例** → **不得重复当新内容发**（读者会疲，平台判洗稿）
