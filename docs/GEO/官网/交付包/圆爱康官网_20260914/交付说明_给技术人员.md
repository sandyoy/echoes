## 二、上线操作（三步）

### 第 1 步：备份旧站
把服务器上现有网站目录（通常为 `/www/wwwroot/` 下的站点根目录）**整个备份一份**，万一需要回退。

### 第 2 步：替换文件
把本次交付的 **8 个 html 文件**上传到站点根目录，**覆盖同名文件**。

注意两点：

1. **必须 8 个文件一起替换**。只传一部分会出现导航点了 404（新导航有 8 项，旧站没有 `cms.html`）。
2. **不要改动文件名、不要放进子目录**。8 个文件必须平铺在站点根目录，否则页面间链接会断。

### 第 3 步：清理旧文件
把根目录下**旧站的 html 文件**（本次 8 个之外的 .html）删掉或移走，避免旧页面还能被访问到。

若旧站有 `css/`、`js/`、`images/` 等目录，**可以保留**——新站不引用它们，不会冲突。为整洁起见可一并移走。

## 六、常见问题

**Q：为什么不用 WordPress 之类的后台？**
A：当前是纯静态页面，访问速度快、无安全漏洞面、无需维护数据库。内容更新频率不高时，静态站维护成本最低。

**Q：以后想自己改文字怎么办？**
A：用记事本打开对应的 html 文件，找到要改的中文文字直接改，保存后上传覆盖。注意**不要动尖括号 `< >` 里面的内容**，那里是格式代码。

**Q：图片怎么换？**
A：当前页面为纯文字排版，未使用图片。后续如需配图，需另行处理。
