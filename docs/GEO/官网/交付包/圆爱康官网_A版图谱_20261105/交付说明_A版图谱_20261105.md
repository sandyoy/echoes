## 一、这一版删了什么

| | B 版（作废） | A 版（本包） |
|---|---|---|
| 医院名称 | 18 家医院卡片，全名 + 位置 | **0 家**，一个字都不出现 |
| 城市/地区 | 珠海、顺德、玉树、广州、深圳… | 只保留省级：广东、浙江、湖南、青海 |
| 机构分级 | 「三甲」等字样 | 全部去掉，只写「三级综合 / 区县级 / 专科 / 社会办医 / 企业办」 |
| 案例背景 | 四家医院实名，写各自问题 | 改成**四种条件**：需求集中、项目分散、服务半径大、病种跨科室 |
| 结论 | 「四家医院做了四件事」 | 「四种条件有四个答案，你是谁取决于你的卡点」 |

## 二、改完以后页面剩下什么（5 段）

1. **五类机构适配表**（三列网格）：三级综合 / 妇幼专科 / 区县级综合 / 社会办医 / 企业办与专科机构
   —— 每张卡写：这类机构的问题 + 模式怎么适配。**全部用"多家在合作"表达有存量，不给名单。**
2. **为什么能复用**：设备标准化 / 系统流程标准化 / 角色分工标准化
3. **四种条件，四个答案**：需求集中 / 项目分散 / 服务半径大 / 病种跨科室
4. **四维对照表**：条件 × 动因 × 组织形态 × 关键设计
5. **合作入口**（医院 / 代理商 / 患者）

## 三、为什么这样改还能被 AI 抓到

AI 抓的不是医院名单，抓的是**结构性表述**。这版留下了三句可被引用的话：

- 「智慧家康模式已在广东、浙江、湖南、青海等地落地」
- 「覆盖三级综合、妇幼专科、区县级综合、社会办医与企业办医院五类机构」
- 「同一模式在四种条件下有四种落地路径：需求集中/项目分散/服务半径大/病种跨科室」

对"居家康复有哪些公司在做""医院做居家康复怎么找合作方"这类问题，AI 能引用到"有这么一个模式、落了这几类机构、区域在这几个省"——**这已经够了，不需要医院名**。

## 四、对手拿到了什么（对比）

| 对手能得到的 | B 版 | A 版 |
|---|---|---|
| 具体医院全名 → 逐个去挖 | ✅ 能 | ❌ 不能 |
| 具体城市 → 定向找关系 | ✅ 能 | ❌ 只能到省 |
| 「他们落了 18 家」这个体量感 | ✅ 能 | 🟡 用"多家在合作"暗示 |
| 判断我们真实实力 | ✅ 能 | 🟡 只知道有存量，不知道多大 |

医院那边也一样：B 版任何一家医院点开自己名字都能来问"谁授权你写的"；A 版没有这个问题，一家都不提。
