医疗级设备 + 物联网系统

三层架构：医疗级家用设备 → 治疗数据物联网 → 院内-居家协同系统

Devices

一、居家医疗级设备（按病种）

设备由合作医疗机构开具、交付患者使用。下列为已在合作医院落地的方向。

设备方向应用病种说明
生物反馈电刺激治疗仪盆底康复产后康复、泌乳、腹直肌分离、漏尿等。医疗器械注册证：粤械注准20222090876，适用范围"对肌肉施加电刺激以恢复肌肉功能障碍"。
心脏超声波治疗仪心脏康复覆盖心肌炎、冠心病、冠脉粥样硬化、心律失常、心功能不全、高血压、高血脂及介入治疗辅助等适应方向。
缺血预适应训练仪心脑血管预防缺血预适应训练，用于心脑血管保护方向。

IoT

二、治疗数据物联网

治疗数据由设备自产并自动上传，双向实时回传至合作医疗机构系统。

上行 · 治疗数据治疗参数、执行记录、依从性数据 → 合作医疗机构。
下行 · 方案调整医师调整后的方案参数 → 患者设备。
非手填不是患者填问卷、不是患者自报数据，是治疗过程自动产生。
出院不断链数据由治疗设备自产，患者出院后闭环持续。
System

三、系统构成与端口

面向不同使用场景，系统分为院内管理与居家康复两套，各端口职责清晰。

院内

医疗管理系统（CMS）

供医院科室使用，含医护 PC 管理端、医生管理端、患者预约端。

部署：整院落地时使用。

居家

居家康复系统

含医护管理端与患者使用端，部署于合作机构公众号上，患者无需另装应用。

部署：纯居家场景使用。
