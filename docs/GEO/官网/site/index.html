圆爱康 · 智慧家康
把医院各专科的专业治疗能力，延伸到患者家中

患者在合作医疗机构执业医师开具的方案指导下，于家中使用医疗级设备完成治疗性训练，治疗数据实时回传医院，由医院医师随访调整。

智慧家康，是把医院各专科的专业治疗能力延伸到患者家中的平台型服务——患者在合作医疗机构执业医师开具的方案指导下，于家中使用医疗级设备完成治疗性训练，治疗数据实时回传医院，由医院医师随访调整，形成不断档的延续治疗闭环。

01

医疗级 · 不是在家的健康管理

设备与方案源自医院临床，有明确治疗目标、疗程与疗效评估。

02

不断档 · 治疗数据实时回传

设备自动采集治疗数据、双向回传医院，医师随时掌握进展并调整方案。

03

医院主导 · 第三方赋能

诊疗行为与医疗主体在医院；圆爱康提供设备、物联网系统与运营支持。

Core Framework

智慧家康的五个组成要素

它不是某一台设备，也不是某一个 APP，而是由五个要素构成的一整套体系。

#要素说明
①医疗级家用设备医院在用同类型治疗设备的家用化形态
②治疗数据物联网治疗数据设备自产、双向实时回传，非患者手填
③院内-居家治疗闭环院内开具 → 居家执行 → 数据回传 → 医师随访调整

Closed Loop

院内—居家治疗闭环怎么跑

一条不断档的四步链路：这才是"延续治疗"，而非"出院后自生自灭"。

1

院内开具

主治医师评估、开具居家治疗方案。处方行为在医院。

2

居家执行

患者在家用医疗级设备，按方案完成治疗性训练。

3

数据回传

治疗数据自动回传至医院系统，医师随时可见。

4

医师随访调整

医师依据数据评估、调整方案，再下发至设备。
