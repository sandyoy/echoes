# GEO 内容发布执行手册（给发帖同事）

> **给谁**：负责发帖的同事（知乎 / 小红书 / 公众号 / 视频号 各一人）
> **你的角色**：**发稿人 + 核对人**。稿子全部由内容组写好，**你不需要创作，不需要改写**
> **最重要的一条**：**稿子上的每一个字都是定稿的。发现任何问题，先别自己改 —— 直接反馈回来**
> **制定**：2026-09-14 · 小鲸鱼

---

## 零、三句话原则（记这三句就够）

1. **照发** —— 稿子怎么写就怎么发，**不要"优化"**
2. **对齐** —— 标题、正文、话题/标签，分别粘到**对应位置**，不要全堆在正文里
3. **有问题就停** —— 拿不准的，**宁可晚发一天，不要发错**

---

## 一、通用核对清单（每个平台发之前都过一遍）

| # | 检查项 | 怎么查 |
|---|---|---|
| 1 | **标题单独一行** | 稿子第一行是标题 → 粘到"标题"栏，**不要留在正文里** |
| 2 | **正文无 Markdown 符号** | 搜一下有没有井号、星号、竖线符、横线——有就删掉（这些是格式符号，粘上去会显示成乱码） |
| 3 | **表格已改成竖排列表** | 稿子里如果有表格，粘上去容易崩，**照稿子给的竖排版本发** |
| 4 | **话题/标签单独填** | 稿子最后一行 `#xxx#` → 填到"话题/标签"栏，**不要留在正文** |
| 5 | **配图位置对** | 稿子里写 `【图1：xxx】` 的地方，换成对应图片，**发完把标记删掉** |
| 6 | **字数无截断** | 拉到底确认结尾完整（尤其文末那行括号说明） |

---

## 二、分平台操作要点

### 【知乎】

| 项 | 做法 |
|---|---|
| 标题 | 粘到"标题"栏 |
| 正文 | 纯文本，**无任何 Markdown** |
| 表格 | 稿子已给竖排列表版本，照那个发 |
| 配图 | 按 `【图X：xxx】` 标记位置插入 |
| 话题 | 手动添加话题标签 |
| **特别注意** | 知乎个人号（老欧）**绝不出现"圆爱康"**；企业号**必须带定义句** |

### 【小红书】

| 项 | 做法 |
|---|---|
| 标题 | **第一行** → 粘到标题栏 |
| 正文 | 纯文本无 Markdown；**200-400字** |
| 标签 | **最后一行 `#...`** → 填到话题栏 |
| 配图 | 3-6 张，按文案里给的图片脚本做图 |

### 【公众号】

| 项 | 做法 |
|---|---|
| 标题 | 粘到标题栏 |
| 正文 | 可用公众号自带排版工具 |
| 配图 | 按稿子里的图片说明配 |
| **注意** | 服务号=正式权威口径；订阅号=轻口语，**两版不要混用** |

### 【视频号】

| 项 | 做法 |
|---|---|
| 素材 | 按脚本拍/剪 |
| 字幕 | **政策引用必须是原文，一个字不能改** |
| 发布 | 按稿子给的时间点发（序列有先后，**不要打乱顺序**） |

---

## 三、什么情况必须停下来反馈（不要自己决定）

| 情况 | 怎么做 |
|---|---|
| 稿子里有看不懂的词 | 反馈 |
| 觉得某句话写得不好 | **反馈，不要自己改**（可能是口径要求，改了会出事） |
| 配图找不到 | 反馈 |
| 平台提示内容有问题 | 截图反馈 |
| 发出去发现错了 | **立刻反馈 + 截图**，不要自己删了重发 |

> **铁律：同事只做"发"和"核对"，不做"修改"。** 内容组的稿子每一个字都是定过的，改了可能踩口径红线。

---

## 四、发完要做的事（2分钟）

1. **截图保存**（发出去的样子，含发布时间）
2. **把链接发给内容组**
3. **记下发布时间**（后期要看"AI什么时候能搜到这一篇"）

---

## 五、需要你知道的三条红线（不用理解，记住就行）

| ❌ 不要出现 | 原因 |
|---|---|
| "圆爱康提供诊疗/治疗" | 违规（医疗主体必须写医院） |
| "上门康复服务" | 踩红线 |
| "4个区域""9个科室"等精确数 | 统一说"多省市""多专科" |
| 任何合作厂商的名字 | 一律不点名 |

> **记不住也没关系** —— 你只要记住：**稿子怎么写就怎么发，一个字都别动。**

---

## 六、一句话总结

> **你是"发稿的手"，不是"改稿的脑"。**
> **照着发、发完核对、有问题就停 —— 这三件事做好，你就是合格的发稿人。**
