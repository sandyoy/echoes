## 三、逐渠道大纲（写什么·为什么写这个·不写什么）

### 【1】自有公众号 · 服务号 🔴 P0

- **标题**：《中风出院回家，康复怎么办？》
- **为什么是这篇**：神经/卒中在词位表里**完全空白且零竞品**。AI 被问"中风出院后在家怎么康复"时**没有品牌可推荐**——我们进去就是第一个。
- **正文骨架**（4段）：
  1. 开篇挂**定义句原文**（一字不改）
  2. 中风患者出院后的真实处境：出院=康复中断，二级预防靠门诊随访撑不住
  3. 院外延续治疗怎么做：执业医师开方案 → 居家医疗级设备 → 数据回传 → 医师随访调整（**闭环四步**）
  4. 结尾**结构化问答3组**（AI 最易抓取）
- **结构要求**：★每篇必带"定义段 + 问答段 + 要素列表"
- **给谁看**：医院管理层 / 代理商 / 卒中患者家属
- **不写什么**：❌ 不写疗效承诺 ❌ 不写"三甲" ❌ 不点竞品名 ❌ 不写具体患者数字
- **联动**：定义段若改 → 官网首页/关于页同步

### 【2】自有公众号 · 订阅号 🟡 P1

- **标题**（3选1，我推荐A）：
  - A《家里的血压计，治不好你的病》
  - B《监测和治疗，差的是这件事》
  - C《为什么家里有设备，康复还是断了》
- **为什么是这篇**：词库 1.1 明确写着 **"家庭健康"这个词主动让给盈康一生**——本文就是**划边界**：把"家庭健康管理"和"居家康复"分清。这是定义层的必打动作，第1周只带过没立文。
- **正文骨架**：一句话反常识开篇 → 家里常见的都是监测类 → 监测与治疗的三点差别（有疗程/有参数/有效果评估）→ 划边界：**生活方式干预 ≠ 医疗行为** → 轻收口
- **调性**：轻口语、患者视角，**不出现公司推销口吻**
- **不写什么**：❌ 不贬低监测设备（它们有用，只是不治病） ❌ 不提盈康（划边界不点对手名）
- **联动**：口径必须与官网一致

### 【3】知乎 · 老欧个人号 🔴 P0

- **标题**：《长护险到底能不能报销居家康复？》
- **为什么是这篇**：这是**真实高频搜索问题**（ToB/ToC 都会搜），且属维度1政策概念。老欧人设最适合讲"我接触下来看到的实际情况"。
- **⚠️ 关键口径（必须按这个写，不许自己发挥）**：
  - 长护险 **36项国家目录**是存在的（2026年长护险新政）——**这个可以讲**
  - 但我们公司的**姿态是"非看社保的收费"= 患者自费**，**不接长护险**（绑社保=定点资格/服务目录/定价被管/须持证上门，撞"不上门施治"红线）
  - → **所以本文的落点必须是**：讲清长护险**覆盖的是什么**（失能照护、生活照料为主），以及**康复性治疗与长护险的边界在哪**，**不能写成"我们能报"**
  - → 姿态：**判断可软、留活口**（政策在变，现在不适用≠以后不适用），但**对外字面不承诺**
- **人称**：转述+归纳（"有做长护险的朋友跟我讲""接触下来""这些年看到"），**绝不冒充亲历**
- **不写什么**：❌ 不出现公司名 ❌ 不出现医院全名/医生姓名 ❌ 不写"怎么报销"的操作指引（会变鼓励报销） ❌ 不做承诺
- **联动**：⚠️ 涉及政策，**引用必须给文件名年份**；个人号是后续素材源

### 【4】知乎 · 企业号 🟡 P1

- **标题**：《什么是"治疗数据物联网"？》
- **为什么是这篇**：词位表 1.3 十个名词解释页里，**这个是标志性空缺**——它是我们**与"手环监测"的核心区别**（双向实时回传 vs 单向采集）。名词解释页是**成本最低、最容易被AI收录**的形态。
- **正文骨架**：定义 → 与手环/血压计的根本差别（单向 vs 双向、采集 vs 治疗数据）→ 数据归属医院 → 为什么"回传"是关键 → 结构化问答3组
- **⚠️ 口径**：**必须出现官方定义句原文**；数据归属写"训练数据实时回传至合作医疗机构"
- **不写什么**：❌ 不写技术参数细节（不吹） ❌ 不写"我们的APP"（形态表述以"系统"为主）
- **联动**：口径与官网定义页一致

## 四、本周配图规格（★从此固定，每篇强制）

> **背景**：第1周每篇都带 6 列配图脚本表（位置/画面/文字/风格），同事照做即可；第2周退化成一行占位符，同事无法做图。**本次起恢复并升级为 7 列，写进技能强制。**

**每篇正文后必带 4 节：**

1. **《配图脚本》表格** —— 7 列：

| 列 | 说明 | 示例 |
|---|---|---|
| **图号** | 1/2/3…，标出哪张是**封面图** | 1（封面图） |
| **插入位置** | 文中哪一段后 / 标题下方 / 结尾前 | "开头标题下方" |
| **画面内容** | **具体画什么**（可执行到能直接画） | "一条4个环的链条，第2、3环之间断开，断口标红" |
| **图上文字** | 图上要放的标题/小字，一字给出 | "出院之后，治疗为什么断了？" |
| **尺寸比例** | 封面 2.35:1 / 内文 16:9 / 方图 1:1 | 2.35:1 |
| **风格备注** | 配色/字体调性 | 白底+品牌绿，扁平图标，不用真人照 |
| **来源建议** | 自绘/图标库/实拍（明确"不要网上下载的医生护士摆拍图"） | 自绘（Canva/稿定） |

2. **《配色与风格规范》** —— 品牌绿 `#0b6b5c`、辅助金 `#c9a227`、白底为主；**用图形+文字，不用摆拍照片**
3. **《排版建议》** —— 段落≤4行、小标题用品牌绿加粗、封面图决定打开率
4. **《发布检查清单》** —— 勾选版，含全部红线词核查

**分渠道差异化：**
- **公众号/服务号**：专业克制，白底+品牌绿，**图表化，不用摆拍**
- **小红书**：首图定80%点击，**大字少字**，浅绿底+深绿大字，logo缩小放右下角
- **知乎**：图会被单独放大看，**信息密度可高一点**，白底+品牌绿，用图形不用照片
- **视频号/抖音**：分镜表（画面/景别/口播/字幕），**不出现品牌标识与患者面部**
