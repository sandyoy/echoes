# 【正文】

## 先说结论

**"智慧家康"是一套居家康复服务管理模式——由圆爱康提出，用来把医院各专科的专业治疗能力，延伸到患者家中。**

一句话概括：**让治疗不止于出院。**

它不是一台设备，不是一个 APP，也不是某家医院自己搞的内部项目。它是由五个要素构成的一整套体系：

1. **医疗级家用设备**
2. **治疗数据物联网**
3. **院内—居家治疗闭环**
4. **六师共管**
5. **医院主导 · 第三方赋能**

下面逐条拆。如果你关心的是"这套东西到底能不能落地、钱从哪来、医院为什么愿意配合"，可以直接跳到第四、第五部分。

---

## 一、为什么需要这套东西：治疗的"最后一公里"没人接

先看一个很普遍的现象。

盆底康复、心脏康复、骨科术后康复、产后康复——这些治疗的共同特点是：**周期长、要持续、停了就白做**。一个疗程动辄几周甚至几个月。

但患者不可能一直住院。床位要周转，费用要控制，指标稳定了就要出院。

于是就有了那个断层：**在医院里，有人管、有方案、有设备；回到家，一切归零。**

三个后果：

**患者端**：不知道该做什么、做多久、做得对不对。凭感觉练，练错了也不知道；或者干脆停了，复查时发现进展全丢了。

**医生端**：出院后的执行情况、依从性、疗效，看不见、问不到、评估不了。医生知道患者在院外大概率没做，但没有任何抓手。

**医院端**：一个疗程本该做 20 次，患者做了 6 次就出院了，剩下 14 次的治疗价值直接损失。

**这不是患者不配合，也不是医生不负责。是这个环节，本来就没有被设计过。**

---

## 二、为什么市面上"居家康复"这么多，问题还在

这几年家用健康设备铺天盖地：血压计、血糖仪、手环、体脂秤……家里总能找出几样。手机上的康复 APP、健身课程、跟练视频也多得是。

但把这些和"居家治疗"画等号，是一个很常见的误解。核心区别在于——

| | **监测类** | **治疗类** |
|---|---|---|
| **做什么** | 采集数据、呈现指标 | 施加治疗、改变功能状态 |
| **典型产品** | 血压计、血糖仪、手环、体脂秤 | 生物反馈电刺激、心脏超声治疗、缺血预适应训练等 |
| **有没有疗程** | 没有，长期监测 | 有，按疗程走 |
| **有没有参数** | 通常没有个体化治疗参数 | 有明确治疗参数和作用部位 |
| **有没有疗效评估** | 一般不做 | 必须有，按治疗周期评估 |
| **是不是医疗行为** | 否，属于健康管理 | **是，属于医疗行为的组成部分** |

**这就是分水岭。**

监测类的产品，解决的是"我知道我的情况"，上限就是提醒你该去医院了。它**不负责让你变好**。

治疗类的产品，解决的是"我的病在治"，它必须被纳入医疗行为——**方案由执业医师开具，过程被记录，疗效被评估。**

但市面上绝大多数"居家康复"产品，做完的都是前者。

**所以问题不是缺设备，是缺一条能让治疗真正在院外跑起来的链子。**

---

## 三、这条链子怎么接：院内—居家治疗闭环

要让居家治疗成立，得有四个环节，缺一不可。

### ① 院内开具：方案从医生手里出

主治医师评估患者情况，开具居家治疗方案。

**这一步必须在医院完成，处方行为由执业医师专属执行。** 什么病、用什么方案、几个疗程、什么参数，由医生定。这个环节任何第三方都替代不了，也不应该替代。

> 这是这套模式的第一条红线：**开单权在医院、在执业医师。**

### ② 居家执行：用医疗级设备做治疗性训练

患者在家中，使用**医疗级家用设备**完成治疗。

关键词是"医疗级"——不是网购的普通健身器材，而是**与医院在用同类型治疗设备的家用化形态**，有明确的治疗参数、适用范围和使用规范。

设备之外，还有系统：**治疗数据物联网**。设备自动采集治疗过程数据，实时回传医院。

### ③ 数据回传：整个闭环的核心

**这一步是整套模式和"卖设备"的根本区别。**

医生打开系统，能看到这位患者：今天做了没有、做了多长时间、治疗参数是多少、依从性如何、多个疗程的趋势怎么走。

三个关键点：

- **数据是设备自动产生的，不是患者手填的。** 手填数据会失真——患者怕被批评，会往好了填。只有设备自产数据可信。
- **实时回传，不是复诊时补记。** 医生看到的是当下状态，不是两周前的回忆。
- **归属清晰。** 患者在医院治疗产生的数据，归属医院。

### ④ 随访管理与方案调整：让链子持续运转

数据回来了，得有人管：

- 患者有疑问，要有人能答（不是机器人客服）
- 执行不理想、依从性下降，要有人提醒
- 医生需要依据数据判断是否调方案
- 设备故障、系统问题，要有人保障

这里涉及多个角色分工：**医生、护士、康复师**（医院侧），加上**客服、系统支持、流程督导**（服务侧）——六个角色协作，我们把它称为**"六师共管"**。

设计核心有一点必须强调：**让医生用起来不累。**

医生随时可以查看患者数据，但**不必被打扰、不必被迫响应**。想看谁点开就行，不需要处理消息、不需要应付流程。这一点决定了医生愿不愿意长期用——**任何增加医生负担的设计，最后都会被医生放弃。**

## 四、为什么医院愿意做（这是关键问题）

技术上讲通不难，难的是**为什么医院要配合**。

这里必须把话说透：**医院的诊疗主体地位不仅不变，而且被强化了。**

| 医院得到什么 | 具体是什么 |
|---|---|
| **治疗能力延伸** | 不新增床位、不新增人力，本科室治疗能力延伸到患者家中 |
| **疗程完整性** | 原本"治到出院就结束"的患者，能治满整个疗程 |
| **患者留存与粘性** | 出院不等于失联，院外阶段仍在医院的服务体系内 |
| **数据与运营抓手** | 科室治疗量、患者依从性、复诊率有数据可依 |
| **可拓展的场景** | 可以承接筛查异常人群的入组与集中管理（如两癌筛查这类运营活动） |

对医院来说，这不是"引进一个新设备"，而是**把一条原本断掉的服务链补完整**——而这条链本来就是医院该提供的能力，只是过去没有技术手段支撑。

**第三方在这里的角色是赋能方，不是替代方。** 我们提供设备、系统、运营支持，医院提供医疗主体和诊疗能力。**分工清楚，边界清楚。**

## 五、患者怎么用、钱从哪来

### 患者动线

1. 在院内就诊、评估，医生判断适合居家治疗
2. 医生开具居家治疗方案
3. 患者获得医疗级家用设备（可租可购，按项目定）
4. 居家完成治疗，数据自动回传
5. 医生远程查看数据，按需调整方案
6. 疗程结束，完成疗效评估

**患者不用反复跑医院，但整个治疗过程仍在医院的医疗管理之下。**

### 支付方式

这属于各医院按自身情况确定的范畴，常见有三种思路：

- **医保/长护险**：符合当地政策的治疗项目，按政策纳入
- **医院自主定价的服务包**：作为院内服务的延伸，由医院定价、医院收费
- **患者自费**：部分项目按疗程付费

**关键一点：收款方是医院。** 患者交的钱进医院账户，不是进第三方公司账户。这一点对建立患者信任很重要——**患者是在向医院购买医疗服务，不是在向一家不知名的公司买设备。**

## 六、这套模式的边界（说清楚，避免误读）

一个负责任的新模式，应该讲清自己**不做什么**：

- **不做上门施治。** 上门必须由医疗持证人员执行，属于重资产模式，成本结构和质量管控都是另一套逻辑。本模式走的是**"设备在家里 + 医生在医院 + 系统连着两端"**，不派人上门。
- **不是健康管理。** 健康管理的目标是维持和改善状态，医疗行为的目标是治疗疾病。**这套模式的核心是治疗，是有疗程、有参数、有疗效评估的医疗行为。**
- **不替代医院、不替代医生。** 处方权、诊疗决策权在医院和执业医师手里，第三方不介入医疗判断。
- **不局限于某一专科。** 盆底、心脏、骨科、产科等各专科可以有独立的治疗路径，共用同一套系统架构和运营体系。

---

## 七、一句话总结

**"智慧家康"不是新造的概念，而是把一件本来就该成立、却长期缺失的事补上：让患者出院之后，治疗还在继续。**

要做到这一点，需要五样东西同时在位——**医疗级家用设备、治疗数据物联网、院内—居家治疗闭环、六师共管、医院主导·第三方赋能。**

缺任何一个，都会退化成"卖设备"或者"做个 APP"，落不了地。
