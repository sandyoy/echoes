## 一、稿子里哪些东西不能复制进去

你手上那份"成稿第1篇"里有这些东西，**都不能进小红书 App**：

| 内容 | 为什么不能发 |
|---|---|
| 标题备选 A1/A2/A3/A4 | 那是给你挑的，挑 1 个用 |
| 「# 【正文】」「## 出院，不应该是治疗的终点」 | 那是 Markdown 格式，小红书不认 `#`，会原样显示成乱码感 |
| 表格（监测类 vs 治疗类对比表） | **小红书正文不支持表格**。只能改成纯文字，或做成图片 |
| 建议、导演提示、发布检查清单 | 内部用的 |
| `**加粗**` 星号 | 小红书不认 Markdown 加粗，星号会原样显示 |

**所以：直接用我新做的那份"可直接复制粘贴版"，里面全是纯文本，没有 Markdown 符号。**

## 二、10 分钟发布流程

### 第 1 步：选标题（30 秒）

从 4 个备选里挑 1 个，或者自己改顺口：

- **推荐**：出院之后治疗就断了？这个断层正在被补上
- 备选：为什么盆底康复总有人做一半就停了
- 备选：居家康复的坑：你在家做的可能根本不是"治疗"

> 小红书标题**最多 20 字**，超出会被截断显示成"..."。上面这几个都在范围内。

### 第 2 步：复制正文（1 分钟）

打开《可直接复制粘贴版》→ **全选 → 复制 → 粘进小红书正文框**。

⭐ **重点**：小红书**不认换行格式**，粘贴后要手动检查一遍——
- 每段之间**空一行**（我稿子里已经空好了，但粘贴有时会丢）
- **关键句单独成行**（比如"这不是你不自律。是这个环节，本来就没有被设计过。"要独立一段）

### 第 3 步：做图（5 分钟 · 最花时间的一步）

小红书是**图片平台**，正文其实没多少人细看，**图决定一切**。

我稿子里给了 6 张图的脚本。分两种情况：

**情况 A：你自己做图（推荐，快）**
用**稿定设计 / 创客贴 / Canva**，搜"小红书 科普 图文模板"，挑一套白底绿字的模板，把文字填进去。6 张大约 20 分钟。

**情况 B：交设计师**
把 6 张图脚本给他，说"白底+深绿#0b6b5c+金色点缀大字少字"。

> **首图最重要**——决定 80% 点击。首图文字：
> **出院之后 / 治疗就断了？**（分两行大字）
> 下面小字：*这个断层正在被补上*

### 第 4 步：填话题标签（30 秒）

正文末尾我写了 7 个标签，**直接复制**：

```
#居家康复 #出院后康复 #盆底康复 #产后康复 #康复训练 #智慧家康 #健康科普
```

> 说明：前 5 个是**有真实流量的宽词**（负责被搜到），后 2 个是我们**要占的词**（负责种草）。
> 小红书标签**最多 10 个**，7 个正合适。

### 第 5 步：检查 4 件事（1 分钟）

- [ ] 标题没超 20 字
- [ ] 正文里**没有** `#` `*` `|` 这些符号（Markdown 残留）
- [ ] 图有没有露真实患者信息/病历（本篇是通用科普，没有，放心）
- [ ] **没有**留联系方式、没说"私信我"

## 三、关于"排版"这个问题的直接回答

你问"要不要重新排版"——**要，但不是重写，是换一层皮**：

| | 我给你的工作稿 | 小红书要的样子 |
|---|---|---|
| 格式 | Markdown（有 #、表格、加粗） | 纯文本 + 空行分段 |
| 表格 | 用表格讲"监测 vs 治疗" | **改成纯文字讲**（已改好） |
| 重点 | `**加粗**` | 单独成行 / 加 emoji |
| 视觉 | 文字为主 | **图为主**，正文是配角 |

**所以我做了两份**：
1. **工作稿**（有成稿第1篇）→ 内部留档、给设计师看配图脚本
2. **可粘贴版**（新做的）→ **你直接复制去发**

## 四、还有一件事：小红书能不能不放公司名

**这是个真问题，你要拍板。**

我在稿子里**没有**硬塞"圆爱康"三个字到正文——只在"智慧家康"出现时带了"圆爱康提出的"。原因：

- 小红书用户对"公司宣传"很敏感，硬塞品牌名会掉互动
- **但我们的目标是占词**，品牌名又必须出现

**我的建议**：保持现在这样——**正文出现 1 次"圆爱康"（在定义"智慧家康"那句里），其余靠账号名和 logo 水印承担品牌露出**。

这样既不像硬广，又把"智慧家康 = 圆爱康提出"这个关联钉死了。

如果你觉得不够，我可以加到 2–3 次，但互动可能掉一点。你说。
