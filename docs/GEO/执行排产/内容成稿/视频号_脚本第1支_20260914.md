# 【拍摄与制作要求】

## 画面风格

- **调性**：克制、专业、干净。**不要煽情、不要患者哭诉、不要"感谢信"式表达**。
- **场景**：
  - 医院场景 → 建议**借用合作医院的真实环境**（哪怕只拍走廊、诊室、护士站），比摆拍影棚可信十倍
  - 家庭场景 → 明亮、整洁、有生活感的客厅，**不要医院化的白墙**
  - 系统界面 → **必须脱敏**：真实患者姓名、病历号、诊断信息一律打码或替换成演示数据
- **色调**：品牌绿 #0b6b5c 为主，金色 #d9b13b 点缀关键数字/文字。**不要用蓝白科技风**（和一堆 SaaS 撞脸）。

## 音乐

- 前 18 秒：克制、微沉的弦乐或钢琴单音（营造"断层"感）
- 18 秒后：逐渐加入温暖的层次（**不要激昂、不要励志 BGM**，那会瞬间拉低专业感）
- 结尾：干净收束，留 0.5 秒静音再结束

## 配音

- **男声或女声均可，中低音、语速偏慢、不念稿感**
- 关键词必须**停顿**：`不新增床位` `不增加人力` `数据归属医院` `让治疗不止于出院`

## 字幕

- **全程字幕**（视频号大量静音观看）
- 字幕字号要大，**手机上占屏宽 80% 以上**
- 关键数字（20次/6次/14次）用**金色**突出

## ⚠️ 合规红线（本片特别注意事项）

视频号对医疗内容审核严格，**以下必须做到**：

- [ ] 全片**无**疗效承诺（不出现"治愈""康复效果好""有效改善"）
- [ ] 全片**无**真实患者姓名/病历号/面部（如用患者形象，必须有**书面肖像授权**；建议**不出现正面**）

- [ ] 全片**无**"三甲"字样（统一"医院""各级医院"）

- [ ] 圆爱康身份**始终表述为**辅助方/赋能方；**不出现**"我们治疗患者"类表述
- [ ] 医院名称使用需**事先取得医院书面同意**（建议先不放具体医院名，或取得同意后放）
