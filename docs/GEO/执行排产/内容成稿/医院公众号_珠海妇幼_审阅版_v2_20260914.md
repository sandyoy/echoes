盆底康复，不一定天天跑医院
——我院盆底康复科的居家治疗服务

很多做完盆底功能评估、拿到治疗方案的女性，都会问我们同一个问题：

"这个疗程要做这么久，我是不是得天天往医院跑？"

答案是：不一定。在我们科室，您可以选择来院治疗，也可以选择在家里完成一部分治疗。

今天就把这件事，跟大家讲清楚。

一、我们在做的这件事

盆底康复，通常需要一个完整的疗程，不是做一两次就能结束的。治疗的效果，很大程度上取决于一件事——疗程能不能坚持做完。

我们在临床中看到，不少患者不是治不好，而是中途断了：有的要上班，有的要带孩子，有的住得远，来回一趟就是半天。做着做着，就停了。

所以这几年，我们科室一直在做一件事：把一部分治疗放回患者家里完成。

具体是这样做的：患者在我院完成盆底功能评估、明确诊断后，由医师开具治疗单。如果患者愿意，可以在家里使用医疗级治疗设备，按照医师设定的方案完成治疗性训练。训练的数据可以回传，医师能了解到患者在家的完成情况，按疗程进行随访和方案调整。

也就是说，治疗还在继续，只是场景从医院换到了家里。

二、为什么不少患者愿意选择居家

接触下来，患者选择居家治疗，考虑的大多是这几件事：

1. 时间上更灵活。不用为了做一次治疗请半天假、排半天队，下班在家就可以完成。

2. 更容易坚持。疗程中断，往往不是因为不想治，而是因为"今天实在去不了"。在家做，把这件事的门槛降下来了。

3. 隐私上更自在。盆底康复涉及比较私密的部位和感受，有些患者在家里做会更放松。

4. 家里人也更方便照顾。尤其是产后不久的妈妈，孩子在身边，出门一趟不容易。

当然，也不是所有人都适合居家。具体选哪种方式，我们会根据患者的评估结果、病情情况和个人条件，一起商量着定。

三、我们能帮您做什么

如果您或家人有盆底康复方面的需求，可以到我院盆底康复科就诊。

我们会做三件事：

1. 先评估。由医师进行盆底功能评估，明确是不是需要治疗、需要怎么治。

2. 再定方案。评估之后，医师会给出治疗方案，并和您说明来院治疗和居家治疗各自的情况。

3. 全程跟进。无论您选择哪种方式，科室都会按疗程进行随访和恢复情况评估，医师根据情况调整方案。

治疗的方式，您自己选；治疗的过程，我们跟着。
