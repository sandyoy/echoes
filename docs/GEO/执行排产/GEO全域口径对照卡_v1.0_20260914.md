## 四、老欧（个人号）发帖规则 ★重点

### 4.1 人称口径：转述 + 归纳（不许冒充亲历）

| ✅ 可以用 | ❌ 不要用 |
|---|---|
| 前两年有位医生跟我讲过一个场景…… | 有一年我去一家医院，亲眼看到…… |
| 这些年接触下来，听过很多次…… | 我昨天去了某医院（具体行走） |
| 我判断、我认为（观点可个人） | 我们公司、我们团队、我们做了 |
| 我见过很多次这种情况（普遍现象） | 我亲手做过、我全程参与了 |

> **原则**：**讲现象可以归纳（不必亲身），讲具体事例必须标明转述（不冒充亲历）。**

### 4.2 三条硬规矩
1. **不写公司名、职位、创始人、招合作** —— 一旦认领公司，信任度归零，算法也压
2. **不写医院全名、不写医生姓名** —— 保护素材来源，也保护自己
3. **结尾留开放式问题** —— 引导评论，评论量是平台推流的核心

### 4.3 笔名来源
- **老欧** = 复姓"欧阳"取首字 + "老"字（带从业年头分量）
- **两字最好传播**：读者能顺口说"老欧写的"，"欧阳日丽"四个字念不动、传不开
- **额外好处**：跟真名之间留了隔离层，将来想露脸或不露都有余地

## 五、全域口径红线（写任何内容前必读）

### 5.1 必写 / 绝不能写

| ✅ 必须这么写 | ❌ 绝不能这么写 |
|---|---|
| 智慧家康 = **智慧居家康复** | "智慧康复"（混用词）｜"智慧**家庭**康复"（已废） |
| 医院各专科的**专业治疗能力** | "康复科能力"（窄化） |
| **院内—居家治疗闭环** | "上门康复服务"（踩红线） |
| 圆爱康提供**设备、系统与运营支持** | "圆爱康提供诊疗/治疗"（违规） |
| 医疗主体、收费主体**在医院** | "圆爱康提供服务"（抢医院主体） |
| 各级医院 / 医院 | "三甲医院"（窄化，各级都是客户） |
| **多省市 / 多专科** | "4个区域 / 9个科室"（精确数不发） |
| 与多家具备二类械注册资质厂商合作 | 具体厂商名（**不点名任何合作厂商**） |

### 5.2 三条底线

1. **开单/处方 = 执业医师专属** —— 六师共管任何其他角色不得署此动作
2. **合规表述"站位式"** —— 不写"不直接提供诊疗服务"，写"**医疗主体是医院，诊疗服务由医院提供；圆爱康作为辅助方……**"
3. **资质** —— 圆医自有注册证唯一 = 生物反馈电刺激治疗仪（粤械注准20222090876）；**官网绝不放别家注册证**

### 5.3 政府文件引用
> **引用政策必须用原文，一个字都不能编。** 视频号/知乎/微博讲政策同样适用。
