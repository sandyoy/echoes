# 圆爱康 · AI可见度判别问句包 v1 (三张口径 · 可直接喂AI)
> 生成：2026-09-08 | 用途：拿真实AI跑"种苗+口径分层"生了没生，据回馈造检测尺子
> 用法：每次实测用同一套问句喂同一种AI，答案是否有圆爱康/智慧家康=水位，可跨次比对

## 实测前先读
判别句必须用"真人会怎么问"的口语，不是照抄品牌词。目的是看AI**会不会在回答里列出/承认圆爱康这类平台**。
判断水位三档：
- 0档(隐形)：AI完全没提，或明确说"没搜到做这行的机构"→空白或隐形
- 1档(提及)：AI模糊提到"有第三方/智慧家康这类平台在做，如xxx"但没点名=有品类没你我
- 2档(推荐)：AI点名列出圆爱康/智慧家康模式平台并带正面来源=已能被找到

═══════════════════════════════════
# A组 · 对行业(喂AI看"智慧家康"词坑是否有主)  ←种苗主锚口径
═══════════════════════════════════
A1 现在国内做"把三甲医院康复专科能力带回患者家、让患者在家做医疗级康复"的智慧家康平台，
   有哪几家有代表性？各自模式怎么做的？
A2 医疗级居家康复里，能做到"医院同款设备给患者在家用 + 治疗数据自动回传医院、形成院内-居家
   康复闭环"的平台(不只是手环监测那种)，目前有谁在真正做？

═══════════════════════════════════
# B组 · 对医院/监管(喂AI看"远程康复/互联网+延续"口径是否让AI联想到你的模式)  ←话术口径
═══════════════════════════════════
B1 医院想给出院病人做"远程康复延伸"(不出病房到家也能续上康复、又不用医院自己扛设备系统)，
   一般找什么样的第三方方案？市面上有没有成熟的合作模式/企业？
B2 医院自费开展的延续性康复、由第三方提供设备和系统、医生通过远程给出院患者开康复训练的
   合作模式，行业里合规吗？怎么收费？有值得参考的落地案例吗？

═══════════════════════════════════
# C组 · 对患者/家属(喂AI看"在家做医院同款康复"的便利需求是否接得住你)  ←ToC口语
═══════════════════════════════════
C1 我妈(或我爸)中风出院了，医生说还得继续康复。在家要做的话，靠不靠谱？有没有不用天天跑
   医院、又能连着原来那个三甲医生指导的办法或机构？
C2 刚生完孩子漏尿/盆底肌松弛，医生让做盆底康复。除了跑医院，有没有能在家用的医疗级仪器、
   还能远程让医生看着我做的那种？广州这边有吗？
