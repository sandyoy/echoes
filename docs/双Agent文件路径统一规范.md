## 核心理念

- **wiki/** = 读的（知识库，永久存档，不太常改）
- **docs/** = 写的（我们产出的方案、分析、文案）
- **圆爱康业务**和**个人事情**（投资、教育、笔记）分开存放，互不干扰

## 根目录

`~/echoes/` — 唯一工作根目录。

所有协作文件、代码、知识库、方案文档，**全部**放这里。不允许在 `~/echoes/` 之外另建工作目录。

## 关键规则

| 规则 | 说明 |
|------|------|
| **唯一根目录** | `~/echoes/`，不允许其他地方 |
| **wiki 是读的** | 知识库，不经常改，放永久参考资料 |
| **docs 是写的** | 我们产出的方案、分析、文案，按编号分类 |
| **圆爱康 vs 个人** | 圆爱康放在 `01_圆爱康业务` 和 `wiki/medical/01_圆爱康产品资料/`，个人其他的放对应分类 |
| **代码全归 code/** | 小程序的、网站的、后端的，都放 `code/` 下对应子目录 |
| **Git同步** | 谁更新谁 `git push`，对方 `git pull` |
| **历史文件迁移** | 小龙虾把 `~/yuanekang/` 和 `~/HermesFiles/` 下的内容整理到上述目录后，旧目录可删除 |
