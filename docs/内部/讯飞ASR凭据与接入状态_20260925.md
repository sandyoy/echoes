## 三、⚠️ 2026-09-25 实测发现（重要）

**现象**：用上述凭据实跑讯飞语音听写（`wss://iat-api.xfyun.cn/v2/iat`），服务端返回：

```
HMAC signature cannot be verified: apikey not found
```

**判读**：
- ✅ **签名算法本身正确** —— 服务端认了签名格式（否则会先报格式错）
- ❌ **`XF_API_KEY` 在讯飞侧查不到** —— 属于"key 无效"而非"签名算错"

**可能原因（按概率排序）**：
1. 该 API Key **未在讯飞开放平台"语音听写"服务下开通/启用**
2. key 被复制时**遗漏或多带字符**（长度虽对，但值可能有误）
3. 用的是**别的应用**的 key（如 TTS 应用 vs ASR 应用——讯飞不同服务需在同一应用下开通）
4. key 已**失效/重置**
