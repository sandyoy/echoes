## 一、这条线要解决什么

**把内容变成患者，把患者送到合作医院。**

一句话定位：我们做内容 → 内容带来患者 → 患者走进合作医院 → 医院有患者量、我们有服务量。

对医院的杀伤力：**把第三方从"抢患者"变成"送患者"。** 这是面对医院最硬的一张牌。

## 四、地域护栏（核心机制）

**本质矛盾**：平台不让你公开说"去XX医院"（违规），但**不禁止你说"本地/同城"**。

**护栏下的做法**：
1. 内容里只说地域，不说医院名 —— "珠海的姐妹可以就近做评估"
2. 靠平台地域推荐机制自动推给同城（抖音同城 / 小红书本地流量池）
3. 患者自己搜"珠海 盆底康复" → 搜到内容 → 评论区/私信问"哪家"
4. 我们一对一给医院信息（私域承接，不公开）

**平台红线表**：

| 平台 | 禁 | 可 |
|---|---|---|
| 视频号 | — | 可挂公众号/医院信息（自有地盘） |
| 抖音 | 医院名、外链、价格 | 地域标签、同城词、"本地" |
| 小红书 | 医院名、外链、具体价格 | 地域词（城市名）、价格逻辑（"以就诊医院说明为准"） |

## 五、钩子设计（内容怎么"长"出动作）

**错误做法**：正文讲完知识，结尾贴个二维码说"扫码咨询"。
**正确做法**：钩子长在内容里，让患者产生"这件事我搞不定，得找人"的感觉。

三类钩子：

**A. 评估钩子（最硬）**
内容教患者自测 → 结尾点明"准确分级需要仪器，只能到院做" → 患者心里挂着"我到底几级"。
> 把"去医院"变成"拿答案"。人对拿答案的欲望远大于看病。

**B. 疗效钩子（我们最强，有3篇论文）**
讲居家康复 vs 到院康复的疗效 → 结尾"不是所有人都适合居家，要医生看评估报告才能定" → 患者想"那我适合吗"。

**C. 进度钩子**
讲康复周期规律 → 结尾"你现在练到第几周了？到院评估一次，医生告诉你进度对不对" → 拉已入组患者回来复查。

**动作设计要求**：一步到位、有确定回报（拿东西不是咨询）、不吓人（"预约评估"轻于"挂号看病"）。

**反常识**：不用"优惠/减免"做钩子。①医疗广告违规 ②补贴来的不是真需求，会拉低医院对我们的评价。

## 六、归因机制（钱的问题）

医院会问："凭什么说这些患者是你们带来的？"

**做法：一院一码。**
- 每家合作医院一个专属二维码
- 患者只可能从一个码进来 → 归因清楚
- 码是我们系统的入口（不是微信个人号）→ 流量落进我们系统，数据在我们手里

---

## 七、跟医院怎么谈

话术：
> "我们做内容，把人送到你院来。人来了你接住，服务你做。我们不分你的诊疗费，我们只分我们做的服务。"

**分成逻辑（sandy 已定，不分两套并行）**：
- 患者拿二维码到院 → 医院即给分成
- 比例两景不同：**居家服务包 = 医院多我们少 / 流量带来的患者 = 我们多他们少**
- **按服务量分，不按人头费**

**收费节奏（sandy 已定）**：
1. 先免费跑（带二维码）
2. 量大后医院提需求
3. 三选项：继续免费 / 投流成本医院出 / 投流我们出但投流患者分成
