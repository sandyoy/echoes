## 一、这条线要解决什么

**把内容变成患者，把患者送到合作医院。**

一句话定位：我们做内容 → 内容带来患者 → 患者走进合作医院 → 医院有患者量、我们有服务量。

对医院的杀伤力：**把第三方从"抢患者"变成"送患者"。** 这是面对医院最硬的一张牌。

## 三、载体结构：一鱼多吃

```
视频号（母体 · 长内容 · 我们的地盘）
    │
    ├─ 剪短视频 → 抖音（地域标签 / 同城推荐）
    ├─ 剪短视频/图文 → 小红书（地域词 / 本地流量池）
    └─ 公众号图文（挂医院信息，我们自己地盘）
```

**一条母体内容 = 1条视频号 + 3-5条抖音 + 3-5条小红书。**

## 四、地域护栏（核心机制）

**本质矛盾**：平台不让你公开说"去XX医院"（违规），但**不禁止你说"本地/同城"**。

**护栏下的做法**：
1. 内容里只说地域，不说医院名 —— "珠海的姐妹可以就近做评估"
2. 靠平台地域推荐机制自动推给同城（抖音同城 / 小红书本地流量池）
3. 患者自己搜"珠海 盆底康复" → 搜到内容 → 评论区/私信问"哪家"
4. 我们一对一给医院信息（私域承接，不公开）

**平台红线表**：

| 平台 | 禁 | 可 |
|---|---|---|
| 视频号 | — | 可挂公众号/医院信息（自有地盘） |
| 抖音 | 医院名、外链、价格 | 地域标签、同城词、"本地" |
| 小红书 | 医院名、外链、具体价格 | 地域词（城市名）、价格逻辑（"以就诊医院说明为准"） |

## 五、钩子设计（内容怎么"长"出动作）

**错误做法**：正文讲完知识，结尾贴个二维码说"扫码咨询"。
**正确做法**：钩子长在内容里，让患者产生"这件事我搞不定，得找人"的感觉。

三类钩子：

**A. 评估钩子（最硬）**
内容教患者自测 → 结尾点明"准确分级需要仪器，只能到院做" → 患者心里挂着"我到底几级"。
> 把"去医院"变成"拿答案"。人对拿答案的欲望远大于看病。

**B. 疗效钩子（我们最强，有3篇论文）**
讲居家康复 vs 到院康复的疗效 → 结尾"不是所有人都适合居家，要医生看评估报告才能定" → 患者想"那我适合吗"。

**C. 进度钩子**
讲康复周期规律 → 结尾"你现在练到第几周了？到院评估一次，医生告诉你进度对不对" → 拉已入组患者回来复查。

**动作设计要求**：一步到位、有确定回报（拿东西不是咨询）、不吓人（"预约评估"轻于"挂号看病"）。

**反常识**：不用"优惠/减免"做钩子。①医疗广告违规 ②补贴来的不是真需求，会拉低医院对我们的评价。

## 六、归因机制（钱的问题）

医院会问："凭什么说这些患者是你们带来的？"

**做法：一院一码。**
- 每家合作医院一个专属二维码
- 患者只可能从一个码进来 → 归因清楚
- 码是我们系统的入口（不是微信个人号）→ 流量落进我们系统，数据在我们手里

## 七、收费与分成（sandy 原话落账 · 2026-09-28）

> 本节按 sandy 原话记录，**不加推论**。此前助手自造的"模式④"及自行排的"重资产/放最后"节奏，均为助手臆造，已删除。

### 7.1 总原则

**不分两套逻辑，就一套：只要患者拿了我们的二维码、到这家医院 → 这家医院就给我们分成。**
这是**已经存在的机制**（我们现在跟医院做的居家服务包，就是分成的），不是新发明的选项。

### 7.2 分成比例（两景不同）

| 场景 | 比例 |
|---|---|
| 居家服务包（现在这块） | **医院多、我们少** |
| 流量带来的患者 | **我们多、他们少** |

**计费口径**：**不是人头费**，是**按这个患者到院接受的服务的服务量**来分。

### 7.3 节奏（sandy 原话）

**第一步：先用免费的先走。**
> "先用免费的先走，然后里面我们可以带上医院的二维码……如果真的有患者拿着二维码去到医院去领服务"

**第二步：量起来了，医院自己会开口。**
> "医院如果量比较多的话，医院可能会后面会提出来说，那能不能在节日里头帮我们做一下这个活动？"

**第三步：到那时，给医院两个/三个选项。**
> "我们可以说两种活动：
> 一种是我们继续这样投免费的那能来多少患者确实很难说。
> 第二的话就是我们可以做一点投流，那做投流的需要成本，那需要医院给钱。
> 第三种我们可以做投流，然后我们可以送给医院投流，但是如果投流回来的这个患者，我们要进行分成"

整理成表：

| 选项 | 内容 | 风险/代价 |
|---|---|---|
| ① 继续免费 | 保持现状，带医院二维码自然跑 | 能来多少患者，**确实很难说** |
| ② 投流，成本医院出 | 我们做投流，投放成本由医院承担 | 医院要掏钱 |
| ③ 投流我们出（送医院） | 我们垫投放成本，送给医院 | 但投流回来的患者，**我们要分成** |

### 7.4 底线（sandy 原话）

> "先用纯自然流量走，有一定的回馈了。然后呢，再来看把它是做成送给患者客户的，还是让客户自己买单的。"

即：**先不谈钱，用自然流量验证链路通不通。** 跑出回馈再决定钱谁出。
