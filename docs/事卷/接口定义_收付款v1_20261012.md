## 一、为什么现在做（第4期才用，却今天落）

§9.2 写死一句话：**"第4期一次性预留三种模式（免费/单本/年费），后续随意切换：改价/开关不用找开发、不用重发版本。"**
§十一 铁律：**"能预埋的先预埋，否则回头撬接口牵动整条链。"**
而 `models.py` 里 `Pricing`/`Order`/`PrintOrder` 三张表**早已建好却零代码使用**——本文件把它接上，做到**凭证一到即可收钱**。

## 三、请求/响应形状

### 1) `GET /pay/plans`
```json
{ "ok": true, "data": { "plans": [
  { "plan_code":"free","plan_name":"免费使用","price":0.0,"period_days":0,"active":true,"remark":"" },
  { "plan_code":"single_book","plan_name":"单本电子书","price":39.9,"period_days":0,"active":true,"remark":"" }
], "count": 2 } }
```

### 2) `POST /pay/admin/set_plan`（★后台配置）
body：`{ "plan_code":"single_book", "price":39.9, "active":true, "period_days":0, "plan_name":"", "remark":"" }`
- `plan_code` 仅支持 `free` / `single_book` / `yearly`（§9.2 三模式预留）
- **改价、免费↔收费，全部走这里 → 不需要重发小程序版本**（§9.3）
- 幂等：存在则更新，不存在则新建

### 3) `GET /pay/quote?user_id=&plan_code=`
```json
{ "ok": true, "data": {
  "plan_code":"single_book", "amount":39.9, "payable":true, "pay_channel":"wechat",
  "channel_ready":false, "notice":"支付凭证未配置，收款能力尚未开通" } }
```
- **金额一律服务端现算**（接口无 amount 入参 → 前端无法篡改）
- `channel_ready=false` → §9.5 待调研项未落地，**明确告知"尚不能收"，不假成功**

### 4) `POST /pay/order`
body：`{ "user_id":"u_xx", "plan_code":"single_book", "pay_channel":"wechat" }`
- 免费模式 → 直接返回 `status:"paid", amount:0, free:true`（不走支付通道）
- **未配凭证** → 单仍落 `pending`（业务可追踪），但 **`code:"not_configured"` 且 `pay_params:null`**（绝不返回伪造的 prepay 参数）
- 凭证就绪 → `code:"pay_not_implemented"`（统一下单接口第4期实现，**当前不臆造**）

### 5) `GET /pay/order?order_id=&user_id=` / 6) `GET /pay/orders?user_id=`
查单 / 我的购买记录。**越权：非本人单 → `forbidden`。**

### 7) `POST /pay/callback`
`?order_id=&transaction_id=` → 把 pending 置 paid（**幂等**：重复回调 `idempotent:true`）。
- ⚠️ 真上线**必须验签**（微信回调带签名），本桩**不验签**，仅联调用
- **未配凭证时回调被拒**（防被伪造回调白嫖）

## 四、对照 §九 逐条

| § | 要求 | 落点 |
|---|---|---|
| 9.1 | 收不收/收多少=后台配置，不写死 | 所有金额读 `Pricing` 表；代码零硬编码（自测②证） |
| 9.2 | 三模式一次性预留，改价/开关免重发版 | `free`/`single_book`/`yearly` + `set_plan` |
| 9.3 | 改价=后台改 / 免费↔收费=后台开关 | 同上；`active` 开关（自测⑤证） |
| 9.4 | 微信支付为主，预留其他渠道 | `pay_channel` 字段 + `load_pay_config` 配置化 |
| 9.5 | 待调研（能否收款/年费挂哪/改价免重发政策） | 未配 → `not_configured`，不假成功 |
