## 铁律（2026-09-21 sandy 定）

sandy 原话精神：
> **"我是用人的脑子在记，你是用机器的脑子在记。你怎么样让机器脑子跟我人一样，原来我们提过的内容你都能够留下印记——先去查，查完之后再来跟我讨论，不要刚开始就来跟我说你没做、他没做什么的。"**

**因此，凡 sandy 提"以前/上次/我们定过"类问题，我的强制三步（不许跳步）**：
1. **翻够**：事卷 + 仓库文件 + 历史会话 + inbound 日志，四处都过
2. **交叉验证**：不拿单方说法下判断（尤其不拿小龙虾的上报当全部事实）
3. **才开口**：说清"我查到什么 / 信几分 / 哪里有洞"，**第一次回答不许出裁决**
