## 〇、一句话

第2期「能排对」的第二块后端了：**AI 主动当记者问、老人能随时打断、自述页归类问带全套安全兜底**。
本层只做**判定**，真机 1 秒打断延迟由前端录音/播放切换决定（**须真机测，本层不承诺**）。

---

## 一、接口清单（6 条，全 POST）

| # | 路径 | 干什么 |
|---|---|---|
| 1 | `POST /api/echoes/interview/start` | 开始采访，AI 出第一问 |
| 2 | `POST /api/echoes/interview/next` | 答完出下一问（打断则不丢话题） |
| 3 | `POST /api/echoes/interview/barge_in` | ★老人打断判定（出声→停 TTS） |
| 4 | `POST /api/echoes/interview/ask_classify` | 自述页保存后，要不要弹归类问 |
| 5 | `POST /api/echoes/interview/classify_answer` | 老人对归类问的回答 → 新建/某一件 |
| 6 | `POST /api/echoes/interview/pref` | 「别问了」开关 + 打断灵敏度档位 |

**统一信封**：`{ok, data, error, code}`（与 timeline/anchor 同款）。`owner_id` = 书主人（讲述人），必传。

## 二、逐条形状

### 1. `start` —— AI 出第一问
请求（query）：`owner_id`（必）, `viewer_id`（选, 默认=owner）
```json
// 200
{ "ok": true, "data": {
  "question": { "kind":"anchor", "anchor_type":"birth", "anchor_label":"出生",
                "text":"老人家，您是哪年出生的呀？", "follow_up":"那年您出生在什么地方、家里排行老几？",
                "audio_hint":"语音播放（老人只用听）" },
  "missing_anchors": ["birth","work","marriage","child_birth","move"],
  "state": "asking",
  "wait_ms": 1800,                 // ★AI 主动让路：问完留等待，别连珠炮
  "follow_digression": true,       // ★允许跑题
  "asked_at": "..." } }
```
**口径**：① 优先问**人生锚点**（§5.3「采访中有意自然询问」，不是闲聊）——按 出生→工作→结婚→生娃→搬迁 顺序补缺口；② 锚点齐了自动转开放问题；③ 外人（非主人非家人）→ `{ok:false, code:"forbidden"}`。

### 2. `next` —— 出下一问
请求体：`owner_id`,`viewer_id`,`last_answer`,`interrupted_question`,`interrupt_count`
```json
// 正常：和 start 同形
// ★被打断且老人这句没答清（空/嗯/对）：
{ "ok": true, "data": { "question": { "kind":"resume", "text":"<刚才原样那句>", ... },
                        "state":"resumed", "wait_ms":1800, "follow_digression":true } }
```
**前端铁律**：若上一次 TTS 被 `barge_in` 打断，**把当时问的那句原样存下来**，下次调 `next` 时回填 `interrupted_question` —— 这就是「打断不丢话题」。老人答清了（说了具体内容）→ 正常换下一问，不 resume。

### 3. `barge_in` —— ★打断判定
请求体：`owner_id`(选), `energy_db`(选, dB), `assuming_norm`(选: `normal/tv/crowd/baby`)
```json
{ "ok": true, "data": {
  "stop_tts": true,               // ★立刻停 TTS（前端据此收麦/停播）
  "hold_topic": true,             // 记住刚才问的
  "follow_digression": true,      // 允许跑题
  "sensitivity_gear": "low",      // 自动档（嘈杂→low）
  "silence_ms": 350 } }
```
**判定规则**：`energy_db` 超过档位阈值 → `stop_tts=true`；没给 `energy_db` 但前端明确报「出声」→ 保守判停（安全侧）；`assuming_norm` 是 `tv/crowd/baby/noisy` → 自动降灵敏（`low`，防电视/哭声误触）。
**灵敏度档位**（内部档，供真机校准）：`low` 阈值 -20dB / `high` -42dB（阈值越低越好触发）。
**⚠️ 本层不承诺「1 秒」**：真实延迟取决于小程序录音/播放切换，**须真机实测**（需求书 §7.2 待验证项）。

### 4. `ask_classify` —— 要不要弹归类问（频率保护）
请求体：`owner_id`,`viewer_id`,`new_story_id`
```json
// 该问：
{ "ok": true, "data": { "ask": true, "reason":"cluster", "cluster_n": 2,
  "question": { "kind":"classify", "text":"这段是新的一件事吗？",
                "audio_hint":"自动语音播放（老人只用说）",
                "buttons":[{"key":"new","label":"新的一件事"},{"key":"existing","label":"是上面的某一件"}],
                "fallback_buttons_after_ms": 5000 },   // ★5 秒无反应 → 浮大字按钮
  "retry_left": 2, "safe_default": "new" } }
// 不问（防烦）：
{ "ok": true, "data": { "ask": false, "reason": "single_in_year" } }   // 那年只 1 件事
{ "ok": true, "data": { "ask": false, "reason": "muted" } }            // 老人说过「别问了」
```
**频率保护（§7.3 防烦）**：那年（同 `time_sort_key`）只有 1 件事 → 不弹；同桶攒够 2 段才问一次；说过「别问了」永不再问。

### 5. `classify_answer` —— 归类回答 → 决策
请求体：`owner_id`,`viewer_id`,`new_story_id`,`answer_text`,`answer_key`,`retry_used`
```json
{ "ok": true, "data": { "decision":"new",     // new / existing / null(重问)
  "retry": false, "reason":"vague_safe_default" } }
```
**决策表（§7.3 逐字执行，安全优先）**：

| 老人反应 | 结果 | reason |
|---|---|---|
| 点按钮 `new` / `existing` | 对应决策 | `button` |
| 说具体内容（"分了地那年的事"） | `existing`（`need_pick_story:true`，前端再选哪件） | `spoken` |
| **含糊**（嗯/对/好/行/中/是…） | ★**默认新建** | `vague_safe_default` |
| 「没听清/什么/再说一遍」 | **重问**（`retry:true`，最多 2 次） | `misheard` |
| 重问 2 次仍听不清 | ★**默认新建，不纠缠** | `retry_exhausted_safe_default` |
| 5 秒无反应（`answer_key:"timeout"`） | ★**默认新建** | `timeout_safe_default` |

**铁律 F：老人任何反应都不算错，永远有安全默认（新建），绝不卡住他。**

### 6. `pref` —— 「别问了」+ 灵敏度
请求体：`owner_id`,`muted_ask`(选 bool),`sensitivity`(选 `low/normal/high`)
```json
{ "ok": true, "data": { "prefs": {...}, "sensitivity":"high", "muted_ask":false, "muted_note":"" } }
```
非法灵敏度 → `{ok:false, code:"bad_request"}`。

## 三、前端接法（采访页 + 归类弹层）

1. 进采访页 → 调 `start` → 取 `question.text` 走 TTS 播（`audio_hint` 提示"只用听"）→ 播完**等 `wait_ms`** 再听老人说。
2. 老人出声（能量超阈值）→ 调 `barge_in` → `stop_tts=true` 就 **1 秒内停 TTS**，并**把当前问句存下来**。
3. 老人说完 → 调 `next`（回填 `interrupted_question`=刚打断的那句）→ 拿到下一问或 `resumed`。
4. 自述页保存完 → 调 `ask_classify`；`ask=true` → 播归类问 + 起 5 秒计时；5 秒无反应浮大字按钮；老人应声/点按钮 → 调 `classify_answer`；`decision:"new"` → 新建，`"existing"` → 让老人选哪件。
5. 老人说「别问了」→ 调 `pref {muted_ask:true}`。

---

## 四、四条铁律（照做，别打折）

1. **打断要快**：出声 → 停 TTS（延迟须真机测，不得凭印象承诺）。
2. **打断不丢话题**：`next` 回填 `interrupted_question`，先接回再接别的。
3. **AI 主动让路**：每问完留 `wait_ms`，不连珠炮。
4. **任何反应都不算错**：含糊/超时/重问耗尽 → 一律默认新建，绝不卡住老人。
