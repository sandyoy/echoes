## 一、产品是什么（一句话）

老人自己讲、自己留的一生记录。不是"孩子帮老人写回忆录"，是**老人自己那本书**。

## 二、最小闭环（sandy 给了视频号参照物，定死）

```
按下说话 → 屏幕出秒数（知道在录） → 松手 → 文字上屏 → 出音频条可点开重听 → 保存 → 能再次打开看到
```

**这一条不通，界面再好都等于零。** 判据不是"接口返回 ok"，是这一整条在真机上走通。

## 三、采访（不是问答机）

- AI **出声**问（真语音，不是假计时器）
- 老人一开口，AI **立刻停**
- 听完老人这句再决定下一句 → **问句由老人上一句决定，不是预置题库顺次跳**
- 像微信一问一答，一句一句出，不整块刷
