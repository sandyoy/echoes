## 三、顶层口径（sandy 已定，不得擅改）

1. **鹤灵（赫林）医疗 = 唯一主线厂家**；「脑星球」= 鹤灵自家子产品（微信小程序端），非另一家公司。
2. **成人/儿童共用一套任务库**（6模块×36任务，每任务6级难度，按GDS映射）。
3. **评估驱动**（≠心脏康复状态式分档）：评估→认知轮廓图→建议起始难度→医生一键开→训练→回传调难度。**无评估不康复。**
4. **资质口径**：成人有二类械证（粤械注准20232070187《认知功能评估与训练软件》）；**儿童也有二类械证**（证号待补）；注册人均为鹤灵主体，非圆爱康自有。证面"不具备自动诊断功能"→ 禁用"智能诊断/AI诊断"话术。
5. **一律自费定价**，收费编码仅作信任背书、不当定价依据；对外物料不印价格。
6. **行为干预** = 大范畴说法，不走 BPSD 窄口；对外只走"认知训练"。

## 六B、经颅磁刺激治疗仪（新配置·2026-10-14 接入）

**定位**：认知康复线新增的**非药物辅助治疗手段**，与行为干预（认知训练）**并列**，不绑疗效。
**来源**：sandy 2026-10-14 发来注册证 5 页 PDF + 产品彩页 2 页 PDF（同一台设备）。

### 红线（对外物料强制）

1. 证面适用范围**不含**认知障碍 / ADHD / 阿尔茨海默 / 抑郁 / 自闭症。
   → 对外只可落「**非药物辅助治疗手段 + 神经内科场景**」；**禁写**「治认知/改善记忆/治多动症/治抑郁」。
2. 厂家彩页自写的「神经心理科（抑郁、精分）、儿科（脑瘫、自闭症）」= **厂家宣传口径，非注册范围**，不得照搬进我方物料。
3. 厂家海报违规话术（「抑制异常脑电」「增加脑血流量」等）= **禁进对医院/对患者物料**。
4. **禁宣称「经颅磁＋行为干预组合疗效（协同/加倍）」**——无我方临床数据。只讲「两法均可居家、可灵活组合（都居家 / 一院内一居家）」。
5. ⚠️**分成比例（五五分成 / 我方实得=患者总收÷2）属内部最高密级**，一律不进任何对外材料。出定价物料前先 grep「分成/比例/五五/我方得」须=0。

### 套餐结构（sandy 2026-10-14 定）

- 医院预先定死频次/疗程 → 之后不再每次开医嘱，**医生动作=选套餐编号**。
- 三入口：①**综合套餐**（行为干预＋经颅磁，含一二三分档）②**行为干预套餐** ③**经颅磁套餐（居家）**。
- 治疗节奏**各走不绑**：经颅磁随医嘱（例隔天做）；行为干预每天做。
- **套餐表不要「配置清单」列**（sandy 2026-10-14 定：本来就没内容可写）。
- ⚠️待补：**综合套餐（行为干预＋经颅磁）三档具体数字**——sandy 说"口径跟经颅磁一样"，但数字尚未发。
