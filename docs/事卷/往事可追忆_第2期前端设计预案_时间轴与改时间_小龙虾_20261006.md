## 一、时间轴页（`pages/timeline/`，新建，属第2期）

### 1.1 页面职责
把老人/家人采集进来的素材，按**时间**排成一列，让人**一眼看出排得对不对**。这是「能排对」这期的验收面（日历 §四 第2期）。

### 1.2 视觉结构（竖向时间线）

```
往事可追忆 · 时间轴
────────────────────────────────
 1958年          ●  ── 出生（锚点）
                 │
 1966年          ●  ── 上小学（锚点）
                 │     └ [故事卡] 村里办扫盲班
                 │
 1970年代(老人说的)  ●  ──  〔模糊精度，原样显示，不凑整〕
                 │     └ [故事卡] 挣工分那些年
                 │
 1980年5月       ●  ──
                 │     ├ [故事卡] 分到第一套房
                 │     └ [故事卡] 女儿出生      ← 同一节两故事
                 │
 【时间待定】    ?  ──  〔无法判定的，不瞎猜，单列到底部〕
                       ├ [故事卡] 「那年冬天…」(未提到年份)
────────────────────────────────
```

### 1.3 关键结构规则（照 v2.4 定死）
1. **节 = 一个时间点**；一节下可挂**多个故事卡**（§5之二.2：同一时间点允许多个故事）。
2. **精度分级显示**：年 / 季 / 月 / **模糊**（早年·年中·年末）。模糊的**原样显示老人原话**，例：`1970年代（老人说的）`，**绝不显示成「1975年3月」**（§5.5 第3条）。**精度不影响排序**（粗的排粗位）。
3. **【时间待定】独立成"节"**，永远排在最底部，**不参与排序、不猜**（§5.4 保命线）。视觉上用问号灰点区分，别让老人以为它排在某年。
4. **点是"看故事"、不是"改时间"**：点故事卡 = 展开看这段内容；点「改时间」三字 = 改时间（§5.5：点段=看故事，点改时间=改）。
5. **人生锚点单独标出**（出生/上学/结婚/生娃/退休）：§5.3 —— 锚点是"让时间轴变准的核心"，视觉上给个小标记（如「锚」角标），便于后面反推（"我八岁那年"）。

### 1.4 空态 / 边界
- **零故事**：显示「还没有故事，先去说说/传张照片吧」+ 直达采集页按钮（标准版）；大字版把按钮做成大号「按住说话」。
- **全部"时间待定"**：不报错，照常列出，顶部一句轻提示：「有些还没听出年份，等您说说就排上了」——**不吓用户**。
- **时间倒序/正序**：默认**正序**（早→晚，符合"一生"的阅读感）；左右滑动或顶部按钮可切倒序（熟手功能，不做大字版引导）。

## 二、「改时间」弹层（v2.4 §5.5 定型的交互，逐条落地）

### 2.1 三层交互流（完全照 sandy 定案的 ASCII 图）

```
点「改时间」 / 长按该节
        │
        ▼
┌──────────────────────────────┐
│  这段是 1980年5月，对吗？      │   ← 回读当前时间
│  🔊「不对您说个时间，我给您挪过去」│ ← 自动播放，老人只用嘴说
│                              │
│   [   按住说   ]  [  自己选  ] │ ← 两个大按钮
└──────────────────────────────┘
        │
   ┌────┴─────────────┐
   ▼                  ▼
【按住说】          【自己选】
 说话→识别时间       大字号年份滚轮（上下滑，不做日历小格子）
 例"不是，是1968年"   选完年份 → 问"大概哪个月" → 可直接跳过
   │                  │
   └────────┬─────────┘
            ▼
   🔊「给您挪到1968年了，对吗？」  ← 回读确认
            │
        ┌───┴────┐
        ▼        ▼
     对/挪完   不对→可再改（不催不锁）
```

### 2.2 三条定案（§5.5，前端必须照做）
1. **语音第一**：打开弹层**自动播放**问句，老人**只用嘴说**、不用点。
2. **「自己选」是底线、不是备选**：嗓子哑了 / 旁边有人不方便说 / 不想跟机器说话的老人，**不能被卡死** → 必须始终可见、可点。打开=**大字号年份滚轮**（上下滑），选完年份问「大概哪个月」→ **可直接跳过**。
3. **模糊时间原样保留，绝不凑整**：老人说「七几年」→ 存 `1970年代（老人说的）`，**不许显示"1975年3月"**；「我八岁那年」→ 用**人生锚点**反推年份（出生年已知时）。**排序照样有位：精度不影响排序。**

### 2.3 补充口径（前端需守）
- **改完回读确认**；**改错随时能再改，不催不锁**（§5.5 末）。
- **不做小铅笔 ✎**（图标太小老人点不准）、**不做"故事页另放按钮"**（§5.5：老人看到哪段不对就动哪段）——入口只此两个：节后「改时间」三字 + 长按。
- **不分段诱导**：改时间弹层内不放其它操作（比如"顺便分享"），一次只问一件事，防老人被绕晕。

## 三、双界面（标准版 / 大字版）差异

| 维度 | 标准版 | 大字版 |
|---|---|---|
| 时间轴字号 | 常规（时间行加粗） | **显著加大**，时间行与「改时间」三字同步放大 |
| 故事卡 | 摘要 + 缩略图，可点开 | 只留一行大标题 + 大缩略图，点开看 |
| 「改时间」三字 | 正常大小 | **放大到可一指点击**（老人手抖也能点准） |
| 长按入口 | 保留（熟手） | 保留但不提示 |
| 手势引导 | 可提示左右滑切序 | **不提示手势**（大字版禁复杂引导） |
| 禁词 | — | 全页不得出现「设置 / 权限 / 分享」（v2.4 §3.3 硬线，与首页同口径） |

> 交付前自检沿用现有硬线：`grep -n "设置\|权限\|分享"` **只允许命中注释、零用户可见文案**。

## 四、前端对后端的接口需求（提给 小鲸鱼，待其定义，本文件不代定）

> 说明：§4 只是**前端要什么**、**为什么**，具体字段/路径由小鲸鱼《时间轴接口定义》拍板。前端已学会「接口没定就留 TODO(接口)，不写死假路径」（09-26 踩过旧路径的坑）。

| # | 前端需要的能力 | 用途 | 备注 |
|---|---|---|---|
| N1 | **取时间轴（按时间排好的节数组）** | 渲染 §1.2 时间线 | 每节需含：时间显示串（含模糊原文）、精度级别、是否锚点、该节故事卡数组、是否"时间待定"节 |
| N2 | **改时间（提交一个时间）** | §2 弹层确认后提交 | 入参形状建议能表达：精度（年/季/月/模糊）、模糊时的原文串；返回挪动后的新排序 |
| N3 | **回读用的"当前时间串"** | 弹层第一句「这段是 X，对吗？」 | 就是 N1 里该节的时间显示串 |
| N4 | **锚点表读取**（可选） | 「我八岁那年」反推、锚点角标 | 若反推在后端做，前端只需显示结果；若前端做，需出生年等锚点 |

**联调纪律（承 09-26/09-28 教训）**：N1~N4 任一形状未定前，前端**不写死路径、不接假数据流**；路径一律与 `api_adapter_fastapi.py` 注册路径**逐条比对**后才接（此前 7 条/12 条/4 条路由均如此做，且均本机实测通过）。
