## 一、这条卡点是什么，为什么现在清

自 **09-26** 起，每天的推进日历「卡点」列都写着同一句：

> 对象存储未定（照片/语音/视频 `media_url` 无落点，上传只到一半）

后果：老人传的照片 / 录的语音（**声音本身就是记忆资产**）/ 视频，**没有一个字节能存下来** →
「采进来 → 看得到 → 出书 → 分享」整条链路**在"素材落地"这一步断头**。

**sandy 要定的是"买哪家"（采购决策）；"通道长什么样"是技术设计，本端今天就做完了。**
做法：**抽象统一存储接口 + 落一个今天就能跑的本地后端**，腾讯云 COS 按同一接口预留——
**sandy 一点头买 COS，改一个环境变量就切过去，前端一行不用改。**

## 二、三件套（前端照这个流程走）

```
① 取上传地址   POST /api/echoes/storage/upload_url
      入参: actor_id(谁传·必填) · kind(image/audio/video/original) · file_name · file_size · mime
      返回: { upload_url, method, headers, key, backend }
                    ↓
② 传字节       按 ① 给的 method + headers，把文件字节发到 upload_url
              （带 key；本地后端 = PUT /api/echoes/storage/put?key=...）
                    ↓
③ 确认入库     POST /api/echoes/storage/confirm
      入参: actor_id · key · kind · story_id · visibility(public/private) · duration?
      返回: { clip_id, media_url, visibility, ... }
              ★ **调用本接口时当场定公开/私有**（v3.0 §6.2.1：放的人当场决定）
```

**为什么分三步**：素材**只由本人入库**（§6.2.1），"谁传的"必须一路带着（actor_id）；
且**没传成功不许登记**（③ 会真的去查对象在不在，不在就拒，不假装成功）。

## 三、接口逐条

### 1. `POST /api/echoes/storage/upload_url`

| 入参 | 必填 | 说明 |
|---|---|---|
| `actor_id` | ✅ | **谁在上传**（素材只由本人入库 → 也是防越权槽位的前缀） |
| `kind` | ✅ | `image` / `audio` / `video` / `original`（原声：只存声音不转写） |
| `file_name` | ✅ | 原始文件名（用于校验+净化，中文保留） |
| `file_size` | ✅ | 字节数 |
| `mime` | ⬜ | 可选；无扩展名时靠它兜 |

**返回**：
```json
{
  "ok": true,
  "data": {
    "upload_url": "/api/echoes/storage/put",
    "method": "PUT",
    "headers": {"Content-Type": "image/jpeg"},
    "key": "clips/u_zhang/image/1750000000_a1b2c3d4_老屋.jpg",
    "expire": 3600,
    "backend": "local",
    "confirm_tip": "传完调 /api/echoes/storage/confirm 登记（含公开/私有）才算数"
  }
}
```

**错误码**（都可直接给老人看中文）：

| code | 含义 | 处理 |
|---|---|---|
| `missing_actor` | 没带 actor_id | 前端先登录拿 user_id |
| `bad_kind` | 类型不认识 | 前端传对 kind |
| `empty_file` | 文件 0 字节 | 重选文件 |
| `too_large` | 超限（图/音 20MB，视频 200MB） | 压缩或换文件 |
| `bad_ext` | 扩展名不支持 | 换文件 |
| `storage_not_configured` | 后端没配存储 | 联系后端（本地后端默认开，正常不会出现） |
| `cos_not_configured` | 选了 COS 但凭证不齐 | 联系后端补凭证 |

### 2. `PUT /api/echoes/storage/put?key=<key>`

body = 文件字节。本地后端的"上传地址"就是这个端点（`upload_url` 已给全）。
**切 COS 后**：`upload_url` 变成 COS 签名地址，前端**一行不用改**（还是按 method/headers 传）。

> ⚠️ 小程序注意：`wx.uploadFile` 是 **POST multipart**，不是 PUT。
> 真机两条路任选：**(a)** 让后端加一个 POST form 兜底端点（下一版可加）；
> **(b)** 用 `wx.request` 带 `ArrayBuffer` 走 PUT。**本端点仅服务本地后端**，切 COS 后直传 COS。

### 3. `POST /api/echoes/storage/confirm`

| 入参 | 必填 | 说明 |
|---|---|---|
| `actor_id` | ✅ | 谁在放（**必须与 ① 的 actor_id 一致**，否则 key 前缀对不上 → 拒） |
| `key` | ✅ | ① 返回的 key |
| `owner_id` | ⬜ | 这个故事的主人（不传 = actor_id，自述场景两者同一人） |
| `kind` | ✅ | 同 ① |
| `story_id` | ✅ | 挂到哪条故事 |
| `visibility` | ✅ | `public` / `private`（**默认 private**，当场定） |
| `duration` | ⬜ | 音/视频时长（秒） |

**返回**：`{ok, data:{clip_id, story_id, clip_type, sort_order, media_url, visibility, kind, key}}`

**错误码**（除 ① 那批外）：

| code | 含义 | 处理 |
|---|---|---|
| `key_actor_mismatch` | **这个上传地址不是你的**（key 前缀 ≠ actor） | 正常不会出现；出现了 = 有人在抢别人的槽 |
| `object_not_found` | 刚上传的文件找不到（**没传成功**） | 重传 |
| `missing_key` | 没给 key | 走完 ① 再调 |

### 4. `GET /api/echoes/storage/media_url?key=<key>`
给回放/看图用的稳定地址（§6.2.3 回放按钮）。本地 = `/media/<key>`；COS = 签名 GET。

### 5. `GET /api/echoes/storage/status`
存储体检：现在用哪个后端、能不能写。联调前排障用。

## 四、关键口径（与需求书对齐）

| # | 口径 | 落在哪 |
|---|---|---|
| 1 | **素材只由本人入库** | `actor_id` 必填；key 前缀 `clips/{actor}/`；confirm 校验前缀 → 别人抢不了槽 |
| 2 | **放的人当场定公开/私有** | confirm 带 `visibility`，默认 private（§1.2 闸门于此成形） |
| 3 | **原声不转写** | `kind=original` → 走 `api_add_original_clip`（§6.2.2 声音是资产） |
| 4 | **语音留声+留字** | `kind=audio` → `do_transcribe=True`（§6.2.2 两边都要） |
| 5 | **回放按钮** | `GET /storage/media_url`（§6.2.3） |
| 6 | **文件名可中文** | `sanitize_filename` 保留中文、去穿越（老人照片常是中文名） |
| 7 | **不假装** | 未配存储 → 明确 `storage_not_configured`，绝不返回假 URL |

## 五、切到腾讯云 COS（sandy 定了之后）

**前端：一行不用改。** 后端设 4 个环境变量（或放 `~/.config/yuanekang/cos.json`）：
```
ECHOES_STORAGE=cos
ECHOES_COS_SECRET_ID / ECHOES_COS_SECRET_KEY / ECHOES_COS_REGION / ECHOES_COS_BUCKET
```
→ `get_storage()` 自动切 `CosStorage`（同一套方法），`upload_url` 变成 COS 签名地址。
**缺凭证 → 明确报 `storage_not_configured`，不静默回落到本地假装成功（铁律）。**

> 依赖：`pip install cos-python-sdk-v5`（本机未装，切 COS 时才需要）。
