1. 先读该线的**框架锚**（顶层框架 / 总纲 / 总表）—— 定位

3. 最后按本次话题**钻进对应文件** —— 不漏关键决策

## 三、执行规则（写给小鲸鱼自己）

1. **sandy 提线 → 先扫再谈**。扫完在回复开头用一句话点明"我已扫了 X 线的 A/B/C 文件，现状是……"，让 sandy 确认我站在正确的上下文里。
2. **不跨线串味**。GEO 的口径（老欧号不出公司名、患者内容不出招合作、企业号不冒充亲历）不带到 Echoes；反之亦然。
3. **框架锚优先**。任何话题先对齐框架锚，冲突以框架锚为准，禁止绕过框架直接改单篇稿。
4. **扫的结果要落地**。如果扫的过程中发现框架/总表与现实不一致 → 当场修框架/总表，回检下游。
5. **本条规则本身的维护**：新线立项时，把新线补进本表第二节；线结项时移到"已结项"区。
