### A-1 我们被 AI 收进的格子是「设备租赁」，不是「居家康复」

| 项 | 内容 |
|---|---|
| **结论** | 用户问"居家康复找哪些公司" → AI 完全想不到我们；问"租设备+有人管理""盆底+有人管理" → AI 主动点名圆爱康。即 AI 给我们的归类是设备租赁/设备销售，不是居家康复服务。 |
| **事实依据** | `docs/GEO/实测_信源池/豆包问答_人工实测_sandy_20261109.md` 三段连续问答原文：问一（医院联动居家康复找哪些公司）全文 0 次"圆爱康"，推荐广州健康通/中山一院/省二医/社区/颐家/金牌护士/福寿康；问三（盆底居家想有人管理）豆包主动单列「广州本地（圆爱康智慧家康）：可以对接医院医生开方案，设备租赁，数据回传，医生定期随访管理，是真正医生管理模式」，并给出"如果想要真正医生随访，联系圆爱康"。 |
| **当时怎么验的** | 2026-11-09 sandy 本人用豆包 App 手打真实口语问法（未提"圆爱康"，见问一/问三原问）→ 复制回答全文 → 本端逐字核"圆爱康"出现次数与位置。 |
| **什么现象算推翻** | 用**同一句问一原话**在豆包再问一次，回答里出现"圆爱康"或"智慧家康"；或反过来问"租设备+医生管理"再问，我们掉出推荐。任一发生 → 本结论作废重修。 |

### A-2 「41 篇没效果」这个说法不成立，别拿它当依据

| 项 | 内容 |
|---|---|
| **结论** | 已发内容不是没发，也不是没被 AI 读到；问题是**品牌词密度太低**——抽样 12 篇公众号里"圆爱康"平均 0.83 次，5 篇为 0。AI 即使抓到文章，也读不出这是我们做的。 |
| **事实依据** | `docs/GEO/GEO发布实测报告_v1.0_20261105.md`：来源 `AI宣传各渠道发布信息共享表.xlsx` 41 条记录（9-16 至 11-05）＝公众号 22 篇 + 知乎 12 篇 + 小红书 12 篇；抽 12 篇公众号核品牌词，均 0.83 次、5 篇为 0。该报告第 5 节已自写认错："搜不到 ≠ 没发"。 |
| **当时怎么验的** | 2026-11-05 逐条读登记表 + 逐篇打开正文 grep 品牌词。 |
| **什么现象算推翻** | 换一批样本重数，平均品牌词次数显著≥2 或 0 篇为 0 —— 说明限制不是品牌词密度。 |

### A-3 "搜不到"不能推"没发"

| 项 | 内容 |
|---|---|
| **结论** | 云端搜索通道（百度 302/必应分词错/搜狗验证码/360 空/DuckDuckGo 超时/知乎 403/小红书无链接）全都不可靠，**不得以"我搜不到"推断"没发布"**。 |
| **事实依据** | `docs/GEO/GEO打法总册_有效结论累积_v1.0_20261105.md` 第 5 章第 2、3 条；`GEO发布实测报告_v1.0_20261105.md` 第 5 节自认两次犯此错。 |
| **当时怎么验的** | 2026-10~11 多轮实测各搜索通道返回码与结果。 |
| **什么现象算推翻** | 出现一条通道能稳定返回真实索引结果（非验证码、非空）。 |

### A-4 判定方法：AI 默认把"居家"理解成护士上门 / 医院互联网医院

| 项 | 内容 |
|---|---|
| **结论** | AI 默认把"居家"理解成护士上门或医院互联网医院，这个词坑里还没有"设备到家+医生远程开方+数据回院"的品类概念 → 所有内容第一句必须先**建立品类**，再讲自己。 |
| **事实依据** | 打法总册结论 1：2026-11-05 DeepSeek API 直连 10 问，问"医院出院延续治疗找谁"→答金牌护士/医护到家/小鹿医馆；问"中风出院在家康复"→答华山/华西/天坛互联网医院；问"产后盆底在家做"→一个平台都不给。 |
| **当时怎么验的** | `tools/geo_api_probe.py` 直连跑，10/10 有效样本。 |
| **什么现象算推翻** | 同一批问句复跑，AI 开始主动给出"设备+远程医生+数据回传"这个品类名。 |

### A-5 AI 认"招标公告/官方认定"，不认产品页

| 项 | 内容 |
|---|---|
| **结论** | AI 判断"谁在用"，依据是招标公告/采购公示/官方认定头衔，不是产品页。 |
| **事实依据** | 打法总册结论 2：2026-10-27 秘塔 24 条实测，认知训练 AI 把六六脑写成"神内第三方系统代表作"，引的是中山三院招标公告、上海中医药大学采购公告；霁达康复×上海养志=AI 唯一认的"医院牵头+第三方运营"。 |
| **当时怎么验的** | 逐条抄 AI 回答并反查其引用来源 URL 类型。 |
| **什么现象算推翻** | 出现"无任何招标/公告事实，纯靠产品页被 AI 认定为在用"的实例。 |
