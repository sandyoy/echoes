### A-7 医院公众号能出现「智慧家康」，绝不能出现「圆爱康」

### A-9 【标题查重·2026-11-09 sandy 定·每次交包前必跑】

| 项 | 内容 |
|---|---|
| **结论** | **交出去的每一批稿，标题不许与历史稿重复或高度相似。** 写完先搜标题库，同标题、同文字复述一律不许再交。根因追溯：曾有一批交付包里文章内容根本没改就再交了一遍，sandy 当场指出"内容没改、文章没改"。故**"有没有新东西"必须靠机器查，不能靠我记得**。 |
| **事实依据** | 2026-11-09 sandy 原话：「不要把已经写过的内容重新再写一遍，或者是同样的标题、同样的文字再复述一遍，因为有一次你交的交付包里头就是内容没改，文章没改啊，所以以后你写的时候都是要搜一，就是起码把这个标题搜一遍，不要让自己的标题重复出现。」 |
| **当时怎么验的** | 建 `tools/geo_selfcheck.py` L0 层：扫 `docs/GEO/内容成稿` + `docs/GEO/执行排产` 下全部稿件提取「标题：」行（当前 52 篇），新批标题做**归一化后精确比对 + SequenceMatcher 相似度 ≥85% 判重**。首跑第9周包：6 个标题、0 重复。同时扫出历史存量重复 5 组（均为同目录下 .md 源稿与 .txt 成稿的孪生文件，属正常，非重写）。 |
| **什么现象算推翻** | sandy 说可以重发同一篇（如需换平台重发）→ 改为"重发需显式标注〔重发〕"而不是全禁。 |
