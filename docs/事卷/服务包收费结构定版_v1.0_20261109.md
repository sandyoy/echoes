# 服务包收费结构定版 v1.0（2026-11-09 sandy 拍定）

> 本文件是**唯一现行口径**。凡涉及服务包怎么收钱、谁开票、谁入账，一律以此为准。

---

## 一、定版结论：一次支付 + 两个商户 + 两张票

```
患者点「盆底康复」→ 一次支付 2300 元（一次确认，不分两次付）
        │
        ├─ 子单1：医疗服务费  1000 元 → 结算至【医院子商户号】
        │         ├ 进医院账（真实入账，可审计）
        │         ├ 医院开医疗票据给患者
        │         └ 医疗责任由医院承担
        │
        └─ 子单2：居家康复配套服务费 1300 元 → 结算至【圆爱康子商户号】
                  ├ 进圆爱康账
                  ├ 圆爱康开服务发票给患者
                  └ 服务责任由圆爱康承担
```

**技术实现**：微信支付「合单支付」（合单下单 API），圆爱康为服务商，医院与圆爱康均为其下的特约子商户。

**sandy 2026-11-09 定：以后所有医院都按这个结构做，不区分。**

## 二、铁律六条

### 1. 医疗服务部分 = 医院原价，不加价
- 严格按医院现有价格项目收费，**一分不能多**
- 宁可低于原价，绝不高于原价
- 项目内涵如与居家场景不符，须由医院物价科确认（含居家指导的表述）

### 2. 服务费名称禁用「管理费」
- ❌ 居家服务管理费 / 居家协同管理费 / 服务管理费
- ✅ 居家康复配套服务费 / 康复设备与数据服务费 / 居家康复平台服务费
- 原则：名字说出「我提供了什么」，不说「我管理了什么」

### 3. 服务费必须拆明细
- 设备使用与配送到家 / 平台与数据服务 / 随访与客服支持
- 每项单独标价，各有税收分类编码
- 患者看得懂钱花在哪 → 投诉少；税务逐项对得上 → 不怕查

### 4. 资金不经过圆爱康账户
- 患者两笔钱各自直达各自商户号，互不过手
- 协议须写明：「圆爱康仅提供微信支付服务商技术接入，不参与资金结算，不接触、不经手医疗费资金」

### 5. 主动给医院「可随时脱离」的选项
- 话术：「如贵院希望独立接入微信支付，我们可以配合迁移，不影响服务」
- 目的：医院内部审批不再被视为「把收款通道交给第三方」，而是「临时用第三方技术，随时可自建」

### 6. 患者支付页必须明示两笔
- 展示两张订单、两个收款方、各自服务内容
- 隐瞒才是投诉源头，透明不是风险

## 三、这套结构解决了什么（对照旧做法）

| 项目 | 旧做法（医院商户号收款→直接分账） | 新做法（合单支付） |
|---|---|---|
| 钱进谁的账 | 只在医院商户号过一手，**不入医院账** | 各自真入账 |
| 合规性 | 违反医院财务制度（账外资金） | 两笔独立交易，各自完整 |
| 医院义务 | 要价格项目、要入账，但都没做 | 只需按原价收，义务自然满足 |
| 「管理费」定性 | 有（发票已固化） | 无 |
| 审计风险 | 高（过账、账外资金） | 低 |

## 五、遗留问题（不解决会反复）

1. **已开出的「生产生活服务·居家协同管理费」发票如何处理**
   - 跨月已开票不能作废，只能红冲
   - 主动红冲 = 把风险主动暴露给税局
   - 处理原则：不动已开的票；从下一份合同起切换新结构
2. **医院商户号挂在圆爱康服务商体系下，公立医院内部审批难过**
   - 尤其信息科、财务科
   - 缓解手段：见铁律第4、5条（协议写明 + 可脱离选项）
3. **服务费占比可能高于医疗费，患者感受问题**
   - 2300 里医疗 1000、服务 1300 —— 商业上合理，患者感受上需解释
   - 支付页需给「不用居家这些钱花在哪」的对比说明

## 六、与历史口径的关系

- 本文件**取代**此前「医院收不低于套餐费 45% 管理费」的表述
- 本文件**取代**「由医院向市医保局申请新增居家康复远程指导价格项目」的表述（该服务不属于医疗服务价格项目，不需申报立项）
- 政策依据：国家医保局《关于完善"互联网+"医疗服务价格和医保支付政策的指导意见》——「不属于诊疗活动的服务」「非医务人员提供的服务」不作为医疗服务价格项目，包括但不限于健康咨询、健康管理、便民服务等
