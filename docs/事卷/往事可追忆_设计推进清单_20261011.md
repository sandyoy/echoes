## 10-11 关键发现（成书这一跳的真相）

**此前"成书"是空壳，不是没做——是两层都空：**
- 后端 `story_api.api_create_book` 只做"确保 owner User 存在"，**不装素材**；
- 前端 `pages/book/*` = 10 行 js + 5 行 wxml（写着"第3期上线"）。

**本次补齐的是后端那半（§八 两筐）：**
- `POST /book/source` → 筐①own（自己自动装，**含自己的私有**）/ 筐②public（**只收别人公开的**，带署名）
- `POST /book/generate` → 生成/覆盖刷新电子书；点选的公共素材入书标 `is_quote=true`+`editable=false`+`quote_label`（引用段不可改）
- `GET /book/ebook` → 取我的书；无书 `empty=true` 不当报错
- 越权：`actor_id≠owner_id` → 403（谁成书"我"就是谁）

**留给前端（小龙虾）：** book 页从空壳做成能点能跳能出书 + 8 页跳转打通（真机验）。
**分工判据**：前端页 = 小龙虾；成书要用的素材接口 = 我（已发派单 `docs/派单/派单_小龙虾_成书接口_20261011.md`）。
