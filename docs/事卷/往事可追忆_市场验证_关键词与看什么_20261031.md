# 往事可追忆 · 市场验证：搜什么词 · 看什么 · 记什么

**日期**：2026-10-31｜**执行**：sandy（人肉搜索）｜**判读**：小鲸鱼
**目的**：四步法第①步"找需求"——找到**已经有人在收钱**的同类产品，确认谁买、多少钱、交付什么。

---

## 一、平台优先级（按"能看到真实成交"排序）

| 优先 | 平台 | 为什么 | 怎么搜 |
|---|---|---|---|
| ⭐⭐⭐ | **闲鱼** | 唯一能看到**真实成交价 + 已售数量 + 别人的议价留言**（"这个多少钱""能便宜点吗"= 真需求铁证） | 直接搜商品词，按"最新/销量"排 |
| ⭐⭐⭐ | **小红书** | 卖家的产品笔记 + 评论区问"怎么买""多少钱" | 搜索框输词 → 顶部切「商品」标签 |
| ⭐⭐ | **抖音** | 看**有没有人在投流**（有广告标=已验证能赚钱），看评论区问价 | 搜索 → 切「商品/团购」 |
| ⭐⭐ | **视频号** | 中老年子女客群最集中的地方，但**看不到销量**，只能看内容有没有人问 | 搜索 → 看评论区 |
| ⭐ | **知乎** | 内容种草 + 长尾答案，能看出**用户怎么描述自己的需求**（原话最值钱） | 搜问题，不搜商品 |

> 抖音和视频号：搜，但**判断标准和闲鱼/小红书不一样**——它们给的是"有没有人在投钱做这件事"，不是"卖多少钱"。

## 三、看到就记（每个号记这 6 样，截图最省事）

1. **粉丝量**（重点抓 2000–20000 的，这种才可复制；10万+的学不来）
2. **他卖什么**（是代写？是软件？是印刷？是课程？是模板？）
3. **多少钱**（一口价/套餐档位/加价项）
4. **销量/已售**（闲鱼看"已售x件"，小红书看商品销量）
5. **评论区问的是什么**（尤其"怎么买""多少钱""能不能加急"——这是需求铁证）
6. **付款的人是谁**（子女口吻"给我妈买" / 老人自己口吻）

## 四、什么算"找到一个真需求"（判据，省得回来一堆截图我还要再问）

- ✅ **有人在问价**，且卖家**回过价** → 真需求
- ✅ 有**晒单/好评/返图**（尤其晒实体书） → 价格带可信
- ✅ 同一个号**持续更新 3 个月以上还在卖** → 说明不是一次性生意
- ❌ 只有点赞没有问价 → 内容火了但没人买，不算
- ❌ 只有大V发过、看不到卖 → 学不了
