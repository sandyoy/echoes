## 一、一句话讲清楚这个产品（v3 版）

> **一个把老人一生的话、字、照片、视频、原声收集起来，自动按时间轴排好，让每个"我"都能从中长出一本自己的书。**

**关键词：每个"我"。**
旧说法"一键变成一本书"——**错在只有一个"我"**。新版必须承认：同一件事，**每个在场的人，都是各自书里的那个"我"**。

---

## 二、地基：视角容器模型

### 2.1 这个产品不做"真相的裁决者"，只做"视角的容器"

- 一件事，八个人看，有八面。**八面都对，不需要拼成一个"完整真相"。**
- 系统**不负责**把事情对齐、拼合、裁决出唯一版本。
- 系统**只负责**：让每个"我"看的那一面，被好好留下来。

**反例（不许做的事）**：把"我"变成侦探——非要八个人的说法对齐成一条线索链、拼出唯一结论。**这不是这个产品。**

### 2.2 素材是公共的，"看"是私人的

- **素材（事件、照片、片段）** = 公共的池子。谁都能往里放。
- **"我"** = 藏在"谁在看"里，不写在主角身上。
  - 甲写"邻居家那场火" → 书的主角是邻居，但书里的"我"是甲（那个观察者）。
  - 邻居写同一场火 → 他的"我"是当年的小孩。
- **"为谁写"不重要**：写给谁、送给谁，是**写完之后**的事，不定义"这书是谁的"。
  - **"作者只要在写，就都是为自己写——哪怕写的是别人的故事，那也是自己想说的话。"**（sandy 原话）

### 2.3 一棵树：素材长在主干，每本书是各人摘下的枝

| 层级 | 对应 | 说明 |
|---|---|---|
| **主干** | 公共素材池 | 所有人共同经历的那些"事"（不带"我"） |
| **枝** | 各人成书 | 各人从素材池按自己的视角"摘"出来的一本 |

- 甲摘 → 《我记忆里的老邻居》（主角=邻居）
- 邻居摘 → 《我这辈子》（主角=自己）
- **同一批素材，两个人摘出两本完全不同的书，都成立。**

### 2.4 死结的解法：不是"复制素材"，是"引用素材 + 各写各的胶水"

（这是本模型最关键、也最容易被实现带偏的一条）

- **甲写的原话，在邻居的书里是"引用"，不是"复制"。**
  - 例：邻居的书里出现「那年冬天，隔壁张家着了火」→ 下小字标：**这段来自张大叔的讲述**。
- **引用段：邻居改不了，但可以在旁边加自己的话。**
- **引用段不算进邻居的署名**；邻居署的是他自己写的那部分。
- → 结果：**甲的名誉保住，邻居的书也完整。** 死结（素材算谁的 / 能不能改 / 署谁的名）自然消失。

### 2.5 唯一绕不过去、必须系统管的真问题

- **"我"不会自动换人。** 甲写的引用段用的是甲的"我"，邻居自己写的用邻居的"我"。
- 系统**不需要**去"转换"人称——**只需要保证：每个人只写自己的"我"、只引用别人的话。**
- **系统唯一要兜住的**：别让另一个人的字，冒充成我的字（引用段要标出处、不可改）。

### 2.6 明确不管的（写下来，防止将来又有人想管）

| 问题 | 系统态度 |
|---|---|
| 两本书对不上（同一场火细节不同） | **不管。** 这是本来的样子，是卖点不是毛病 |
| 谁是"主编"、谁是"供稿人" | **不管。** 不设主编这套 |
| "送礼物"算不算主线 | **不管。** 送礼是写完之后顺手的一个动作，是边角料 |
| 主角能不能换人 | **不管。** 谁出的书谁是主角；一份素材可以被多本书用 |

## 三、【留口】今天想到、但还没想透的（写出来，别装没有）

> 这一节是给未来的自己和技术同学的"雷区地图"。**现在不给答案，但必须留位。**

1. **【留口·接口】素材条目从第1期起就带"来路"字段**
   - 必须能记：这条素材**谁放的**、是**原创还是引用**、引用的话**原出处是谁**。
   - 第1期可以不用，但字段要在 → 第3期成书直接用，**不用回头撬第1期接口**。
   - 关联：v2.4 §2.1（故事为主体）、§6（素材篮子）。

2. **【留口·权限】"能看"与"能写"与"能引用"可能是三件事**
   - v2.4 定的是"能看就能补充"（看=写）。
   - 今天新增了"引用"这一层 → **看这篇 / 补自己的话 / 引用他的话，要不要分开？** 待定。
   - 注意红线：**看提到自己的那篇，永不需要授权**（v2.4 铁律，不可破）。

3. **【留口·成书】第3期成书时，"各摘各枝"的操作入口怎么给**
   - 老人不可能理解"fork"。需要一个**不出现技术词**的做法（如"用这段""这是我的版本"）。
   - 待第3期设计时解。

4. **【留口·人名】"认领"靠转发、不靠系统识别被提到的人**（v2.4 已定）
   - 因记忆里用称呼/笔名，非微信名，识别很难。
   - 今天"引用要标出处"这条 → **出处的名字是谁，也要跟着这条走**（可能是个称呼，不是账号）。

5. **【留口·边界】《罗生门》式多视角，读者端要不要"收一收"**
   - 已明确：**不收。** 读者得到的不是"一个结论"，是"多个视角的入口"。
   - 但**怎么呈现给读者**（八本怎么摆、从哪本进），是第3期的事。
