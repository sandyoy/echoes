# 两版《Hermes 执行手册》差异对照表

对比对象：
- **A 版（小龙虾发来）**：Hermes Agent 通用执行手册 v1.0（融合版）· docx · 422 段 / 16 表
- **B 版（小鲸鱼仓库）**：Hermes 执行守则 融合版 v2.0 · md · 14 条铁律

对比日期：2026-10-23  
结论先放前面：**两份的"骨头"高度重合（都会要求自证、禁编造、先扫再开口），真正的分歧在 ① 铁律该有几条 ② 有没有"判断场合"这一章 ③ 对 Git / 双 Agent 的依赖程度。**

---

## 一、总体结构差异

| 维度 | A 版（小龙虾） | B 版（小鲸鱼） | 差异性质 |
|---|---|---|---|
| 三层结构 | 有（12 铁律 / 细则 10 章 / 附录 A-D） | 有（14 铁律 / 细则 2.1-2.10 / 附录 A-E） | 结构理念一致 |
| 铁律条数 | **12 条** | **14 条** | ⚠️ 实质分歧 |
| 有没有"第 0 章 判场合" | 无（放在细则第一章"三种对话模式"） | **有，且提到最前面** | ⚠️ 实质分歧 |
| 细则章数 | 10 章（按主题分章） | 10 节（2.1-2.10，按职能分节） | 编号体系不同，内容大量重叠 |
| 附录数量 | A-D（4 个） | A-E（5 个） | B 版多一个"新 Agent 接入第一天" |
| 每条铁律是否带"违反的后果" | 有（部分条缺） | **14 条全部带** | B 版更齐 |
| 病症开篇表 | 有（5 种病：失忆/失语/失实/失重/失效） | 无（改成"三种场合翻车"） | 叙事方式不同 |

| 版本记录表 | 无 | 有（v1.0→v2.0 变更说明） | B 版有 |

## 四、对"单机小龙虾"而言的污染项（哪些字句必须处理）

| 位置 | A 版（小龙虾） | B 版（小鲸鱼） |
|---|---|---|
| 第七章整章 | ❌ 7.1 任务总表 / 7.2 派单方改状态 / 7.3 多端同步 / 7.4 追责查作者 / 7.5 传声筒 — **5 节全部建立在"有第二个 agent + 共享仓库"上** | 无此章 |
| 4.5 | "多方协作时各写各区，不越区改对方文件" | — |

| 铁律 9 | — | ❌ 整条是 Git 远端验证，单机无共享仓库时无用 |
| 2.5 Git 纪律 | — | ❌ 整节 Git（含合作冲突、文件名超长 pull 冲突） |
| 附录 C | 1 条 `git log origin` | ❌ 4 条 git 命令 |
| 附录 D | — | ❌ "给另一个 Agent 派活的任务单模板" |
| 附录 E | — | ❌ 可选开关里"双 Agent 交叉复核" |
| 8.2/铁律 10 | "球在我手上""不依赖他人" — 轻微，可保留 | "卡在谁身上 + 倒计时" — 轻微，可保留 |

- **A 版要砍的是整章第七章 + 4.5 一句**（约 1 章）
- **B 版要砍的是铁律 9 + 2.5 + 附录 D + 附录 C 的 git 部分 + 附录 E 一条**（约 1 条铁律 + 1 节 + 1 附录）
