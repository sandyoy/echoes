## 为什么要重启才生效（给你的技术说明）

`api_add_audio_clip` / `api_transcribe_clip` 两条路径原来只回填 `transcript` 文字，
没同步把 `transcript_status` 置成 `done`。造成两个后果：

1. 前端会对老人显示「还在转写」，实际已经转好了；
2. 后台补写任务扫到 `pending` 会重复跑同一段音频，白烧 ASR 额度。

修复就是在这两处补上 status 回填。**Python 进程不重启不会加载新代码**，所以必须重启。
