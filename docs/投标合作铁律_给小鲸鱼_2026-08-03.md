## ⚠️ 一、这条铁律是什么

sandy 最近在处理公司面向医院的投标/应标。她反复强调过一个原则，我之前理解偏了被纠正。**核心就一条：**

> **Agent 只负责"客观呈现每份招标的覆盖程度"，"投不投"的最终决策权永远在人（sandy）手里。**

- Agent 该做的：把每份招标文件，用公司能力清单客观摆出——**能用哪些产品线覆盖、覆盖到几成、有哪些硬性门槛**（资质/注册证/垫资/现金流/硬性★条款）。
- Agent **绝对不做**：用"🟢最契合 / 🟡能投但重 / 🔴接不住 / 不匹配"这类主观结论，替 sandy 做"投不投"的决定。
- 输出形式 = **每份的覆盖程度清单 → 交给人判断投哪份、不投哪份**。

## 📌 二、配合"积极覆盖优先"基调

在此基础上，判断基调是**"积极覆盖优先"**：

> 凡是跟公司有关系的项目，都用自己能力**大范围覆盖去投**；**只有硬门槛真过不去**（资质注册证没有、现金流/垫资谈不成、硬性★条款真满足不了）才标记出来给人看，作为"可能放弃"的候选。

- **不要轻易说"不匹配就不投"**。
- 区分清楚：**"门槛高" ≠ "不能投"**。门槛高是提醒人注意成本，不是替人拒绝。

## ❌ 三、常见的错误写法（务必避免）

| 错误 | 对 | 
|---|---|
| "这份🟢最契合，建议投" | "这份覆盖度高：盆底+永磁旋振，产品线完全对得上" |
| "这份🔴接不住，不投" | "这份偏运营/引流，我方覆盖有限，需你判断覆盖到几成才决定" |
| "这份🟡能投但重" | "这份免费投100台设备，成本面是主要顾虑（这是门槛高，仍需你定）" |
