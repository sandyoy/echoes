## 一、术语(读者=任何能拿到本表的技术人员/团队，先看懂再测)
- **老人**：用 Echoes 的口述者（最终用户，通常 60-80 岁会用微信）。
- **子女**：帮老人安装/录入/下单的连接人（常是实际下单人）。
- **云端自测**：小鲸鱼在腾讯云服务器上用 curl/脚本直接打接口验（不需要手机）。
- **真机回归**：小龙虾在本地 Mac 用「微信开发者工具+真机」跑一遍交互（接口要在 server 指向云上真库或测试库）。
- **真人实测**：sandy 或真实老人，在真机上从头走一遍「能不能顺利用起来」——只在前三级验完后才做。
- **验收标准里的动作**：都写成"点X→输Y→应看到Z"型，可直接照做。
