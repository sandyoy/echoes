一、一句话打法
一条视频号母体内容，剪成短视频铺抖音+小红书，靠平台地域推荐机制推给同城人，
患者在评论区/私信问"哪家"，我们一对一给合作医院信息，一院一码归因。

二、内容生产动线（母体→分发）

【第1步】视频号拍母体：3-5分钟长内容
  - 选一个钩子（评估/疗效/进度），讲透一个点
  - 视频号尾部挂公众号（我们自有地盘，可说医院信息）

【第2步】剪短：一条母体剪3-5条
  - 每条30-60秒，只讲一个点，独立能看懂
  - 剪法：把长内容里"最扎人的那一句"单独拎出来做成一条

【第3步】分发
  - 抖音：加地域标签（城市名），靠同城推荐
  - 小红书：标题带地域词（"珠海"），进本地流量池

三、地域护栏执行细则

【能说的】
  - 城市名："珠海""郑州""本地""同城"
  - 模糊地点："就近""当地医院""三甲医院"
  - 价格逻辑："具体费用以就诊医院说明为准"

【不能说的】
  - 具体医院名（抖音/小红书公开内容）
  - 外链、微信号、二维码（会被限流/封）
  - 具体价格数字（小红书 A方案）
  - "来我们医院""我们合作医院"（暴露商业关系）

【承接路径】
  公开内容（地域词）→ 患者搜同城 → 评论区/私信问 → 我们私信给医院信息 → 到院

五、一院一码归因机制
  1. 每家合作医院一个专属二维码
  2. 二维码入口指向我们系统的预约/咨询页
  3. 患者到院时出示码/报手机号 → 系统记录来源
  4. 月度报表：各医院从内容带来的到院人数、服务量
  5. 归因钥匙 = 手机号（患者/订单/二维码三方关联）

六、启动步骤（第一轮实测）
  Step1 拍3条母体（H01/H02/H07）
  Step2 剪12条分发（抖音8 + 小红书4）
  Step3 跑2周，观察：播放量 / 私信问"哪家"的人数 / 到院人数
  Step4 有效则放量，无效则调钩子

七、红线清单（每篇发布前对照）
  [ ] 抖音/小红书公开内容无医院名
  [ ] 无外链、无二维码、无微信号
  [ ] 小红书无具体价格数字
  [ ] 无"我们合作医院"这类暴露商业关系的表述
  [ ] 地域词已埋（城市名/同城/本地）
  [ ] 结尾有明确动作（私信/评论/到院评估）

八、跟医院谈的话术
  "我们做内容，把人送到你院来。人来了你接住，服务你做。
   我们不分你的诊疗费，我们只分我们做的服务。"

  分成：患者拿码到院即给分成；
       居家服务包 = 医院多我们少；流量患者 = 我们多他们少；
       按服务量分，不按人头费。

  节奏：先免费跑 → 量大后医院提需求 → 继续免费/医院出投流/我们出投流但分成。
