## 一、这是什么
一套**财务记账 Web 工具**。sandy 姐个人/家庭用：导入微信账单(.xlsx) → 自动分类 → 出图表报表。
技术栈：Python FastAPI + SQLite + 纯前端(HTML/CSS/JS) + Chart.js。

- 本地开发位置（同步到仓库后）：`docs/财务记账工具/`
- 本地跑通过：`http://localhost:8008`，账号 `admin/admin123`

## 二、项目结构
```
docs/财务记账工具/
├── frontend/          # 前端（index.html / style.css / app.js）
├── backend/           # 后端 FastAPI
│   ├── main.py        # 服务入口
│   ├── bill_parser.py # 微信账单解析引擎（注意：README写成parser.py，实际是bill_parser.py，以实际文件为准）
│   ├── database.py    # SQLite 操作
│   ├── requirements.txt
│   └── data/          # SQLite 数据库（含测试数据，部署时建议清空）
├── deploy/nginx.conf  # Nginx 反代配置
├── start.sh           # 一键启动
└── README.md          # 部署说明
```

## 三、部署目标（分工约定）
- 把 `财务记账工具/` 部署到服务器，绑定域名，做反代+HTTPS。
- 部署用 systemd 守护进程（示例在 README 里）。
- 默认端口 8008，改密码在 `main.py` 的 `lifespan` 里。

## 四、当前功能（已实现）
- 上传微信 .xlsx 账单，自动解析
- 自动分类（餐饮/交通/购物/医疗/生活等）
- 分类饼图 + 月度趋势图
- 按分类/月份/收支类型/金额/关键词筛选
- 多账号、数据隔离（SQLite）
