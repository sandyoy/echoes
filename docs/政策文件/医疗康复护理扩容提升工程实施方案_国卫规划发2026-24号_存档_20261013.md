## 二、⭐ 与本项目最相关的核心表述（对外可直引）

### 1. 康复护理资源"向社区和家庭延伸"（★最硬依据）

> **"推动资源向社区和广大家庭延伸，切实增强人民群众的获得感和满意度。"**
> —— 国家发展改革委社会发展司司长刘德春，健康报专访（2026-10-09）

### 2. "社区卫生服务中心等基层机构"要拓展居家康复护理功能

> "对于城市社区卫生服务中心等基层医疗卫生机构，主要承接慢性稳定期的患者，**重点支持加强基本康复护理能力建设，配置适合家庭病床服务的便携式设备，拓展社区、居家康复护理等延伸功能**，让群众就近就便享受到更加优质高效的康复护理服务。"
> —— 刘德春司长，健康报专访

### 3. "探索医疗卫生机构、社区、居家有效联动的康复护理模式"（★三级联动表述）

> "支持医疗卫生机构为失能失智老年人、残疾人提供健康服务和康复护理指导……做好医疗康复护理服务与长期护理服务的衔接，**探索医疗卫生机构、社区、居家有效联动的康复护理模式**。"
> —— 国家卫健委规划发展与信息化司司长庄宁，健康报专访

### 4. 基层要发展家庭病床 + 居家康复护理（上门服务的政策口子）

> "支持有条件的基层医疗卫生机构发展**家庭病床**，鼓励在**家庭医生签约服务中提供居家康复护理**等服务；支持规范发展**网约护理、上门服务**。"
> —— 庄宁司长，健康报专访

### 5. 完善多元支付体系（★支付端，最值钱）

> "完善多元支付体系……在医疗服务价格动态调整中重点考虑历史价格偏低的治疗性康复训练等价格项目，更好体现技术劳务价值；按程序将疗效确切、群众急需的康复护理类医疗服务项目纳入基本医疗保险支付范围；对接受康复护理服务的长期住院患者探索实行按床日付费等支付方式。"
> —— 《方案》第13项任务举措 + 庄宁司长解读

## 三、方案框架（4方面·13项任务举措）

| 方面 | 任务举措 |
|---|---|
| **① 健全医疗康复护理服务体系** | 完善康复护理服务网络 / 强化医疗卫生机构康复护理功能 / 推进康复护理能力条件建设 |
| **② 加强医疗康复护理人才队伍建设** | 加大培养培训力度 / 加强人才配备使用 |
| **③ 提升医疗康复护理服务水平** | 增强服务连续性 / 推进服务标准化规范化 / 发挥中医药独特优势 / **强化数智赋能康复护理** |
| **④ 强化医疗康复护理支撑保障** | 加强创新产品研发和应用 / 壮大康复护理相关产业 / 强化医疗服务价格管理 / 完善多元支付体系 |

### 量化目标（2030年）
- 每万人口**康复医师达0.7人**、**康复治疗师达1.6人**（现状0.61人 / 1.19人）
- 每千人口**康复护理床位达0.48张左右**（现状约0.4张）
- 人口较多、老龄化程度较深、康复护理需求较大的地市，**至少设立1所公立康复医院和护理院**

### 体系定位（"强基、稳二、控三"·首次明确）
- **三级医院**：承接急危重症、疑难复杂疾病急性治疗期后患者；牵头组建区域内紧密型康复医联体
- **二级医院**：承接诊断明确、病情稳定的疾病恢复期患者；**为主体**（探索共建康复联合病房）
- **基层（社区卫生服务中心）**：承接慢性稳定期患者；**为网底**；拓展社区、居家康复护理延伸功能

### 落地机制
- **优先支持城市**：城区常住人口100万人以上的地级及以上城市
- **县域**：通过"医疗卫生强基工程"，支持县级医院康复科建设、拓展中心乡镇卫生院康复护理功能
- **实施原则**："一城一策"编制总体实施方案；统筹"硬投资"（中央投资支持）+ "软建设"（医保支付、服务价格、人才培养激励改革）

## 四、健康报两部门司长解读全文（2026-10-09）

**标题**：《以基层为重点 统筹增加医疗康复护理供给》
**来源**：健康报，记者 孙艺，2026-10-09 09:49
**原文链接**：https://www.jkb.com.cn/news/depth/2026/1009/514349.html
**受访人**：
- 国家卫生健康委规划发展与信息化司司长 **庄宁**
- 国家发展改革委社会发展司司长 **刘德春**

### 出台背景（庄宁）
- 党的二十届四中全会提出"扩大康复护理、安宁疗护服务供给"；2025年中央经济工作会议和2026年政府工作报告均提出"实施康复护理扩容提升工程"
- 康复护理服务链条长，涵盖从急性期到恢复期乃至回归家庭社会的多个环节
- 截至2025年底：可提供康复护理服务的医疗卫生机构达**2万余家**，每千人口康复护理床位约**0.4张**，每万人口康复医师约**0.61人**、康复治疗师约**1.19人**
- 四大短板：**服务供给相对不足 / 服务体系不够连贯（尚未打通三级医院→二级医院→社区、居家全流程）/ 服务水平不够高（基层薄弱）/ 保障政策不够协同**
- 定位：聚焦"**扩容、提质、均衡、连续**"

### "十五五"推进考虑（刘德春）
1. **应对人口老龄化的重要举措**：每年新增超1000万老年人
2. **公共服务系统性补缺**：残疾人约8500万、失能半失能老年人约3700万；长期照护师/养老护理员/家庭照护员**数百万人才缺口**
3. **畅通"防治康管"全链条**：我国3.87万家医院中仅约**20%设置康复科**，康复医院仅**870家**左右

### 五大创新亮点（庄宁）
1. **注重体系重构**：首次明确"健全以二级医院为主体、基层医疗卫生机构为网底、三级医院指导支持、其他医疗卫生机构共同参与的康复护理服务网络"；首次提出2030年每千人口康复护理床位0.48张
2. **注重人才为本**：办好康复大学等学科专业；支持其他专业医师经转岗培训增加注册为康复医师；薪酬总量内向康复护理人员倾斜
3. **注重中西医结合**：制定推广中医康复护理方案和技术规范；推动康复医院发挥中医康复治疗室功能
4. **注重科技赋能**：围绕神经康复、运动康复、创面修复等重点领域，加快**脑机接口、具身智能、仿生驱动**等前沿技术布局；发展"人工智能＋康复护理"服务
5. **注重政策协同**：重点考虑历史价格偏低的**治疗性康复训练**价格项目；康复护理类项目纳入医保支付；长期住院患者探索**按床日付费**

### 增强服务连续性三大举措（庄宁）
1. **构建院内全流程服务模式**：二级及以上医院明确康复护理管理部门；重点科室配备康复护理专业技能人员
2. **畅通院外全链条服务通道**：健全转诊机制；发展家庭病床、家庭医生签约提供居家康复护理；支持网约护理、上门服务；依托区域全民健康信息平台加强全程数智化应用
3. **强化与非医疗卫生机构衔接协作**：与养老、儿童福利、残疾人服务机构协作；**探索医疗卫生机构、社区、居家有效联动的康复护理模式**

### 落地见效（刘德春）
- **硬投资**：加大中央投资投入力度，**推动资源向社区和广大家庭延伸**
- **软建设**："一城一策"编制总体实施方案；鼓励在医保支付、服务价格管理、人才培养激励等方面加大改革力度
