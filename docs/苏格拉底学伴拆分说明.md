# 苏格拉底学伴 · 从往事可追忆小程序拆分说明

> 拆分日期：2026-08-01
> 决策人：sandy

## 背景
「往事可追忆」小程序本是回忆录产品，但底部「学习」Tab 里藏着一个**完全不同的产品——苏格拉底学伴**（给孩子个性化伴读/陪伴学习，帮孩子建个人学习知识库）。

两者是独立产品，不应共用一个小程序。按 sandy 决策：**拆成两个独立项目，各自发展**。

## 拆分做了什么

### 1. 新建独立小程序：`sugeladi-miniprogram/`
完整保留苏格拉底学伴全部代码，作为一个**可独立提审的小程序骨架**：
- `pages/learn/` 全部页面（learn首页、拼音闪电卡、拼音查询、数学运算律）
- 独立 `app.js` / `app.json` / `app.wxss` / `sitemap.json` / `project.config.json`
- 独立配色（紫色 #6a5acd），与回忆录的暖棕红区分开

### 2. 修改回忆录小程序：`miniprogram/app.json`
- 从 `pages` 列表移除全部 `learn` 页面
- 从底部 `tabBar` 移除「学习」Tab
- 现在回忆录是干净的 **记录 · 时光轴 · 我的** 三 Tab 结构，完全面向老人回忆录场景

## 知识库存储架构（重要设计）
| 阶段 | 存储 | 说明 |
|------|------|------|
| 当前 | 本地 `wx.getStorageSync` | 孩子自己设备上用 |
| 未来 | 后端服务器共享 | 跨设备同步、家长查看孩子知识库 |

**已预留后端扩展口**：`app.js` 里的 `CONFIG.BACKEND_SYNC` 开关 + 统一接口 `getKB()`/`setKB()`。未来接后端只需实现这两个接口、打开开关，无需改页面。

## ⚠️ 提审苏格拉底前需要做
1. 在微信公众平台注册苏格拉底自己的小程序号 → 拿到真实 **appid**
2. 把真实 appid 填进 `sugeladi-miniprogram/project.config.json`（当前是 `touristappid` 占位，可预览但无法真机发布）
3. 按真实孩子用户需求补全功能（**当前不二次开发**，等真实需求）
