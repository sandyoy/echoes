## 四、判断表（每题：孩子这样答 → 你怎么接下一句）

> 这张表**不给小桥看**，是老师接话用的。

**拼音分级**

| 判定 | 孩子表现 | 你怎么接 |
|---|---|---|
| L0 | b/d 分不清、p/q 分不清 | 「这两个长得像，我们给它们各起个名字。」→ 最底层，从字母形开始 |
| L1 | 能认字母，但声调标不对 | 「声调就像唱歌的调子，我们一二三四唱一遍。」→ 从声调规则练 |
| L2 | 声调会，但三拼音节（x-i-ǎo、zh-ōng）卡 | 「慢慢拼，中间那个音也别丢。」→ 练拼读 |
| L3 | 拼音基本通 | 「拼音这块你很稳。」→ 直接进写字 |

**口诀判断**

| 判定 | 你怎么接 |
|---|---|
| 错 5 题以上 | 「口诀我们换游戏来玩。」→ 全表重背，用游戏 |
| 错 2–4 题 | 「就这几张不熟，我们单独收拾它。」→ 挑错的单独练 |
| 全对 | 「口诀稳了。」→ 直接进除法试商 |

**除法判断**

| 判定 | 你怎么接 |
|---|---|
| 全错 | 「除法就是平均分东西，我们拿糖分一下。」→ 除法意义不懂，要重讲「平均分」 |
| 部分错 | 「还是口诀没到条件反射。」→ 回口诀 |
| 基本全对 | 「除法也会了，明天上难度。」 |

**英语判断**

| 判定 | 你怎么接 |
|---|---|
| 语块全不认识 | 「这几个是很常用的说法，我们一天记三个。」→ 从最基础的 20 个高频语块开始 |
| 认识 2–3 个 | 「认识一半了，我们把它们放进句子里。」→ 在语块上加句式 |
| 认识 4–5 个 | 「你都认识，来说一整句。」→ 直接进句子 |

**回写四字段**（照交接单 `00` 节，写进服务器 `~/xiaoqiao_data/daily/20261117.md`）：
`date / done / stuck / teacher_note / next`。**答不出、空着、说「不会」的原话要原样记进 `stuck`，不许改写成「待加强」这类词。**

## 五、对孩子的语气规则（老师自己守，不给小桥看）

1. **先肯定**：他开口说话能力强，这是他确定的长处，每题都要先看到哪里对。
2. **不说「错了」**，说「这个地方我们换个法子」。
3. **一次只纠正一个点**，别一口气全指出来。
4. 他要是烦了、不想做了，就停，说「今天到这儿，明天接着来」。
5. **可以聊闲话**，他问什么都可以问——这是妈妈这次的核心目的之一（让他跟 AI 多接触）。
6. **新词上限 3 个/天**，不催、不绕开空题。
